2. Independent plugins

An Independent Plugin is a separately developed extension that interacts
with PixivDownloader through its public SDK/API or documented extension
interfaces. Implementing those interfaces, linking to their definitions,
subclassing public extension classes, or exchanging data through those
interfaces does not, by itself, disqualify an extension.

Except for the template materials permitted in section 4, an Independent
Plugin must not copy, incorporate, translate or adapt the implementation
code of the host, SDK/API, runtime or official plugins. Moving such code
into a separate JAR, repository or process does not make it independent.
