The vendored file is the official classic-script browser build
dist/array.full.js from the npm tarball (the "array full" build that bundles
surveys and all optional extensions so no external CDN dependency is loaded
at runtime). It is committed byte-for-byte; it is never re-built or re-minified
by this project.

Update procedure (paths relative to the repository root):
  1. re-run the npm commands above for the chosen version;
  2. replace pixivdownload-plugin-posthog/src/main/resources/static/vendor/
     posthog-js/<version>/array.full.js and this directory's LICENSE,
     INTEGRITY.txt and SOURCE.txt;
  3. update SDK_VERSION in pixivdownload-plugin-posthog/src/main/resources/
     static/pixiv-posthog/pixiv-posthog.js, then update the versioned resource
     paths and SDK behavior checks in the PostHog and download-workbench tests;
  4. run the PostHog tests (including real-posthog-sdk-identity.test.js),
     the layout-feedback tests and DistributionPackagingBoundaryTest;
  5. update plugin.version in pixivdownload-plugin-posthog/src/main/resources/
     plugin.properties before publishing a new immutable plugin release.
