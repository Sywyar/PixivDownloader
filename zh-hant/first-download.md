# 第一次下載

本教程以最常見的場景爲例，帶你完成第一次下載的全過程。

## 前提

- PixivDownloader 已安裝並啓動
- 已完成[首次配置](/zh-hant/first-setup)

---

## 新手引導（首次自動）

首次以管理員身份打開下載頁（Solo 模式 / 多人模式已登錄管理員）時，會自動開始一個**跨頁面的新手引導**，一步步帶你走完從下載到瀏覽的完整流程：

1. 先問你想用的**稱呼**，並檢測後端到 Pixiv 的**網絡連通性**（顯示往返延遲，不通會提示檢查代理 / 網絡）
2. 逐區域認識下載頁的 **Cookie 區 / 油猴腳本區 / 下載方式（Tab）**，並以「批量導入單作品」爲例
3. 帶你**粘貼示例作品鏈接 → 加入隊列 → 瞭解附加篩選與下載設置 → 開始下載**，下載過程中會高亮狀態欄與下載隊列、實時顯示進度
4. 下載完成後自動跳轉**畫廊**逐區域講解（瀏覽視圖 / 搜索 / 篩選 / 作品網格），再進入**作品詳情頁**講解作品圖 / 功能區 / 簡介 / 作者 / 系列與相關

引導可隨時點「跳過」，也能通過下載頁右下角的「**操作指引**」按鈕重新查看（已設置過稱呼時會跳過稱呼這一步、直接從連通性檢測開始）。多人模式訪客不會觸發該引導。

?> 你在引導裏填寫的**稱呼**會保存下來，用於畫廊 / 小說畫廊側邊欄底部的用戶卡片，以及計劃任務通知、郵件測試等系統郵件的問候語；留空時統一以「管理員」稱呼。

下面的步驟是同一流程的手動版——無論跟着引導走還是自己操作，都能完成第一次下載。

---

## 第一步：打開下載頁面

在瀏覽器中訪問：

```
http://localhost:6999/pixiv-batch.html
```

**Solo 模式**下會彈出登錄框，輸入你在首次配置時設置的管理員賬號和密碼。

?> 如果不記得地址，打開 GUI → 狀態頁 → 點「批量下載」快捷按鈕。

---

## 第二步：獲取 Pixiv Cookie（推薦，非必須）

Cookie 是你的 Pixiv 登錄憑證，配置後可以：

- 下載 R-18 / R-18G 內容（未配置時這類作品會跳過）
- 使用「搜索下載」和「快捷獲取」功能
- 下載需要登錄才能看到的內容

**不配置 Cookie 也可以下載全年齡公開作品。** 如果你只想先試試，可以跳過這一步，之後再補配置。

### 獲取步驟

下面任選一種方式獲取 Cookie，得到的內容都能用，按自己熟悉程度選一個即可。無論哪種方式，都請先在瀏覽器中登錄 [Pixiv](https://www.pixiv.net/)。

?> 後端真正需要的只有 `PHPSESSID` 這一項（你正常登錄後 Pixiv 下發的 `PHPSESSID` 形如 `12345678_xxxxxxxx`）。帶上完整 Cookie 也可以，但只填 `PHPSESSID` 同樣能用。

#### 方式一：Cookie-Editor 擴展（最簡單）

1. 安裝 [Cookie-Editor](https://chromewebstore.google.com/detail/cookie-editor/hlkenndednhfkekhgcdicdfddnkalmdm) 瀏覽器擴展（Chrome/Edge 均可）
2. 點擊 Cookie-Editor 擴展圖標
3. 右下角點 **Export** → 選擇 **Netscape** 格式
4. 點「Copy Export」複製全部內容
5. 填入時格式選 **Netscape**

#### 方式二：開發者工具 → Application → Cookies

1. 在 Pixiv 頁面按 **F12** 打開開發者工具
2. 切到 **Application（應用）** 面板 → 左側 Storage → **Cookies** → 選中 `https://www.pixiv.net`
3. 在右側列表裏找到 **Name** 爲 `PHPSESSID` 的那一行，複製它的 **Value**
4. 拼成 `PHPSESSID=剛複製的值` 一行（例如 `PHPSESSID=12345678_xxxxxxxx`）
5. 填入時格式選 **Header String**

?> 想一次帶上更多 Cookie 時，可把列表裏多行拼成 `名字=值; 名字2=值2` 的形式，同樣用 **Header String** 格式。`PHPSESSID` 是 HttpOnly Cookie，但 Application 面板能正常顯示它的值，所以這種方式無需調整任何油猴權限。

#### 方式三：開發者工具 → Network 抓請求頭

1. 在 Pixiv 頁面按 **F12** 打開開發者工具 → 切到 **Network（網絡）** 面板
2. 刷新一下頁面，在請求列表裏點任意一條發往 `www.pixiv.net` 的請求（如頂部的 document 文檔請求或某個 ajax 請求）
3. 在 **Headers（標頭）** 裏找到 **Request Headers（請求標頭）→ `Cookie`** 這一項，複製它的完整值
4. 填入時格式選 **Header String**

?> 請求頭裏的 `Cookie` 已經是 `名字=值; 名字2=值2` 的格式，裏面就包含 `PHPSESSID`，直接整段粘貼即可。

#### 方式四：油猴「一鍵導入 Cookie」（無需手動複製）

需先安裝「**體驗增強工具箱 (Toolbox)**」油猴腳本：

1. 在 `pixiv-batch.html` 的 Cookie 卡片裏點「**一鍵導入 Cookie**」
2. 腳本會自動打開 Pixiv 頁面讀取 Cookie，並直接回傳給後端，無需手動複製粘貼、也無需選格式

!> **此方式需要油猴授予 HttpOnly Cookie 讀取權限。** Pixiv 的登錄憑證 `PHPSESSID` 是 HttpOnly Cookie，油猴腳本默認讀不到，因此一鍵導入會提示「未檢測到 PHPSESSID」而失敗。需到 **Tampermonkey（油猴）→ 設置 → 把配置模式設爲 `高級` → 安全 → 將「允許腳本訪問 Cookie」設爲 `全部 / All`** 後再使用。

!> **不建議長期保持該設置爲 `全部`**：一旦開啓，你安裝的**其它任何油猴腳本也能讀取到你的登錄憑證**，存在賬號被盜風險。除非你信任已安裝的全部腳本，否則建議**僅在使用一鍵導入時臨時設爲 `全部`，成功獲取後立即改回 `除 HttpOnly 之外的全部 / All except HttpOnly`**。若不想動這個權限，優先用上面的方式二、方式三（開發者工具）——它們同樣能拿到 HttpOnly 的 `PHPSESSID`，且無需改任何油猴權限。

### 填入 Cookie

> 以下手動粘貼步驟適用於方式一 / 二 / 三；方式四（一鍵導入）會自動回傳，無需手動填入。

1. 在 `pixiv-batch.html` 頁面找到頂部的「**Cookie**」卡片（灰色摺疊卡片），點擊展開
2. 把格式切換爲與獲取方式對應的項：方式一（Cookie-Editor 導出）選 **Netscape**；方式二、方式三（開發者工具）選 **Header String**
3. 把複製的內容粘貼進去
4. 點「**保存 Cookie**」

?> Cookie 有效期較長，通常幾個月才需要重新獲取一次。Pixiv 重新登錄或修改密碼後 Cookie 會立即失效。

## 第三步：下載一張作品

### 在 Pixiv 找到想下載的作品

在 Pixiv 上找到你想下載的作品，複製瀏覽器地址欄裏的 URL，例如：

```
https://www.pixiv.net/artworks/12345678
```

或者只複製數字 ID 部分（`12345678`）也可以。

### 粘貼並下載

1. 在 `pixiv-batch.html` 頂部切換到「**🎨 批量導入單作品**」Tab
2. 在文本框裏粘貼 URL（每行一條，可以一次粘多個）
3. 點「**獲取信息**」— 等待幾秒，會顯示作品預覽
4. 確認信息無誤後，點「**開始下載**」

---

## 第四步：查看下載進度

下載開始後，頁面下方「**下載隊列**」區域會出現任務條目：

| 狀態 | 含義 |
|------|------|
| ⏳ 等待中 | 排隊等待開始 |
| 🔄 下載中 | 正在下載文件 |
| ✅ 已完成 | 下載成功 |
| ⏩ 已存在，跳過 | 該作品之前已經下載過，無需重複 |
| ❌ 失敗 | 下載出錯，點條目可查看原因 |

---

## 第五步：找到下載的文件

下載完成後，文件保存在**程序工作目錄**下的 `pixiv-download/` 文件夾：

```
(程序目錄)/
└── pixiv-download/
    └── 123456/          ← 作品 ID 命名的子目錄
        ├── 123456_p0.jpg    ← 第 1 張圖
        ├── 123456_p1.jpg    ← 第 2 張圖（多圖作品）
        └── ...
```

**程序目錄在哪裏？**

- **Windows 安裝包**：安裝時選的目錄，默認 `C:\Users\用戶名\PixivDownload\`
- **JAR 包**：你運行 `java -jar` 命令時所在的那個文件夾
- **GUI 方式**：在 GUI → 狀態頁 → 「下載目錄」欄裏有顯示

?> 可以在 `config.yaml` 裏修改 `download.root-folder` 改變保存位置，支持絕對路徑。

---

## 第六步：在畫廊裏瀏覽

打開畫廊頁面查看所有已下載的作品（支持搜索、篩選、收藏等）：

```
http://localhost:6999/pixiv-gallery.html
```

詳細用法見[作品畫廊](/zh-hant/gallery)。

## 常見問題

### 點「獲取信息」後報錯

- **「需要 Cookie」**：該作品需要登錄才能查看，請先配置 Cookie（見第二步）
- **「代理連接失敗」**：檢查代理是否正常運行，以及 `config.yaml` 裏代理地址和端口是否正確
- **「作品不存在」**：作品可能已被作者刪除或設爲私有

### 下載完成但找不到文件

查看 `config.yaml` 裏的 `download.root-folder` 配置項，它決定文件保存位置。如果配的是相對路徑，實際位置是「程序工作目錄 + 該路徑」。

### 想批量下載更多內容

- 一次粘貼多個 URL → 見[URL 批量下載](/zh-hant/batch-download)
- 下載某位畫師的全部作品 → 見[畫師批量下載](/zh-hant/user-download)
- 按關鍵詞搜索下載 → 見[搜索下載](/zh-hant/search)
