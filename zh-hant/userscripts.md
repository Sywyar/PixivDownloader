# 油猴腳本

油猴腳本讓你在 Pixiv 網頁上直接操作——瀏覽時看到想下載的作品，點一下就加入隊列，無需切換到 PixivDownloader 頁面。

?> 油猴腳本是可選的。不安裝腳本也可以通過 `pixiv-batch.html` 完成絕大多數下載操作。

---

## 前提條件

1. 瀏覽器安裝了 [Tampermonkey](https://www.tampermonkey.net/) 擴展
2. PixivDownloader 後端正在運行
3. Solo 模式下需已登錄

---

## 腳本列表

| 腳本名稱 | 用途 |
|---------|------|
| **All-in-One 整合包** | 包含下面所有腳本（推薦安裝這一個） |
| 頁面批量下載器 (Page Scrape) | 在搜索頁、排行榜等頁面批量勾選下載 |
| User 批量下載器 (User Batch) | 在畫師主頁一鍵批量下載全部作品 |
| URL 批量導入 (URL Batch) | 在任意頁面打開面板，粘貼鏈接批量下載 |
| 單作品下載器 (Java 後端版) | 在單作品頁面一鍵下載（經後端） |
| 單作品下載器 (Local Download) | 在單作品頁面一鍵下載（瀏覽器本地，**無需 Java 後端**） |
| 體驗增強工具箱 (Toolbox) | 已下載作品加邊框標記、一鍵導入 Cookie 等 |

---

## 安裝方式

### 方式一：從 Web 管理頁安裝（推薦）

1. 啓動 PixivDownloader，打開 `http://localhost:6999/pixiv-batch.html`
2. 找到頂部「**🧩 油猴腳本**」卡片，點擊展開
3. 點對應腳本的「**⬇ 安裝**」按鈕
4. Tampermonkey 會彈出安裝確認頁，點「安裝」

?> 通過這種方式安裝時，腳本會自動將 `@connect` 配置爲當前後端地址。

### 方式二：從 Release 下載

1. 前往 [Releases](https://github.com/Sywyar/PixivDownloader/releases) 下載腳本文件（`.user.js`）
2. 將文件拖入 Tampermonkey 管理面板，點「安裝」

## 各腳本使用說明

### All-in-One 整合包（推薦）

安裝此包即可獲得所有功能。如果你已單獨安裝了部分腳本，安裝 All-in-One 後請禁用原來的獨立版，**避免雙面板衝突**。

### 頁面批量下載器 (Page Scrape)

在 Pixiv **搜索頁**、**關注動態頁**、**排行榜頁**等列表頁面生效：

- 每個作品縮略圖角落出現**複選框**
- 勾選想要的作品
- 點浮動面板上的「開始下載」

已加入下載隊列的作品會在縮略圖上顯示邊框標記。

### User 批量下載器 (User Batch)

在 Pixiv **畫師主頁**（`/users/<id>` 及其子頁面）顯示浮動面板：

- 一鍵將該畫師的**全部作品**加入下載隊列
- 支持插畫和小說分開

### URL 批量導入 (URL Batch)

在**任意 Pixiv 頁面**顯示浮動面板，功能等同於 `pixiv-batch.html` 的「批量導入單作品」Tab：
- 粘貼 URL 列表批量下載

### 單作品下載器 (Java 後端版)

在**單個作品頁面**（`/artworks/<id>`）顯示下載按鈕：
- 一鍵通過後端下載，包含元數據、自動收藏等功能

### 單作品下載器 (Local Download)

在**單個作品頁面**顯示下載按鈕：
- 直接通過瀏覽器下載，**不需要 Java 後端**
- 沒有元數據記錄，不入畫廊數據庫

### 體驗增強工具箱 (Toolbox)

在 Pixiv **任意頁面**的右側顯示工具欄（各功能可單獨開關）：

| 功能 | 說明 |
|------|------|
| **已下載作品加邊框** | 服務器數據庫裏有的作品，縮略圖上會加彩色邊框，方便區分哪些已下載 |
| **一鍵導入 Cookie** | 一鍵讀取 Pixiv Cookie 並保存到服務器（需開 Tampermonkey 特殊權限） |

### 跳過歷史下載與已刪除作品

各下載腳本的設置面板都有「**跳過歷史下載**」開關，開啓後已下載過的作品會被自動跳過。展開後還有兩個子選項：

- **實際目錄檢測**：除查歷史記錄外，還檢查文件是否真實存在於磁盤，缺失則重新下載
- **允許已刪除的作品被重新下載**：通過畫廊刪除的作品會保留[刪除標記](/zh-hant/gallery?id=刪除作品)，默認（不勾選）視爲已下載並跳過（原因顯示「已經下載過，但被刪除」）；勾選後視爲未下載並重新下載，成功後刪除標記自動清除

## 部署在非 localhost 時的額外配置

腳本默認連接 `http://localhost:6999`。如果你的後端部署在其他機器或其他端口：

1. Tampermonkey 管理面板 → 找到對應腳本 → 點「編輯」
2. 修改腳本頂部的 `@connect` 行，將 `localhost` 替換爲實際的服務器地址

通過 Web 管理頁安裝的腳本已經自動配置好了當前後端地址。

## 常見問題

### 安裝了腳本但 Pixiv 頁面上看不到任何變化

1. 確認 Tampermonkey 已啓用（瀏覽器擴展圖標顯示腳本數量）
2. Tampermonkey 管理面板裏確認腳本狀態爲「已啓用」
3. 刷新 Pixiv 頁面（腳本在頁面加載時注入）
4. 確認當前頁面與腳本的 `@match` 規則匹配（例如 User Batch 只在 `/users/` 頁面顯示）

### All-in-One 和獨立腳本同時啓用，出現兩個面板

禁用獨立版本，只保留 All-in-One，或反之。兩個版本的存儲數據是互相獨立的，建議只用一個。

### 腳本提示「後端未運行」或「連接失敗」

確認 PixivDownloader 後端服務正在運行，且腳本里配置的地址和端口正確。
