# 搜尋下載

在下載頁「Search 模式」輸入關鍵字，由後端呼叫 Pixiv 搜尋介面取得結果，篩選後加入下載佇列。此功能搜尋的是 Pixiv 線上作品，不是本地畫廊檢索。

!> Search 模式必須先儲存含 `PHPSESSID` 的有效 Pixiv Cookie；尚未設定時，搜尋按鈕無法使用。

## 操作步驟

1. 開啟 `http://localhost:6999/pixiv-batch.html`，切換到「Search 模式」。
2. 輸入搜尋關鍵字（中文、日文、英文皆可）。
3. 選擇子模式、排序方式與內容分級，點擊「搜尋」。
4. 在預覽網格中勾選作品並點擊「選取項目加入佇列」，或點擊「目前頁面全部加入佇列」。
5. 點擊「開始下載」，在佇列核對下載結果。

## 搜尋範圍、排序與篩選

| 子模式 | 取得範圍 |
| --- | --- |
| 搜尋模式 | 僅取得第 1 頁結果，適合快速確認關鍵字 |
| 作品批次取得模式 | 取得至指定結束頁（預設 3 頁）；結束頁設為 `-1` 時會向後翻頁取得全部結果（翻頁間隔約 10 秒，最多 1,000 頁） |

| 排序方式 | 說明 |
| --- | --- |
| 最新 (`date_d`) | 依發布時間倒序排列，所有登入帳號皆可使用 |
| 熱門 (`popular_d`) | 依熱門程度排序，需 Pixiv Premium 會員權限；無權限時請改用「最新」，勿將傳回結果視為完整熱門榜 |

內容分級可選「全年齡」「R-18」「R-18G」或「全部」（需 Pixiv 帳號開啟對應年齡設定）。結果載入後，可透過「附加篩選」依排除 AI、最低收藏數、標籤與頁數範圍即時篩選預覽頁。

## 結果核對與排程工作

建議先用單一關鍵字和較少頁數驗證結果，再擴大頁數範圍。搜尋結果為空時，檢查關鍵字、分級、帳號權限和附加篩選；搜尋發生錯誤時，檢查 Cookie 是否過期及後端代理連線。佇列中的篩選略過不代表搜尋請求失敗。

需要將目前搜尋儲存為定時任務時，在頁面底部「儲存為排程工作」卡片設定觸發頻率即可。「最新排序 + 結束頁 `-1`」的任務支援依進度水位增量擷取，其餘組合與上限規則見[排程工作](/zh-hant/scheduled-tasks)。
