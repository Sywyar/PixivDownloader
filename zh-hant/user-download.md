# 畫師批量下載

在「User 模式」輸入畫師首頁連結或 ID，可預覽該畫師的插畫、漫畫、動圖、小說或已公開的約稿成品，再下載全部或選定作品。下載範圍仍受帳號存取權限、附加篩選及已下載檢查限制。

---

## 使用步驟

1. 打開 `http://localhost:6999/pixiv-batch.html`
2. 開啟「User 模式」
3. 粘貼畫師主頁鏈接或數字 ID
4. 選擇下載範圍（圖片類、小說或約稿）；小說需要啟用 `novel` 外掛
5. 點「**解析並預覽**」
6. 配置附加篩選（可選）
7. 點「**全部入隊**」或手動選擇部分作品入隊
8. 開始下載；完成後檢查佇列中的成功、略過和失敗結果

---

## 支持的鏈接格式

直接粘貼以下任意格式，系統會自動提取數字 ID：

```
https://www.pixiv.net/users/123456
https://www.pixiv.net/users/123456/artworks
https://www.pixiv.net/users/123456/illustrations
https://www.pixiv.net/users/123456/novels
https://www.pixiv.net/users/123456/request/artworks   ← 約稿頁鏈接（自動切到「約稿」範圍）
https://www.pixiv.net/en/users/123456
123456                                       ← 只填數字 ID 也可以
```

---

## 下載範圍切換

| 範圍 | 包含內容 |
|------|---------|
| **插畫 + 漫畫 + 動圖** | 該畫師所有圖片類作品 |
| **小說** | 該畫師所有小說 |
| **約稿** | 該畫師**已完成並公開的約稿（リクエスト）成品**——約稿成品本質是普通插畫，按插畫的預覽 / 入隊 / 下載 / 判重鏈路處理 |

預覽區**一次只能獲取一種類型**——切換後舊預覽結果會清空。但下載隊列不受影響，可以先把插畫加入隊列，再切換到小說獲取一次、再入隊，最後一併下載。

> 直接粘貼約稿頁鏈接（`https://www.pixiv.net/users/{id}/request/artworks`）時會**自動切到「約稿」範圍**，無需手動選擇。

---

## 附加篩選

展開「附加篩選」卡片可以縮小範圍，例如：
- 只下載該畫師的 R-18 作品
- 排除 AI 生成作品
- 只下載收藏數 100 以上的作品

篩選不僅在預覽時生效，**實際下載時也會對每個作品逐個過濾**，不符合的自動跳過。

---

## 存爲計劃任務

如果你想**定期自動補充**該畫師的新作品，可以把當前配置保存爲計劃任務：

向下滾動到「⏰ 存爲計劃任務」卡片 → 填任務名 → 設觸發頻率 → 點「創建任務」。

建立任務後，後端保持執行時會依排程尋找並下載新作。需要登入的內容必須為任務綁定有效 Cookie；帳號失效或存取失敗時，請查看任務狀態並處理。

詳見[計劃任務](/zh-hant/scheduled-tasks)。

---

## 未取得預期作品

先檢查 ID 是否來自畫師首頁，而非單一作品網址；再檢查目前的圖片／小說／約稿範圍、篩選條件和 Cookie。切換範圍會清除預覽，但不清除已加入的佇列。無法存取或已刪除的作品，不會因選擇「全部入隊」而變得可下載。

## 數據量提示

一位畫師可能有幾百甚至幾千張作品，首次下載可能需要較長時間。可以：
- 用附加篩選縮小範圍
- 調低「最大併發數」減輕對 Pixiv 服務器的壓力
- 設置「作品間隔」（毫秒），在作品之間等待一段時間
