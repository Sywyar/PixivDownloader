# 畫師批次下載

在下載頁「User 模式」輸入畫師首頁連結或數字 ID，可預覽該畫師的插畫、漫畫、動圖、小說或已公開約稿成品，並選擇全部或部分作品下載。實際可取得範圍受目前帳號權限、附加篩選和已下載偵測限制。

## 操作步驟

1. 開啟 `http://localhost:6999/pixiv-batch.html`，切換到「User 模式」。
2. 貼上畫師首頁連結或純數字使用者 ID。
3. 選擇下載範圍（插畫 + 漫畫 + 動圖、小說或約稿作品；小說需啟用 `novel` 外掛）。
4. 點擊「解析並預覽」，依需求設定附加篩選。
5. 點擊「全部加入佇列」或勾選部分作品加入佇列，再點擊「開始下載」。
6. 下載完成後，在佇列檢查成功、略過和失敗紀錄。

支援以下輸入格式（`123456` 僅為範例，請替換為實際畫師 ID）：

```text
https://www.pixiv.net/users/123456
https://www.pixiv.net/users/123456/artworks
https://www.pixiv.net/users/123456/illustrations
https://www.pixiv.net/users/123456/novels
https://www.pixiv.net/users/123456/request/artworks
https://www.pixiv.net/en/users/123456
123456
```

## 下載範圍與附加篩選

| 範圍 | 包含內容 |
| --- | --- |
| 插畫 + 漫畫 + 動圖 | 該畫師投稿的圖片類作品 |
| 小說 | 該畫師投稿的小說作品 |
| 約稿作品 | 該畫師已完成並公開的約稿（リクエスト）成品，依一般插畫流程預覽、加入佇列、下載與重複判定 |

貼上約稿頁連結（`/users/{id}/request/artworks`）時會自動切換到「約稿」範圍。預覽區每次顯示一種範圍，切換範圍會清空目前的預覽清單，但不會清空已加入的下載佇列；可先將插畫加入佇列，再切換到小說並加入佇列，最後一併下載。

「附加篩選」可依內容分級、排除 AI、最低收藏數、標籤或頁數篩選，在預覽和實際下載時均逐件生效。畫師作品數量較多時，建議搭配附加篩選、降低「最大並行數」並設定「作品間隔」（毫秒），減少觸發上游限制的風險。

## 儲存為排程工作

在頁面底部「儲存為排程工作」卡片填寫任務名稱與觸發方式，可定期自動探索並下載該畫師的新作。需登入才能存取的內容，必須為任務綁定有效 Cookie；設定與進度水位增量規則見[排程工作](/zh-hant/scheduled-tasks)。

## 未取得預期作品

先確認輸入的是畫師使用者 ID，而非單件作品 ID，再核對所選範圍（圖片 / 小說 / 約稿）、附加篩選及 Cookie 登入狀態。已刪除或無權存取的作品，不會因點擊「全部加入佇列」而變為可下載。
