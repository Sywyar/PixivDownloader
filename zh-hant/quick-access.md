# 快速取得

在下載頁的「快速取得」中，使用已儲存的 Pixiv Cookie 取得目前帳號的收藏、投稿、約稿作品、關注清單、關注新作和珍藏集。先載入預覽，再將作品加入佇列並開始下載；取得清單本身不會儲存檔案。

!> 快速取得必須先儲存含有效 `PHPSESSID` 的 Cookie；尚未儲存時，各入口按鈕會維持停用。

## 支援的資料來源與操作步驟

| 資料來源 | 取得範圍 |
| --- | --- |
| 我的收藏 | 插畫 / 漫畫與小說，支援公開與不公開收藏 |
| 我的作品 | 目前帳號投稿的插畫 / 漫畫與小說，含不公開作品 |
| 我的約稿作品 | 目前帳號已完成並公開的約稿（リクエスト）成品，依插畫流程處理 |
| 我的關注 | 已關注的畫師清單（含不公開關注），支援依使用者名稱或 ID 即時篩選 |
| 已關注使用者的新作 | 關注畫師的最新插畫 / 漫畫 / 動圖（フォロー新着作品），支援分頁瀏覽 |
| 我的珍藏集 | Pixiv 珍藏集（コレクション）中的插畫與小說混合清單 |

1. 開啟 `http://localhost:6999/pixiv-batch.html`，切換到「快速取得」。
2. 點擊目標資料來源按鈕，等待下方顯示作品清單。
3. 在「我的關注」或「我的珍藏集」中，點擊特定畫師或珍藏集以展開作品預覽（關注畫師可切換插畫 / 小說）。
4. 選擇單件加入佇列、「將目前頁加入佇列」或「全部加入佇列」，再點擊「開始下載」。

## 附加篩選

展開特定作品清單後，可透過「附加篩選」依內容分級、AI 作品、標籤、作品類型、頁數、字數和最低收藏數，即時篩選目前的預覽頁：

- **將目前頁加入佇列**：僅將目前頁面篩選後可見的作品加入佇列。
- **全部加入佇列**：將來源內的全部作品加入佇列，下載時逐件依篩選條件判定；不符合條件的作品會在佇列中標示略過原因。

停留在關注畫師清單或珍藏集清單時，需先點進特定畫師或珍藏集才能使用篩選與加入佇列功能。

## 儲存為排程工作（管理員）

展開任一特定來源（收藏、我的作品、我的約稿作品、已關注使用者的新作，或點進某位關注畫師、某個珍藏集）後，可在頁面底部「儲存為排程工作」卡片填寫名稱和觸發方式，將其儲存為背景自動下載任務。

?> 收藏、關注新作和珍藏集屬於帳號私人來源，任務必須綁定有效 Cookie（單人模式新增時會自動綁定目前的 Cookie）。建立後來源類型為唯讀，更換來源需刪除任務後重新建立；詳見[排程工作](/zh-hant/scheduled-tasks)。

## 結果核對與疑難排解

下載結束後，在佇列中分別核對完成、略過和失敗項目，再到畫廊確認作品。若預覽清單為空，先檢查所選帳號、公開 / 不公開範圍與附加篩選條件；按鈕停用或出現驗證錯誤時，重新儲存有效 Cookie；發生網路錯誤時檢查後端代理連線，不要將空清單直接視為已同步完成。

指定連結下載見 [URL 批次下載](/zh-hant/batch-download)，依畫師 ID 下載見[畫師批次下載](/zh-hant/user-download)，依關鍵字搜尋見[搜尋下載](/zh-hant/search)。
