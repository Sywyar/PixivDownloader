# 快捷獲取

「快捷獲取」是 `pixiv-batch.html` 打開後默認顯示的第一個 Tab，憑你已保存的 Pixiv Cookie 自動識別賬號，一鍵拉取個人相關數據加入下載隊列。

?> 此功能需要先保存含 `PHPSESSID` 的 Cookie。未保存時按鈕顯示爲禁用狀態並有提示。

---

## 可獲取的數據

| 數據源 | 說明 |
|--------|------|
| **我的收藏** | 插畫/漫畫 + 小說，含「不公開」收藏 |
| **我的作品** | 你自己投稿的插畫/漫畫 + 小說，含「不公開」 |
| **我的約稿作品** | 你自己已完成並公開的約稿（リクエスト）成品（按插畫處理） |
| **我的關注** | 所有已關注的畫師列表，含「不公開關注」；支持按用戶名/ID 實時過濾 |
| **已關注的用戶的新作** | 你關注的所有畫師的最新插畫/漫畫/動圖（Pixiv「フォロー新着作品」），可按頁翻閱 |
| **我的珍藏集** | Pixiv 珍藏集（コレクション）中的作品 |

---

## 使用步驟

1. 打開 `http://localhost:6999/pixiv-batch.html`
2. 確認默認停留在「**⚡ 快捷獲取**」Tab
3. 點擊對應按鈕（「我的收藏」「我的作品」等）
4. 等待數據加載完成，作品列表展示在下方
5. 點「**全部入隊**」或勾選單個作品後「**選中入隊**」
6. 隊列出現後點「**開始下載**」

---

## 關注列表的二層展開

點擊關注列表中的某位畫師，會在下方展開其作品預覽（插畫/小說可切換）。

可以：
- 點單張圖片旁的「入隊」加入單個作品
- 點「整頁入隊」把當前頁所有作品都加入
- 翻頁後繼續入隊

---

## 珍藏集

點擊某個珍藏集，展開其中的插畫+小說混合列表，操作方式與關注列表相同。

---

## 附加篩選（實時預覽過濾）

展開任意作品列表後，上方的「**附加篩選**」卡片可按內容分級 / AI / 標籤 / 作品類型 / 頁數 / 字數 / 收藏數實時過濾當前預覽頁：

- 「整頁入隊」加入的是**過濾後**的作品；
- 「全部入隊」仍會入隊全部，不符合條件的會在實際下載時被逐個跳過並標註原因。

未展開具體作品列表（如停留在關注列表 / 珍藏集列表選擇頁）時，卡片會提示先展開具體作品列表。

---

## 存爲計劃任務（管理員）

快捷獲取裏的**每一種來源**都能存爲後臺自動下載的[計劃任務](/zh-hant/scheduled-tasks)：

| 來源 | 計劃任務效果 |
|------|------|
| 我的收藏（插畫/小說 × 公開/不公開） | 定期把新增收藏下載下來 |
| 我的作品 | 定期下載你自己的新投稿 |
| 我的約稿作品 | 定期下載你自己新完成的約稿成品 |
| 已關注的用戶的新作 | 定期下載關注畫師的新作（フォロー新着） |
| 點進某位關注畫師 | 定期下載該畫師新作 |
| 點進某個珍藏集 | 定期下載珍藏集內新增的插畫與小說 |

展開來源後，頁面底部的「**⏰ 存爲計劃任務**」卡片會顯示來源說明，填好名稱與觸發方式即可創建；未展開來源時會提示需先展開。

?> 收藏 / 關注新作 / 珍藏集屬於賬號私有內容，對應任務必須已授權含 `PHPSESSID` 的 Cookie 才能運行（Solo 模式新建時會自動綁定）。編輯這幾類任務時來源爲只讀，更換來源請刪除後重新創建。
