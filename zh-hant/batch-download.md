# URL 批次下載

已有一批作品連結或 ID 時，可在下載頁「批次匯入單一作品」一次貼上並下載。支援插畫、漫畫、動圖與小說混合輸入；下載小說需啟用 `novel` 外掛，下載受限作品需儲存含 `PHPSESSID` 的 Pixiv Cookie。

## 操作步驟

1. 開啟 `http://localhost:6999/pixiv-batch.html`，切換到「批次匯入單一作品」。
2. 在文字方塊貼上 URL 或 ID 清單（每行一筆），點擊「取得資訊」。
3. 核對辨識出的作品類型與數量。
4. 依需求設定附加篩選與下載設定，將作品加入佇列並點擊「開始下載」。
5. 下載結束後，在佇列檢查結果（完成、已存在而略過、篩選略過與失敗會分別統計）。

## 輸入格式

每行填寫一筆紀錄，以下作品 ID 僅為格式範例，使用時請替換為實際作品：

```text
# 完整 URL
https://www.pixiv.net/artworks/12345678
https://www.pixiv.net/novel/show.php?id=87654321

# 純數字 ID（預設依插畫處理，可選擇附帶標題）
12345678
12345679 | 作品標題

# 區段標頭：指定後續純數字 ID 的作品類型
artwork:
11111
22222
novel:
33333
44444 | 小說標題

# OneTab / N-Tab 匯出格式
https://www.pixiv.net/artworks/55555 | 分頁標題
```

- `artwork:` 與 `novel:` 單獨成行（不區分大小寫，半形 / 全形冒號皆可），將後續純數字 ID（或 `id | title`）依對應類型解析，直到遇到下一個區段標頭或輸入結尾。
- 以 `https://` 開頭的完整連結始終依連結本身的類型解析，不受區段標頭影響。
- 可直接貼上 OneTab / N-Tab 匯出的 `URL | 標題` 清單，非 Pixiv 作品連結會自動略過。

## 附加篩選與下載設定

「附加篩選」支援依內容分級（全部 / 全年齡 / R18+ / R-18 / R-18G）、AI 作品（全部 / 排除 AI / 僅 AI）、標籤（逗號分隔，精確或模糊比對且需全部符合）、最低收藏數、插畫頁數、小說字數與作品類型（插畫 / 漫畫 / 動圖）篩選。下載時逐件判定，不符合條件的作品會在佇列中顯示具體略過原因。

| 下載設定 | 作用 |
| --- | --- |
| 檔名範本 | 使用 `{artwork_id}`、`{author_name}`、`{page}` 等變數，詳見[檔名範本變數](/zh-hant/usage-guide#檔名範本變數) |
| 下載目錄（收藏夾） | 指定要儲存到的本地收藏夾 |
| 略過已下載作品 | 符合下載歷史紀錄時直接略過 |
| 實際目錄檢查 | 除查詢歷史紀錄外，同時檢查磁碟檔案是否存在；缺少時重新下載 |
| 允許重新下載已刪除的作品 | 畫廊刪除的作品帶有[刪除標記](/zh-hant/gallery#刪除作品)，預設略過；勾選後重新下載並清除刪除標記 |
| 自動收藏 | 下載完成後呼叫 Pixiv API 收藏作品（需有效 Cookie） |
| 小說格式 | 選擇儲存為 TXT、HTML 或 EPUB |

## 疑難排解與相關入口

- **純數字小說 ID 被當成插畫**：改用完整小說連結，或在數字 ID 上方單獨新增一行 `novel:`。
- **辨識數量少於輸入行數**：檢查空行、區段標頭、非 Pixiv 連結或格式錯誤的 URL，以預覽清單為準。
- **作品被略過或下載失敗**：查看佇列項目的具體原因；在 Pixiv 原站確認作品可存取，並核對 Cookie 與代理設定（參閱[常見問題](/zh-hant/faq)）。

下載指定畫師作品見[畫師批次下載](/zh-hant/user-download)，依關鍵字查找見[搜尋下載](/zh-hant/search)，定時自動下載見[排程工作](/zh-hant/scheduled-tasks)。
