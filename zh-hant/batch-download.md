# URL 批量下載

「批量導入單作品」Tab 是最靈活的下載方式：粘貼一批作品 URL 或 ID，一次性批量下載，支持插畫和小說混合。

---

## 快速上手

1. 打開 `http://localhost:6999/pixiv-batch.html`
2. 切換到「**🎨 批量導入單作品**」Tab
3. 在文本框裏粘貼 URL 列表
4. 點「**獲取信息**」
5. 預覽確認後點「**開始下載**」

---

## 輸入格式說明

文本框每行一條，支持多種格式混合：

```
# 完整 URL（最常用）
https://www.pixiv.net/artworks/12345678
https://www.pixiv.net/novel/show.php?id=87654321

# 只填數字 ID（默認當插畫處理）
12345678
12345679 | 作品標題（標題可選，留空自動獲取）

# 區段頭：指定後續 ID 的類型
artwork:
11111
22222
novel:
33333
44444 | 這是小說標題

# 兼容 OneTab、N-Tab 導出格式
https://www.pixiv.net/artworks/55555 | Tab 標題
```

### 區段頭說明

`artwork:` 和 `novel:` 單獨成行，大小寫不限，全角/半角冒號均可。

放在區段頭下方的**純數字 ID**（`id | title` 格式）會按該類型解析，直到遇到下一個區段頭或文本末尾。

完整鏈接（以 `https://` 開頭）**始終按鏈接本身的類型**解析，不受區段頭影響。

## 附加篩選

展開「**附加篩選**」卡片，可以在下載前對隊列中的作品進行過濾：

| 篩選項 | 說明 |
|--------|------|
| **內容分級** | 全部 / 全年齡 / R18+ / R-18 / R-18G |
| **AI 作品** | 全部 / 排除 AI / 僅 AI |
| **標籤** | 精確匹配 / 模糊匹配（逗號分隔，需全部命中） |
| **收藏數** | 最少多少收藏才下載 |
| **頁數** | 插畫頁數範圍 |
| **字數** | 小說字數範圍 |
| **作品類型** | 插畫 / 漫畫 / 動圖 |

篩選在**實際下載時**對每個作品逐個執行，不符合條件的作品會在隊列中顯示跳過原因（如「內容分級不符」「標籤不匹配」）。

---

## 下載設置

展開「**下載設置**」卡片，可調整：

- **文件名模板**：支持 `{artwork_id}`、`{author_name}`、`{page}` 等變量，詳見[配置參考](/zh-hant/configuration)
- **下載目錄**（收藏夾）：下載到哪個本地收藏夾
- **跳過已下載作品**：隊列處理時檢查下載歷史，已下載的作品直接跳過。勾選後可進一步展開：
  - **實際目錄檢測**：除了查歷史記錄，還會檢查文件是否真實存在於磁盤，文件缺失會重新下載
  - **允許已刪除的作品被重新下載**：通過畫廊刪除的作品會保留[刪除標記](/zh-hant/gallery?id=刪除作品)，默認視爲已下載並跳過（原因顯示「已經下載過，但被刪除」）；勾選後視爲未下載並重新下載，成功後刪除標記自動清除
- **自動收藏**：下載完成後自動通過 Pixiv API 收藏該作品（需要 Cookie）
- **小說格式**：TXT / HTML / EPUB

---

## 兼容 OneTab / N-Tab 導出

從 OneTab 或 N-Tab 瀏覽器擴展導出標籤頁列表後，可以直接粘貼進來，格式爲 `URL | 標題`，PixivDownloader 會自動解析。

不是 Pixiv 作品鏈接的行（如其他網站）會被自動跳過。
