# 小說下載

要保存單篇小說或整套系列，先確認 `novel` 插件已啓用，再在下載頁面選擇小說來源和 TXT / HTML / EPUB 格式。本文也說明本地閱讀、合訂本、翻譯和朗讀；翻譯需設定翻譯外掛，AI 多角色朗讀需分別設定 AI / TTS 外掛。

以下地址中的 ID 僅示範格式，請替換爲你有權訪問的實際小說或系列 ID。

---

## 下載單本小說

### 方式一：URL 批量導入

1. 打開 `pixiv-batch.html` → 選擇「**🎨 批量導入單作品**」模式
2. 粘貼小說鏈接：
   ```
   https://www.pixiv.net/novel/show.php?id=12345678
   ```
3. 或粘貼純 ID，前面加 `novel:` 區段頭：
   ```
   novel:
   12345678
   ```
4. 選擇格式（TXT / HTML / EPUB）
5. 開始下載

### 方式二：快捷獲取（你自己的小說/收藏）

打開「**⚡ 快捷獲取**」模式 → 點「我的收藏（小說）」或「我的作品（小說）」，直接入隊。

---

## 下載小說系列

1. 打開 `pixiv-batch.html` → 選擇「**📚 系列模式**」
2. 粘貼系列鏈接：
   ```
   https://www.pixiv.net/novel/series/123456
   ```
3. 點「**解析並預覽**」，顯示系列所有章節
4. 選擇「**全部入隊**」或部分章節入隊
5. 開始下載

### 生成系列合訂本（EPUB）

系列下載時可同時生成 EPUB 合訂本：

- 展開下載設置，勾選「**生成系列合訂本**」，選擇合訂格式（推薦 EPUB）
- 合訂本文件保存在 `novel-series-{seriesId}/` 目錄下，文件名格式爲 `{系列標題}.epub`（AI 譯文合訂本爲 `{系列標題}_{語言代碼}.epub`）

EPUB 合訂本特性：
- EPUB3 規範，支持多級目錄（系列 → 章節）
- 內嵌系列封面圖片
- 攜帶書籍元數據（簡介、標籤、來源鏈接）

?> 需要章節目錄和封面時選擇 EPUB；只需要正文時可選 TXT。

### 在系列目錄頁隨時下載合訂本

進入小說系列目錄頁（`pixiv-series.html?type=novel&seriesId=...`），操作區提供「**下載合訂本**」按鈕：

- 點擊後彈窗讓你選擇語言：**原文**，或該系列已有的任一譯文語言；
- 選擇非原文語言時彈窗會提示：合訂本只會用所選語言替換**已翻譯**的章節，**未翻譯章節回退原文**；若希望整本完全使用所選語言，請先點擊「翻譯整個系列」翻譯完所有章節後再下載；
- 確認後後端按當前數據庫狀態即時生成最新的 EPUB 合訂本並觸發瀏覽器下載，無需事先勾選「生成系列合訂本」。

## 格式說明

| 格式 | 特點 |
|------|------|
| **TXT** | 純文本，兼容性最好，無格式 |
| **HTML** | 保留原始排版（Ruby 注音、標題等），可在瀏覽器直接打開 |
| **EPUB** | 適合電子書閱讀器（Kindle、Apple Books 等），支持目錄和封面 |

## 本地閱讀

下載完成後，可以在小說畫廊瀏覽：

```
http://localhost:6999/pixiv-novel-gallery.html
```

畫廊支持按標題、作者、系列、標籤搜索，還支持**正文全文檢索**（搜索已保存小說正文中的文字）。

### 在線閱讀

點擊小說縮略圖進入 `pixiv-novel.html?id=<id>`：
- 查看正文、標籤、作者、系列章節導航
- 上一章/下一章快速跳轉

## 聽書（TTS 朗讀）

在小說閱讀頁點擊「**🎧 聽書**」按鈕，逐段朗讀正文。

兩種語音引擎：

| 引擎 | 特點 |
|------|------|
| **瀏覽器引擎**（默認） | 使用瀏覽器提供的語音；可用聲音及是否需要聯網取決於瀏覽器和系統語音服務 |
| **在線引擎（Edge 神經語音）** | 微軟在線 TTS，音質自然，語言豐富；需聯網（經後端代理） |

播放控制：
- 播放/暫停、上一段/下一段、停止
- 當前朗讀段高亮並自動滾動
- 進度條可跳轉到任意位置
- 支持選擇語音和調整語速

朗讀進度會自動保存，下次打開同一本小說可以從上次繼續。

## AI 多角色朗讀（管理員）

先在 AI 模型設置中檢查文本模型與 TTS 引擎是否可用。分析失敗時檢查模型響應；合成失敗時檢查所選引擎及參考音配置。

在小說閱讀頁點「**🎭 多角色朗讀**」，由大模型把整章逐句歸屬到說話人（旁白 / 各角色），每個角色用一段固定的音色畫像，逐句合成並連續播放——區別於上面的單一嗓音「聽書」。需要配置大模型與朗讀引擎，二者分別在 GUI「AI 模型」配置頁的「文本模型」（大語言模型，OpenAI 兼容）與「TTS 模型」（朗讀引擎：可自行啓動 VoxCPM 等本地服務，也可選用多家雲端 TTS，無需自備 GPU）模態下配置並啓用。**兩者任一未配置時，「聽書」裏不會出現「富感情朗讀（多角色）」這個引擎選項。**

- **逐句播放 + 跟隨**：按句合成、順序播放並預取下一句；當前句所在**段落高亮並自動滾動**，朗讀條上顯示「說話人：當前句」字幕。
- **旁白音色**：首次分析前的設置彈窗裏可爲本作旁白選定一種音色基調（溫暖女聲 / 沉穩男聲 / 中性，可試聽）；確認後該旁白音色會被**鎖定**、AI 之後不再改寫，避免旁白音色逐章漂移。不選（保持當前）則沿用本作現有 / 默認旁白（默認爲溫暖女聲）。
- **選角與音色**：點朗讀條上的「🎭」打開面板，查看每個角色的性別 / 年齡 / 英文音色畫像；可**編輯某角色音色並保存**（保存後即標記爲「已鎖定」，AI 之後不再覆蓋），也可單獨試聽。編輯音色對**後續合成立即生效**，無需重新分析。
- **角色參考音克隆**：在面板裏可爲任意角色（含旁白）**一鍵生成一段「標準音」**或**上傳真人蔘考音**（wav/mp3，可附轉錄）。配了參考音後，該角色的逐句朗讀會**克隆這段參考音的音色**——音色跨句 / 跨章更穩定一致，同時仍保留每句的情緒起伏；參考音可試聽、刪除，變更後已緩存的逐句音頻會自動按新音色重算。可在配置裏關閉克隆或調整克隆生成上限。
- **音色衝突**：當正文證據與某個你鎖定的角色音色明顯矛盾 / 不完整時，會在面板裏列出衝突，可選擇「採納建議 / 保留當前 / 改寫」。
- **分段字數**：與「AI 翻譯」同義——`0`（默認）表示整章一次性分析（整章共享一次請求的上下文）；填數字則按段落累積到約該字數分多批分析（控制單次請求的文本量）。
- 分析結果（逐句歸屬）會**緩存**，重播不重算；需要重新分析時在設置裏點「重新分析」。超長正文會拒絕一次性分析並提示縮小範圍。

## 翻譯引擎（管理員）

安裝並啟用 `translation` 外掛，在桌面設定的「翻譯」頁選擇引擎，儲存後依提示重新啟動後端。小說與翻譯共用的 `novel-translation-contract` 會隨相依外掛安裝。手動翻譯與下載後自動翻譯都使用此處選定的引擎。

- AI 使用 `ai` 中已儲存的模型、基礎網址與憑證。本機大型語言模型只要提供 OpenAI 相容介面，即可沿用現有設定。
- 有道需要有道智雲文字翻譯 API 的應用 ID 與應用金鑰；有道詞典的登入資訊不能代替這些憑證。
- LibreTranslate 使用自行部署的服務基礎網址，必要時填寫 API Key。離線使用前須自行安裝服務與語言模型，確認所需語言可用。外掛不下載模型或啟動服務。

小說頁的「翻譯」與系列頁的「翻譯整個系列」使用同一引擎，可選正文、標題、簡介，以及覆寫或略過現有譯文。譯文仍與原文一起儲存在小說資料庫；內容語言切換、譯文合訂與朗讀繼續使用這些結果。

有道與 LibreTranslate 接受 `en`、`ja`、`zh-CN` 等目標語言代碼，實際支援語言由服務決定。請求依段落及每次最多 1,000 個 Unicode 碼點分批；分段字數 `0` 使用此上限，正數則取指定值與上限的較小值。圖片、分頁、跳轉等 Pixiv 標記會保留。它們不使用或自動學習 AI 名詞映射表，標題與正文分別翻譯。下文的提示詞、自由輸入語言名稱及名詞映射表說明僅適用於 AI 引擎。

AI 憑證仍由 `ai` 管理，有道與 LibreTranslate 憑證由 `translation` 管理，語音憑證仍由 `tts` 管理。一般朗讀不依賴翻譯外掛；多角色分析繼續使用 AI，語音合成使用 TTS。

## AI 翻譯（管理員）

在小說閱讀頁「聽書」按鈕左側點「**翻譯**」，把正文翻譯成指定語言並保存到本地，之後直接查看、無需重複翻譯。

> 需先在 GUI「AI 模型」配置頁的「文本模型」模態中配置並啓用大語言模型（OpenAI 兼容協議）。**未配置時小說 / 系列詳情頁不會顯示「翻譯」按鈕。**

翻譯彈窗：

- **目標語言**：默認按當前界面語言預填（中文界面填「簡體中文」、英文界面填「english」），可自由修改填寫任意語言；AI 會判斷該語言是否真實存在，不存在會提示。
- **分段字數**：`0` 表示整篇一次性翻譯；填一個數字（如 `5000`）則把長文按段落累積到約該字數切成多段、逐段翻譯再拼接，適合超長篇。
- **已翻譯過該語言時**：可選擇「覆蓋重譯」或「跳過」。

確認開始翻譯後會彈出進度彈窗：實時顯示當前用時計時，底部提供「隱藏」和「取消」按鈕。「隱藏」只關閉彈窗、後臺繼續翻譯，翻譯進行中再次點擊「翻譯」按鈕會重新彈出當前進度；「取消」會中斷當前請求並丟棄前端結果（後端可能仍寫入數據庫，無法攔截）。本章翻譯成功後，如果該小說屬於某個系列，會自動重生該語言變體的系列合訂本，與下文「翻譯整個系列」入口保持一致。

### 名詞映射表（複用專有名詞譯法）

爲避免人名、地名、組織名等專有名詞在不同段落 / 章節裏被翻譯成不同寫法，翻譯彈窗提供「**名詞映射表**」選項（在「已翻譯過該語言時」下方）。

- 一張映射表裏是一組「**原文 → 各語言譯名**」的對應關係。默認會帶出該作品的映射表：**系列裏的小說共用同一張表**（默認名爲系列名），**單獨的小說各用一張表**（默認名爲小說名）；你也可以選「不使用」、選用其它已有的表，或「＋ 新建映射表」。
- 選中映射表後，表裏的譯名會隨翻譯請求一併發給 AI，供它沿用既定寫法。請檢查譯文，模型仍可能偏離映射。
- AI 在翻譯中遇到表裏還沒有的新專有名詞時，會把譯名回報回來並**自動併入所選映射表**，供後續段落、後續章節以及以後重譯複用。
- 點選項旁的「**編輯**」會依次打開三層彈窗：先改表名、選擇或添加目標語言，再對所選語言用「**原文 ↔ 譯名**」成對輸入框逐條增刪映射。

?> 整個系列一起翻譯時各章共用同一張映射表，新發現的譯名會實時累積到後續章節，便於複用全系列的譯名。

### 切換內容語言

小說閱讀頁與系列目錄頁提供「**內容語言**」下拉，可在原文與已有的各譯文語言之間切換查看正文。該切換**獨立於界面語言**（只改正文顯示、不改界面），並會被記住；「聽書」也會朗讀當前所選語言的譯文。

切換到某種譯文語言時，標題也會自動換成譯後標題：

- 小說詳情頁：小說標題切換爲譯後小說標題；
- 系列目錄頁：頂部系列名 + 各章節卡片的標題都切換爲譯後標題；
- 語言變體合訂本（EPUB）：系列名 + 各章節標題也使用譯後版本。

某章節 / 系列名尚未翻譯時回退到原文標題。

**標題翻譯的上下文策略：**

- 章節標題與該章節正文在**同一次 AI 請求**裏翻譯（共享上下文 + 同一張名詞映射表），爲標題中的人名 / 地名 / 設定術語提供與正文相同的翻譯依據。
- 系列名的翻譯是獨立請求（沒有"正文"可附），但請求裏會帶上：該系列在同語言下**已翻譯完成的章節標題對**（原標題 → 譯後標題）作爲命名 / 風格樣例，以及當前選用的名詞映射表，讓系列名跟章節標題的術語用法保持一致。

### 翻譯整個系列

在系列目錄頁點「**翻譯整個系列**」，以章節爲單位逐章翻譯爲指定語言（彈窗與單篇一致，可選跳過已翻譯章節）。完成後會爲該語言生成獨立的系列合訂本 `{系列標題}_{語言代碼}.epub`：已翻譯的章節用譯文，未翻譯的章節仍保留原文，**原文合訂本不受影響**。

整個過程顯示進度彈窗：頂部給出「請勿關閉標籤頁 / 單篇耗時較長 / 取消行爲說明」三條提示，下方展示當前章節序號、本輪成功 / 跳過 / 失敗統計與當前用時。可「隱藏」讓翻譯在後臺繼續，也可「取消」終止後續章節；取消後已翻譯完成的章節保留在本地數據庫，並仍會觸發該語言合訂本生成。在「跳過已翻譯」模式下，會先以一次小型 AI 請求把填寫的目標語言名解析爲規範語言代碼（彈窗顯示「正在識別語言代碼」狀態），隨後已存在該語言譯文的章節直接跳過、不再爲識別語言而觸發一次完整翻譯。

?> 重新生成系列合訂本時會一併刷新所有已存在譯文語言的合訂本，並替換其中已翻譯的章節。

### 下載即自動翻譯（批量 / 計劃任務 · 管理員）

在批量下載頁（`pixiv-batch.html`）或計劃任務的「**小說設置**」裏勾選「**新下載小說自動翻譯**」，旁邊設置**目標語言**與**分段字數**（與上文「AI 翻譯」彈窗同義）：之後每本新下載完成的小說都會自動翻譯成目標語言，無需逐本手動點「AI 翻譯」。

- 自動翻譯固定使用該小說 / 系列的**默認名詞映射表**（按需自動創建），此處不支持指定其它映射表；如需精細控制術語，仍可在小說閱讀頁用「AI 翻譯」彈窗選表。
- 系列下載時，若同時勾選了「生成系列合訂本」，會在每本譯完後自動重生該語言的譯文合訂本。
- 翻譯在後臺進行、**不阻塞下載**：下載隊列與計劃任務的「本輪隊列詳情」會顯示「**AI 翻譯中**」「**等待同系列前序章節翻譯完成，還有 n 章**」等狀態（同一系列按章節順序逐本翻譯以保證術語一致）。
- **下載成功即算成功**：翻譯失敗只在該條目標註「完成（翻譯失敗）」，不影響已下載的小說文件。
- 僅管理員可用，且需先在 GUI「AI 模型」配置頁啓用大語言模型（OpenAI 兼容協議）。翻譯結果可在小說閱讀頁用「內容語言」下拉切換查看。

## 刪除小說（管理員）

與作品畫廊一致，管理員可刪除已下載的小說：在小說閱讀頁點紅色「**刪除**」按鈕，或在小說畫廊點「**批量管理**」多選後通過「操作」菜單批量刪除。對本程序管理的文件，刪除會移除正文 / 封面等產物與派生數據，不能從界面撤銷；通過[外部下載導入](pixiv-batch-downloader-import.md)登記的只讀源文件會保留。與作品一樣，被刪除的小說會保留[刪除標記](/zh-hant/gallery?id=刪除作品)——對畫廊不可見，但「跳過已下載」時會按「已經下載過，但被刪除」跳過，除非在下載設置中勾選「允許已刪除的作品被重新下載」。

小說畫廊的批量管理與作品畫廊功能一致：支持「全選所有結果」按當前篩選條件整批選擇，「操作」菜單提供**導出**（可選打包方式、打包格式、是否導出後刪除源文件，後臺打包並在「任務列表」面板跟蹤進度與下載）、**添加到收藏夾**與**刪除**，詳見[作品畫廊](gallery.md)。

## 檢查下載與閱讀結果

隊列完成後，打開保存的 TXT / HTML / EPUB，檢查正文與章節順序；再從小說畫廊打開同一作品。文件存在但畫廊沒有記錄時，先確認數據庫與下載目錄是否屬於同一套實例，勿通過刪除數據庫嘗試重建。

譯文或朗讀入口缺失時，檢查管理員登錄狀態、插件啓用狀態和模型配置。下載成功與翻譯成功分別判斷：譯文失敗不會使已下載的原文失效。
