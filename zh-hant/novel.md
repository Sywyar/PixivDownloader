# 小說與朗讀

啟用 `novel` 外掛後，可將單篇小說或整套小說系列儲存為 TXT、HTML 或 EPUB，並在本地小說畫廊中閱讀、全文檢索、翻譯和聽書。翻譯需啟用 `translation` 外掛，AI 多角色朗讀需同時設定 `ai` 與 `tts` 外掛。下文 ID 僅為格式範例，請替換為你有權存取的實際作品或系列。

## 下載小說與系列

### 單篇小說

1. 開啟 `http://localhost:6999/pixiv-batch.html`，選擇「批次匯入單一作品」。
2. 貼上小說連結：

   ```text
   https://www.pixiv.net/novel/show.php?id=12345678
   ```

   僅填純數字 ID 時，需在上方單獨寫一行 `novel:` 區段標頭：

   ```text
   novel:
   12345678
   ```

3. 在下載設定中選擇儲存格式（TXT / HTML / EPUB），加入佇列並開始下載。自己的小說或收藏也可從[快速取得](/zh-hant/quick-access)直接加入佇列。

### 小說系列與 EPUB 合訂本

1. 在下載頁選擇「系列模式」，貼上系列連結並點擊「解析並預覽」：

   ```text
   https://www.pixiv.net/novel/series/123456
   ```

2. 選擇「全部加入佇列」或勾選部分章節加入佇列，開始下載。

| 格式 | 特點 |
| --- | --- |
| TXT | 純文字，無排版格式 |
| HTML | 保留 Ruby 注音、標題等原始排版，可在瀏覽器直接開啟 |
| EPUB | 遵循 EPUB3，包含多層章節目錄、內嵌封面與書籍中繼資料（簡介、標籤、來源連結） |

- **下載時產生合訂本**：在下載設定勾選「產生系列合訂本」並選擇格式（建議 EPUB），檔案儲存在 `novel-series-{seriesId}/{系列標題}.epub`（譯文合訂本為 `{系列標題}_{語言代碼}@{引擎}.epub`）。
- **在系列目錄頁隨時產生**：開啟 `pixiv-series.html?type=novel&seriesId=...`，點擊「下載合訂本」，分別選擇閱讀語言（原文或既有譯文）與翻譯引擎，即可依目前資料庫狀態即時產生並下載 EPUB。選擇譯文語言時，尚未翻譯的章節會退回原文；若需整本使用相同語言，請先完成「翻譯整個系列」。

## 本地閱讀與全文檢索

存取小說畫廊：

```text
http://localhost:6999/pixiv-novel-gallery.html
```

支援依標題、作者、系列、標籤篩選，以及依本地索引進行的**正文全文檢索**。點擊卡片進入 `pixiv-novel.html?id=<id>` 閱讀正文、查看系列目錄並切換上 / 下一章。

閱讀頁頂部保留返回、聽書、翻譯與收藏入口。「更多操作」選單中可切換介面語言與外觀、開啟 Pixiv 原小說連結；管理員也可從這裡匯出或刪除小說，刪除前仍需確認。

管理員可在閱讀頁的「更多操作」中選擇匯出，分別選擇閱讀語言與翻譯引擎，直接下載單篇 EPUB。匯出不會建立壓縮工作或暫存封存檔，也不會修改已下載的原始檔案。

批次匯出從小說畫廊勾選作品後操作，同樣分別選擇語言與引擎，並保留打包方式與 ZIP 選項。譯文依既有本地文件的格式產生；沒有本地文件時產生 EPUB。只提供所選小說都已儲存的譯文組合；未翻譯的欄位保留原文。

## 聽書（單一語音 TTS）

在小說閱讀頁點擊「聽書」按鈕，依段落順序朗讀正文，自動醒目顯示目前段落、捲動頁面並儲存閱讀進度：

| 語音引擎 | 說明 |
| --- | --- |
| 瀏覽器引擎（預設） | 呼叫瀏覽器 / 系統語音服務；可用音色及是否連網取決於瀏覽器與作業系統 |
| 線上引擎（Edge 神經語音） | 經後端代理呼叫微軟線上 TTS，需連網 |

## AI 多角色朗讀（管理員）

在桌面設定「AI 模型」中，同時設定並啟用「文字模型」（OpenAI 相容大型語言模型）和「TTS 模型」（本地 VoxCPM / CosyVoice 或雲端 TTS）後，閱讀頁可使用「多角色朗讀」（任一未啟用時，「聽書」中不會顯示該引擎選項）。先確認模型與 TTS 連線可用；分析失敗時檢查文字模型回應，合成失敗時檢查 TTS 引擎與參考音設定。

- **逐句歸屬與播放**：大型語言模型將整章逐句分配給旁白與各角色，依固定角色音色合成、依序播放並預先取得下一句；播放列會顯示目前說話者與台詞。
- **旁白與角色音色鎖定**：首次分析前可試聽並鎖定旁白基調（預設溫暖女聲）；在配角面板可查看或修改各角色的性別、年齡和英文音色描述，儲存後即鎖定，後續章節不再被 AI 覆寫，修改對後續合成立即生效。
- **角色參考音複製**：可為任意角色（含旁白）產生標準參考音或上傳 WAV / MP3（可附轉錄文字），跨句與跨章維持一致音色並保留情緒起伏；變更參考音後，會自動依新音色重新計算快取音訊。可在設定中關閉音色複製或調整產生上限。
- **音色衝突處理**：當正文新證據與已鎖定角色音色明顯衝突時，面板會列出衝突，供選擇「採納建議 / 保留目前 / 改寫」。
- **分段字數與快取**：`0`（預設）表示整章以單次請求分析（正文過長時會拒絕並提示縮小範圍）；填入正整數則依段落累積至約該字數，分批分析。分析結果快取於本地，重播無需重新計算，需要時可點擊「重新分析」。

## 翻譯引擎（管理員）

安裝並啟用 `translation` 外掛（會隨相依套件安裝 `novel-translation-contract`），在桌面設定「翻譯」頁選擇引擎，儲存後依提示重新啟動後端。閱讀頁手動翻譯、系列翻譯與下載後自動翻譯共用所選引擎：

| 引擎 | 設定與限制 |
| --- | --- |
| AI 模型 | 使用 `ai` 外掛已儲存的模型、基底位址與憑證（支援本地 OpenAI 相容服務） |
| 有道 | 填寫有道智雲文字翻譯 API 的應用程式 ID 與應用程式金鑰（無法使用有道詞典用戶端帳號） |
| LibreTranslate | 填寫自架服務基底位址（不含 `/translate`）與選用 API Key；需自行準備服務與語言模型 |

有道與 LibreTranslate 依各自的請求設定拆分長文本，將短段落合併為批次請求，並保留換行、圖片、分頁與跳轉標記。單段優先在句末或空白處切開；超過上限的長單詞依 Unicode 碼點切分，不拆開代理對。標題與正文分別請求，不使用或學習 AI 名詞對照表。

在桌面設定「翻譯」中，只顯示目前引擎的請求參數。以下為用戶端預設值；設定鍵分別加前綴 `translation.youdao.` 或 `translation.libretranslate.`。儲存後重新啟動後端。

| 參數 | 有道預設值 | LibreTranslate 預設值 | 可設範圍 |
| --- | --- | --- | --- |
| `request-chars` | 5000 | 5000 | Youdao: 1–5000; LibreTranslate: 1–1,000,000 |
| `batch-size` | 50 | 10 | 1–100 |
| `request-interval-ms` | 1000 ms | 0 ms | 0–60,000 ms |
| `request-concurrency` | 1 | 1 | 1–32 |
| `max-retries` | 3 | 3 | 0–10 |
| `read-timeout-seconds` | 120 s | 120 s | 1–3600 s |
| `use-proxy` | false | false | true / false |


字元預算同時約束單段和整批總量。有道單次查詢的官方上限為 5000 字元；LibreTranslate 的實際字元、批次條數與呼叫額度由部署方或 API 金鑰決定，5000 是本用戶端預算。每批 50/10 條和有道 1000 毫秒間隔也只是用戶端預設，不代表帳戶額度。LibreTranslate 依批次中的文本條數消耗呼叫額度，因此傳送間隔會乘以文本條數；第三方服務仍須依實際額度調整批次條數。

手動、系列和下載後自動翻譯共用各引擎的請求並行數與間隔。僅遇到有道 `411` / `412` 或 HTTP `429` 時重試目前批次，並逐次延長等待；遵守 `Retry-After`。需要等待超過 60 秒時先回報限流，冷卻期間不提前傳送新工作。驗證失敗、逾時及其他錯誤不自動重送。整篇所選內容全部成功後才儲存，失敗不會覆蓋既有譯文；繼續原工作時重用已儲存的成功回應。日誌記錄批次、請求、重試和已譯字元計數，不記錄原文、譯文或憑證。
- AI 憑證歸 `ai` 外掛管理，有道與 LibreTranslate 憑證歸 `translation` 外掛管理，語音憑證歸 `tts` 外掛管理。

翻譯對話框顯示目前引擎。有道的目標語言下拉選單使用官方語種表；LibreTranslate 從設定的服務讀取實際支援的目標語言，失敗時可重新載入。AI 保留自由輸入與名詞對照表。失敗提示依原因提供處理說明，後端英文日誌記錄執行 ID、作品 ID、引擎、階段和安全錯誤碼，不記錄正文或金鑰。

同一小說、同一目標語言可以同時保留不同引擎的譯文。「覆寫重譯」和「略過」只針對目前引擎。閱讀頁與系列頁在同一組控制項中分別選擇「閱讀語言」與「翻譯引擎」，只提供已有譯文的組合；選擇原文時，引擎顯示「不適用」。合訂本下載與小說匯出也分別選擇語言與引擎，聽書讀取目前選取的譯文。沒有引擎記錄的舊譯文保留為「來源未知」，不會歸入某個引擎；其合訂檔案仍使用原有語言後綴。AI 模型共用 `ai` 引擎身分，切換 AI 模型不會新增譯文版本。

翻譯進度由後端儲存。關閉或隱藏頁面後工作繼續執行；再次點擊「翻譯」可查看原工作，選擇暫停、繼續或取消。取消會等待執行中的請求退出，保留成功檢查點與已完成章節。捨棄工作需要再次確認，只清除工作與檢查點，不刪除正式譯文。

後端重新啟動後，未完成工作保持暫停，不會自動再次呼叫翻譯服務。繼續時會檢查原文、目標譯文、引擎位址、模型與分段設定；不符時需恢復設定，或捨棄工作後重新翻譯。AI 術語上下文隨檢查點保留。模型截斷輸出不會儲存為完整譯文。可捨棄工作後以更小分段重新翻譯；如模型服務支援，也可在服務端調整輸出限制後繼續。

如果 AI 回覆缺少必要欄位、語言與目標不符或語言代碼無效，工作會暫停。點擊繼續後會重新請求無效部分，並重用其餘已儲存的成功回應。

最多保留 256 項工作，檢查點合計最多 256 Mi UTF-16 碼元。完成紀錄在建立新工作時依 7 天保留期或容量需要清理；暫停與取消的工作需手動捨棄。外部服務已執行但回應尚未落盤時，繼續可能再次傳送該請求，無法保證只計費一次。

## AI 翻譯與名詞對照表（管理員）

設定並啟用文字模型後，在小說閱讀頁或系列目錄頁點擊「翻譯」：

- **目標語言**：預設依目前介面語言預填，可改為任意自然語言名稱。
- **分段字數**：`0` 使用設定中的 `translation.ai-segment-size`（預設 `0`，表示整章）；正數依段落累積到約該長度。此值以 UTF-16 碼元計，是段落分組目標，不是嚴格的請求上限，單個長段落可能超過該值。模型上下文與輸出 token 上限仍由 AI 模型設定控制，字元數不能換算成固定 token 數。普通翻譯對話框的 `0` 則沿用對應服務的字元預算，正數只能進一步縮小單段。
- **既有譯文處理**：選擇「覆寫重譯」或「略過」。
- **名詞對照表**：儲存「原文 ↔ 各語言譯名」以統一專有名詞譯法。系列作品預設共用同名表，單篇作品預設使用各自的表；也可選擇不使用、切換既有表或新增 / 編輯對照表。AI 在翻譯中發現的新專有名詞，會自動併入所選表供後續章節使用（模型仍可能偏離對照表，請核對譯文）。
- **內容語言切換**：閱讀頁與系列頁的「閱讀語言」與「翻譯引擎」可獨立於介面語言切換原文或既有譯文（正文、章節標題、系列名稱與譯文 EPUB 標題同步切換，未翻譯項目退回原文），聽書也會朗讀目前所選語言。章節標題與正文在同一 AI 請求中翻譯；系列名稱翻譯會附帶同語言已譯章節的標題對與名詞對照表。
- **翻譯整個系列**：在系列頁依章節順序批次翻譯，支援隱藏至背景或取消（取消後保留已譯章節），完成後產生 `{系列標題}_{語言代碼}@{引擎}.epub`。選擇「略過已翻譯」時，先用一次輕量請求將目標語言名稱解析為標準語言代碼，已存在譯文的章節直接略過。本次翻譯只更新所選語言與引擎的合訂本。
- **下載後自動翻譯**：在下載頁或排程工作「小說設定」勾選「自動翻譯新下載的小說」，並指定目標語言與分段字數。自動翻譯固定使用作品 / 系列的預設名詞對照表，在背景依系列章節順序執行，不阻塞下載；下載成功即記為完成，翻譯失敗僅標示「完成（翻譯失敗）」，不影響已儲存的原文。

## 刪除、批次管理與結果核對

管理員可在閱讀頁刪除單篇小說，或在小說畫廊透過「批次管理」全選篩選結果、批次匯出 ZIP（可選擇匯出後刪除來源檔案，在側欄「任務清單」查看進度）、加入收藏夾或批次刪除。程式管理的檔案刪除後，無法從介面復原，但會保留[刪除標記](/zh-hant/gallery#刪除作品)以避免預設重複下載；透過[匯入外部下載](/zh-hant/pixiv-batch-downloader-import)登記的唯讀來源檔案會保留。完整批次管理規則與[作品畫廊](/zh-hant/gallery)一致。

下載完成後，請分別檢查本地 TXT / HTML / EPUB 檔案與小說畫廊紀錄。若磁碟有檔案但畫廊無紀錄，先核對目前資料庫與下載目錄是否屬於同一執行個體，切勿刪除資料庫嘗試重建。
