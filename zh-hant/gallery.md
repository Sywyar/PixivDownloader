# 作品畫廊

作品畫廊是查看、整理、管理已下載作品的核心頁面。

訪問地址：`http://localhost:6999/pixiv-gallery.html`

---

## 界面概覽

畫廊頁面主要分爲三個區域：

- **左側邊欄（導航模塊）**：視圖切換（全部圖片 / 按作者 / 按系列漫畫）、收藏夾列表及新建按鈕、導航鏈接（畫廊 / 下載 / 監控 / 統計 / 疑似重複 / 邀請碼管理）
- **中央網格**：作品縮略圖列表
- **頂部工具欄**：搜索框、排序、篩選、視圖切換

側邊欄右緣有兩個外凸按鈕：

- **導航**：展開 / 收起左側邊欄。
- **任務列表**（僅管理員）：展示後臺壓縮任務（批量導出、打包）的進度與剩餘有效期，任務完成後可在列表中手動下載壓縮包；過期任務自動清理，服務重啓後列表清空。點擊批量導出後會自動打開該面板。

頂部工具欄還有畫廊類型切換標籤：**漫畫**（當前插畫/漫畫/動圖畫廊）和**小說**（跳轉到小說畫廊 `pixiv-novel-gallery.html`）。

## 搜索

搜索框支持多種搜索範圍（點擊搜索框左側的下拉切換）：

| 範圍 | 說明 |
|------|------|
| **綜合** | 標題 + 作者名（默認） |
| **標題** | 按作品標題搜索 |
| **作者名** | 按作者名稱搜索 |
| **作品 ID** | 精確匹配作品 ID |
| **作者 ID** | 精確匹配作者 ID |
| **簡介** | 按作品簡介搜索 |
| **標籤（模糊）** | 標籤包含關鍵詞 |
| **標籤（精確）** | 標籤完全匹配 |

---

## 篩選

點擊工具欄「**篩選**」按鈕展開篩選面板：

- **內容分級**：全部 / 全年齡 / R-18 / R-18G
- **AI 生成**：全部 / 排除 AI / 僅 AI
- **圖片格式**：JPG / PNG / GIF / WebP 等
- **收藏夾**：按收藏夾篩選

### 標籤/作者三態篩選

這是畫廊最強大的篩選功能，每個標籤或作者可以單獨設置爲三種狀態：

| 狀態 | 含義 |
|------|------|
| ✅ 必須有 | 作品必須包含該標籤/來自該作者 |
| ❌ 不能有 | 作品不能包含該標籤/來自該作者 |
| 🔵 或者有 | 滿足任意一個「或者有」條件即可 |

多個「必須有」之間取**交集**，多個「或者有」之間取**並集**，然後再排除「不能有」。

## 排序

| 排序選項 | 說明 |
|---------|------|
| 下載時間 | 按入庫時間排序（默認，最新在前） |
| 作品 ID | 按 Pixiv 作品 ID 排序 |
| 圖片數 | 按該作品的圖片總數排序 |
| 狀態 | 按作品的下載/歸檔狀態排序 |
| 畫師 ID | 按畫師 ID 排序（同一畫師的作品聚在一起） |
| 標籤數 | 按標籤數量排序 |
| 漫畫系列 | 有系列的作品按系列排序聚在一起 |

每種排序均支持升序/降序切換。

## 查看作品詳情

點擊任意作品縮略圖，進入 `pixiv-artwork.html` 詳情頁：

- 標題、作者、發佈時間、標籤
- 作品簡介
- 多圖瀏覽（支持左右切換、全屏燈箱）
- 相關作品推薦
- 該作者其他作品
- 跳轉 Pixiv 原站按鈕

## 批量管理（管理員）

在畫廊頂部工具欄點「**批量管理**」進入多選模式，勾選作品後通過底部操作條的「**操作**」菜單執行批量動作。選擇方式：

- **全選本頁 / 清除選擇**：僅作用於當前頁。
- **全選所有結果**：選中當前篩選條件下的**全部**結果（可再點單個作品取消個別項），翻頁不丟失選擇。

「操作」菜單提供三種動作：

- **導出**：彈窗中可選擇**打包方式**（按作者 / 作品分類，或以作品 ID 爲文件夾名）、**打包格式**（當前支持 ZIP）以及**是否導出後刪除源文件**。確認後在後臺打包，自動打開「任務列表」面板展示進度，完成後自動開始下載，也可隨時在任務列表中手動下載；壓縮包內附帶記錄作品信息與原始路徑的 `manifest.json`。勾選「導出後刪除」時，**只有打包成功後**纔會刪除源文件與下載記錄。
- **添加到收藏夾**：把選中作品批量加入指定收藏夾。
- **刪除**：批量刪除選中作品。

### 刪除作品

> ⚠️ 刪除會移除作品在本地的圖片文件與派生數據（標籤、收藏夾關聯與縮略圖緩存），文件**不可恢復**，且僅管理員可用。

- **刪除單個作品**：在作品詳情頁點紅色「**刪除**」按鈕，彈窗確認後刪除。
- **批量刪除**：批量管理多選後在「操作」菜單點「**刪除**」並確認。

小說畫廊提供完全相同的批量管理入口，小說閱讀頁提供相同的單本刪除入口。

**刪除標記**：被刪除的作品會在下載歷史中保留一個「刪除標記」——它們對畫廊、篩選、統計等所有瀏覽入口不可見，但批量下載、油猴腳本與計劃任務在「跳過已下載作品」時仍能識別出「**已經下載過，但被刪除**」，默認不會把它們當作新作品重新下載。如果確實想重新下載，在下載設置中勾選「**允許已刪除的作品被重新下載**」即可；重新下載成功後刪除標記自動清除，作品重新出現在畫廊中。

## 收藏夾管理

收藏夾用於在本地對作品進行分類整理（獨立於 Pixiv 收藏，僅在 PixivDownloader 內有效）。

### 新建收藏夾

左側邊欄底部點「**+ 新建收藏夾**」，填寫名稱即可。

### 自定義設置

右鍵收藏夾或進入收藏夾編輯頁面：
- **重命名**
- **自定義圖標**（支持 PNG / JPG / WEBP，最大 1MB）
- **自定義下載目錄**（下載時自動存入該目錄）
- **刪除**

### 將作品加入收藏夾

在畫廊縮略圖上懸停，點出現的「❤️」圖標；或進入詳情頁點「收藏到...」按鈕。

## 作品賞析模式

在詳情頁點「**作品賞析**」按鈕，進入 `pixiv-showcase.html`，沉浸式全屏瀏覽當前作品，無干擾閱讀。

## 訪客邀請

管理員可以創建邀請碼，分享畫廊的查看權限給其他人（僅查看，不能下載或修改）：

1. 畫廊頁面右上角點「**邀請訪客**」
2. 設置過期時間、內容分級（可限制 SFW 範圍）、標籤/作者白名單
3. 複製生成的邀請鏈接發給對方

訪客通過 `http://host:port/invite?code=xxx` 訪問，只能看到白名單範圍內的作品。

詳細邀請管理見 `http://localhost:6999/pixiv-invite-manage.html`。

## 統計儀表盤

訪問 `http://localhost:6999/pixiv-stats.html`（管理員專屬）：

- 總作品數 / 總圖片數 / 作者數 / 標籤數
- 按月下載量折線圖
- 下載量 Top 作者排行
- 熱門標籤詞雲（點擊直達畫廊篩選）
