# 作品畫廊

作品畫廊用於瀏覽、篩選、整理和批次匯出資料庫中已登記的插畫、漫畫與動圖。需啟用 `gallery` 外掛；批次管理、匯出、刪除與收藏夾管理需管理員登入。畫廊以資料庫紀錄為準，將圖片直接放入資料夾不會自動登記為作品。

存取位址：`http://localhost:6999/pixiv-gallery.html`

## 查找、篩選與排序

左側邊欄用於切換檢視（全部圖片、依作者、依系列漫畫）、管理本地收藏夾及存取各功能頁面；側欄右緣按鈕可收合導覽或開啟管理員「任務清單」（查看背景打包進度與有效期限）。頂部工具列提供畫廊類型切換（插畫 / 小說等已啟用畫廊外掛）、搜尋框、篩選與排序。

| 搜尋範圍 | 比對內容 |
| --- | --- |
| 綜合 | 標題 + 作者名稱（預設） |
| 標題 / 作者名稱 / 簡介 | 對應文字欄位模糊比對 |
| 作品 ID / 作者 ID | 數字 ID 精確比對 |
| 標籤（模糊 / 精確） | 包含關鍵字或完全符合標籤名稱 |

「篩選」支援依內容分級（全部 / 全年齡 / R-18 / R-18G）、AI 生成（全部 / 排除 AI / 僅 AI）、圖片格式、收藏夾及上傳日期範圍（含結束日期當天，依瀏覽器時區解讀；未知上傳時間不會列入日期範圍結果）篩選。標籤與作者支援三態組合：

| 狀態 | 規則 |
| --- | --- |
| 必須有 | 多個「必須有」之間取交集 |
| 或者有 | 多個「或者有」之間取聯集 |
| 不能有 | 從結果中排除符合的項目 |

排序支援依**下載時間**（預設最新在前）、**上傳時間**（未知上傳時間在升冪和降冪中均排在最後）、**作品 ID**、**圖片數**、**狀態**、**畫師 ID**、**標籤數**和**漫畫系列**升冪或降冪排列。

點擊縮圖進入 `pixiv-artwork.html` 查看多圖（支援左右切換與燈箱）、簡介、標籤、同作者作品、相關推薦及原站連結；點擊「作品賞析」可進入 `pixiv-showcase.html` 全螢幕瀏覽。

## 批次管理與匯出（管理員）

點擊頂部「批次管理」進入多選模式：

- **全選本頁 / 清除選取**：僅作用於目前頁面。
- **全選所有結果**：選取目前篩選條件下的全部作品（跨頁保留選取，可單獨取消個別作品）。

在底部「操作」選單可執行：

| 動作 | 結果 |
| --- | --- |
| 匯出 | 選擇目錄結構（依作者/作品分類，或依作品 ID 分目錄）、格式（ZIP）及是否「匯出後刪除來源檔案」，在背景產生含 `manifest.json` 的壓縮檔 |
| 加入收藏夾 | 將所選作品批次加入指定本地收藏夾 |
| 刪除 | 批次刪除所選作品 |

開始匯出後會自動開啟側欄「任務清單」顯示進度，打包完成後自動觸發下載，也可在有效期限內從任務清單手動下載（過期或重新啟動服務後會清理任務）。

!> 勾選「匯出後刪除」時，伺服器端成功產生壓縮檔後就會刪除來源檔案與下載紀錄，不會等待瀏覽器下載完成或人工檢查壓縮檔內容。

## 刪除作品

管理員可在作品詳細資料頁點擊紅色「刪除」按鈕，或透過「批次管理 → 操作 → 刪除」移除作品。對本程式管理的作品，刪除會移除本地媒體檔案及衍生資料（標籤、收藏夾關聯、縮圖），無法從介面復原；透過[匯入外部下載](/zh-hant/pixiv-batch-downloader-import)登記的唯讀來源檔案會保留。小說畫廊與小說閱讀頁提供相同的刪除與批次管理入口。

**刪除標記**：被刪除的作品會在下載歷史中保留刪除標記，對畫廊、篩選和統計不可見；當批次下載、使用者腳本或排程工作開啟「略過已下載作品」時，預設將其辨識為「已經下載過，但被刪除」並略過。如需重新下載，在下載設定中勾選「允許重新下載已刪除的作品」，下載成功後會自動清除刪除標記。

## 收藏夾與訪客邀請

本地收藏夾獨立於 Pixiv 線上收藏。在左側邊欄底部點擊「+ 新增收藏夾」建立；在收藏夾按滑鼠右鍵或進入編輯頁，可重新命名、上傳自訂圖示（PNG / JPG / WebP，最大 1 MB）、綁定獨立下載目錄或刪除收藏夾。游標停留在縮圖上時點擊心形圖示，或在詳細資料頁點擊「收藏到...」，即可歸入收藏夾。

管理員可點擊畫廊右上角「邀請訪客」，設定有效期限、內容分級（如僅 SFW）及標籤 / 作者白名單，產生 `http://host:port/invite?code=xxx` 唯讀分享連結（在 `http://localhost:6999/pixiv-invite-manage.html` 管理邀請碼）。訪客無修改或批次管理權限，但已顯示在瀏覽器中的圖片仍可能被訪客另存。

## 未找到作品與統計看板

找不到預期作品時，先清除搜尋與篩選條件（特別是上傳日期範圍與三態標籤），並核對邀請碼白名單、目前連線的資料庫、下載目錄和刪除標記。僅在磁碟上移動檔案不會更新另一資料庫，搬遷與還原見[儲存與備份](/zh-hant/storage)。

管理員存取 `http://localhost:6999/pixiv-stats.html`（需啟用 `gallery-tools` 外掛）可查看作品與圖片總數、每月下載折線圖、Top 作者排行及熱門標籤文字雲（點擊作者或標籤可直接進入畫廊篩選）。
