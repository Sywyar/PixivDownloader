# 本機作品匯入與本機匯入預設

已經存在自己目錄中的圖片，可以透過路徑中的作品 ID 登記到作品庫。匯入會保留原目錄與原檔案；缺少標題、作者等資訊時先登記，等待後續補全。

?> 請使用包含「本機作品匯入」工具的版本，並保持後端執行。Compose 與 Swing 都從桌面工具頁進入。HTTP API 中的路徑也指執行後端的電腦上的路徑。

Compose 中的本機作品匯入位於「快捷工具」，以彈窗開啟。收起後，已啟動的掃描或匯入繼續執行；可從工具頁重新開啟查看進度或取消。

## 將實際路徑寫成路徑範本

**路徑範本**用大括號標出路徑中會變動的部分，軟體從這些位置讀取資訊。每條範本必須包含 `{artwork_id}`，可放在目錄名稱或檔名中。

| 現有檔案的實際路徑 | 填入的路徑範本 | 解析結果 |
| --- | --- | --- |
| `D:/xxx/12345/pic.png` | `D:/xxx/{artwork_id}/` | 作品 ID 為 12345，收集該目錄及子目錄中支援的檔案 |
| `D:/xxx/12345_xxx.png` | `D:/xxx/{artwork_id}_xxx.{extension}` | 作品 ID 為 12345，副檔名為 png；`_xxx` 是固定文字 |
| `D:/678/12345/pic.png` | `D:/{author_id}/{artwork_id}/` | 作者 ID 為 678，作品 ID 為 12345 |
| `D:/xxx/12345_p0.jpg` | `D:/xxx/{artwork_id}_p{page}.{extension}` | 作品 ID 為 12345，第 0 頁 |

目錄範本以 `/` 結尾；檔案範本須寫到檔名與副檔名。請使用絕對路徑，Windows 可使用 `/` 或 `\`。範本不會建立目錄或重新命名檔案。

## 偶爾匯入：直接填寫臨時範本

1. 開啟桌面「工具 → 本機作品匯入」。
2. 在臨時路徑範本欄位輸入範本，每行一條，例如 `D:/xxx/{artwork_id}/`。
3. 只匯入一件作品時，在作品 ID 欄位填 `12345`；批次匯入時輸入多個 ID，以換行、空格或逗號分隔。留空會掃描所有符合的作品。
4. 只想登記一個檔案時，填寫指定檔案欄位。仍須提供能解析該檔案的範本。
5. 掃描並預覽，核對作品 ID、路徑與處理結果後，再開始匯入。

有填寫臨時範本時，只使用這些範本；留空才使用預設。工具頁的輸入僅用於當次操作，不會儲存至設定。

## 經常匯入：儲存本機匯入預設

**本機匯入預設**是已儲存的路徑範本清單，直接顯示輸入路徑。匯入時自動使用全部路徑，無需命名或選取。

1. 在設定頁找到「本機匯入預設」，開啟預設編輯器。
2. 點選「新增路徑」，在清單輸入 `D:/{author_id}/{artwork_id}/` 等絕對路徑範本，每行一條。按兩下路徑進行編輯，也可移除一行。
3. 套用至草稿，返回設定頁儲存，再依提示重新啟動後端。
4. 開啟「本機作品匯入」，將臨時路徑範本留空，輸入 `12345` 或 ID 清單。
5. 工具會顯示並使用全部已儲存路徑。預覽確認後開始匯入。

上例會在 `D:/` 的作者目錄下尋找作品 12345，不需要先輸入作者 ID。盡量指定實際存放作品的較小目錄，以縮小掃描範圍。設定鍵是 `local-import.presets`，建議透過設定頁編輯。

## 可用變數

| 變數 | 意義 |
| --- | --- |
| `{artwork_id}` | 必填，正整數作品 ID |
| `{author_id}` | 正整數作者 ID |
| `{artwork_title}` | 路徑中已有的作品標題 |
| `{author_name}` | 路徑中已有的作者名稱 |
| `{page}` | 頁碼，從 0 開始 |
| `{extension}` | 副檔名，不含前面的點 |
| `{name}` | 比對單一路徑片段中的其他名稱，不作為作品標題 |

變數名稱固定使用表中的小寫底線寫法，精確比對。相鄰變數需要固定分隔文字，例如 `{artwork_id}_{name}`，不能寫成 `{artwork_id}{name}`。`*` 不是萬用字元。

## 預覽、重新掃描與結果

- 支援掃描 JPG、JPEG、PNG、APNG、GIF、WebP、WebM、MP4 與 ZIP；檔案仍須通過匯入驗證，ZIP 支援不表示可解壓匯入任意壓縮檔。
- 預覽會區分新增作品、補充檔案、已登記、衝突與找不到檔案。請先處理衝突，現有登記不會被強制覆寫。
- 最近的掃描索引保留在記憶體中 5 分鐘，不會自動監視目錄。新增、搬移或刪除檔案後，請勾選重新掃描並更新索引，再次預覽。
- 取消會等待目前作品登記結束，已登記的作品會保留。掃描範圍過大時，請拆分目錄或 ID 清單。
- 外部檔案以唯讀方式參照；在應用程式刪除作品登記不會刪除原檔案。之後搬移或刪除原檔案可能使參照失效，請同時備份資料庫與外部目錄。
- 路徑不一定包含標題、作者與完整頁數。中繼資料待補全不代表登記失敗；後續連線補全請見[網路存取說明](/zh-hant/network-access)。

## HTTP API

管理員可透過 `/api/local-import` 使用相同流程，沿用應用程式的登入驗證與 CSRF 保護：

1. `GET /api/local-import/presets` 讀取已儲存預設。
2. `POST /api/local-import/previews` 提交 JSON，取得預覽 ID。
3. `GET /api/local-import/previews/{id}` 等待 `phase` 為 `READY`；以 `/previews/{id}/items?offset=0&limit=20` 查看明細。
4. 向 `POST /api/local-import/tasks` 提交 `{"previewId":"傳回的預覽 UUID"}`。
5. `GET /api/local-import/tasks/{id}` 查詢結果；`POST /api/local-import/tasks/{id}/cancel` 取消。

使用全部已儲存路徑掃描兩件作品的請求內容：

```json
{
  "templates": [],
  "artworkIds": [12345, 12346],
  "refreshIndex": false,
  "selectedFile": ""
}
```

`202` 表示已接受請求，仍須查詢結果。每個執行個體同時只執行一個匯入工作；預覽與索引不會在程序重新啟動後保留。本頁介紹 HTTP 介面，不表示已提供獨立 MCP 工具。

下載器歷史 JSON 請使用另一個入口：[匯入外部下載](/zh-hant/pixiv-batch-downloader-import)。
