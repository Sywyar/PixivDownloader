# 작가 일괄 다운로드

다운로드 페이지의 '사용자 모드'에 작가 프로필 링크나 숫자 ID를 입력하면 해당 작가의 일러스트, 만화, 움짤, 소설 또는 공개된 커미션 결과물을 미리 보고 전체 또는 일부 작품을 선택하여 다운로드할 수 있습니다. 실제로 가져올 수 있는 범위는 현재 계정 권한, 추가 필터와 기존 다운로드 검사에 따라 달라집니다.

## 사용 순서

1. `http://localhost:6999/pixiv-batch.html`을 열고 '사용자 모드'로 전환합니다.
2. 작가 프로필 링크나 숫자로 된 사용자 ID를 붙여넣습니다.
3. 다운로드 범위를 선택합니다. 일러스트 + 만화 + 움짤, 소설 또는 커미션를 선택할 수 있으며 소설에는 `novel` 플러그인이 필요합니다.
4. '해석하고 미리 보기'를 누르고 필요한 추가 필터를 설정합니다.
5. '모두 대기열에 추가'를 누르거나 일부 작품을 선택하여 대기열에 추가한 후 '다운로드 시작'을 누릅니다.
6. 다운로드가 완료되면 대기열에서 성공, 건너뜀과 실패 기록을 확인합니다.

다음 입력 형식을 지원합니다. `123456`은 예시이므로 실제 작가 ID로 바꾸세요.

```text
https://www.pixiv.net/users/123456
https://www.pixiv.net/users/123456/artworks
https://www.pixiv.net/users/123456/illustrations
https://www.pixiv.net/users/123456/novels
https://www.pixiv.net/users/123456/request/artworks
https://www.pixiv.net/en/users/123456
123456
```

## 다운로드 범위 및 추가 필터

| 범위 | 포함 내용 |
| --- | --- |
| 일러스트 + 만화 + 움짤 | 해당 작가가 투고한 이미지 작품 |
| 소설 | 해당 작가가 투고한 소설 작품 |
| 커미션 | 해당 작가가 완료하여 공개한 커미션(リクエスト) 결과물. 일반 일러스트 흐름으로 미리보기, 대기열 추가, 다운로드 및 중복 검사 |

커미션 페이지 링크(`/users/{id}/request/artworks`)를 붙여넣으면 자동으로 '커미션' 범위로 전환됩니다. 미리보기 영역에는 한 번에 한 범위만 표시됩니다. 범위를 전환하면 현재 미리보기 목록이 비워지지만 이미 추가한 다운로드 대기열은 유지됩니다. 일러스트를 먼저 대기열에 추가하고 소설로 전환하여 추가한 다음 함께 다운로드할 수 있습니다.

'추가 필터'는 콘텐츠 등급, AI 제외, 최소 북마크 수, 태그나 페이지 수를 지원하며 미리보기와 실제 다운로드에서 작품별로 적용됩니다. 작가의 작품 수가 많다면 추가 필터를 사용하고 '최대 동시 작업 수'를 낮추며 '작품 간격'(밀리초)을 설정하여 외부 서비스의 제한에 걸릴 위험을 줄이는 것이 좋습니다.

## 예약 작업으로 저장

페이지 하단의 '예약 작업으로 저장' 카드에서 작업 이름과 트리거 방식을 입력하면 해당 작가의 새 작품을 주기적으로 찾아 자동 다운로드할 수 있습니다. 로그인이 필요한 콘텐츠에는 작업에 유효한 Cookie를 연결해야 합니다. 설정과 워터마크 기반 증분 규칙은 [예약 작업](/ko/scheduled-tasks)을 참고하세요.

## 예상한 작품을 가져오지 못한 경우

입력한 ID가 단일 작품 ID가 아닌 작가의 사용자 ID인지 먼저 확인하고, 선택한 범위(이미지 / 소설 / 커미션), 추가 필터와 Cookie 로그인 상태를 점검하세요. '모두 대기열에 추가'를 눌러도 삭제되었거나 접근 권한이 없는 작품을 다운로드할 수는 없습니다.
