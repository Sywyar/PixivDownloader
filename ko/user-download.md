# 작가 일괄 다운로드

## 사용 단계

사용자 모드에서 Pixiv 사용자 URL 또는 ID를 입력하고 작품 유형과 페이지 상한을 선택합니다. 결과를 검토한 뒤 대기열에 추가하세요.

## 지원 링크 형식

`https://www.pixiv.net/users/<id>`, 사용자 작품 페이지와 일부 Pixiv 사용자 URL을 지원합니다. URL에서 ID를 확인할 수 없으면 숫자 ID를 직접 입력하세요.

## 다운로드 범위

전체 작품, 일러스트, 만화, 우고이라, 소설, 공개 북마크와 의뢰 작품 등 사용 가능한 범위를 선택합니다. 비공개 범위는 Cookie 권한이 필요합니다.

## 추가 필터

업로드 날짜, 태그, 연령 등급, 다운로드 이력과 삭제 표시를 조합할 수 있습니다.

## 예약 작업으로 저장

작가와 현재 필터를 예약 작업으로 저장하면 새 작품을 주기적으로 발견합니다. [예약 작업](/ko/scheduled-tasks)에서 간격과 첫 실행 상한을 조정하세요.

## 데이터량 주의

대형 작가 계정은 페이지 상한과 동시성을 낮추고 여러 실행으로 나누세요. Pixiv 제한을 피하고 저장 공간과 네트워크 사용량을 관리할 수 있습니다.
