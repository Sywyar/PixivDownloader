# 작가 일괄 다운로드

User 모드에서 작가의 Pixiv 프로필 링크나 ID를 입력하면 일러스트, 만화, Ugoira, 소설 또는 공개 의뢰 결과물을 미리보고 전체나 일부를 다운로드할 수 있습니다. 범위는 계정 접근 권한, 추가 필터, 다운로드 이력 검사의 영향을 받습니다.

## 사용 순서

1. `http://localhost:6999/pixiv-batch.html`에서 **User 모드**를 선택합니다.
2. 작가 프로필 링크나 숫자 ID를 붙여 넣습니다.
3. 이미지, 소설, 의뢰 중 범위를 고릅니다. 소설에는 `novel` 플러그인이 필요합니다.
4. 분석·미리보기를 누릅니다.
5. 필요하면 추가 필터를 설정합니다.
6. 전체 또는 선택한 작품을 대기열에 넣고 다운로드를 시작합니다.
7. 완료, 건너뜀, 실패를 각각 확인합니다.

## 지원 링크

다음 예시에서 숫자는 실제 작가 ID로 바꾸세요.

```text
https://www.pixiv.net/users/123456
https://www.pixiv.net/users/123456/artworks
https://www.pixiv.net/users/123456/illustrations
https://www.pixiv.net/users/123456/novels
https://www.pixiv.net/users/123456/request/artworks
https://www.pixiv.net/en/users/123456
123456
```

의뢰 페이지 `/users/{id}/request/artworks`를 붙여 넣으면 자동으로 의뢰 범위로 전환합니다.

## 범위 전환

| 범위 | 내용 |
| --- | --- |
| 일러스트·만화·Ugoira | 해당 작가의 이미지 작품 |
| 소설 | 해당 작가의 소설 |
| 의뢰 | 완료하여 공개한 의뢰(リクエスト) 결과물 |

의뢰 결과물은 일반 일러스트이므로 같은 미리보기, 대기열, 다운로드, 중복 확인 절차를 사용합니다.

미리보기는 한 번에 한 유형만 가져옵니다. 범위를 바꾸면 기존 미리보기는 지워지지만 대기열은 유지됩니다. 일러스트를 먼저 추가하고 소설로 전환해 추가한 뒤 함께 다운로드할 수 있습니다.

## 필터와 예약

추가 필터로 R-18만 선택하거나 AI 작품을 제외하거나 최소 북마크 수를 정할 수 있습니다. 예를 들어 북마크 100개 이상으로 범위를 좁힐 수 있습니다. 필터는 미리보기뿐 아니라 실제 다운로드에도 적용되며 조건에 맞지 않으면 건너뜁니다.

정기적으로 신작을 받으려면 아래의 예약 작업 저장 카드에서 이름과 실행 주기를 입력하고 생성하세요. 백엔드가 실행 중이어야 정기 확인과 다운로드가 진행됩니다. 로그인 제한 콘텐츠에는 작업에 연결된 유효 Cookie가 필요합니다. 만료나 접근 실패가 생기면 작업 상태를 확인하세요. 자세한 내용은 [예약 작업](/ko/scheduled-tasks)을 참고하세요.

## 예상한 작품이 없을 때

단일 작품 ID 대신 작가 프로필 ID를 입력했는지, 이미지·소설·의뢰 중 올바른 범위를 선택했는지 확인합니다. 필터와 Cookie도 점검하세요. 범위 전환은 미리보기만 지우며 대기열은 지우지 않습니다. 전체 추가를 선택해도 접근 불가능하거나 삭제된 작품을 받을 수는 없습니다.

작품이 수백·수천 개인 작가는 첫 다운로드가 오래 걸릴 수 있습니다. 필터로 범위를 좁히고 최대 동시 작업 수를 낮추거나 작품 사이 간격(밀리초)을 늘려 Pixiv 요청 부하를 조절하세요.
