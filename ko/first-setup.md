# 최초 설정

## 설정 진입점

- 데스크톱: GUI 마법사
- 브라우저: 설치 후 웹 설정 마법사
- 서버/Docker: `--setup` CLI 명령

## 방법 1: GUI 마법사

### 1단계: 서비스 준비 대기

애플리케이션을 실행하고 상태가 준비될 때까지 기다립니다. 브라우저에서 기본 주소를 열어도 됩니다.

### 2단계: 관리자 계정과 실행 모드

관리자 사용자 이름과 강한 비밀번호를 설정하고 단일 모드 또는 다중 모드를 선택합니다. 비밀번호는 저장소나 로그에 기록하지 마세요.

### 3단계: HTTP 프록시

Pixiv에 접근할 프록시가 있으면 호스트와 포트를 입력합니다. 프록시가 없으면 비활성화할 수 있으며, 이후 [설정](/ko/configuration)에서 변경할 수 있습니다.

### 4~7단계: 안내된 설정

다운로드 루트, Cookie, 테마, 언어 및 선택적 플러그인을 확인합니다. 설치 후 상태 페이지에서 FFmpeg와 플러그인 상태를 검토하세요.

## 방법 2: 브라우저 설정 마법사

`http://localhost:6999/setup.html`을 열고 화면의 단계에 따라 계정, 실행 모드, 프록시와 다운로드 루트를 저장합니다.

## 방법 3: CLI 명령

### 대화형 초기화

```bash
java -Dfile.encoding=UTF-8 -jar PixivDownload-vX.X.X.jar --setup
```

대화형 모드는 계정, 모드와 프록시를 차례로 묻습니다.

### 자동화

자동화 스크립트에서는 비대화형 옵션을 사용하세요. 명령줄 인수와 프로세스 목록에 비밀번호가 남을 수 있으므로 보호된 실행 환경에서만 사용합니다.

## 설정 후

`http://localhost:6999/pixiv-batch.html`을 열어 첫 다운로드를 실행합니다. 비밀번호 변경은 설정 메뉴에서, 분실 시 재설정은 서버가 중지된 복구 절차에서 수행합니다.

## 재초기화

재초기화 전 `config/`, `state/`, `data/`를 백업하세요. 이미 다운로드한 파일을 보존하려면 다운로드 루트는 삭제하지 마세요.
