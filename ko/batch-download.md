# URL 일괄 다운로드

## 빠른 시작

다운로드 페이지에서 URL 일괄 가져오기를 선택하고 작품 URL 또는 ID 목록을 붙여 넣은 뒤 다운로드를 시작합니다. 한 줄에 URL 하나를 입력할 수 있으며, 제목을 보존하려면 `url | title` 형식을 사용하세요.

## 입력 형식

```text
# 가장 일반적인 형식
https://www.pixiv.net/artworks/12345678

# 숫자 ID만 입력하면 기본적으로 일러스트로 처리
12345678

# 이후 ID의 유형을 지정하는 섹션
douyin:
12345678

# OneTab / N-Tab 내보내기 형식도 지원
https://www.pixiv.net/artworks/12345678 | 작품 제목
```

### 섹션 헤더

`pixiv:`와 `douyin:` 헤더는 다음에 오는 ID의 출처를 지정합니다. 헤더가 없는 숫자 ID는 Pixiv 작품으로 처리됩니다. 빈 줄과 `#`으로 시작하는 주석은 무시됩니다.

## 추가 필터

작품 유형, 날짜, 태그, 작가 및 다운로드 이력 필터를 사용할 수 있습니다. 기록 검증 옵션을 켜면 기존 기록의 폴더와 이미지 파일을 확인하고, 유효하지 않은 기록만 다시 다운로드합니다.

## 다운로드 설정

파일명 템플릿, 동시 작업 수, 프록시, 다운로드 후 북마크, Ugoira 변환 및 소설 병합 형식을 설정할 수 있습니다. 자세한 내용은 [설정](/ko/configuration)을 참고하세요.

## OneTab / N-Tab 호환

탭 관리자에서 내보낸 목록을 그대로 붙여 넣을 수 있습니다. 파이프 뒤의 제목은 선택 사항이며, URL에 포함된 구분 문자는 안전하게 처리됩니다.
