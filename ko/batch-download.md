# URL 일괄 다운로드

여러 작품 링크나 ID가 있다면 다운로드 페이지의 '단일 작품 일괄 가져오기'에 한 번에 붙여넣어 다운로드할 수 있습니다. 일러스트, 만화, 움짤과 소설을 섞어 입력할 수 있습니다. 소설을 다운로드하려면 `novel` 플러그인을 활성화해야 하며, 접근이 제한된 작품에는 `PHPSESSID`가 포함된 Pixiv Cookie를 저장해야 합니다.

## 사용 순서

1. `http://localhost:6999/pixiv-batch.html`을 열고 '단일 작품 일괄 가져오기'로 전환합니다.
2. 텍스트 상자에 URL이나 ID 목록을 한 줄에 하나씩 붙여넣고 '정보 가져오기'를 누릅니다.
3. 인식한 작품 유형과 개수를 확인합니다.
4. 필요한 추가 필터와 다운로드 설정을 지정하고 작품을 대기열에 추가한 후 '다운로드 시작'을 누릅니다.
5. 다운로드가 끝나면 대기열에서 결과를 확인합니다. 완료, 기존 파일로 건너뜀, 필터로 건너뜀과 실패는 각각 집계됩니다.

## 입력 형식

한 줄에 항목 하나를 입력합니다. 아래 작품 ID는 형식 예시이므로 실제 작품으로 바꾸세요.

```text
# 전체 URL
https://www.pixiv.net/artworks/12345678
https://www.pixiv.net/novel/show.php?id=87654321

# 숫자 ID(기본적으로 일러스트로 처리, 제목은 선택 사항)
12345678
12345679 | 작품 제목

# 구역 헤더: 이후 숫자 ID의 작품 유형 지정
artwork:
11111
22222
novel:
33333
44444 | 소설 제목

# OneTab / N-Tab 내보내기 형식
https://www.pixiv.net/artworks/55555 | 탭 제목
```

- `artwork:`와 `novel:`은 한 줄에 단독으로 입력합니다. 대소문자를 구분하지 않으며 반각 / 전각 콜론을 모두 사용할 수 있습니다. 이후 숫자 ID 또는 `id | title`을 다음 구역 헤더나 입력 끝까지 해당 유형으로 해석합니다.
- `https://`로 시작하는 전체 링크는 항상 링크 자체의 유형으로 해석하며 구역 헤더의 영향을 받지 않습니다.
- OneTab / N-Tab에서 내보낸 `URL | 제목` 목록을 바로 붙여넣을 수 있습니다. Pixiv 작품 링크가 아닌 항목은 자동으로 건너뜁니다.

## 추가 필터 및 다운로드 설정

'추가 필터'는 콘텐츠 등급(전체 / 전연령 / R18+ / R-18 / R-18G), AI 작품(전체 / AI 제외 / AI만), 태그(쉼표로 구분, 정확 또는 유사 일치이며 모두 일치해야 함), 최소 북마크 수, 일러스트 페이지 수, 소설 글자 수와 작품 유형(일러스트 / 만화 / 움짤)을 지원합니다. 다운로드 시 작품마다 판정하며 조건에 맞지 않는 작품은 대기열에 구체적인 건너뜀 이유가 표시됩니다.

| 다운로드 설정 | 기능 |
| --- | --- |
| 파일명 템플릿 | `{artwork_id}`, `{author_name}`, `{page}` 등의 변수 사용. [파일명 템플릿 변수](/ko/usage-guide#파일명-템플릿-변수) 참고 |
| 다운로드 폴더(컬렉션) | 저장할 로컬 컬렉션 지정 |
| 다운로드한 작품 건너뛰기 | 다운로드 기록에 있으면 바로 건너뜀 |
| 실제 디렉터리 확인 | 기록과 함께 디스크 파일의 존재 여부도 확인하고 파일이 없으면 다시 다운로드 |
| 삭제된 작품 다시 다운로드 허용 | 갤러리에서 삭제한 작품에는 [삭제 표시](/ko/gallery#작품-삭제)가 남아 기본적으로 건너뜀. 선택하면 다시 다운로드하고 삭제 표시 제거 |
| 자동 북마크 | 다운로드 완료 후 Pixiv API로 작품 북마크(유효한 Cookie 필요) |
| 소설 형식 | TXT, HTML 또는 EPUB로 저장 |

## 다운로드 설정 저장과 여러 Cookie

관리자는 다운로드 설정과 추가 필터를 프로필로 저장하고 드롭다운에서 전환할 수 있습니다. 프로필은 최대 64개까지 저장할 수 있습니다. 전환은 직접 편집과 동일하게 즉시 적용됩니다. 대기 중이거나 새로 추가한 작품은 새 설정을 사용하고, 이미 다운로드를 시작한 작품은 기존 처리를 계속합니다. Cookie, 프록시, 저장 위치, 대기열은 프로필에 포함되지 않습니다.

페이지의 현재 설정, 프로필 모음, 예약 작업은 별도로 저장됩니다. 페이지 설정을 편집해도 프로필은 덮어쓰지 않으며 프로필 저장 작업이 필요합니다. 프로필을 수정하거나 삭제해도 저장된 예약 작업은 바뀌지 않습니다. 예약 작업을 편집하면서 프로필을 적용하면 초안만 바뀌고 저장한 뒤 해당 작업에 반영됩니다. 실행 중인 수동 대기열에는 영향을 주지 않습니다. 페이지를 새로 고치면 현재 페이지 설정을 복원하며 선택한 프로필을 다시 적용하지 않습니다.

Cookie 관리는 관리자만 사용할 수 있으며 최대 8개를 저장합니다. 사용할 Cookie를 선택하고 위아래로 이동해 우선순위를 정합니다. 서버는 Cookie를 암호화해 저장하며 페이지에는 이름과 상태만 반환합니다. 기존 페이지 Cookie는 저장과 다시 읽기 검증을 마친 뒤에만 삭제합니다. 저장된 자격 증명을 예약 작업에 연결하면 후보를 복사합니다. 이후 모음이나 페이지 선택을 변경해도 작업의 사본은 바뀌지 않으므로 다시 연결해야 합니다. 사용할 후보가 없으면 대기열이 일시 정지됩니다. 자격 증명을 수정한 뒤 수동으로 계속하세요.

## 문제 해결 및 관련 문서

- **숫자로 된 소설 ID가 일러스트로 처리됨**: 전체 소설 링크를 사용하거나 숫자 ID 위에 `novel:`을 한 줄에 단독으로 추가하세요.
- **인식한 개수가 입력 줄 수보다 적음**: 빈 줄, 구역 헤더, Pixiv가 아닌 링크와 형식이 잘못된 URL을 확인하고 미리보기 목록을 기준으로 판단하세요.
- **작품을 건너뛰거나 다운로드 실패**: 대기열 항목의 구체적인 이유를 확인하세요. Pixiv 원본에서 작품에 접근할 수 있는지 확인하고 Cookie와 프록시 설정을 점검하세요([자주 묻는 질문](/ko/faq) 참고).

지정한 작가의 작품은 [작가 일괄 다운로드](/ko/user-download), 키워드로 찾으려면 [검색 다운로드](/ko/search), 정기 자동 다운로드는 [예약 작업](/ko/scheduled-tasks)을 참고하세요.
