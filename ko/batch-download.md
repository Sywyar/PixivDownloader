# URL 일괄 다운로드

작품 링크 목록이 있다면 다운로드 페이지의 단일 작품 일괄 가져오기에 붙여 넣으세요. 일러스트와 소설을 함께 입력할 수 있습니다. 소설에는 활성화된 `novel` 플러그인이, 로그인 제한 작품에는 유효한 Pixiv Cookie가 필요합니다.

## 시작하기

1. `http://localhost:6999/pixiv-batch.html`을 엽니다.
2. 단일 작품 일괄 가져오기 탭에 URL 목록을 붙여 넣습니다.
3. 정보 가져오기를 누릅니다.
4. 인식된 유형과 작품 수를 확인한 뒤 현재 화면에 따라 대기열에 추가합니다.
5. 다운로드를 시작하고 완료 후 결과를 확인합니다. 완료, 기존 파일, 필터 건너뜀, 실패는 서로 다른 결과입니다.

## 입력 형식

한 줄에 하나씩 입력하고 여러 형식을 섞을 수 있습니다. 다음 ID는 형식 예시이므로 실제 작품으로 바꾸세요.

```text
# 전체 URL
https://www.pixiv.net/artworks/12345678
https://www.pixiv.net/novel/show.php?id=87654321

# 숫자 ID는 기본적으로 일러스트
12345678
12345679 | 작품 제목

# 다음 숫자 ID의 유형 지정
artwork:
11111
22222
novel:
33333
44444 | 소설 제목

# OneTab / N-Tab 내보내기 형식
https://www.pixiv.net/artworks/55555 | 탭 제목
```

제목은 선택 사항이며 비워 두면 자동으로 가져옵니다. `artwork:`와 `novel:`은 단독 줄에 쓰며 대소문자와 전각·반각 콜론을 모두 허용합니다. 이후 숫자 ID 또는 `id | title`은 다음 분류 줄이나 입력 끝까지 해당 유형으로 처리합니다. 전체 `https://` 링크는 항상 링크 자체의 유형으로 해석합니다.

## 추가 필터

| 항목 | 선택 또는 의미 |
| --- | --- |
| 콘텐츠 등급 | 전체, 전연령, R18+, R-18, R-18G |
| AI 작품 | 전체, AI 제외, AI만 |
| 태그 | 정확히 또는 부분 일치, 쉼표로 구분하며 모두 일치해야 함 |
| 북마크 수 | 최소 북마크 수 |
| 페이지 수 | 일러스트 페이지 범위 |
| 글자 수 | 소설 글자 수 범위 |
| 작품 유형 | 일러스트, 만화, Ugoira |

필터는 실제 다운로드 때 각 작품에 적용됩니다. 조건에 맞지 않으면 등급 또는 태그 불일치 등 건너뛴 이유가 대기열에 표시됩니다.

## 다운로드 설정

- 파일명 템플릿은 `{artwork_id}`, `{author_name}`, `{page}` 등을 지원합니다. [파일명 변수](/ko/usage-guide?id=파일명-템플릿-변수)를 참고하세요.
- 다운로드 디렉터리는 저장할 로컬 컬렉션을 선택합니다.
- 이미 다운로드한 작품 건너뛰기는 다운로드 이력을 확인합니다. 실제 디렉터리 확인도 켜면 디스크에서 파일 존재 여부를 검사하고 누락된 파일을 다시 받습니다.
- 갤러리에서 삭제한 작품은 [삭제 표시](/ko/gallery?id=작품-삭제)를 유지하며 기본적으로 다운로드한 것으로 보고 건너뜁니다. 삭제된 작품의 재다운로드를 허용하면 다시 받고, 성공할 때 표시가 해제됩니다.
- 자동 북마크는 다운로드 후 Pixiv API로 북마크하며 Cookie가 필요합니다.
- 소설 형식은 TXT, HTML, EPUB을 선택할 수 있습니다.

## OneTab / N-Tab 목록

브라우저 확장에서 내보낸 `URL | 제목` 목록을 그대로 붙여 넣을 수 있습니다. 다른 사이트 등 Pixiv 작품 링크가 아닌 줄은 건너뜁니다.

## 입력과 결과가 다를 때

- 소설 ID가 일러스트로 인식되면 전체 소설 링크를 쓰거나 앞에 `novel:` 한 줄을 넣습니다.
- 작품 수가 줄 수보다 적으면 분류 줄, 빈 줄, 잘못된 링크, 다른 사이트 링크를 확인합니다.
- 건너뛴 항목은 이유를 확인한 뒤 필터나 이력 검사를 조정합니다. 삭제 표시가 자동으로 미다운로드 상태가 되지는 않습니다.
- 접근·다운로드 실패는 Pixiv에서 작품 접근 여부를 확인하고 Cookie와 백엔드 네트워크를 점검합니다. [FAQ](/ko/faq)를 참고하세요.

다른 작업은 [작가 다운로드](/ko/user-download), [검색](/ko/search), [예약 작업](/ko/scheduled-tasks)을 사용하세요.
