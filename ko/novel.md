# 소설 다운로드

`novel` 플러그인을 활성화하고 다운로드 페이지에서 소설 원본과 TXT·HTML·EPUB 형식을 선택하세요. 로컬 읽기, 합본, 번역, 듣기도 지원합니다. 번역은 번역 플러그인 설정이 필요하며 AI 낭독은 AI·TTS 설정이 필요합니다. 아래 ID는 형식 예시이며 접근 가능한 실제 소설·시리즈로 바꾸세요.

## 단일 소설과 시리즈

`pixiv-batch.html`의 단일 작품 일괄 가져오기에 소설 URL을 입력합니다.

```text
https://www.pixiv.net/novel/show.php?id=12345678
```

숫자만 입력한다면 분류 줄을 먼저 둡니다.

```text
novel:
12345678
```

형식을 고르고 다운로드를 시작하세요. 내 소설이나 북마크는 빠른 가져오기의 해당 소설 원본에서 대기열에 추가할 수 있습니다.

시리즈 모드에서는 `https://www.pixiv.net/novel/series/123456`을 입력하고 분석·미리보기를 누른 뒤 전체 또는 선택한 장을 추가합니다.

### 시리즈 합본

다운로드 설정의 시리즈 합본 생성에서 형식을 선택합니다. EPUB는 EPUB3 다단계 목차, 내장 시리즈 표지, 소개·태그·출처 메타데이터를 제공합니다. 목차·표지가 필요하면 EPUB, 본문만 필요하면 TXT를 선택하세요.

파일은 `novel-series-{seriesId}/`에 `{시리즈제목}.epub`, 번역은 `{시리즈제목}_{언어코드}.epub`로 저장합니다.

시리즈 목록 `pixiv-series.html?type=novel&seriesId=...`의 합본 다운로드에서도 원문 또는 기존 번역 언어를 선택할 수 있습니다. 백엔드가 현재 데이터베이스로 새 EPUB를 생성하므로 사전에 합본 생성을 켜 둘 필요는 없습니다. 번역이 없는 장은 원문으로 남습니다. 전체를 같은 언어로 받으려면 먼저 전체 시리즈 번역을 완료하세요.

## 형식과 읽기

| 형식 | 용도 |
| --- | --- |
| TXT | 서식 없는 일반 텍스트 |
| HTML | Ruby, 제목 등 원래 서식을 보존하며 브라우저로 열기 |
| EPUB | 전자책 리더용 목차와 표지 |

소설 갤러리는 `http://localhost:6999/pixiv-novel-gallery.html`입니다. 제목·작가·시리즈·태그 및 저장된 본문 전체 검색을 지원합니다. 작품을 누르면 `pixiv-novel.html?id=<id>`에서 본문, 태그, 작가, 시리즈 목록과 이전·다음 장을 볼 수 있습니다.

## 듣기

읽기 페이지의 듣기를 누르면 본문을 문단별로 읽습니다.

| 엔진 | 특성 |
| --- | --- |
| 브라우저, 기본 | 브라우저 음성 사용. 음성과 네트워크 필요 여부는 브라우저·시스템 서비스에 따라 다름 |
| 온라인 Edge 신경 음성 | Microsoft 온라인 TTS, 백엔드 프록시를 통한 네트워크 필요 |

재생·일시정지, 이전·다음 문단, 중지, 위치 이동, 음성·속도 선택을 지원합니다. 현재 문단을 강조하고 자동으로 스크롤합니다. 진행 위치를 저장하여 다음에 같은 소설을 이어 들을 수 있습니다.

## AI 다중 화자 낭독

관리자는 AI 모델 설정에서 OpenAI 호환 텍스트 모델과 TTS 모델을 각각 설정하고 활성화해야 합니다. TTS는 직접 실행한 VoxCPM 등의 로컬 서비스 또는 클라우드 공급자를 사용할 수 있으며 직접 GPU를 준비할 필요가 없는 공급자도 있습니다. 둘 중 하나가 없으면 듣기 엔진 목록에 감정 표현 다중 화자 항목이 나타나지 않습니다.

다중 화자 낭독은 모델이 장 전체의 문장을 내레이터와 각 인물에 배정하고 인물별 음성 프로필로 문장마다 합성해 이어 재생합니다. 분석 실패는 모델 응답을, 합성 실패는 엔진과 참조 음성을 확인하세요.

- 문장별로 합성·재생하고 다음 문장을 미리 가져옵니다. 현재 문단을 강조·스크롤하며 재생 막대에 화자와 현재 문장을 표시합니다.
- 첫 분석 전 내레이터의 따뜻한 여성·차분한 남성·중립 음색을 미리 듣고 선택할 수 있습니다. 확인하면 잠겨 이후 AI가 바꾸지 않습니다. 선택하지 않으면 기존 또는 기본 따뜻한 여성 음성을 사용합니다.
- 재생 막대의 캐스팅 버튼에서 성별·나이·영문 음성 프로필을 보고 수정·저장·미리 듣기할 수 있습니다. 저장한 프로필은 잠기며 이후 AI가 덮어쓰지 않습니다. 다시 분석하지 않아도 후속 합성에 즉시 적용됩니다.
- 내레이터를 포함한 인물별 표준 참조 음성을 생성하거나 WAV/MP3와 선택적 전사문을 업로드할 수 있습니다. 참조 음성의 음색을 복제하면서 문장별 감정을 유지합니다. 미리 듣기·삭제가 가능하고 변경 시 캐시 음성을 새 조건으로 다시 계산합니다. 설정에서 복제를 끄거나 생성 상한을 바꿀 수 있습니다.
- 본문의 근거와 잠긴 음색이 모순되거나 부족하면 충돌을 표시합니다. 제안 수용, 현재 유지, 직접 수정 중 선택합니다.
- 분할 글자 수 `0`은 장 전체를 한 요청에서 분석합니다. 숫자를 지정하면 문단을 모아 대략 해당 크기로 나누며 요청별 텍스트 양을 제한합니다.
- 화자 분석을 캐시하여 재생 때 재분석하지 않습니다. 필요하면 설정에서 재분석을 선택합니다. 지나치게 긴 본문은 한 번에 분석하지 않고 범위를 줄이도록 안내합니다.

## 번역 엔진（관리자）

`translation` 플러그인을 활성화하고 데스크톱 설정의 번역 페이지에서 엔진을 선택하세요. 저장 후 안내에 따라 백엔드를 재시작합니다. 소설과 번역이 공유하는 `novel-translation-contract`는 의존 플러그인으로 설치됩니다. 수동 번역과 다운로드 후 자동 번역은 선택한 엔진을 함께 사용합니다.

- AI는 `ai`에 저장된 모델, 기본 URL, 인증 정보를 사용합니다. OpenAI 호환 API가 있는 로컬 LLM도 기존 설정으로 사용할 수 있습니다.
- Youdao는 텍스트 번역 API의 애플리케이션 ID와 비밀 키가 필요합니다. 사전 앱의 로그인 정보로는 사용할 수 없습니다.
- LibreTranslate는 직접 준비한 서비스의 기본 URL과 필요한 경우 API 키를 입력합니다. 오프라인 사용 전 서비스와 언어 모델을 설치하고 필요한 언어를 확인하세요. 플러그인은 모델을 다운로드하거나 서비스를 시작하지 않습니다.

소설 페이지의 번역과 전체 시리즈 번역에서 본문·제목·소개 및 기존 번역 덮어쓰기·건너뛰기를 선택합니다. 결과는 원문과 함께 소설 데이터베이스에 저장되며 콘텐츠 언어, 번역 합본, 듣기에서 사용합니다.

Youdao와 LibreTranslate는 `en`, `ja`, `zh-CN` 같은 대상 언어 코드를 받으며 지원 언어는 서비스에 따라 다릅니다. 문단 단위와 최대 1,000 Unicode 코드 포인트로 나누어 요청합니다. 분할 크기 `0`은 이 상한을 사용하고 양수는 지정값과 상한 중 작은 값을 사용합니다. 이미지·페이지·점프 등 Pixiv 표시는 보존합니다. AI 용어집을 사용하거나 자동 학습하지 않으며 제목과 본문은 별도로 번역합니다. 아래의 프롬프트, 자유 입력 언어명, 용어집 설명은 AI 엔진에만 적용됩니다.

AI 인증 정보는 `ai`, Youdao·LibreTranslate 인증 정보는 `translation`, 음성 인증 정보는 `tts`가 관리합니다. 일반 듣기는 번역 플러그인이 필요하지 않습니다. 다중 화자 분석은 AI를, 음성 합성은 TTS를 계속 사용합니다.

## AI 번역

관리자 로그인과 활성 OpenAI 호환 텍스트 모델이 필요합니다. 없으면 소설·시리즈 상세에 번역 버튼이 표시되지 않습니다. 읽기 페이지에서 듣기 옆의 AI 번역을 선택하면 본문을 번역해 로컬에 저장하며 이후 다시 요청하지 않고 볼 수 있습니다.

번역 창에서 다음을 설정합니다.

| 항목 | 의미 |
| --- | --- |
| 대상 언어 | 현재 화면 언어로 미리 채우며 자유롭게 변경 가능. 실제 언어인지 AI가 확인 |
| 분할 글자 수 | 0은 전체 한 번, 예를 들어 5000은 문단 단위로 약 5000자씩 번역 후 결합 |
| 기존 번역 | 덮어쓰기 또는 건너뛰기 |

진행 창은 경과 시간을 표시합니다. 숨기기는 창만 닫으며 번역은 계속합니다. 번역 중 버튼을 다시 누르면 현재 진행 창을 엽니다. 취소는 현재 요청을 중단하고 프런트엔드 결과를 버리지만 백엔드가 데이터베이스에 저장하는 것까지 막지는 못할 수 있습니다. 장 번역이 성공하면 해당 언어의 시리즈 합본도 다시 생성합니다.

### 용어집

용어집에는 원문 용어와 언어별 번역을 저장합니다. 시리즈 소설은 기본적으로 시리즈 이름의 한 표를 공유하고 독립 소설은 소설 이름의 표를 사용합니다. 사용 안 함, 기존 다른 표, 새 표 생성도 선택할 수 있습니다.

선택한 표를 번역 요청에 함께 보내지만 모델이 벗어날 수 있으므로 결과를 확인하세요. 새 고유 명사 번역은 선택한 표에 자동 병합하여 후속 문단·장·재번역에 재사용합니다. 편집에서는 표 이름, 언어 선택·추가, 원문↔번역 쌍 추가·삭제를 차례로 진행합니다. 시리즈 번역 중 발견한 이름도 다음 장에 누적됩니다.

### 콘텐츠 언어

소설 읽기와 시리즈 목록의 콘텐츠 언어는 UI 언어와 별개이며 선택을 기억합니다. 원문·저장된 번역을 바꾸면 듣기도 현재 언어의 본문을 읽습니다. 소설 제목, 시리즈 이름·장 카드, 언어별 EPUB의 제목도 번역본으로 바뀌며 번역이 없으면 원문 제목을 씁니다.

장 제목과 본문은 같은 AI 요청과 용어집으로 번역합니다. 시리즈 이름은 별도 요청이지만 같은 언어로 완료한 장 제목의 원문·번역 쌍과 선택한 용어집을 함께 보내 명칭을 맞춥니다.

### 전체 시리즈 번역

시리즈 목록에서 전체 번역을 선택하면 장별로 순서대로 번역합니다. 단일 번역과 같은 설정을 쓰며 기존 번역을 건너뛸 수 있습니다. 해당 언어의 독립 EPUB를 만들고 번역되지 않은 장은 원문으로 남깁니다. 원문 합본은 바뀌지 않습니다.

진행 창은 탭을 닫지 말라는 안내, 단일 장 처리 시간·취소 설명, 장 번호, 성공·건너뜀·실패 수, 경과 시간을 표시합니다. 숨기면 계속 진행하고 취소하면 이후 장을 중지합니다. 완료한 번역은 데이터베이스에 남고 해당 언어 합본도 생성합니다.

기존 번역 건너뛰기에서는 먼저 작은 AI 요청으로 입력 언어를 표준 코드로 해석합니다. 이미 번역이 있는 장마다 언어 확인을 위해 전체 번역을 반복하지 않습니다. 시리즈 합본을 재생성할 때는 기존 모든 번역 언어 합본도 갱신합니다.

### 다운로드 후 자동 번역

관리자는 일괄 다운로드 또는 예약 작업의 소설 설정에서 새 소설 자동 번역을 켜고 언어·분할 글자 수를 정할 수 있습니다. 활성 텍스트 모델이 필요합니다.

자동 번역은 소설·시리즈의 기본 용어집을 필요에 따라 만들고 사용하며 다른 표를 지정하지는 못합니다. 세부 제어는 읽기 페이지에서 하세요. 시리즈 합본 생성도 켰다면 장 번역마다 해당 언어 합본을 갱신합니다.

번역은 다운로드를 막지 않고 백그라운드에서 진행합니다. 대기열과 예약의 현재 실행 상세에 번역 중 또는 앞선 시리즈 장을 기다리는 수를 표시하며 같은 시리즈는 장 순서로 처리합니다. 다운로드가 성공했다면 번역 실패는 번역 실패가 있는 완료로만 표시하고 원문 파일은 유지합니다. 결과는 콘텐츠 언어로 확인하세요.

## 소설 삭제

관리자는 읽기 페이지 또는 소설 갤러리 일괄 관리에서 삭제합니다. 프로그램 관리 파일의 본문·표지와 파생 데이터를 제거하며 화면에서 되돌릴 수 없습니다. [외부 가져오기](/ko/pixiv-batch-downloader-import)의 읽기 전용 원본은 보존합니다.

삭제 표시는 갤러리에서 숨겨지지만 이미 다운로드한 작품 건너뛰기에는 남습니다. 재다운로드 허용을 켜야 다시 받고 성공 후 해제됩니다. 일괄 관리의 모든 결과 선택, ZIP 내보내기와 선택적 원본 삭제, 컬렉션 추가, 작업 목록은 [작품 갤러리](/ko/gallery)와 같습니다.

## 결과 확인

저장한 TXT·HTML·EPUB를 열어 본문과 장 순서를 확인하고 소설 갤러리에서도 같은 작품을 엽니다. 파일만 있고 기록이 없다면 데이터베이스와 다운로드 디렉터리가 같은 인스턴스의 것인지 먼저 확인하세요. 데이터베이스 삭제로 재구성을 시도하지 마세요.

번역·낭독 메뉴가 없으면 관리자 로그인, 플러그인, 모델 설정을 확인합니다. 다운로드와 번역 성공은 별도로 판단하며 번역 실패가 이미 받은 원문을 무효화하지 않습니다.
