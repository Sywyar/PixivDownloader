# 소설 및 낭독

`novel` 플러그인을 활성화하면 개별 소설이나 소설 시리즈 전체를 TXT, HTML 또는 EPUB로 저장하고 로컬 소설 갤러리에서 읽기, 전문 검색, 번역과 낭독을 사용할 수 있습니다. 번역에는 `translation` 플러그인이 필요하며 AI 다중 화자 낭독에는 `ai`와 `tts` 플러그인을 모두 설정해야 합니다. 아래 ID는 형식 예시이므로 접근 권한이 있는 실제 작품이나 시리즈로 바꾸세요.

## 소설 및 시리즈 다운로드

### 개별 소설

1. `http://localhost:6999/pixiv-batch.html`을 열고 '단일 작품 일괄 가져오기'를 선택합니다.
2. 소설 링크를 붙여넣습니다.

   ```text
   https://www.pixiv.net/novel/show.php?id=12345678
   ```

   숫자 ID만 입력한다면 위에 `novel:` 구역 헤더를 한 줄에 단독으로 적어야 합니다.

   ```text
   novel:
   12345678
   ```

3. 다운로드 설정에서 저장 형식(TXT / HTML / EPUB)을 선택하고 대기열에 추가한 후 다운로드를 시작합니다. 자신의 소설이나 북마크는 [빠른 가져오기](/ko/quick-access)에서 바로 대기열에 추가할 수도 있습니다.

### 소설 시리즈 및 EPUB 합본

1. 다운로드 페이지에서 '시리즈 모드'를 선택하고 시리즈 링크를 붙여넣은 후 '해석하고 미리 보기'를 누릅니다.

   ```text
   https://www.pixiv.net/novel/series/123456
   ```

2. '모두 대기열에 추가'를 선택하거나 일부 장을 선택하여 대기열에 추가한 후 다운로드를 시작합니다.

| 형식 | 특징 |
| --- | --- |
| TXT | 서식 없는 일반 텍스트 |
| HTML | 루비, 제목 등 원래 서식을 유지하며 브라우저에서 바로 열 수 있음 |
| EPUB | EPUB3 준수. 다단계 목차, 내장 표지와 책 메타데이터(소개, 태그, 원본 링크) 포함 |

- **다운로드 시 합본 생성**: 다운로드 설정에서 '시리즈 합본 생성'을 선택하고 형식을 고릅니다(EPUB 권장). 파일은 `novel-series-{seriesId}/{시리즈 제목}.epub`에 저장하며 번역 합본은 `{시리즈 제목}_{언어 코드}@{엔진}.epub`입니다.
- **시리즈 목차 페이지에서 언제든 생성**: `pixiv-series.html?type=novel&seriesId=...`을 열고 '합본 다운로드'를 누른 후 읽기 언어(원문 또는 저장된 번역)와 번역 엔진을 각각 선택하면 현재 데이터베이스 상태에 따라 EPUB를 즉시 생성하고 다운로드합니다. 번역 언어를 선택했을 때 미번역 장은 원문으로 대체됩니다. 책 전체를 같은 언어로 만들려면 먼저 '전체 시리즈 번역'을 완료하세요.

## 로컬 읽기 및 전문 검색

소설 갤러리 주소:

```text
http://localhost:6999/pixiv-novel-gallery.html
```

제목, 작가, 시리즈와 태그 필터 및 로컬 색인 기반 **본문 전문 검색**을 지원합니다. 카드를 누르면 `pixiv-novel.html?id=<id>`에서 본문을 읽고 시리즈 목차를 보며 이전 / 다음 장으로 이동할 수 있습니다.

읽기 페이지 도구 모음에는 돌아가기, 듣기, 번역, 즐겨찾기 기능이 있습니다. '더 많은 작업'에서 인터페이스 언어와 화면 모드를 바꾸거나 Pixiv 원작을 열 수 있습니다. 관리자는 이 메뉴에서 소설을 내보내거나 삭제할 수도 있으며, 삭제 전에는 확인이 필요합니다.

관리자는 읽기 페이지의 '더 많은 작업'에서 내보내기를 선택하고 읽기 언어와 번역 엔진을 각각 지정해 단일 EPUB를 바로 다운로드할 수 있습니다. 압축 작업이나 임시 압축 파일을 만들지 않으며, 이미 다운로드한 원본 파일도 변경하지 않습니다.

일괄 내보내기는 소설 갤러리에서 작품을 선택한 뒤 실행합니다. 언어와 엔진을 각각 선택하고 분류 방식과 ZIP 옵션도 사용할 수 있습니다. 번역은 기존 로컬 문서의 형식으로 생성하며, 로컬 문서가 없으면 EPUB로 생성합니다. 선택한 모든 소설에 저장된 번역이 있는 조합만 제공하며, 번역되지 않은 필드는 원문을 유지합니다.

## 책 듣기(단일 음성 TTS)

소설 읽기 페이지의 '책 듣기'를 누르면 문단 순서대로 본문을 읽습니다. 현재 문단을 자동 강조하고 페이지를 스크롤하며 읽기 진행 상황을 저장합니다.

| 음성 엔진 | 설명 |
| --- | --- |
| 브라우저 엔진(기본값) | 브라우저 / 시스템 음성 서비스 호출. 사용 가능한 음성과 네트워크 필요 여부는 브라우저 및 운영체제에 따라 다름 |
| 온라인 엔진(Edge 신경망 음성) | 백엔드 프록시를 통해 Microsoft 온라인 TTS 호출. 네트워크 필요 |

## AI 다중 화자 낭독(관리자)

데스크톱 설정의 'AI 모델'에서 '텍스트 모델'(OpenAI 호환 대규모 언어 모델)과 'TTS 모델'(로컬 VoxCPM / CosyVoice 또는 클라우드 TTS)을 모두 설정하고 활성화하면 읽기 페이지에서 '다중 화자 낭독'을 사용할 수 있습니다. 하나라도 비활성화되어 있으면 '책 듣기'에 이 엔진 옵션이 표시되지 않습니다. 먼저 모델과 TTS 연결을 확인하세요. 분석 실패 시 텍스트 모델 응답을, 합성 실패 시 TTS 엔진과 참조 음성 설정을 확인하세요.

- **문장별 화자 지정 및 재생**: 대규모 언어 모델이 장 전체의 각 문장을 내레이터와 등장인물에게 배정하고 고정된 역할별 음성으로 합성합니다. 순서대로 재생하면서 다음 문장을 미리 가져오며 재생 막대에 현재 화자와 대사를 표시합니다.
- **내레이터 및 등장인물 음성 고정**: 첫 분석 전에 내레이터의 기본 음색을 미리 듣고 고정할 수 있습니다(기본값은 따뜻한 여성 음성). 등장인물 패널에서 각 역할의 성별, 나이와 영어 음성 프로필을 확인하거나 수정할 수 있습니다. 저장하면 고정되어 이후 장에서 AI가 덮어쓰지 않으며 변경 내용은 이후 합성에 즉시 적용됩니다.
- **역할별 참조 음성 복제**: 내레이터를 포함한 모든 역할에 표준 참조 음성을 생성하거나 WAV / MP3를 업로드할 수 있습니다. 전사 텍스트도 첨부할 수 있습니다. 문장과 장 사이에 같은 음색을 유지하면서 감정 변화도 보존합니다. 참조 음성을 바꾸면 새 음색으로 캐시 오디오를 자동 재생성합니다. 설정에서 복제를 끄거나 생성 상한을 조정할 수 있습니다.
- **음성 충돌 처리**: 본문의 새 근거가 고정된 등장인물 음성과 명백히 충돌하면 패널에 충돌을 표시하고 '제안 수락 / 현재 설정 유지 / 수정'을 선택하게 합니다.
- **분할 글자 수 및 캐시**: 기본값 `0`은 장 전체를 한 번의 요청으로 분석합니다. 본문이 너무 길면 거부하고 범위를 줄이라는 안내를 표시합니다. 양의 정수를 입력하면 문단을 대략 해당 글자 수까지 모아 나누어 분석합니다. 분석 결과는 로컬에 캐시되므로 다시 재생할 때 재분석할 필요가 없으며 필요하면 '다시 분석'을 누를 수 있습니다.

## 번역 엔진(관리자)

`translation` 플러그인을 설치하고 활성화합니다. 의존성인 `novel-translation-contract`도 함께 설치됩니다. 데스크톱 설정의 '번역' 페이지에서 엔진을 선택하고 저장한 후 안내에 따라 백엔드를 재시작하세요. 읽기 페이지의 수동 번역, 시리즈 번역과 다운로드 후 자동 번역은 선택한 엔진을 공유합니다.

| 엔진 | 설정 및 제한 |
| --- | --- |
| AI 모델 | `ai` 플러그인에 저장된 모델, 기본 주소와 자격 증명 재사용. 로컬 OpenAI 호환 서비스 지원 |
| Youdao | Youdao AI Cloud 텍스트 번역 API의 애플리케이션 ID와 애플리케이션 키 입력. Youdao 사전 클라이언트 계정은 사용할 수 없음 |
| LibreTranslate | 자체 호스팅 서비스의 기본 주소(`/translate` 제외)와 선택적 API Key 입력. 서비스와 언어 모델은 직접 준비해야 함 |

Youdao와 LibreTranslate는 엔진별 요청 설정에 따라 긴 텍스트를 나누고 짧은 구간을 배치로 보냅니다. 줄바꿈과 이미지·페이지·이동 Pixiv 마커는 유지합니다. 문장 끝이나 공백에서 우선 나누며, 상한보다 긴 단어는 서로게이트 쌍을 깨뜨리지 않고 유니코드 코드 포인트 단위로 나눕니다. 제목과 본문은 별도로 요청하며 AI 용어 대응표를 사용하거나 학습하지 않습니다.

데스크톱 설정의 번역 페이지에는 선택한 엔진의 요청 설정만 표시됩니다. 아래는 클라이언트 기본값입니다. 키 앞에 `translation.youdao.` 또는 `translation.libretranslate.`를 붙입니다. 저장 후 백엔드를 다시 시작하세요.

| 매개변수 | Youdao 기본값 | LibreTranslate 기본값 | 허용 범위 |
| --- | --- | --- | --- |
| `request-chars` | 5000 | 5000 | Youdao: 1–5000; LibreTranslate: 1–1,000,000 |
| `batch-size` | 50 | 10 | 1–100 |
| `request-interval-ms` | 1000 ms | 0 ms | 0–60,000 ms |
| `request-concurrency` | 1 | 1 | 1–32 |
| `max-retries` | 3 | 3 | 0–10 |
| `read-timeout-seconds` | 120 s | 120 s | 1–3600 s |
| `use-proxy` | false | false | true / false |


문자 예산은 개별 텍스트와 배치 합계 모두에 적용됩니다. Youdao의 공식 상한은 쿼리당 5000자입니다. LibreTranslate의 문자·배치·호출 제한은 배포 환경이나 API 키에 따라 다르며, 5000자는 이 클라이언트의 예산입니다. 배치 50/10개와 Youdao의 1000ms 간격도 계정 할당량을 뜻하지 않습니다. LibreTranslate는 배치 내 텍스트 수만큼 호출 할당량을 사용하므로 전송 간격에도 그 수를 곱합니다. 외부 서비스의 실제 할당량에 맞게 배치 크기도 조정하세요.

수동·시리즈·다운로드 후 자동 번역은 엔진별 동시 요청 수와 간격을 공유합니다. Youdao `411` / `412` 또는 HTTP `429`에만 대기 시간을 늘리며 현재 배치를 재시도하고 `Retry-After`를 따릅니다. 60초를 초과하는 대기는 호출 제한 오류로 반환하며, 대기 기간 중 새 작업도 조기 전송하지 않습니다. 인증 실패·시간 초과·기타 오류는 자동 재전송하지 않습니다. 선택한 장의 내용이 모두 성공한 뒤 저장하므로 실패해도 기존 번역을 보존합니다. 같은 작업을 계속하면 저장된 성공 응답을 재사용합니다. 로그에는 배치·요청·재시도·번역한 문자 수를 기록하고 원문·번역문·자격 증명은 기록하지 않습니다.
- AI 자격 증명은 `ai` 플러그인, Youdao와 LibreTranslate 자격 증명은 `translation` 플러그인, 음성 자격 증명은 `tts` 플러그인이 관리합니다.

번역 대화상자에 현재 엔진이 표시됩니다. Youdao의 대상 언어 드롭다운은 공식 언어 표를 사용하고, LibreTranslate는 설정한 서비스의 지원 언어를 가져옵니다. 불러오기에 실패하면 다시 불러올 수 있습니다. AI는 자유 입력과 용어 대응표를 유지합니다. 실패 시 원인에 맞는 해결 방법을 안내합니다. 백엔드 영어 로그에는 실행 ID, 작품 ID, 엔진, 처리 단계 및 안전한 오류 코드를 기록하며 본문이나 비밀 키는 기록하지 않습니다.

같은 소설을 같은 언어로 번역해도 엔진별 번역을 함께 저장할 수 있습니다. 덮어쓰기와 건너뛰기는 현재 엔진의 번역에만 적용됩니다. 읽기 페이지와 시리즈 페이지에서는 같은 그룹 안의 읽기 언어와 번역 엔진을 각각 선택합니다. 저장된 번역이 있는 조합만 표시하며, 원문을 선택하면 엔진은 해당 없음으로 표시됩니다. 합본 다운로드와 소설 내보내기에서도 언어와 엔진을 각각 선택하며, 듣기도 선택한 번역을 사용합니다. 엔진 기록이 없는 기존 번역은 "출처 알 수 없음"으로 보존하고 합본 파일명의 기존 언어 접미사도 유지합니다. 모든 AI 모델은 `ai` 엔진 식별자를 공유하므로 AI 모델을 바꿔도 별도의 번역 버전이 생기지는 않습니다.

번역 진행 상황은 백엔드에 저장됩니다. 페이지를 닫거나 숨겨도 작업은 계속됩니다. 번역을 다시 열어 기존 작업을 확인하고 일시 중지, 계속 또는 취소할 수 있습니다. 취소는 실행 중인 요청이 끝날 때까지 기다리며 성공한 체크포인트와 완료된 장을 보존합니다. 작업 폐기는 재확인이 필요하며 작업 기록과 체크포인트만 지우고 게시된 번역은 유지합니다.

백엔드를 다시 시작하면 미완료 작업은 일시 중지 상태로 남고 번역 서비스를 자동 호출하지 않습니다. 계속할 때 원문, 기존 번역, 엔진 주소, 모델과 분할 설정을 확인합니다. 변경되었다면 설정을 복원하거나 작업을 폐기하고 다시 번역하세요. AI 용어 문맥도 체크포인트에 보존됩니다. 중간에 잘린 모델 응답은 완성된 번역으로 게시하지 않습니다. 작업을 폐기하고 더 작은 구간으로 새 작업을 만들 수 있습니다. 모델 서비스에서 지원한다면 서비스 측 출력 제한을 조정한 뒤 계속할 수도 있습니다.

AI 응답에 필수 필드가 없거나 목표와 다른 언어가 지정되거나 언어 코드가 유효하지 않으면 작업이 일시 중지됩니다. 계속하면 유효하지 않은 부분을 다시 요청하고 나머지 저장된 성공 응답을 재사용합니다.

최대 256개 작업과 총 256 Mi UTF-16 코드 단위의 체크포인트를 보관합니다. 새 작업을 만들 때 완료 후 7일이 지난 기록을 정리하고, 용량이 가득 찼으면 가장 오래된 완료 기록을 삭제합니다. 일시 중지하거나 취소한 작업은 직접 폐기해야 합니다. 외부 서비스에서 처리했지만 응답이 로컬에 저장되지 않은 경우에는 계속할 때 같은 요청을 다시 보내 추가 비용이 발생할 수 있습니다.

## AI 번역 및 용어 매핑 테이블(관리자)

텍스트 모델을 설정하고 활성화한 후 소설 읽기 페이지나 시리즈 목차 페이지에서 '번역'을 누릅니다.

- **대상 언어**: 현재 UI 언어를 기본으로 입력하며 원하는 자연어 이름으로 바꿀 수 있습니다.
- **분할 글자 수**: `0`은 설정의 `translation.ai-segment-size`를 따릅니다(기본값 `0`은 장 전체). 양수이면 해당 길이를 목표로 단락을 묶습니다. UTF-16 코드 단위로 세는 단락 분할 목표이며 엄격한 요청 상한이 아니므로 긴 단일 단락은 초과할 수 있습니다. 컨텍스트 및 출력 토큰 상한은 AI 모델 설정에서 관리하며 문자 수를 고정 비율로 토큰 수로 바꿀 수 없습니다. 일반 번역에서 `0`은 서비스 문자 예산을 따르고, 양수는 구간을 더 작게 나눌 때 사용합니다.
- **기존 번역 처리**: '번역을 덮어써 다시 번역' 또는 '건너뛰기'를 선택합니다.
- **용어 매핑 테이블**: '원문 ↔ 각 언어 번역명'을 저장하여 고유명사 번역을 통일합니다. 시리즈 작품은 기본적으로 같은 이름의 테이블을 공유하고 개별 작품은 각자의 테이블을 사용합니다. 사용하지 않거나 기존 테이블로 전환하거나 새로 만들고 편집할 수도 있습니다. AI가 번역 중 찾은 새 고유명사는 선택한 테이블에 자동 병합하여 이후 장에서 재사용합니다. 모델이 매핑을 따르지 않을 수도 있으므로 번역을 확인하세요.
- **콘텐츠 언어 전환**: 읽기 페이지와 시리즈 페이지의 '읽기 언어'와 '번역 엔진'에서 UI 언어와 별도로 원문 또는 기존 번역을 선택할 수 있습니다. 본문, 장 제목, 시리즈 이름과 번역 EPUB 제목이 함께 전환되며 미번역 항목은 원문으로 대체합니다. 듣기도 현재 선택한 언어를 읽습니다. 장 제목과 본문은 같은 AI 요청으로 번역합니다. 시리즈 이름 번역에는 같은 언어로 번역된 장 제목 쌍과 용어 매핑 테이블을 함께 제공합니다.
- **전체 시리즈 번역**: 시리즈 페이지에서 장 순서대로 일괄 번역합니다. 백그라운드로 숨기거나 취소할 수 있으며 취소해도 번역한 장은 유지됩니다. 완료 후 `{시리즈 제목}_{언어 코드}@{엔진}.epub`를 생성합니다. '번역된 항목 건너뛰기'를 선택하면 가벼운 요청 한 번으로 대상 언어 이름을 표준 언어 코드로 해석하고 기존 번역이 있는 장을 바로 건너뜁니다. 이번 번역에서는 선택한 언어와 엔진의 합본만 갱신합니다.
- **다운로드 후 자동 번역**: 다운로드 페이지나 예약 작업의 '소설 설정'에서 '새로 다운로드한 소설 자동 번역'을 선택하고 대상 언어와 분할 글자 수를 지정합니다. 자동 번역은 작품 / 시리즈의 기본 용어 매핑 테이블을 고정으로 사용하고 백그라운드에서 시리즈 장 순서대로 실행하여 다운로드를 막지 않습니다. 다운로드 성공 즉시 완료로 기록하며 번역에 실패하면 '완료(번역 실패)'만 표시하고 저장된 원문에는 영향을 주지 않습니다.

## 삭제, 일괄 관리 및 결과 확인

관리자는 읽기 페이지에서 소설 하나를 삭제하거나 소설 갤러리의 '일괄 관리'로 필터 결과를 모두 선택하여 ZIP 일괄 내보내기, 컬렉션 추가 또는 일괄 삭제를 할 수 있습니다. 내보내기 후 원본 파일 삭제를 선택할 수 있으며 사이드바의 '작업 목록'에서 진행 상황을 확인합니다. 프로그램이 관리하는 파일은 삭제 후 UI에서 되돌릴 수 없지만 기본적으로 다시 다운로드하지 않도록 [삭제 표시](/ko/gallery#작품-삭제)를 보존합니다. [외부 다운로드 가져오기](/ko/pixiv-batch-downloader-import)로 등록한 읽기 전용 원본 파일은 유지됩니다. 전체 일괄 관리 규칙은 [작품 갤러리](/ko/gallery)와 같습니다.

다운로드 후 로컬 TXT / HTML / EPUB 파일과 소설 갤러리 기록을 각각 확인하세요. 디스크에 파일이 있지만 갤러리에 기록이 없다면 현재 데이터베이스와 다운로드 폴더가 같은 인스턴스에 속하는지 먼저 확인하세요. 재구성을 시도한다며 데이터베이스를 삭제하지 마세요.
