# 설정 참고

## 호스트 설정

### 서비스, 디버그 및 다운로드

`server.port`, 바인드 주소, GUI/CLI 모드, 디버그 로깅, 다운로드 루트, 동시 다운로드 수를 설정합니다. 운영 환경에서는 필요한 주소에만 바인드하고 다운로드 루트의 권한을 제한하세요.

### 플러그인 마켓

공식 저장소 URL, 사용자 지정 저장소, 프록시, 최대 응답 크기와 타임아웃, 서명 신뢰 루트를 설정합니다. 서명 검증을 우회하는 설정은 제공되지 않습니다.

### 외부 프록시

Pixiv, 업데이트, FFmpeg 및 일부 온라인 TTS 요청에 사용할 HTTP 프록시를 설정합니다. 호스트, 포트, 인증 및 적용 범위는 배포 환경에 맞게 지정하세요. 브라우저의 직접 연결과 SMTP는 별도 경로일 수 있습니다.

### 다중 모드 할당량과 속도 제한

다중 사용자 모드에서는 사용자별 요청 제한과 전역 동시성을 설정할 수 있습니다. 프록시 뒤에 배포할 때는 신뢰할 수 있는 프록시 CIDR만 지정해야 실제 클라이언트 주소가 올바르게 계산됩니다.

### 유지보수 시간

예약 작업을 실행하지 않을 시간대를 지정할 수 있습니다. 이미 실행 중인 작업의 중단 여부와 알림은 각 작업 정책을 따릅니다.

### HTTPS와 역방향 프록시

HTTPS 종료를 프록시에서 수행하는 경우 `Forwarded` 또는 `X-Forwarded-*` 헤더를 신뢰할 프록시만 설정하세요. 공개 클라이언트 네트워크를 신뢰 목록에 넣지 마세요.

### 언어와 데스크톱 UI

`app.language`에 `ko-KR`, `en-US`, `zh-CN`, `zh-Hant`, `ja-JP` 같은 BCP 47 태그를 지정할 수 있습니다. 비워 두면 시스템 언어를 따르며, 현재 UI 언어와 콘텐츠 번역 언어는 서로 독립적입니다.

### 업데이트 및 예약 호스트

온라인 업데이트 채널, 확인 주기, 예약 작업의 호스트 주소와 기본 프록시를 설정합니다. 변경 후 즉시 적용되는지 여부는 설정 항목과 플러그인의 수명 주기 정책에 따라 다릅니다.

### 플러그인 활성화 상태

`plugins.<plugin-id>.enabled`로 선택적 플러그인을 활성화하거나 비활성화합니다. 필수 플러그인은 비활성화할 수 없으며, 일부 변경은 백엔드 또는 소프트웨어 재시작이 필요합니다.

## 플러그인 업무 설정

각 플러그인은 자체 설정 네임스페이스를 소유합니다. 예를 들어 다운로드 워크벤치는 검색, 파일명, Cookie 및 작업 큐 설정을 관리하고, 소설 플러그인은 EPUB·TTS·AI 번역 설정을 관리합니다.

## 플러그인 인증 정보

SMTP, 푸시, LLM 및 기타 자격 증명은 해당 플러그인의 전용 설정에 저장합니다. 로그, URL, 원격 콘텐츠 및 지원 요청에 비밀 값을 포함하지 마세요.

## 현재 계약 확인

설정 변경 후 상태 페이지와 로그에서 실제 적용된 값, 플러그인 상태, 프록시 적용 범위 및 재시작 필요 여부를 확인하세요. 저장 성공만으로 런타임 적용을 가정하지 마세요.
