# 사용자 스크립트

## 사전 조건

Tampermonkey 또는 호환 사용자 스크립트 관리자를 설치하고 Pixiv 페이지에 로그인하세요. Java 백엔드 스크립트는 실행 중인 PixivDownloader 주소와 `@connect` 권한이 필요합니다.

## 스크립트 목록

- All-in-One bundle
- 페이지 작품 수집기
- 사용자 일괄 다운로드
- URL 일괄 가져오기
- 단일 작품 다운로드(Java 백엔드)
- 단일 작품 다운로드(Local Download)
- 경험 향상 도구 상자

## 설치

### 웹 관리 페이지에서 설치(권장)

다운로드 페이지의 사용자 스크립트 영역에서 원하는 스크립트를 설치합니다. 업데이트 후에는 관리자의 버전과 권한을 확인하세요.

### 릴리스에서 다운로드

릴리스의 `.user.js` 파일을 열어 사용자 스크립트 관리자에 설치합니다. All-in-One을 사용할 때 같은 기능의 독립 스크립트를 비활성화하세요.

## 사용 세부 사항

### All-in-One

모든 기능을 한 파일에서 제공하며 페이지 수집, 사용자, URL 가져오기와 도구 상자를 포함합니다.

### 페이지 수집기

검색 결과, 팔로잉 피드, 랭킹과 Pixiv 페이지에서 작품을 수집하여 백엔드 큐에 추가합니다.

### 사용자 및 URL 일괄

사용자 페이지의 작품 ID를 수집하거나 URL 목록을 검증해 다운로드합니다. 각 항목의 성공·실패·건너뜀 상태를 확인하세요.

### 단일 작품 다운로드

Java 백엔드 버전은 서버의 Cookie·프록시·이력을 사용하고, Local Download 버전은 브라우저 저장소만 사용합니다.

### 경험 향상 도구 상자

다운로드 표시, Cookie 가져오기와 Pixiv 페이지 보조 기능을 제공합니다.

### 다운로드 이력과 삭제 작품

기본적으로 이미 다운로드한 작품은 건너뜁니다. 갤러리에서 삭제된 작품을 다시 받으려면 해당 옵션을 활성화하세요.

## 로컬호스트가 아닌 배포

스크립트 헤더의 `@connect`를 실제 서버 호스트로 바꾸고 HTTPS·인증·프록시 정책을 확인합니다. 임의의 공개 호스트를 허용하지 마세요.

## FAQ

페이지에 패널이 없으면 스크립트 활성화, 대상 URL, Cookie와 `@connect` 권한을 확인하세요. All-in-One과 독립 스크립트가 동시에 활성화되면 패널이 두 개 표시됩니다. "Backend Unavailable"은 서버 주소·포트·로그인 상태를 확인하세요.
