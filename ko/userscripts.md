# 사용자 스크립트

Pixiv 페이지에서 작품을 보다가 다운로드 대기열에 바로 추가할 수 있습니다. 사용자 스크립트는 선택 사항이며 대부분의 다운로드는 `pixiv-batch.html`에서 할 수 있습니다.

스크립트 목록과 설치 API는 호스트가 제공하므로 다운로드 작업대에 의존하지 않습니다. 활성 플러그인이 선언한 스크립트만 설치할 수 있습니다. 작업대를 끄면 해당 다운로드 보조 스크립트가 목록에서 사라지지만 다른 플러그인의 스크립트는 사용할 수 있습니다. solo 모드에서는 로그인이 필요하며, 백엔드 `@updateURL`을 지정해도 Tampermonkey 백그라운드 요청이 세션을 포함한다고 보장할 수 없습니다.

## 준비

브라우저에 [Tampermonkey](https://www.tampermonkey.net/)를 설치하세요. Java 백엔드 다운로드나 Toolbox를 쓸 때는 PixivDownloader 백엔드가 실행 중이고 개인 모드에서 로그인한 상태여야 합니다. 순수 브라우저 **Local Download**는 백엔드가 필요 없으며 갤러리에 등록하지 않습니다.

## 스크립트 선택

| 스크립트 | 용도 |
| --- | --- |
| All-in-One | 내장 다운로드 보조 스크립트 묶음, 플러그인 별도 스크립트 제외 |
| Page Scrape | 검색·랭킹 등 목록에서 작품 선택 |
| User Batch | 작가 프로필의 전체 작품 다운로드 |
| URL Batch | Pixiv 페이지에서 링크 목록 붙여 넣기 |
| 단일 작품 Java 백엔드 | 작품 페이지에서 백엔드로 다운로드 |
| 단일 작품 Local Download | 브라우저로 직접 다운로드, Java 불필요 |
| Toolbox | 다운로드한 작품 테두리 표시와 Cookie 가져오기 |

[PixivBatchDownloader 가져오기 지원](/ko/pixiv-batch-downloader-import)은 별도 공식 플러그인과 스크립트를 설치해야 합니다. 플러그인 설치 후 프로그램을 재시작하고 스크립트를 개별 설치하세요. All-in-One에는 포함되지 않습니다.

## 설치

### 프로그램의 웹페이지에서 설치

1. 백엔드를 실행하고 `http://localhost:6999/pixiv-batch.html`을 엽니다.
2. 사용자 스크립트 메뉴에서 원하는 스크립트의 설치를 누릅니다.
3. Tampermonkey 확인 화면에서 설치합니다.
4. 다운로드 페이지와 Pixiv 페이지를 새로 고치고 감지 결과와 실제 패널을 확인합니다.

이 경로는 현재 백엔드 주소에 맞게 `@connect` 권한을 설정합니다.

### 저장소의 독립 스크립트 설치

1. [소스 저장소](https://github.com/Sywyar/PixivDownloader)에서 버전 관리되는 독립 `.user.js` 파일을 선택하고 Raw 내용을 엽니다.
2. Tampermonkey에서 설치하거나 파일을 내려받아 관리 화면으로 가져옵니다.
3. 백엔드 주소와 호스트 권한을 설정하고 Pixiv 페이지를 새로 고쳐 확인합니다.

All-in-One은 빌드 중 생성하므로 현재 백엔드에서 설치하세요. 현재 배포 workflow는 독립 유저스크립트를 Release 첨부로 올리지 않습니다.

## 기능별 사용

All-in-One을 설치했다면 묶음에 포함된 독립 스크립트는 비활성화하여 이중 패널을 피하세요. 플러그인의 별도 가져오기 스크립트는 계속 켜 둡니다.

**Page Scrape**는 Pixiv 검색, 팔로우 신작, 랭킹 등의 목록에서 썸네일 모서리에 선택 상자를 표시합니다. 작품을 고르고 패널의 다운로드를 누릅니다. 대기열에 추가한 작품은 테두리로 표시합니다.

**User Batch**는 `/users/<id>`와 하위 페이지에서 작가 전체 작품을 추가하며 일러스트와 소설을 구분합니다. **URL Batch**는 Pixiv의 어느 페이지에서나 패널을 열어 링크 목록을 입력할 수 있으며 다운로드 페이지의 단일 작품 일괄 가져오기와 같은 용도입니다.

**Java 백엔드 단일 작품**은 `/artworks/<id>`에서 다운로드 버튼을 표시하고 메타데이터, 자동 북마크 등을 백엔드로 처리합니다. **Local Download**는 작품 페이지에서 브라우저로 바로 저장하며 메타데이터나 갤러리 데이터베이스 기록을 만들지 않습니다.

**Toolbox**는 Pixiv 페이지 오른쪽에 도구를 표시하며 각 기능을 따로 켜거나 끌 수 있습니다. 서버 데이터베이스에 있는 작품의 썸네일에 색 테두리를 표시하고 Cookie를 읽어 서버에 저장할 수 있습니다. Cookie 가져오기에는 별도 HttpOnly 권한이 필요합니다.

## 과거 다운로드와 삭제 작품

다운로드 스크립트의 과거 다운로드 건너뛰기를 켜면 이력을 확인합니다. 하위 옵션은 다음과 같습니다.

- 실제 디렉터리 확인: 기록뿐 아니라 파일 존재 여부도 검사하여 누락된 파일을 다시 받습니다.
- 삭제한 작품 재다운로드 허용: 갤러리에서 지운 작품의 [삭제 표시](/ko/gallery?id=작품-삭제)를 미다운로드로 취급합니다. 기본적으로는 이미 다운로드했지만 삭제한 작품으로 건너뛰며, 다시 다운로드에 성공하면 표시가 해제됩니다.

## 다른 호스트나 포트에 연결

기본 주소는 `http://localhost:6999`입니다.

1. 스크립트 설정에서 실제 프로토콜, 호스트, 포트를 입력합니다.
2. 해당 백엔드 웹페이지에서 스크립트를 다시 설치해 현재 호스트의 `@connect` 권한을 받습니다. 직접 설치했다면 헤더의 호스트 권한을 확인합니다.
3. Pixiv 페이지를 새로 고치고 작품 하나를 제출해 목표 백엔드 대기열에 들어오는지 확인합니다.

`@connect`는 접근 허용 목록입니다. 이것만 바꿔도 실제 요청 주소가 다른 서버로 바뀌지는 않습니다.

## 문제 해결

**Pixiv에 패널이 없다면** 브라우저 확장과 스크립트가 활성화되어 있는지 확인하고 페이지를 새로 고치세요. 현재 URL이 `@match`에 맞아야 합니다. 예를 들어 User Batch는 `/users/`에서 표시됩니다.

**패널이 두 개라면** All-in-One과 같은 기능의 독립 스크립트 중 하나만 켜세요. 두 버전의 저장 데이터는 서로 독립적입니다.

**다운로드 페이지에서 감지하지 못했다면** 현재 페이지가 응답을 받지 못했다는 뜻입니다. 설치되지 않았다는 증거는 아닙니다. 활성 상태, 사이트 권한, 설치 출처를 확인하고 현재 백엔드에서 설치한 뒤 새로 고치세요. 설치 가능한 버전과 실제 응답 버전은 별개이며 설치 버튼을 누른 기록만으로 실행 성공을 판단하지 않습니다.

**백엔드 연결이 실패하면** 서비스 실행 여부와 스크립트의 주소·포트를 확인합니다. 백엔드 방식은 대기열 완료와 파일 열기로, Local Download는 브라우저 다운로드 결과로 성공을 확인하세요. Cookie는 [첫 다운로드](/ko/first-download)의 HttpOnly 안내를 따르며 일반 `document.cookie`를 완전한 로그인 자격 증명으로 간주하지 마세요.
