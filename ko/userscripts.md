# 사용자 스크립트

Tampermonkey 스크립트를 사용하면 Pixiv 웹페이지에서 작품을 직접 선택하거나 가져오고 로컬 백엔드에 작업을 보낼 수 있습니다. 사용자 스크립트는 선택 사항이며 설치하지 않아도 `pixiv-batch.html`에서 일괄 다운로드할 수 있습니다.

스크립트 목록과 설치 API는 애플리케이션 호스트가 제공하며 `download-workbench`에 의존하지 않습니다. 호스트는 현재 활성화된 플러그인이 선언한 스크립트만 표시합니다. 다운로드 작업 화면을 비활성화하면 해당 다운로드 도우미 스크립트가 제거되지만 외부 가져오기 플러그인 등 다른 플러그인이 선언한 스크립트는 계속 설치할 수 있습니다. 개인용 모드에서 백엔드에 연결하려면 먼저 이 프로그램에 로그인해야 합니다. `@updateURL`이 백엔드를 가리키더라도 Tampermonkey의 백그라운드 업데이트 요청에 로그인 세션이 포함된다고 보장하지 않습니다.

## 사전 준비 및 스크립트 목록

브라우저에 [Tampermonkey](https://www.tampermonkey.net/)가 필요합니다. Java 백엔드용 스크립트나 도구 모음을 사용하려면 백엔드가 실행 중이며 개인용 모드로 로그인되어 있어야 합니다. 브라우저 전용 `Local Download`는 백엔드가 필요 없지만 메타데이터 기록이나 갤러리 등록을 하지 않습니다.

| 스크립트 이름 | 적용 위치 및 용도 |
| --- | --- |
| All-in-One 통합 패키지 | 내장 다운로드 도우미 스크립트와 도구 모음 통합. 외부 가져오기 등 다른 플러그인 스크립트는 포함하지 않음 |
| 페이지 일괄 다운로더(Page Scrape) | 검색, 팔로우 활동, 랭킹 등 목록 페이지의 썸네일을 선택하여 일괄 대기열 추가 |
| User 일괄 다운로더(User Batch) | 작가 프로필(`/users/<id>` 및 하위 페이지)에서 일러스트 / 소설의 전체 작품을 한 번에 대기열에 추가 |
| URL 일괄 가져오기(URL Batch) | 모든 Pixiv 페이지에서 플로팅 패널을 열고 URL을 붙여넣어 일괄 다운로드 |
| 단일 작품 다운로더(Java 백엔드용) | 단일 작품 페이지(`/artworks/<id>`)에서 백엔드로 다운로드. 메타데이터와 자동 북마크 유지 |
| 단일 작품 다운로더(Local Download) | 단일 작품 페이지에서 브라우저로 직접 파일 저장. Java 백엔드가 필요 없으며 갤러리 데이터베이스에 등록하지 않음 |
| 탐색 경험 향상 도구 상자(Toolbox) | Pixiv 페이지 오른쪽에 다운로드한 작품의 색상 테두리 표시, Cookie 한 번에 가져오기 등 제공 |

[외부 다운로드 가져오기](/ko/pixiv-batch-downloader-import) 스크립트는 `pixiv-batch-downloader-import` 플러그인이 별도로 제공하며 All-in-One에 포함되지 않습니다. 플러그인을 설치하고 재시작한 후 해당 스크립트를 별도로 설치하세요.

## 설치 순서

### 방법 1: 백엔드 다운로드 페이지에서 설치(권장)

1. PixivDownloader를 시작하고 `http://localhost:6999/pixiv-batch.html`을 엽니다.
2. '사용자 스크립트'를 펼치고 원하는 스크립트의 '설치' 버튼을 누른 후 Tampermonkey에서 확인합니다.
3. 다운로드 페이지와 열려 있는 Pixiv 페이지를 새로고침하여 스크립트 상태와 페이지의 플로팅 패널을 확인합니다.

백엔드에서 설치하면 응답이 스크립트의 `@connect`를 현재 백엔드 호스트로 자동 설정합니다. **All-in-One 통합 패키지**를 설치했다면 그 안에 포함된 개별 다운로드 스크립트는 비활성화하여 패널이 두 개 나타나지 않도록 하세요. 두 종류의 로컬 저장소는 서로 독립적입니다.

### 방법 2: 소스 저장소에서 개별 스크립트 설치

[소스 저장소](https://github.com/Sywyar/PixivDownloader)에서 커밋된 `.user.js`의 Raw 내용을 열어 Tampermonkey로 설치한 후 스크립트 설정의 백엔드 주소와 `@connect` 권한을 확인하세요. All-in-One 통합 패키지는 빌드할 때 생성되며 릴리스 절차에서 별도 userscript Release 첨부 파일을 업로드하지 않습니다. 실행 중인 백엔드에서 직접 설치하세요.

## 이전 다운로드 건너뛰기 및 다른 컴퓨터에 배포

각 백엔드 다운로드 스크립트의 설정 패널은 '이전 다운로드 건너뛰기'를 지원합니다. 켜면 다음 옵션도 선택할 수 있습니다.

- **실제 디렉터리 확인**: 디스크 파일이 있는지도 확인하고 파일이 없으면 다시 다운로드합니다.
- **삭제된 작품 다시 다운로드 허용**: 갤러리에서 삭제한 작품에는 [삭제 표시](/ko/gallery#작품-삭제)가 남아 기본적으로 이미 다운로드한 것으로 처리하여 건너뜁니다. 선택하면 다시 다운로드하고 성공 후 삭제 표시를 제거합니다.

백엔드가 다른 컴퓨터나 기본값이 아닌 포트에 배포되어 있다면(기본값 `http://localhost:6999`):

1. 스크립트 설정에서 백엔드 주소를 실제 프로토콜, 호스트와 포트로 바꿉니다.
2. 해당 백엔드의 Web 페이지에서 스크립트를 다시 설치하여 `@connect` 호스트 권한을 갱신합니다. 수동 설치한 스크립트는 헤더의 `@connect`를 확인해야 합니다. `@connect`만 바꿔도 요청 대상은 변경되지 않습니다.
3. Pixiv 페이지를 새로고침하고 작품 하나를 제출하여 대상 백엔드 대기열이 작업을 받는지 확인합니다.

## 자주 발생하는 문제

- **Pixiv 페이지에 스크립트 패널이 나타나지 않음**: Tampermonkey 확장 프로그램과 해당 스크립트가 모두 활성화되어 있는지, 현재 URL이 스크립트의 `@match` 규칙에 맞는지 확인하고 새로고침하세요. 예를 들어 User Batch는 `/users/` 페이지에만 적용됩니다. Chrome 138+에서는 확장 프로그램 상세 정보에서 '사용자 스크립트 허용'도 켜야 합니다.
- **다운로드 페이지에 '감지되지 않음' 표시**: 현재 페이지가 스크립트의 페이지 내 메시지 응답을 받지 못했다는 뜻이며, 설치되지 않았다는 뜻은 아닙니다. 현재 백엔드에서 다시 설치하고 다운로드 페이지를 새로고침하세요. 목록에서 설치 가능한 버전과 스크립트가 실제 실행하는 버전은 각각 집계됩니다.
- **'백엔드 중지됨' 또는 '연결 실패' 표시**: 백엔드 프로세스 상태, 개인용 모드 로그인 상태와 스크립트의 백엔드 주소를 확인하세요. Cookie 한 번에 가져오기가 실패하면 [첫 다운로드](/ko/first-download#방법-c-사용자-스크립트의-39cookie-한-번에-가져오기39)에 따라 Tampermonkey의 HttpOnly Cookie 권한을 확인하세요.
