# 첫 다운로드

## 사전 조건

- [최초 설정](/ko/first-setup)을 완료합니다.
- 브라우저에서 `http://localhost:6999/pixiv-batch.html`을 엽니다.
- 로그인한 Pixiv Cookie를 준비합니다(공개 작품만 다운로드할 때는 선택 사항).

## 새 사용자 안내

첫 방문에는 설정과 Cookie 입력을 안내하는 화면이 표시됩니다. 안내를 닫아도 설정 메뉴에서 다시 열 수 있습니다.

## 1단계: 다운로드 페이지 열기

다운로드 페이지에서 빠른 가져오기, URL 일괄, 사용자, 검색 또는 시리즈 모드를 선택합니다.

## 2단계: Pixiv Cookie 가져오기

Pixiv에 로그인한 상태에서 Cookie 안내의 방법으로 Cookie를 복사합니다. Tampermonkey를 사용하는 경우 Cookie 가져오기 사용자 스크립트를 사용할 수 있습니다. Cookie는 공개 저장소나 채팅에 붙여 넣지 마세요.

## 3단계: 작품 다운로드

Pixiv 작품 페이지에서 작품 URL을 복사하여 URL 일괄 입력란에 붙여 넣고 정보를 가져옵니다. 제목, 작가, 페이지 수와 다운로드 옵션을 확인한 뒤 대기열에 추가하세요.

## 4단계: 진행률 확인

상태 영역에서 대기, 다운로드 중, 완료, 건너뜀 및 실패 항목을 확인합니다. 작품을 클릭하면 이미지·Ugoira·소설 단계별 진행률과 마지막 메시지를 볼 수 있습니다.

## 5단계: 파일 찾기

설정된 다운로드 루트 아래의 작품·작가 디렉터리에서 파일을 확인하세요. 작품 옆의 메타데이터 파일은 원본 정보와 공식 번역을 보존합니다.

## 6단계: 갤러리에서 보기

완료 후 [작품 갤러리](/ko/gallery)에서 검색, 필터, 컬렉션과 상세 정보를 사용할 수 있습니다.

## FAQ

- 정보 가져오기가 실패하면 Cookie, 프록시와 Pixiv 응답 상태를 확인하세요.
- 완료됐지만 파일이 보이지 않으면 설정된 다운로드 루트와 작업 디렉터리를 확인하세요.
- 여러 작품은 [URL 일괄 다운로드](/ko/batch-download) 또는 [작가 일괄 다운로드](/ko/user-download)를 사용하세요.
