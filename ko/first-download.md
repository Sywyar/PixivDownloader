# 첫 다운로드

Pixiv 일러스트 하나를 입력하고 다운로드한 뒤 파일과 갤러리 기록을 확인하는 안내입니다. 예시 ID는 형식 설명용이므로 실제로 접근 가능한 작품으로 바꾸세요. 프로그램이 실행 중이며 [최초 설정](/ko/first-setup)을 마친 상태에서 시작합니다.

## 처음 표시되는 사용 안내

관리자로 다운로드 페이지를 처음 열면 페이지를 이동하며 사용 방법을 안내합니다. 개인 모드와 다중 사용자 모드의 로그인한 관리자에게 적용됩니다.

1. 사용할 호칭을 묻고 백엔드에서 Pixiv까지의 연결과 왕복 지연을 확인합니다. 실패하면 프록시와 네트워크를 점검하도록 안내합니다.
2. Cookie, 사용자 스크립트, 다운로드 방식 탭을 소개하고 단일 작품 일괄 가져오기를 예로 사용합니다.
3. 작품 링크 입력, 대기열 추가, 필터와 다운로드 설정, 시작 순서로 진행합니다. 상태와 대기열을 강조하고 진행률을 표시합니다.
4. 완료하면 갤러리로 이동해 보기, 검색, 필터, 작품 목록을 설명하고 상세 페이지의 이미지, 기능, 설명, 작가, 시리즈와 관련 작품을 소개합니다.

언제든 건너뛸 수 있습니다. 다운로드 페이지 오른쪽 아래의 사용 안내 버튼으로 다시 볼 수 있으며, 호칭을 이미 정했다면 연결 확인부터 시작합니다. 다중 사용자 모드에서 로그인하지 않은 방문자에게는 이 안내가 표시되지 않습니다.

호칭은 저장되어 갤러리와 소설 갤러리 사이드바의 사용자 카드, 예약 작업 알림과 메일 테스트의 인사말에 사용됩니다. 비워 두면 관리자로 표시됩니다. 안내를 건너뛰었다면 아래 순서를 따르세요.

## 1. 다운로드 페이지 열기

```text
http://localhost:6999/pixiv-batch.html
```

처음에는 새 작업대 `pixiv-batch-alt.html`이 열립니다. 기존 화면 선택은 유지되며 다운로드 페이지에서 바꿀 수 있습니다. 두 주소 모두 저장된 화면 설정을 따릅니다. 로그인이 필요하면 최초 설정에서 만든 프로그램 관리자 계정을 입력하세요. 주소를 잊었다면 데스크톱 상태 페이지의 일괄 다운로드 바로가기를 사용합니다.

## 2. Pixiv Cookie 저장

Cookie는 Pixiv 로그인 자격 증명입니다. R-18/R-18G, 검색, 빠른 가져오기, 로그인이 필요한 콘텐츠에 사용됩니다. Cookie가 없으면 R-18/R-18G 작품을 건너뛰지만 공개 전연령 작품은 다운로드할 수 있습니다.

먼저 브라우저에서 [Pixiv](https://www.pixiv.net/)에 로그인하세요. 백엔드에 필요한 항목은 `PHPSESSID`이며 전체 Cookie를 저장해도 됩니다. 로그인한 계정의 값은 보통 `12345678_xxxxxxxx` 형식입니다.

### 방법 A: Cookie-Editor

1. Chrome/Edge에 [Cookie-Editor](https://chromewebstore.google.com/detail/cookie-editor/hlkenndednhfkekhgcdicdfddnkalmdm)를 설치하고 Pixiv에서 확장 아이콘을 누릅니다.
2. **Export → Netscape → Copy Export**로 내용을 복사합니다.
3. 프로그램에 붙여 넣을 때 **Netscape** 형식을 선택합니다.

### 방법 B: 개발자 도구의 Cookies

1. Pixiv에서 F12를 누르고 **Application → Storage → Cookies → `https://www.pixiv.net`**을 선택합니다.
2. 이름이 `PHPSESSID`인 행의 **Value**를 복사합니다.
3. `PHPSESSID=복사한값`으로 입력하고 **Header String**을 선택합니다.

여러 Cookie는 `이름=값; 이름2=값2`로 연결할 수 있습니다. `PHPSESSID`는 HttpOnly이지만 Application 패널에서는 값을 확인할 수 있으므로 사용자 스크립트 권한을 바꿀 필요가 없습니다.

### 방법 C: 요청 헤더

1. Pixiv에서 F12를 누르고 **Network**를 연 뒤 페이지를 새로 고칩니다.
2. `www.pixiv.net`으로 보내는 요청을 선택합니다.
3. **Headers → Request Headers → Cookie**의 전체 값을 복사합니다.
4. 프로그램에서 **Header String**을 선택합니다.

이 값은 이미 `이름=값; 이름2=값2` 형식이며 `PHPSESSID`를 포함합니다.

### 방법 D: 사용자 스크립트의 Cookie 가져오기

경험 개선 도구 모음 **Toolbox** 스크립트를 설치한 뒤 다운로드 페이지의 Cookie 카드에서 한 번에 가져오기를 누릅니다. 스크립트가 Pixiv 페이지를 열어 Cookie를 읽고 백엔드에 전달하므로 직접 복사하거나 형식을 고를 필요가 없습니다.

!> 이 방법에는 HttpOnly Cookie 읽기 권한이 필요합니다. 없으면 `PHPSESSID`를 찾지 못했다는 메시지가 나옵니다. Tampermonkey 설정의 구성 모드를 고급으로 바꾸고 보안의 Cookie 접근 허용을 **All**로 설정해야 합니다.

!> **All**을 계속 유지하면 설치된 다른 사용자 스크립트도 로그인 자격 증명을 읽을 수 있습니다. 필요한 동안만 켜고 가져온 뒤 **All except HttpOnly**로 되돌리세요. 권한을 바꾸고 싶지 않다면 개발자 도구를 이용하는 B 또는 C를 사용하세요.

### 복사한 Cookie 입력

A/B/C 방법을 사용했다면 다운로드 페이지에서 Cookie 설정을 펼칩니다. 위치는 화면 구성에 따라 다릅니다.

1. A는 **Netscape**, B/C는 **Header String**을 선택합니다.
2. 복사한 값을 붙여 넣고 Cookie 저장을 누릅니다.

D는 자동 전달하므로 이 단계가 필요 없습니다. Cookie의 유효성은 Pixiv가 결정합니다. 로그인이 만료되면 브라우저에서 계정을 확인한 뒤 다시 가져와 저장하세요. Cookie를 스크린샷, 로그, Issue에 포함하지 마세요.

## 3. 작품 추가와 다운로드

Pixiv 작품 페이지의 주소를 복사합니다. 다음 주소와 숫자는 형식 예시입니다.

```text
https://www.pixiv.net/artworks/12345678
```

숫자 ID `12345678`만 입력해도 됩니다. 다운로드 페이지에서 단일 작품 일괄 가져오기를 선택하고 한 줄에 링크 하나씩 붙여 넣으세요. 정보 가져오기를 누르고 미리보기의 작품을 확인한 뒤 현재 화면에 따라 대기열에 추가하고 다운로드를 시작합니다.

## 4. 결과 확인

| 상태 | 의미 |
| --- | --- |
| 대기 | 실행 순서를 기다림 |
| 다운로드 중 | 파일을 받는 중 |
| 완료 | 다운로드 성공 |
| 이미 존재하여 건너뜀 | 이전에 다운로드한 작품 |
| 실패 | 항목을 눌러 오류 원인 확인 |

## 5. 파일 찾기

먼저 데스크톱 상태 페이지에서 실제 다운로드 디렉터리를 확인하세요. 기본 설정은 프로그램 작업 디렉터리 아래의 `pixiv-download/`입니다. 아래는 기본 루트의 예시이며 컬렉션이나 플러그인에서 지정한 경로는 다를 수 있습니다.

```text
(작업 디렉터리)/
└── pixiv-download/
    └── 123456/
        ├── 123456_p0.jpg
        ├── 123456_p1.jpg
        └── ...
```

Windows 설치에서는 선택한 설치 위치와 데스크톱에 표시된 실제 작업·다운로드 디렉터리를 확인하세요. JAR 실행에서는 `java -jar`를 실행한 디렉터리가 작업 디렉터리입니다. GUI 상태 페이지에서도 다운로드 디렉터리를 볼 수 있습니다.

다운로드 루트는 `config/config.yaml`의 `download.root-folder`이며 컬렉션별 경로도 지정할 수 있습니다. 상대 경로는 작업 디렉터리를 기준으로 합니다. 설정만 바꿔도 기존 파일이 이동하는 것은 아닙니다. 이동은 [저장 원칙](/ko/storage)을 따르세요.

## 6. 갤러리 확인

`gallery` 플러그인이 활성화되어 있다면 다음 주소에서 작품을 확인합니다.

```text
http://localhost:6999/pixiv-gallery.html
```

자세한 사용법은 [작품 갤러리](/ko/gallery)를 참고하세요.

## 문제가 생겼을 때

- Cookie가 필요하다고 표시되면 로그인해야 볼 수 있는 작품인지 확인하고 Cookie를 저장합니다.
- 프록시 연결 실패라면 프록시 실행 상태와 `config/config.yaml`의 주소·포트를 확인합니다.
- 작품이 없다고 표시되면 삭제되었거나 비공개로 바뀌었는지 Pixiv에서 확인합니다.
- 완료했지만 파일을 찾지 못하면 실제 다운로드 루트, 컬렉션 경로, 작업 디렉터리를 확인합니다.

여러 링크는 [URL 일괄 다운로드](/ko/batch-download), 작가 전체는 [작가 일괄 다운로드](/ko/user-download), 키워드는 [검색 다운로드](/ko/search)를 사용하세요.
