# 첫 다운로드

이 튜토리얼에서는 Pixiv 작품 하나를 가져와 다운로드하고 로컬 파일과 갤러리에서 확인합니다. 시작하기 전에 [설치 및 실행](/ko/installation)과 [초기 설정](/ko/first-setup)을 완료하세요. 아래 작품 ID는 형식 예시이므로 접근 권한이 있는 실제 작품으로 바꾸세요.

## 1. 다운로드 작업 화면 열기

브라우저에서 `http://localhost:6999/pixiv-batch.html`에 접속하고 관리자 계정으로 로그인합니다. 데스크톱 GUI의 '상태' 페이지에서 '일괄 다운로드'를 눌러 열 수도 있습니다. 새 환경에서는 기본적으로 새 레이아웃인 `pixiv-batch-alt.html`이 열립니다. 페이지 상단에서 신구 레이아웃을 전환할 수 있으며 선택한 설정은 자동 저장됩니다.

관리자로 처음 로그인하면 여러 페이지에 걸친 시작 안내가 자동으로 시작됩니다. 호칭 설정, Pixiv 연결 검사, Cookie와 사용자 스크립트, 단일 작품의 대기열 추가 및 다운로드, 갤러리 탐색을 차례로 소개합니다. 안내에서 입력한 호칭은 갤러리 사이드바 카드와 시스템 알림 이메일의 인사말에 사용되며 비워 두면 기본적으로 '관리자'가 표시됩니다. 안내는 언제든 건너뛸 수 있고 페이지 오른쪽 아래의 '사용 안내'에서 다시 열 수도 있습니다.

## 2. Pixiv Cookie 저장(필요한 경우)

공개된 전연령 일러스트는 Cookie 없이 직접 다운로드할 수 있습니다. **R-18 / R-18G 작품, 검색 다운로드, 빠른 가져오기와 로그인이 필요한 작품에는 유효한 `PHPSESSID`가 포함된 Cookie가 필요합니다.** 설정하지 않으면 접근이 제한된 작품은 건너뜁니다. 먼저 브라우저에서 [Pixiv](https://www.pixiv.net/)에 로그인한 후 다음 방법 중 하나로 Cookie를 가져오세요.

### 방법 A: 브라우저 개발자 도구(권장, 추가 확장 프로그램 권한 불필요)

1. 로그인한 Pixiv 페이지에서 `F12`를 눌러 개발자 도구를 엽니다.
2. **Application(애플리케이션) 패널**: 왼쪽의 `Storage → Cookies → https://www.pixiv.net`을 펼치고 `PHPSESSID`를 찾아 `Value`를 복사한 다음 `PHPSESSID=복사한 값` 형태로 만듭니다.
3. 또는 **Network(네트워크) 패널**에서 페이지를 새로고침하고 `www.pixiv.net`으로 보내는 요청을 하나 선택하여 `Request Headers → Cookie`의 전체 값을 복사합니다.
4. 다운로드 페이지에서 'Cookie'를 펼치고 형식으로 **Header String**을 선택한 다음 내용을 붙여넣고 'Cookie 저장'을 누릅니다.

### 방법 B: Cookie-Editor 확장 프로그램

1. [Cookie-Editor](https://chromewebstore.google.com/detail/cookie-editor/hlkenndednhfkekhgcdicdfddnkalmdm)를 설치하고 로그인한 Pixiv 페이지에서 확장 프로그램 아이콘을 누릅니다.
2. `Export → Netscape`를 눌러 내보낸 내용을 복사합니다.
3. 다운로드 페이지의 'Cookie'에서 **Netscape** 형식을 선택하고 붙여넣은 후 저장합니다.

### 방법 C: 사용자 스크립트의 'Cookie 한 번에 가져오기'

1. '탐색 경험 향상 도구 상자(Toolbox)' 스크립트를 설치하고 활성화합니다([사용자 스크립트](/ko/userscripts) 참고).
2. Tampermonkey의 '설정 → 설정 모드: 고급 → 보안'에서 '스크립트의 Cookie 접근 허용'을 임시로 `전체 / All`로 설정합니다.
3. 다운로드 페이지의 Cookie 영역에서 'Cookie 한 번에 가져오기'를 누릅니다. 스크립트가 `PHPSESSID`를 읽어 백엔드에 전달합니다.

!> `PHPSESSID`는 HttpOnly Cookie여서 Tampermonkey가 기본적으로 읽을 수 없습니다. 하지만 권한을 `전체 / All`로 설정하면 브라우저의 모든 사용자 스크립트가 로그인 자격 증명을 읽을 수 있습니다. 가져오기에 성공하면 즉시 `All except HttpOnly`로 되돌리거나 위의 개발자 도구 방법을 우선 사용하세요. Cookie를 스크린샷, 로그나 Issue에 붙여넣지 마세요.

## 3. 작품 추가 및 다운로드 시작

1. 다운로드 페이지에서 '단일 작품 일괄 가져오기'를 선택합니다.
2. 작품 링크 또는 숫자로 된 일러스트 ID를 한 줄에 하나씩 붙여넣습니다.

   ```text
   https://www.pixiv.net/artworks/12345678
   ```

3. '정보 가져오기'를 누르고 미리보기의 작품 제목과 유형을 확인합니다.
4. 작품을 대기열에 추가하고 '다운로드 시작'을 누릅니다.
5. '다운로드 대기열'에서 상태를 확인합니다. 대기 중, 다운로드 중, 완료, 기존 파일로 건너뜀, 실패가 각각 표시되며 실패 항목을 누르면 구체적인 원인을 확인할 수 있습니다.

## 4. 로컬 파일과 갤러리 확인

데스크톱 GUI의 '상태' 페이지에서 현재 '다운로드 폴더'를 확인합니다. 기본 경로는 프로그램 작업 폴더 아래의 `pixiv-download/`입니다. 실제 위치는 실행 시 작업 폴더나 컬렉션에 별도로 지정한 폴더에 따라 달라집니다.

```text
pixiv-download/
└── 12345678/
    ├── 12345678_p0.jpg
    └── 12345678_p1.jpg
```

다운로드 루트 폴더는 `config/config.yaml`의 `download.root-folder`로 설정합니다. 설정을 바꿔도 기존 파일은 이동하지 않습니다. 폴더를 이전하려면 [저장소 및 백업](/ko/storage)을 따르세요. `gallery` 플러그인이 활성화되어 있으면 `http://localhost:6999/pixiv-gallery.html`에서 방금 데이터베이스에 등록한 작품을 볼 수 있습니다([작품 갤러리](/ko/gallery) 참고).

## 자주 발생하는 문제

- **Cookie가 필요하다는 메시지가 표시되거나 R-18을 건너뜀**: 유효한 `PHPSESSID`가 포함된 Cookie를 저장했는지, 해당 Pixiv 계정의 웹 설정에서 R-18 표시를 켰는지 확인하세요.
- **프록시 연결 실패**: 프록시 프로그램이 실행 중인지 확인하고 데스크톱 설정 페이지에서 `proxy.host`와 `proxy.port`를 확인하세요. 브라우저에서 Pixiv가 열린다고 해서 백엔드 프록시 설정이 올바른 것은 아닙니다.
- **작품이 없다는 메시지**: Pixiv 원본 페이지에서 작품이 삭제되었거나 비공개 또는 마이픽 한정인지 확인하세요.
- **다운로드가 완료됐지만 파일을 찾을 수 없음**: 데스크톱 GUI의 '상태' 페이지에서 실제 작업 폴더와 다운로드 폴더를 확인하거나, 다운로드할 때 사용자 정의 폴더가 지정된 로컬 컬렉션을 선택했는지 확인하세요.

더 많은 콘텐츠를 다운로드하려면 [URL 일괄 다운로드](/ko/batch-download), [작가 일괄 다운로드](/ko/user-download), [검색 다운로드](/ko/search) 또는 [소설 및 낭독](/ko/novel)을 참고하세요.
