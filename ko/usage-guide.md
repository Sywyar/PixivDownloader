# 고급 사용 안내

실행 인수, 파일명 템플릿, 유지 관리와 게스트 초대를 설명합니다. 다운로드 기능은 [빠른 가져오기](/ko/quick-access), [URL 일괄](/ko/batch-download), [작가](/ko/user-download), [검색](/ko/search), [소설](/ko/novel), [갤러리](/ko/gallery), [예약 작업](/ko/scheduled-tasks), [사용자 스크립트](/ko/userscripts) 안내를 사용하세요.

## 실행 인수

배포판을 모두 압축 해제한 디렉터리에서 실행합니다. `APP.jar`를 실제 주 프로그램 JAR 이름으로 바꾸세요. 한 줄 명령은 PowerShell과 Bash에서 사용할 수 있습니다.

```text
java -Dfile.encoding=UTF-8 -jar APP.jar --help
java -Dfile.encoding=UTF-8 -jar APP.jar --no-gui
```

| 인수 | 용도 |
| --- | --- |
| `--no-gui` | 서버·Docker 등에서 데스크톱 GUI 없이 실행 |
| `--intro` | 시작할 때 제품 소개 페이지 열기 |
| `--help`, `-h` | 도움말 표시 후 종료 |

Windows 설치판은 `PixivDownload.exe`를 실행할 수 있습니다. Compose와 Swing이 함께 포함되며 `app.gui-provider`가 비어 있으면 기본 Compose를 선택합니다. 공급자를 바꾼 뒤 완전히 재시작하세요. 최초 무화면 실행 전 초기화가 필요하며, 하지 않았다면 종료 코드 `78`로 끝납니다.

### 관리 명령

| 명령 | 용도 |
| --- | --- |
| `--setup` | 계정, 모드, 프록시 최초 설정 |
| `--change-password` | 관리자 비밀번호 변경 |
| `--reset-password` | 잊은 비밀번호 강제 재설정 |

관리 상태를 수정하므로 같은 데이터 디렉터리의 다른 인스턴스를 먼저 중지하세요. 비밀번호 변경·재설정은 기존 세션을 무효화합니다. 재시작한 뒤 새 비밀번호로 로그인하세요. 세부 입력과 오류 처리는 [최초 설정](/ko/first-setup)을 참고하세요.

## 파일명 템플릿 변수

다운로드 설정의 파일명 템플릿에서 사용합니다.

| 변수 | 의미 |
| --- | --- |
| `{artwork_id}` | 작품 ID |
| `{artwork_title}` | 작품 제목, 허용되지 않는 문자 제거 |
| `{author_id}` | 작가 ID |
| `{author_name}` | 작가 이름, 허용되지 않는 문자 제거 |
| `{timestamp}` | Unix 시각, 밀리초 |
| `{page}` | 0부터 시작하는 페이지 인덱스 |
| `{count}` | 전체 페이지 수 |
| `{ai}` | AI 작품이면 `AI`, 아니면 빈 값 |
| `{ai+}` | `AI` 또는 `Human` |
| `{R18}` | `R18`, `R18G`, 빈 값 |
| `{R18+}` | `SFW`, `R18`, `R18G` |

`{author_name}/{artwork_id}_p{page}`는 작가 이름별 디렉터리에 저장하는 예입니다.

## 자동 북마크

다운로드 웹페이지에서 자동 북마크를 선택하면 다운로드 후 백엔드가 저장된 Cookie로 작품을 북마크합니다. 사용자 스크립트는 브라우저의 Pixiv 로그인 상태를 사용하며 `document.cookie`를 백엔드로 전달하지 않습니다.

`PHPSESSID`를 포함한 유효 Cookie가 필요합니다. 북마크는 가능한 범위에서 수행하며 실패하더라도 다운로드 작업을 실패로 바꾸지 않습니다.

## Ugoira

1. ZIP 프레임 파일을 받습니다.
2. 프레임을 추출하고 파일명으로 정렬합니다.
3. `ffmpeg`로 선택한 애니메이션·동영상 형식을 만듭니다. 형식은 [설정](/ko/configuration)을 참고하세요.
4. 첫 프레임을 `_p0_thumb.jpg` 썸네일로 함께 저장합니다.

시스템 PATH에서 `ffmpeg`를 찾을 수 있어야 합니다. Windows 설치판은 GUI 상태 페이지의 FFmpeg 다운로드 기능으로 설치할 수 있습니다.

## 다운로드 모니터

`http://localhost:6999/monitor.html`에서 현재 다운로드 진행률, 작가·태그·AI 필터와 부분 검색을 지원하는 이력, 다운로드 추세를 확인할 수 있습니다.

## GUI 유지 관리 도구

| 도구 | 용도 |
| --- | --- |
| 이미지 분류 | 다운로드한 이미지 분류와 정리 |
| 데이터베이스 디렉터리 검사 | 기록된 파일 경로의 유효성 확인 |
| 데이터 보충 | 버전 변경 등으로 누락된 데이터 필드 보충 |

!> 데이터베이스 도구는 독점 유지 관리 세션이 필요하며 GUI가 백엔드 중지와 복원을 관리합니다. 먼저 선택한 데이터베이스를 백업하고 같은 데이터 디렉터리의 다른 인스턴스를 열지 마세요. 선택한 데이터베이스 공급자가 사용 가능해야 합니다. PostgreSQL은 서버 데이터도 따로 백업하세요. 완료 후 보고서, 백엔드 상태, 갤러리 접근을 확인해야 하며 창이 닫힌 것만으로 성공을 판단하지 마세요.

## 유사 이미지 찾기

관리자는 `http://localhost:6999/pixiv-duplicates.html`에서 dHash 지각 해시로 시각적으로 비슷한 다운로드 이미지를 찾을 수 있습니다. 이름이나 크기가 달라도 탐지할 수 있습니다.

해밍 거리 임계값은 작을수록 엄격하며 dHash 기본값은 10입니다. 서로 다른 작품 사이 또는 전체 데이터베이스를 비교하고, 썸네일을 눌러 상세 페이지에서 직접 처리합니다.

## 게스트 초대

초대 게스트는 `solo`와 `multi`에서 모두 사용할 수 있습니다. 관리자는 외부 사용자가 갤러리를 읽기 전용으로 보도록 초대할 수 있습니다.

1. 갤러리에서 게스트 초대를 선택합니다.
2. 만료 시각, SFW/R18/R18G, 태그·작가 허용 목록을 정합니다.
3. `http://host:port/invite?code=xxx` 형식의 초대 링크를 공유합니다.

초대 관리는 `http://localhost:6999/pixiv-invite-manage.html`입니다.
