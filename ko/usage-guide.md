# 사용 가이드(고급 참고)

## 시작 인수

```bash
# JAR
java -Dfile.encoding=UTF-8 -jar PixivDownload-vX.X.X.jar

# Windows 실행 파일
PixivDownload.exe

# 공통 인수
--no-gui
--intro
```

### CLI 관리자 명령

서버/Docker 환경에서는 `--setup`, `--change-password`, `--reset-password`와 같은 관리자 명령을 사용할 수 있습니다. 비밀번호가 셸 기록에 남지 않도록 보호된 입력을 사용하세요.

## 파일명 템플릿 변수

작품 ID, 작가 이름, 작품 제목, 페이지 번호, 날짜, 태그와 시리즈 정보를 템플릿에 사용할 수 있습니다. OS에서 사용할 수 없는 문자는 자동으로 정규화됩니다.

## 자동 북마크

다운로드 완료 후 작품 또는 소설을 Pixiv 북마크에 추가할 수 있습니다. Cookie 권한이 없거나 요청이 실패해도 이미 완료된 다운로드는 되돌려지지 않습니다.

## Ugoira 다운로드

FFmpeg를 사용하여 애니메이션 이미지를 WebP로 변환합니다. 원본 프레임과 변환 상태는 작업 결과에서 확인할 수 있습니다.

## 다운로드 모니터

모니터에서 큐, 진행률, 속도, 재시도와 단계별 오류를 확인합니다. SSE 연결이 끊기면 페이지를 새로 고쳐도 백엔드 작업은 계속될 수 있습니다.

## GUI 도구 페이지

GUI에서는 상태, 업데이트, 플러그인, 테마와 네트워크 설정을 관리합니다. 재시작이 필요한 변경은 화면의 안내를 따르세요.

## 중복 의심 작품

지각 해시(dHash)로 유사 이미지를 찾고 임계값과 비교 범위를 조정할 수 있습니다. 결과는 자동 삭제가 아닌 검토용 표시입니다.

## 게스트 초대

관리자는 연령 등급, 태그와 작가 허용 목록을 지정한 초대 링크를 발행할 수 있습니다. 게스트 데이터와 초대 자격 증명을 외부에 공유하지 마세요.
