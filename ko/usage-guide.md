# CLI 및 고급 참조

이 페이지는 명령줄 시작 인수, 파일명 템플릿 변수, 미디어 및 유지 관리 도구와 게스트 초대를 설명합니다. 일반적인 다운로드 및 관리 작업은 [빠른 가져오기](/ko/quick-access), [URL 일괄 다운로드](/ko/batch-download), [작가 일괄 다운로드](/ko/user-download), [검색 다운로드](/ko/search), [소설 및 낭독](/ko/novel), [작품 갤러리](/ko/gallery), [예약 작업](/ko/scheduled-tasks), [사용자 스크립트](/ko/userscripts)를 참고하세요.

## 시작 및 관리 인수

압축을 모두 푼 배포 패키지 폴더에서 실행합니다. `APP.jar`는 실제 주 프로그램 JAR 이름으로 바꾸세요. 한 줄 명령은 PowerShell과 Bash에서 공통으로 사용할 수 있습니다.

```text
java -Dfile.encoding=UTF-8 -jar APP.jar --help
java -Dfile.encoding=UTF-8 -jar APP.jar --no-gui
```

| 인수 | 기능 |
| --- | --- |
| `--no-gui` | 데스크톱 GUI 없이 실행. 헤드리스 서버나 Docker에 적합. 최초 시작 전 `--setup`이 필요하며 완료하지 않으면 종료 코드 `78`로 종료 |
| `--intro` | 시작할 때 브라우저에서 제품 소개 페이지 열기 |
| `--help`, `-h` | 명령줄 도움말을 출력하고 종료 |
| `--setup` | 관리자 계정, 실행 모드와 HTTP 프록시 초기화 |
| `--change-password` | 기존 비밀번호 확인 후 관리자 비밀번호 변경 |
| `--reset-password` | 비밀번호를 잊었을 때 로컬에서 관리자 비밀번호 강제 재설정 |
| `--web-publications` | 페이지 편집기의 게시된 페이지 상태를 오프라인으로 조회하거나 복구. [페이지 편집기](/ko/page-editor#양식-검증-및-리소스-권한) 참고 |

`--setup`, `--change-password`, `--reset-password` 등의 관리 명령을 실행하기 전에 같은 데이터 폴더를 사용하는 인스턴스를 반드시 중지하세요. 비밀번호를 변경하거나 재설정하면 기존 세션이 무효화되므로 재시작 후 새 비밀번호로 로그인을 확인하세요([초기 설정](/ko/first-setup) 참고). Windows 설치 버전은 `PixivDownload.exe`를 직접 실행할 수 있습니다. 배포 패키지에는 Compose(기본값)와 Swing 데스크톱 UI가 모두 포함되며 `app.gui-provider`를 전환한 후에는 완전히 재시작해야 합니다.

## 파일명 템플릿 변수

다운로드 페이지의 '다운로드 설정 → 파일명 템플릿'에서 다음 11개 변수를 사용할 수 있습니다. 파일명에 허용되지 않는 문자는 자동으로 제거하며 새 템플릿은 이후 새 다운로드에만 적용됩니다.

| 변수 | 의미 |
| --- | --- |
| `{artwork_id}` | 작품 ID |
| `{artwork_title}` | 작품 제목 |
| `{author_id}` | 작가 ID |
| `{author_name}` | 작가 이름 |
| `{timestamp}` | 다운로드 시 Unix 타임스탬프(밀리초) |
| `{page}` | 현재 페이지 인덱스(`0`부터 시작) |
| `{count}` | 작품의 전체 페이지 수 |
| `{ai}` | AI 생성 작품이면 `AI`, 아니면 빈 문자열 |
| `{ai+}` | `AI` 또는 `Human` |
| `{R18}` | `R18`, `R18G` 또는 빈 문자열 |
| `{R18+}` | `SFW`, `R18` 또는 `R18G` |

예를 들어 `{author_name}/{artwork_id}_p{page}`는 작가 이름의 하위 폴더를 만들어 이미지를 저장합니다.

## 자동 북마크 및 움짤(Ugoira) 처리

- **자동 북마크**: 다운로드 페이지에서 '자동 북마크'를 선택하면 백엔드가 작품 다운로드 완료 시 저장한 Cookie(`PHPSESSID` 필요)로 Pixiv API를 호출하여 북마크합니다. 사용자 스크립트는 브라우저의 현재 Pixiv 로그인 상태로 북마크하며 `document.cookie`를 백엔드에 전달하지 않습니다. 북마크는 best-effort로 수행하므로 북마크 실패가 완료된 다운로드를 실패로 바꾸지는 않습니다.
- **움짤(Ugoira)**: ZIP 프레임 패키지를 다운로드하고 프레임 순서대로 압축을 푼 후 시스템 `PATH` 또는 자동 설치된 `ffmpeg`를 호출하여 선택한 형식으로 변환합니다. 기본값은 WebP이며 GIF, APNG, MP4 또는 원본 ZIP 보존을 선택할 수 있습니다([설정 참조](/ko/configuration#이미지-및-ugoira-저장-형식) 참고). 첫 프레임은 `_p0_thumb.jpg` 썸네일로도 저장합니다.

## 다운로드 모니터, 중복 의심 검사 및 데스크톱 도구

- **다운로드 모니터(`http://localhost:6999/monitor.html`)**: 현재 진행 중인 다운로드, 작가 / 태그 / AI 상태별 기록 필터와 부분 일치 검색, 다운로드 추세 그래프를 확인합니다.
- **중복 의심 검사(`http://localhost:6999/pixiv-duplicates.html`, 관리자 전용, `gallery-tools` 필요)**: 지각 해시(dHash)로 파일명이나 해상도가 달라도 시각적으로 비슷한 이미지를 찾습니다. 해밍 거리 임계값(기본 `10`, 낮을수록 엄격함)을 조정하고 '작품 간 모드 / 전체 DB 모드'를 전환하며 썸네일을 눌러 상세 페이지에서 처리할 수 있습니다.
- **데스크톱 GUI 도구 페이지**: **이미지 분류 도구**, **데이터베이스 폴더 검사**, **데이터 보완 도구**, **기존 데이터 및 메타데이터 가져오기**, **기존 미디어 처리**와 **PixivBatchDownloader 기록 가져오기**를 제공합니다.

!> 데이터베이스를 사용하는 데스크톱 유지 관리 도구는 독점 유지 관리 세션을 사용하며 GUI가 백엔드를 자동으로 중지하고 복구합니다. 실행 전에 선택한 데이터베이스를 백업하세요. PostgreSQL은 서버 데이터베이스도 백업해야 합니다. 같은 데이터 폴더로 다른 인스턴스를 동시에 시작하지 마세요. 작업이 끝나면 도구 보고서, 백엔드 상태와 갤러리 접근을 확인하세요. 도구 창을 닫았다고 실행이 성공한 것은 아닙니다.

## 게스트 초대

게스트 초대는 `solo`와 `multi` 모드에서 모두 사용할 수 있습니다. 관리자는 갤러리 오른쪽 위의 '방문자 초대'를 누르고 만료 시간, 허용 콘텐츠 등급(SFW / R18 / R18G)과 태그 / 작가 허용 목록을 설정한 후 `http://host:port/invite?code=xxx`를 복사하여 외부 게스트에게 읽기 전용으로 공유할 수 있습니다. 모든 초대 코드는 `http://localhost:6999/pixiv-invite-manage.html`에서 한꺼번에 확인하고 비활성화하거나 삭제할 수 있습니다.
