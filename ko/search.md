# 검색 다운로드

다운로드 페이지의 '검색 모드'에 키워드를 입력하면 백엔드가 Pixiv 검색 API로 결과를 가져옵니다. 결과를 필터링하여 다운로드 대기열에 추가할 수 있습니다. 이 기능은 로컬 갤러리가 아닌 Pixiv 온라인 작품을 검색합니다.

!> 검색 모드를 사용하려면 `PHPSESSID`가 포함된 유효한 Pixiv Cookie를 먼저 저장해야 합니다. 설정하지 않으면 검색 버튼을 사용할 수 없습니다.

## 사용 순서

1. `http://localhost:6999/pixiv-batch.html`을 열고 '검색 모드'로 전환합니다.
2. 검색 키워드를 입력합니다. 중국어, 일본어와 영어를 사용할 수 있습니다.
3. 하위 모드, 정렬 방식과 콘텐츠 등급을 선택하고 '검색'을 누릅니다.
4. 미리보기 그리드에서 작품을 선택하고 '선택 항목 추가' 또는 '현재 페이지 모두 추가'를 누릅니다.
5. '다운로드 시작'을 누르고 대기열에서 다운로드 결과를 확인합니다.

## 검색 범위, 정렬 및 필터

| 하위 모드 | 가져오는 범위 |
| --- | --- |
| 검색 모드 | 1페이지 결과만 가져옴. 키워드 결과를 빠르게 확인할 때 적합 |
| 작품 일괄 가져오기 모드 | 지정한 마지막 페이지까지 가져옴(기본 3페이지). 마지막 페이지를 `-1`로 설정하면 계속 페이지를 넘겨 전체 결과를 가져옴(페이지 간격 약 10초, 최대 1,000페이지) |

| 정렬 방식 | 설명 |
| --- | --- |
| 최신순(`date_d`) | 게시 시간 내림차순. 로그인한 모든 계정에서 사용 가능 |
| 인기순(`popular_d`) | 인기도순. Pixiv Premium 회원 권한 필요. 권한이 없으면 '최신순'으로 바꾸고 반환된 결과를 완전한 인기 순위로 간주하지 말 것 |

콘텐츠 등급은 '전연령', 'R-18', 'R-18G' 또는 '전체'를 선택할 수 있습니다. Pixiv 계정에서 해당 연령 설정을 켜야 합니다. 결과가 로드되면 '추가 필터'에서 AI 제외, 최소 북마크 수, 태그와 페이지 수 범위로 미리보기 페이지를 실시간 필터링할 수 있습니다.

## 결과 확인 및 예약 작업

먼저 키워드 하나와 적은 페이지 수로 결과를 확인한 후 페이지 범위를 늘리는 것이 좋습니다. 검색 결과가 비어 있으면 키워드, 등급, 계정 권한과 추가 필터를 확인하세요. 검색 오류가 발생하면 Cookie 만료 여부와 백엔드 프록시 연결을 확인하세요. 대기열에서 필터로 건너뛴 항목이 있다고 해서 검색 요청이 실패한 것은 아닙니다.

현재 검색을 예약 작업으로 저장하려면 페이지 하단의 '예약 작업으로 저장' 카드에서 실행 주기를 설정하세요. '최신순 + 마지막 페이지 `-1`' 작업은 워터마크 기반 증분 수집을 지원합니다. 다른 조합과 상한 규칙은 [예약 작업](/ko/scheduled-tasks)을 참고하세요.
