# 검색 다운로드

Search 모드에서 키워드를 입력하면 백엔드가 Pixiv를 검색합니다. 결과와 필터를 확인한 뒤 작품을 대기열에 추가하세요. 이 결과는 로컬 갤러리 검색 결과가 아닙니다.

!> `PHPSESSID`가 포함된 Pixiv Cookie를 먼저 저장해야 합니다. 없으면 검색 버튼을 사용할 수 없습니다.

## 사용 순서

1. `http://localhost:6999/pixiv-batch.html`에서 **Search 모드**를 엽니다.
2. 중국어, 일본어, 영어 등으로 키워드를 입력합니다.
3. 정렬과 콘텐츠 등급을 선택하고 검색합니다.
4. 썸네일을 확인한 뒤 원하는 작품을 선택합니다.
5. 선택 항목 또는 현재 페이지 전체를 대기열에 넣고 다운로드를 시작합니다.

## 검색 방식

| 방식 | 동작 |
| --- | --- |
| 검색 모드 | 첫 페이지만 가져와 빠르게 확인 |
| 작품 일괄 가져오기 | 종료 페이지까지 여러 페이지 조회, 기본 3페이지 |

일괄 가져오기에서 종료 페이지를 `-1`로 설정하면 끝까지 조회합니다. 연속 요청을 줄이기 위해 페이지 사이에 약 10초를 기다립니다.

## 정렬과 콘텐츠 등급

| 정렬 | 동작 | Premium |
| --- | --- | --- |
| 최신 `date_d` | 게시 시각 내림차순 | 불필요 |
| 인기 `popular_d` | 인기순 | 필요 |

인기순은 Pixiv 계정 권한의 제한을 받습니다. 권한이 없다면 최신순으로 바꾸세요. 반환된 일부 결과를 전체 인기 목록으로 해석하지 마세요.

콘텐츠 등급은 전연령, R-18, R-18G, 전체를 선택합니다. 전체 결과를 보려면 Pixiv 계정의 연령 확인이 필요합니다.

## 추가 필터와 결과 확인

검색 결과가 로드되면 추가 필터가 현재 미리보기 페이지에 실시간 적용됩니다. AI 제외, 최소 북마크 수, 태그, 페이지 수 범위로 좁힐 수 있습니다.

키워드 하나와 적은 페이지 수로 결과를 확인한 뒤 범위를 넓히세요. 빈 결과는 키워드, 등급, 계정 권한, 필터를 점검합니다. 오류라면 메시지를 보존하고 Cookie와 백엔드 프록시를 확인하세요. 대기열에서 필터 때문에 건너뛴 것은 검색 실패가 아닙니다.

## 예약 작업으로 저장

아래의 예약 작업 저장 카드에서 주기를 정해 생성하면 정해진 시간에 해당 조건을 검색하고 새 작품을 다운로드합니다. 최신순과 페이지 수 `-1`을 함께 사용하는 작업은 마지막으로 확인한 위치를 기준으로 이후 결과를 가져와 과거 범위를 반복 처리하지 않도록 합니다.

작업별 제한과 증분 확인 방식은 [예약 작업](/ko/scheduled-tasks)을 참고하세요.
