# 검색 다운로드

## 사용 단계

검색 모드에서 키워드를 입력하고 작품 유형, 페이지 상한과 기간을 설정한 뒤 결과를 검토하여 대기열에 추가합니다.

## 검색 하위 모드

일러스트, 만화, 우고이라와 소설 검색을 각각 선택할 수 있습니다. Pixiv의 로그인 상태와 공개 범위에 따라 결과가 달라집니다.

## 정렬

관련도, 최신순, 인기순 등 Pixiv가 제공하는 정렬 기준을 선택합니다. 대량 요청 전 결과 수와 속도 제한을 확인하세요.

## 콘텐츠 등급

연령 등급 필터는 Cookie 권한과 Pixiv 정책의 영향을 받습니다. 필요한 경우 검색 결과에서 제외하고, 저장 파일의 접근 권한도 관리하세요.

## 추가 필터

태그, 작가, 업로드 날짜, 다운로드 이력과 AI 작품 여부를 조합할 수 있습니다.

## 예약 작업으로 저장

현재 검색 조건을 관리자 예약 작업으로 저장하면 정해진 주기로 새 결과를 발견할 수 있습니다. [예약 작업](/ko/scheduled-tasks)을 참고하세요.
