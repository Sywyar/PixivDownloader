# 빠른 가져오기

다운로드 페이지의 빠른 가져오기는 저장된 Pixiv Cookie로 내 북마크, 작품, 팔로잉, 컬렉션을 불러옵니다. 미리본 작품을 대기열에 넣은 뒤 다운로드를 시작하세요. 목록을 가져오는 것만으로 파일이 다운로드되지는 않습니다.

?> `PHPSESSID`가 포함된 Cookie를 먼저 저장해야 합니다. 없으면 버튼이 비활성화되고 안내가 표시됩니다.

## 가져올 수 있는 데이터

| 원본 | 내용 |
| --- | --- |
| 내 북마크 | 일러스트·만화와 소설, 비공개 북마크 포함 |
| 내 작품 | 자신이 게시한 일러스트·만화와 소설, 비공개 포함 |
| 내 의뢰 작품 | 자신이 완료하여 공개한 의뢰(リクエスト) 결과물, 일러스트로 처리 |
| 내 팔로잉 | 비공개 팔로우를 포함한 작가 목록, 이름·ID로 실시간 필터 |
| 팔로우한 사용자의 신작 | 팔로우한 작가의 최신 일러스트·만화·Ugoira, 페이지 이동 지원 |
| 내 컬렉션 | Pixiv 컬렉션(コレクション)에 포함된 작품 |

## 사용 순서

1. `http://localhost:6999/pixiv-batch.html`에서 빠른 가져오기를 엽니다.
2. 내 북마크, 내 작품 등 원하는 원본을 선택합니다.
3. 목록이 표시될 때까지 기다립니다.
4. 전체를 대기열에 추가하거나 작품을 선택해 추가합니다.
5. 대기열을 확인하고 다운로드를 시작합니다.

팔로잉 목록에서 작가를 누르면 해당 작가의 작품 미리보기가 펼쳐집니다. 일러스트와 소설을 전환하고 작품 하나, 현재 페이지 전체, 다른 페이지의 작품을 차례로 추가할 수 있습니다. 컬렉션을 누르면 일러스트와 소설이 섞인 목록이 펼쳐지며 같은 방식으로 사용합니다.

## 추가 필터

작품 목록을 펼치면 콘텐츠 등급, AI, 태그, 작품 유형, 페이지 수, 글자 수, 북마크 수로 현재 미리보기 페이지를 실시간 필터링할 수 있습니다.

- 현재 페이지 전체 추가는 필터를 통과한 작품만 추가합니다.
- 전체 추가는 전체 작품을 넣으며, 조건에 맞지 않는 작품은 실제 다운로드 때 이유를 표시하고 건너뜁니다.

팔로잉이나 컬렉션 선택 목록만 보고 있다면 먼저 구체적인 작품 목록을 펼치라는 안내가 나옵니다.

## 예약 작업으로 저장

관리자는 각 원본을 [예약 작업](/ko/scheduled-tasks)으로 저장할 수 있습니다.

| 원본 | 정기 실행 내용 |
| --- | --- |
| 내 북마크: 일러스트/소설, 공개/비공개 | 새로 북마크한 작품 |
| 내 작품 | 자신의 새 게시물 |
| 내 의뢰 작품 | 새로 완료한 의뢰 결과물 |
| 팔로우한 사용자의 신작 | 팔로우한 작가의 신작 |
| 특정 팔로잉 작가 | 해당 작가의 신작 |
| 특정 컬렉션 | 컬렉션에 추가된 일러스트와 소설 |

원본을 펼치면 아래의 예약 작업 저장 카드에 원본 설명이 나옵니다. 이름과 실행 방식을 정해 생성하세요. 아직 원본을 펼치지 않았다면 먼저 펼치라는 안내가 표시됩니다.

북마크, 팔로우 신작, 컬렉션은 계정에 속한 데이터이므로 작업에 `PHPSESSID` Cookie 사용을 허용해야 합니다. 개인 모드에서 생성하면 자동 연결됩니다. 이 작업들의 원본은 편집 화면에서 읽기 전용입니다. 다른 원본이 필요하면 삭제 후 다시 만드세요.

## 결과와 오류 확인

완료, 건너뜀, 실패를 대기열에서 확인한 뒤 갤러리에서 작품을 확인합니다. 빈 목록이면 선택한 계정, 공개·비공개 범위, 현재 필터를 확인하세요. 버튼이 비활성화되거나 로그인이 만료되었다면 유효한 Cookie를 다시 저장합니다. 가져오기 실패는 오류 내용을 보존하고 백엔드의 Pixiv 프록시 연결을 점검하세요. 빈 목록 자체가 동기화 완료를 뜻하지는 않습니다.

다른 원본은 [URL 일괄 다운로드](/ko/batch-download), [작가 일괄 다운로드](/ko/user-download), [검색 다운로드](/ko/search)를 사용하세요.
