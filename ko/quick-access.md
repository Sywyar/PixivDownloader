# 빠른 가져오기

다운로드 페이지의 '빠른 가져오기'에서는 저장한 Pixiv Cookie로 현재 계정의 북마크, 투고 작품, 커미션, 팔로우 목록, 팔로우 새 작품과 컬렉션을 가져옵니다. 먼저 미리보기를 불러온 다음 작품을 대기열에 추가하고 다운로드를 시작하세요. 목록을 가져오는 것만으로는 파일이 저장되지 않습니다.

!> 빠른 가져오기를 사용하려면 유효한 `PHPSESSID`가 포함된 Cookie를 먼저 저장해야 합니다. 저장하지 않으면 각 항목 버튼이 비활성화됩니다.

## 지원하는 데이터 소스 및 사용 순서

| 데이터 소스 | 가져오는 범위 |
| --- | --- |
| 내 즐겨찾기 | 일러스트 / 만화와 소설. 공개 및 비공개 북마크 지원 |
| 내 작품 | 현재 계정이 투고한 일러스트 / 만화와 소설. 비공개 작품 포함 |
| 내 커미션 작품 | 현재 계정에서 완료되어 공개된 커미션(リクエスト) 결과물. 일러스트 처리 흐름 사용 |
| 내 팔로잉 | 팔로우한 작가 목록. 비공개 팔로우 포함, 사용자 이름이나 ID로 실시간 필터링 지원 |
| 팔로잉한 사용자의 새 작품 | 팔로우한 작가의 최신 일러스트 / 만화 / 움짤(フォロー新着作品). 페이지별 탐색 지원 |
| 내 컬렉션 | Pixiv 컬렉션(コレクション)의 일러스트와 소설 혼합 목록 |

1. `http://localhost:6999/pixiv-batch.html`을 열고 '빠른 가져오기'로 전환합니다.
2. 원하는 데이터 소스 버튼을 누르고 아래에 작품 목록이 표시될 때까지 기다립니다.
3. '내 팔로잉'나 '내 컬렉션'에서 특정 작가 또는 컬렉션을 눌러 작품 미리보기를 펼칩니다. 팔로우한 작가는 일러스트 / 소설을 전환할 수 있습니다.
4. 개별 작품 추가, '현재 페이지를 대기열에 추가' 또는 '모두 대기열에 추가'를 선택한 후 '다운로드 시작'을 누릅니다.

## 추가 필터

구체적인 작품 목록을 펼친 뒤 '추가 필터'에서 콘텐츠 등급, AI 작품, 태그, 작품 유형, 페이지 수, 글자 수와 최소 북마크 수로 현재 미리보기 페이지를 실시간 필터링할 수 있습니다.

- **현재 페이지를 대기열에 추가**: 현재 페이지에서 필터를 통과하여 표시되는 작품만 대기열에 추가합니다.
- **모두 대기열에 추가**: 해당 소스의 모든 작품을 대기열에 추가하고 다운로드 시 각 작품에 필터 조건을 적용합니다. 조건에 맞지 않는 작품은 대기열에 건너뛴 이유가 표시됩니다.

팔로우한 작가 목록이나 컬렉션 목록에 머무르고 있다면 특정 작가나 컬렉션에 먼저 들어가야 필터와 대기열 추가를 사용할 수 있습니다.

## 예약 작업으로 저장(관리자)

구체적인 소스(북마크, 내 작품, 내 커미션, 팔로잉한 사용자의 새 작품 또는 특정 팔로우 작가나 컬렉션)를 펼친 후 페이지 하단의 '예약 작업으로 저장' 카드에서 이름과 트리거 방식을 입력하여 백그라운드 자동 다운로드 작업으로 저장할 수 있습니다.

?> 북마크, 팔로우 새 작품과 컬렉션은 계정의 비공개 소스이므로 작업에 유효한 Cookie를 연결해야 합니다. 개인용 모드에서 새로 만들면 현재 Cookie가 자동 연결됩니다. 생성 후 소스 유형은 읽기 전용입니다. 소스를 변경하려면 작업을 삭제하고 다시 만들어야 합니다. 자세한 내용은 [예약 작업](/ko/scheduled-tasks)을 참고하세요.

## 결과 확인 및 문제 해결

다운로드가 끝나면 대기열에서 완료, 건너뜀과 실패 항목을 각각 확인한 후 갤러리에서 작품을 확인하세요. 미리보기 목록이 비어 있으면 먼저 선택한 계정, 공개 / 비공개 범위와 추가 필터 조건을 확인하세요. 버튼이 비활성화되거나 인증 오류가 발생하면 유효한 Cookie를 다시 저장하세요. 네트워크 오류가 발생하면 백엔드 프록시 연결을 확인하세요. 빈 목록만 보고 동기화가 완료되었다고 판단하지 마세요.

링크를 지정한 다운로드는 [URL 일괄 다운로드](/ko/batch-download), 작가 ID를 이용한 다운로드는 [작가 일괄 다운로드](/ko/user-download), 키워드 검색은 [검색 다운로드](/ko/search)를 참고하세요.
