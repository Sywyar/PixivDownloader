# 작품 갤러리

등록된 일러스트, 만화, Ugoira를 찾아 컬렉션에 넣거나 일괄 내보낼 수 있습니다. `gallery` 플러그인이 필요하며 관리, 내보내기, 삭제에는 관리자 로그인이 필요합니다. 갤러리는 데이터베이스 기록을 사용하므로 임의 디렉터리의 이미지를 자동으로 작품으로 등록하지 않습니다.

주소는 `http://localhost:6999/pixiv-gallery.html`입니다.

## 화면과 검색

왼쪽 사이드바에는 전체 이미지·작가·만화 시리즈 보기, 컬렉션과 생성 버튼, 다운로드·모니터·통계·유사 이미지·초대 관리 링크가 있습니다. 가운데에는 썸네일, 위에는 검색·정렬·필터·보기 도구가 있습니다.

사이드바 오른쪽의 탐색 버튼은 사이드바를 접고 펼칩니다. 관리자용 작업 목록 버튼은 내보내기·압축 작업의 진행률과 남은 유효 시간을 보여 줍니다. 완료 파일을 직접 받을 수 있고 만료 작업은 정리됩니다. 서버 재시작 시 목록은 비워지며 내보내기를 시작하면 자동으로 열립니다.

위쪽의 만화 탭은 현재 이미지 갤러리이고 소설 탭은 `pixiv-novel-gallery.html`로 이동합니다.

검색 범위는 드롭다운에서 선택합니다.

| 범위 | 동작 |
| --- | --- |
| 통합 | 제목과 작가 이름, 기본값 |
| 제목 / 작가 이름 | 해당 필드 검색 |
| 작품 ID / 작가 ID | ID 정확히 일치 |
| 설명 | 작품 설명 검색 |
| 태그 부분 일치 | 키워드를 포함한 태그 |
| 태그 정확히 일치 | 같은 태그 |

## 필터와 정렬

필터 패널에서 전체·전연령·R-18·R-18G, AI 포함·제외·AI만, JPG·PNG·GIF·WebP 등의 형식, 컬렉션을 선택합니다.

태그·작가는 각각 세 상태를 조합할 수 있습니다.

| 상태 | 의미 |
| --- | --- |
| 반드시 포함 | 해당 태그 또는 작가가 반드시 있어야 함 |
| 제외 | 해당 태그 또는 작가가 없어야 함 |
| 또는 포함 | 이 상태의 조건 중 하나 이상 충족 |

반드시 포함 조건은 교집합, 또는 포함 조건은 합집합으로 계산한 뒤 제외 조건을 적용합니다.

정렬은 다운로드 시각(데이터베이스 등록 시각, 기본 최신순), 작품 ID, 이미지 수, 다운로드·보관 상태, 작가 ID, 태그 수, 만화 시리즈를 지원합니다. 각 정렬은 오름차순과 내림차순으로 바꿀 수 있습니다.

## 작품 상세

썸네일을 누르면 `pixiv-artwork.html`에서 제목, 작가, 게시 시각, 태그, 설명을 봅니다. 여러 이미지의 좌우 이동과 전체 화면, 관련 작품, 같은 작가의 다른 작품, Pixiv 원본 링크도 제공합니다.

## 일괄 관리

관리자는 위쪽 일괄 관리에서 여러 작품을 선택하고 아래 작업 메뉴를 사용합니다. 현재 페이지 전체 선택·해제는 현재 페이지만 적용합니다. 모든 결과 선택은 현재 필터의 전체 결과에 적용되며 페이지를 넘겨도 유지됩니다. 개별 작품은 다시 제외할 수 있습니다.

| 작업 | 동작 |
| --- | --- |
| 내보내기 | 작가·작품별 또는 작품 ID 디렉터리로 ZIP 생성 |
| 컬렉션에 추가 | 선택 작품을 지정 컬렉션에 등록 |
| 삭제 | 선택한 작품 삭제 |

내보내기에는 원본을 나중에 삭제할지 선택할 수 있습니다. 확인하면 백그라운드에서 압축하고 작업 목록을 엽니다. 완료 후 자동 다운로드하며 목록에서도 직접 받을 수 있습니다. ZIP 안의 `manifest.json`에는 작품 정보와 원래 경로가 들어갑니다.

!> 내보낸 뒤 삭제를 선택하면 **서버가 압축 파일을 성공적으로 만든 후** 원본과 다운로드 기록을 삭제합니다. 브라우저에서 다운로드하거나 내용을 확인할 때까지 기다리지 않습니다.

### 작품 삭제

프로그램이 관리하는 작품을 삭제하면 로컬 이미지와 태그·컬렉션 연결·썸네일 등 파생 데이터를 제거합니다. 화면에서 되돌릴 수 없습니다. [외부 다운로드 가져오기](/ko/pixiv-batch-downloader-import)로 등록한 읽기 전용 원본은 보존됩니다.

상세 페이지의 삭제 버튼 또는 일괄 관리의 삭제 메뉴에서 확인 후 실행합니다. 소설 갤러리와 소설 읽기 페이지에도 같은 일괄·단일 삭제 기능이 있습니다.

삭제한 작품은 다운로드 이력에 삭제 표시를 유지합니다. 갤러리, 필터, 통계에서는 보이지 않지만 일괄 다운로드, 사용자 스크립트, 예약 작업의 이미 다운로드한 작품 건너뛰기에서 인식합니다. 기본적으로 다시 다운로드하지 않습니다. 삭제된 작품 재다운로드를 허용하면 다시 받고, 성공 후 삭제 표시가 해제되어 갤러리에 나타납니다.

## 컬렉션

컬렉션은 Pixiv 북마크와 별개인 로컬 분류입니다. 사이드바 아래에서 새 컬렉션을 만들고 이름을 입력합니다. 오른쪽 클릭이나 편집 화면에서 이름 변경, PNG/JPG/WEBP 아이콘(최대 1 MB), 별도 다운로드 디렉터리, 삭제를 설정합니다.

썸네일에 마우스를 올려 하트 아이콘을 누르거나 상세 페이지의 컬렉션 추가 버튼을 사용하세요.

## 작품 감상과 게스트 초대

상세 페이지의 작품 감상은 `pixiv-showcase.html`에서 현재 작품을 전체 화면으로 보여 줍니다.

관리자는 게스트 초대로 갤러리의 제한된 범위를 공유할 수 있습니다. 게스트에게 수정이나 일괄 관리 권한을 주지 않습니다. 이미 표시된 이미지는 브라우저로 저장할 수 있으므로 초대 코드가 복사를 막지는 않습니다.

갤러리의 초대 버튼에서 만료 시각, 콘텐츠 등급, 태그·작가 허용 목록을 정한 뒤 생성된 `http://host:port/invite?code=xxx` 링크를 공유하세요. 게스트는 허용 범위만 볼 수 있습니다. 관리는 `http://localhost:6999/pixiv-invite-manage.html`에서 합니다.

## 작품을 찾지 못할 때

검색·필터를 해제하고 초대의 공개 범위를 확인합니다. 관리자는 현재 데이터베이스, 다운로드 디렉터리, 대기열 결과, 삭제 표시도 확인하세요. 파일만 이동해도 다른 데이터베이스로 기록이 옮겨지지는 않습니다. 복원과 이동은 [저장 원칙](/ko/storage)을 따르세요.

내보내기는 작업 목록의 성공 상태를 확인하고 ZIP을 받은 뒤 내용도 확인하세요.

## 통계 대시보드

관리자용 `http://localhost:6999/pixiv-stats.html`에서 작품·이미지·작가·태그 수, 월별 다운로드 추이, 많이 다운로드한 작가, 인기 태그 워드클라우드를 볼 수 있습니다. 태그를 누르면 해당 조건의 갤러리로 이동합니다.
