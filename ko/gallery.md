# 작품 갤러리

작품 갤러리는 데이터베이스에 등록된 일러스트, 만화와 움짤을 탐색하고 필터링하며 정리하고 일괄 내보내는 곳입니다. `gallery` 플러그인을 활성화해야 하며 일괄 관리, 내보내기, 삭제와 컬렉션 관리에는 관리자 로그인이 필요합니다. 갤러리는 데이터베이스 기록을 기준으로 합니다. 이미지를 폴더에 직접 넣어도 작품으로 자동 등록되지 않습니다.

접속 주소: `http://localhost:6999/pixiv-gallery.html`

## 찾기, 필터링 및 정렬

왼쪽 사이드바에서는 보기(전체 이미지, 작가별, 만화 시리즈별)를 전환하고 로컬 컬렉션을 관리하며 각 기능 페이지로 이동할 수 있습니다. 사이드바 오른쪽 가장자리의 버튼으로 탐색 영역을 접거나 관리자 '작업 목록'을 열어 백그라운드 압축 진행 상황과 유효 기간을 확인할 수 있습니다. 상단 도구 모음에는 갤러리 유형 전환(일러스트 / 소설 등 활성화된 갤러리 플러그인), 검색창, 필터와 정렬이 있습니다.

| 검색 범위 | 일치 대상 |
| --- | --- |
| 통합 | 제목 + 작가 이름(기본값) |
| 제목 / 작가 이름 / 소개 | 해당 텍스트 필드의 부분 일치 |
| 작품 ID / 작가 ID | 숫자 ID 정확 일치 |
| 태그(유사 / 정확) | 키워드 포함 또는 태그 이름 완전 일치 |

'필터'에서는 콘텐츠 등급(전체 / 전연령 / R-18 / R-18G), AI 생성(전체 / AI 제외 / AI만), 이미지 형식, 컬렉션과 업로드 날짜 범위로 필터링할 수 있습니다. 날짜 범위는 종료일 당일을 포함하며 브라우저 시간대를 기준으로 해석합니다. 업로드 시간을 알 수 없는 작품은 날짜 범위 결과에 포함되지 않습니다. 태그와 작가는 세 가지 상태를 조합할 수 있습니다.

| 상태 | 규칙 |
| --- | --- |
| 반드시 포함 | 여러 '반드시 포함' 조건의 교집합 |
| 하나 이상 포함 | 여러 '하나 이상 포함' 조건의 합집합 |
| 제외 | 일치하는 항목을 결과에서 제외 |

**다운로드 시간**(기본 최신순), **업로드 시간**(시간을 알 수 없는 작품은 오름차순과 내림차순 모두 맨 뒤), **작품 ID**, **이미지 수**, **상태**, **작가 ID**, **태그 수**와 **만화 시리즈**를 기준으로 오름차순 또는 내림차순 정렬할 수 있습니다.

썸네일을 누르면 `pixiv-artwork.html`에서 여러 이미지(좌우 전환과 라이트박스 지원), 소개, 태그, 같은 작가의 작품, 관련 추천과 원본 링크를 볼 수 있습니다. '작품 감상'을 누르면 `pixiv-showcase.html`에서 전체 화면으로 볼 수 있습니다.

## 일괄 관리 및 내보내기(관리자)

상단의 '일괄 관리'를 눌러 다중 선택 모드로 들어갑니다.

- **현재 페이지 전체 선택 / 선택 해제**: 현재 페이지에만 적용됩니다.
- **모든 결과 선택**: 현재 필터 조건에 맞는 모든 작품을 선택합니다. 페이지를 이동해도 선택이 유지되며 개별 작품을 따로 해제할 수 있습니다.

하단의 '작업' 메뉴에서 다음 작업을 수행할 수 있습니다.

| 작업 | 결과 |
| --- | --- |
| 내보내기 | 폴더 구조(작가/작품별 또는 작품 ID별 폴더), 형식(ZIP)과 '내보내기 후 원본 파일 삭제' 여부를 선택. 백그라운드에서 `manifest.json`이 포함된 압축 파일 생성 |
| 컬렉션에 추가 | 선택한 작품을 지정한 로컬 컬렉션에 일괄 추가 |
| 삭제 | 선택한 작품 일괄 삭제 |

내보내기를 시작하면 사이드바의 '작업 목록'이 자동으로 열려 진행 상황을 표시합니다. 압축이 완료되면 다운로드가 자동으로 시작되며 유효 기간 내에는 작업 목록에서 수동으로 다운로드할 수도 있습니다. 만료되거나 서비스를 재시작하면 작업은 정리됩니다.

!> '내보내기 후 삭제'를 선택하면 서버에서 압축 파일을 성공적으로 생성한 즉시 원본 파일과 다운로드 기록을 삭제합니다. 브라우저의 다운로드 완료나 사용자의 압축 내용 확인을 기다리지 않습니다.

## 작품 삭제

관리자는 작품 상세 페이지의 빨간색 '삭제' 버튼 또는 '일괄 관리 → 작업 → 삭제'로 작품을 삭제할 수 있습니다. 이 프로그램이 관리하는 작품은 로컬 미디어 파일과 파생 데이터(태그, 컬렉션 연결, 썸네일)가 삭제되며 UI에서 되돌릴 수 없습니다. [외부 다운로드 가져오기](/ko/pixiv-batch-downloader-import)로 등록한 읽기 전용 원본 파일은 보존됩니다. 소설 갤러리와 소설 읽기 페이지에도 같은 삭제 및 일괄 관리 기능이 있습니다.

**삭제 표시**: 삭제한 작품은 다운로드 기록에 삭제 표시가 남으며 갤러리, 필터와 통계에는 표시되지 않습니다. 일괄 다운로드, 사용자 스크립트나 예약 작업에서 '다운로드한 작품 건너뛰기'를 켜면 기본적으로 '이전에 다운로드했으나 삭제됨'으로 인식하여 건너뜁니다. 다시 다운로드하려면 다운로드 설정에서 '삭제된 작품 다시 다운로드 허용'을 선택하세요. 다운로드에 성공하면 삭제 표시가 자동으로 제거됩니다.

## 컬렉션 및 게스트 초대

로컬 컬렉션은 Pixiv 온라인 북마크와 별개입니다. 왼쪽 사이드바 하단의 '+ 새 컬렉션'을 눌러 만듭니다. 컬렉션을 오른쪽 클릭하거나 편집 페이지에서 이름 변경, 사용자 정의 아이콘 업로드(PNG / JPG / WebP, 최대 1 MB), 별도 다운로드 폴더 연결 또는 삭제를 수행할 수 있습니다. 썸네일 위에 마우스를 올려 하트 아이콘을 누르거나 상세 페이지에서 '컬렉션에 추가...'를 누르면 컬렉션에 넣을 수 있습니다.

관리자는 갤러리 오른쪽 위의 '방문자 초대'를 눌러 유효 기간, 콘텐츠 등급(예: SFW만)과 태그 / 작가 허용 목록을 설정하고 `http://host:port/invite?code=xxx` 형식의 읽기 전용 공유 링크를 생성할 수 있습니다. 초대 코드는 `http://localhost:6999/pixiv-invite-manage.html`에서 관리합니다. 게스트는 수정이나 일괄 관리 권한이 없지만 브라우저에 표시된 이미지를 따로 저장할 수는 있습니다.

## 작품을 찾을 수 없을 때와 통계 화면

예상한 작품을 찾을 수 없으면 먼저 검색과 필터 조건, 특히 업로드 날짜 범위와 3상태 태그를 초기화하고 초대 코드 허용 목록, 현재 연결한 데이터베이스, 다운로드 폴더와 삭제 표시를 확인하세요. 디스크에서 파일을 이동하는 것만으로 다른 데이터베이스가 갱신되지는 않습니다. 이전 및 복원은 [저장소 및 백업](/ko/storage)을 참고하세요.

관리자는 `http://localhost:6999/pixiv-stats.html`에서 작품 및 이미지 총수, 월별 다운로드 선 그래프, 상위 작가 순위와 인기 태그 워드클라우드를 볼 수 있습니다. `gallery-tools` 플러그인이 필요하며 작가나 태그를 누르면 해당 갤러리 필터로 바로 이동합니다.
