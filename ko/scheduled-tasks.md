# 예약 작업

## 사전 조건

관리자 권한, 유효한 Cookie와 다운로드 루트가 필요합니다. 먼저 수동 다운로드로 원본과 필터가 원하는 대로 동작하는지 확인하세요.

## 첫 예약 작업 만들기

새 작업에서 이름, 주기 또는 cron, source type, 상한, 동시성, Cookie와 프록시를 설정합니다. 저장 후 다음 실행 시간과 최근 실행 결과를 확인하세요.

### 예: 작가 새 작품

사용자 모드에서 작가 ID를 입력하고 새 작품 범위와 페이지 상한을 선택합니다. 이미 처리된 작품은 history와 deduplication 정책에 따라 건너뜁니다.

## Cron 형식

cron 표현식은 분, 시, 일, 월, 요일 필드를 사용합니다. 서버의 시간대와 일광 절약 시간 변경을 고려하고, 너무 짧은 주기로 Pixiv를 호출하지 마세요.

## source type 동작

- 작가 새 작품: 사용자 모드에서 작가의 새 작품을 검색
- 작가 의뢰 작품: 사용자의 의뢰 범위에 해당하는 작품 검색
- 검색 키워드: 검색 모드의 키워드·필터 사용
- 만화/소설 시리즈: 시리즈 모드로 장과 작품 검색
- 내 북마크/내 작품/팔로잉/컬렉션: 빠른 가져오기에서 저장한 원본 재사용

## 첫 실행 가져오기 제한

첫 실행에 전체 이력을 다시 가져오지 않도록 작업별 상한을 설정할 수 있습니다. 제한을 초과한 항목은 다음 실행으로 넘깁니다.

## 기존 작업 관리

작업을 일시 중지, 재개, 실행, 편집, 복제 또는 삭제할 수 있습니다. 실행 이력에는 발견·다운로드·건너뜀·실패 수와 마지막 오류가 표시됩니다.

## 전용 프록시와 Cookie

작업별 프록시와 Cookie는 전역 값보다 우선할 수 있습니다. 자격 증명을 바꾼 후 다음 실행이 새 값을 사용하는지 확인하세요.

## 과다 사용 일시 중지

Pixiv가 제한을 반환하거나 실패율이 높아지면 작업을 일시 중지하고 간격·동시성을 낮춥니다. 자동 재시도만으로 제한을 악화시키지 마세요.

## 이메일 및 푸시 알림

작업 실패, 완료와 유지보수 이벤트별로 메일·푸시 알림을 선택할 수 있습니다. 채널 설정과 보존 기간은 [설정](/ko/configuration)을 참고하세요.
