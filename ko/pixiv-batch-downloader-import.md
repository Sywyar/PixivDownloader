# PixivBatchDownloader 가져오기 지원

공식 `pixiv-batch-downloader-import` 플러그인은 전용 사용자 스크립트와 함께 PixivBatchDownloader가 다운로드한 일러스트, 만화, 움짤과 소설을 **읽기 전용 참조**로 로컬 갤러리에 등록합니다. 원본 파일을 복사하거나 이동하지 않으며 갤러리 기록을 삭제해도 원본 파일은 보존됩니다. 기존 PixivBatchDownloader 기록을 갤러리에 일괄 가져올 수도 있습니다.

브라우저와 이 프로그램은 같은 컴퓨터에서 실행해야 하며 프로그램은 개인용 모드(`solo`)여야 합니다. 스크립트는 로컬 루프백 서비스에만 연결하므로 브라우저의 '파일 URL에 대한 액세스 허용' 권한은 필요하지 않습니다.

## 자동 가져오기 활성화

일반 배포 패키지에는 이 플러그인이 사전 설치되어 있지 않으며 오프라인 전체 패키지에는 포함되어 있습니다.

1. 플러그인 마켓에서 'PixivBatchDownloader 가져오기 지원'을 설치하고 활성화한 후 프로그램을 완전히 종료하고 재시작합니다.
2. 브라우저에서 PixivBatchDownloader와 Tampermonkey를 활성화합니다. Chrome 138+에서는 '확장 프로그램 → Tampermonkey → 세부정보'에서 '사용자 스크립트 허용'을 켜야 합니다. 다른 버전은 [Tampermonkey 권한 안내](https://www.tampermonkey.net/faq.php?ext=dhdg&q=Q209)를 참고하세요.
3. 외부 다운로드 루트 폴더를 설정합니다. 데스크톱의 '설정 → PixivBatchDownloader 가져오기 지원'에서 선택하거나 `config/plugins/pixiv-batch-downloader-import.properties`에 절대 경로 `pixiv-batch-downloader-import.source-root=D:/Downloads`를 입력합니다. Windows에서는 슬래시를 사용하며 저장 즉시 적용됩니다. 첫 다운로드 완료 후 팝업에서 후보 폴더를 확인할 수도 있습니다.
4. 브라우저에서 로컬 서비스에 로그인한 후 `http://localhost:6999/api/scripts/pixiv-batch-downloader-import.user.js`에 접속하거나 다운로드 페이지의 '사용자 스크립트'에서 가져오기 스크립트를 설치하고 활성화한 다음 Pixiv 페이지를 새로고침합니다.
5. 로컬 백엔드를 실행한 상태로 PixivBatchDownloader를 평소처럼 사용합니다. 작품의 모든 파일이 디스크에 저장되면 해당 갤러리에 자동 등록됩니다.

폴더를 미리 설정하지 않았다면 첫 완성 작품의 절대 경로를 기준으로 데스크톱에 후보 폴더 확인 팝업이 뜹니다. 후보는 해당 작품의 모든 파일이 공유하는 부모 폴더이므로 단일 작품의 하위 폴더일 수 있습니다. PixivBatchDownloader의 상대 경로를 제외한 최상위 다운로드 루트를 선택하세요. 예를 들어 파일이 `D:/Downloads/pixiv/작가/123_p0.png`에 있고 상대 경로가 `pixiv/작가`이면 `D:/Downloads`를 선택해야 합니다. '폴더 저장'을 누르면 적용되고 자동 재시도합니다. 취소하면 설정을 기록하지 않으며 같은 후보에 대한 팝업은 반복되지 않습니다.

## 자동 가져오기 상태 및 통계

다운로드가 완료됐지만 갤러리에 나타나지 않으면 Pixiv 페이지의 Tampermonkey 메뉴에서 '자동 가져오기 상태'를 여세요.

- `SOURCE_ROOT_REQUIRED`: 데스크톱 팝업에서 후보 폴더를 확인하거나 설정에서 다운로드 루트 폴더를 지정해야 합니다.
- `SERVER_UNAVAILABLE`: 로컬 백엔드가 실행 중인지, 개인용 모드로 로그인했는지, 스크립트 메뉴의 '로컬 서비스 주소 설정'에 올바른 포트가 지정되어 있는지 확인하세요.

백엔드를 일시적으로 사용할 수 없으면 등록 대기 기록은 Tampermonkey 저장소에 보관됩니다(최대 1,000개 작품, 5,000개 파일, 8 MiB). Pixiv 페이지를 열면 간격을 늘리며 자동 재시도합니다. 페이지가 누락되었거나 메타데이터를 알 수 없거나 다운로드를 건너뛰었거나 경로가 충돌하는 작품은 완성 작품으로 등록하지 않습니다. 외부 이벤트는 [PixivBatchDownloader의 고정 버전 소스](https://github.com/xuejianxianzun/PixivBatchDownloader/tree/e3bbdfdd2fb452cc9073450b8aa1ad065f982b64)를 기준으로 하며 같은 배치의 메타데이터가 다운로드 성공 이벤트보다 먼저 도착해야 합니다.

데스크톱 홈의 '가져온 작품'은 `(작품 유형, 작품 ID)`로 중복을 제거하여 이 플러그인이 성공적으로 가져온 작품 수를 집계합니다. `data/pixiv-batch-downloader-import/plugin.db`에 저장되므로 백업할 때 함께 보존하세요. 갤러리 기록을 삭제해도 이 수치는 줄어들지 않습니다.

## 파일 형식, 읽기 전용 참조 및 상한

- 실제 파일은 설정한 루트 폴더 안에 있어야 합니다. 심볼릭 링크, junction, 폴더 범위를 벗어난 경로, 누락된 파일과 잘못된 파일 헤더는 거부합니다.
- 이미지는 JPEG, PNG, WebP, GIF를 지원합니다. 움짤은 WebP, GIF, APNG, WebM, MP4, ZIP을 지원합니다. ZIP 썸네일에는 첫 번째 이미지 항목을 사용하며 원본은 ZIP으로 유지합니다. 소설은 TXT와 EPUB를 지원합니다. 본문은 같은 수집 작업의 메타데이터에서 가져오며 소설 표지, 첨부 파일과 원래 게시 시간은 가져오지 않습니다. 업로드 시간은 등록 시간으로 표시됩니다.
- 기존 기록은 소프트 삭제된 기록도 덮어쓰거나 중복 등록하지 않습니다. 소설 플러그인을 사용할 수 없으면 대기 기록을 보존하고 성공을 반환하지 않습니다. 미디어 유지 관리 도구는 외부 읽기 전용 작품을 건너뜁니다. 원본 파일을 이동했다면 경로를 수정해야 하며 프로그램이 새 위치를 추측하지 않습니다.
- 페이지당 파일 상한은 1 GiB, 작품당 상한은 8 GiB / 1,000페이지입니다. HTTP 요청당 상한은 12 MiB, JSON 깊이는 20, 소설 본문은 300만 자입니다.

## 이전 기록 가져오기

플러그인을 설치하기 전의 다운로드 기록은 두 가지 방법으로 추가할 수 있습니다. 두 방법 모두 위의 파일 형식과 읽기 전용 참조 규칙을 따르며 기존 작품은 소프트 삭제된 작품도 자동으로 건너뜁니다. 가져온 뒤 데이터 보완 도구로 지원 필드를 채울 수 있지만 누락된 원본 파일은 복원할 수 없습니다.

### 방법 1: 사용자 스크립트로 브라우저 기록 직접 읽기(파일 내보내기 불필요)

1. 로컬 백엔드를 실행한 상태로 플러그인 설정에서 '외부 다운로드 폴더'를 저장하고 로그인한 Pixiv 페이지를 새로고침합니다.
2. PixivBatchDownloader를 사용하는 동일한 브라우저 프로필에서 원래 Pixiv 사이트를 열고 외부 다운로드를 일시 중지한 후 Tampermonkey 메뉴의 '브라우저 다운로드 기록 읽기 → 읽기 및 검사'를 누릅니다. 스크립트는 현재 사이트의 기록 데이터베이스를 읽기 전용으로 나누어 검사하며 한 번에 최대 1 GiB를 처리합니다. 그동안 기록을 수정하거나 비우지 마세요.
3. 가져올 항목, 기존 항목과 누락 / 충돌 개수를 확인하고 '가져오기 시작'을 누릅니다. 상세 내역은 최대 100개 표시하며 가져올 항목이 `0`이면 검사로 끝납니다. 브라우저가 각 항목의 Pixiv 메타데이터를 요청하고 로컬 서비스가 파일을 검증한 후 등록합니다. Pixiv Cookie는 브라우저에 남으며 로컬 서비스로 보내지 않습니다.

가져오는 동안 페이지를 열어 두세요. 100%는 처리가 끝났다는 뜻이며 모든 항목이 성공했다는 뜻은 아닙니다. 취소, 페이지 이탈 또는 서버 변경은 이후 처리를 중단하며 이미 등록한 작품은 유지됩니다. 임시 데이터는 `data/pixiv-batch-downloader-import/browser-history/`에 저장되며 정상 종료하거나 약 15분 동안 유휴 상태가 지속되면 자동 정리됩니다.

### 방법 2: 내보낸 JSON을 데스크톱 도구에서 가져오기

1. 데스크톱 GUI의 '도구'에서 'PixivBatchDownloader 기록 가져오기'를 엽니다. 사용자 스크립트는 필요하지 않습니다.
2. PixivBatchDownloader에서 기록 JSON을 내보냅니다. 여러 조각 파일이 있으면 같은 별도 폴더에 넣고 해당 폴더를 선택합니다. 파일당 최대 512 MiB, 최대 64개 파일, 합계 1 GiB입니다.
3. 원본 파일 루트 폴더를 선택합니다. 기록의 상대 경로 `n`과 결합한 경로가 실제 파일과 일치해야 합니다. 이번 선택은 자동 가져오기 설정을 바꾸지 않습니다. '검사 및 미리보기'를 누릅니다.
4. 필요하면 이번 작업에 사용할 Pixiv Cookie를 입력합니다. Cookie는 영구 저장하지 않습니다. '가져오기 시작'을 누르고 성공, 건너뜀과 실패 개수를 확인합니다. 임시 정리 폴더는 `data/pixiv-batch-downloader-import/history-import/`이며 작업 종료나 정상 종료 시 정리됩니다.
