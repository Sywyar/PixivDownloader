# 네트워크 액세스 및 타사 서비스

## 네트워크 개요

PixivDownloader는 동작에 필요한 요청만 수행하며, 요청의 주체·시점·목적·전송 데이터는 플러그인과 작업에 따라 달라집니다. Cookie, 계정, 작품 정보와 로컬 경로는 외부 분석 서비스로 전송하지 않습니다.

## 핵심 및 기본 요청

백엔드는 업데이트 확인, Pixiv 다운로드, FFmpeg 다운로드와 선택적 플러그인 카탈로그를 위해 외부에 연결할 수 있습니다. 브라우저의 같은 출처 요청은 별도 경로이며 관리자 설정에 따라 동작합니다.

## Pixiv 다운로드와 탐색

`download-workbench`는 작품, 작가, 검색, 시리즈, 컬렉션과 팔로잉 메타데이터를 Pixiv에서 가져옵니다. `novel`은 소설 본문과 시리즈를 가져옵니다. 로그인된 요청은 사용자가 제공한 Pixiv Cookie를 사용합니다.

## `douyin` 플러그인

Douyin 기능은 Douyin 공개 페이지와 API에 접근할 수 있습니다. 출처, 서명된 URI와 사용자의 인증 상태에 따라 요청과 사용 가능한 기능이 달라집니다.

## `ai` 플러그인

AI 번역과 분석은 관리자가 설정한 OpenAI 호환 LLM 엔드포인트로 본문 또는 필요한 프롬프트 데이터를 보낼 수 있습니다. 해당 플러그인을 비활성화하거나 모델 설정을 비우면 요청이 발생하지 않습니다.

## `tts` 플러그인

온라인 TTS는 선택한 엔진의 음성 서비스에 텍스트와 음성 파라미터를 보냅니다. 브라우저 엔진은 로컬 OS 기능을 사용하며 같은 외부 요청을 만들지 않습니다.

## `push` 및 `mail` 플러그인

푸시와 메일은 관리자가 설정한 공급자 엔드포인트로 알림 제목, 본문과 수신 대상 정보를 전송합니다. 각각의 채널과 알림 유형을 끄면 해당 요청을 중지할 수 있습니다.

## 플러그인 시장, FFmpeg 및 사용자 스크립트 업데이트

플러그인 시장은 설정된 공식 또는 사용자 지정 저장소에서 카탈로그와 아티팩트를 가져옵니다. 서명, 크기와 SHA-256이 검증됩니다. FFmpeg는 설치 시에만 다운로드하며, 사용자 스크립트 업데이트는 브라우저의 사용자 스크립트 관리자 정책을 따릅니다.

## 공식 플러그인의 선택적 설문(PostHog)

설문은 공식 빌드와 기능이 활성화된 경우에만 최소 이벤트를 PostHog로 보냅니다. Cookie, 계정, 작품, 로컬 경로와 원래 설치 ID는 보내지 않습니다. PostHog 플러그인이 없거나 비활성화되면 설문은 조용히 꺼집니다.

## 고정된 공개 대상이 없는 플러그인

`gui-swing`과 `gui-compose`는 애플리케이션의 로컬 desktop document, 창, tray, theme와 플랫폼 리소스를 사용하며 고정된 제3자 런타임 대상에 연결하지 않습니다. 관리자가 URL, SMTP, LLM, 프록시 또는 사용자 지정 저장소를 설정하면 대상이 동적으로 바뀔 수 있으므로 저장된 설정과 플러그인별 문서를 함께 검토하세요.

## 로컬·같은 출처·관리자 지정 대상

웹 UI와 로컬 PAC 엔드포인트는 기본적으로 같은 호스트에서 제공됩니다. 관리자 지정 SMTP, 프록시와 저장소는 시스템 환경에 따라 외부 연결이 될 수 있습니다.

## 프록시 적용 범위

백엔드 프록시는 호스트 또는 작업 경로가 선택한 요청에 적용됩니다. 브라우저 직접 연결, SMTP와 명시적 직결 정책은 프록시를 우회할 수 있습니다.

## 개발·빌드·릴리스 중 네트워크

Maven, npm, GitHub Actions, Docker와 패키징 도구는 의존성·아티팩트·릴리스 서비스에 연결할 수 있습니다. 이는 최종 사용자 런타임 요청과 별개의 공급망 경계입니다.

## 링크와 URL 참조

문서의 링크는 요청 자체가 아닙니다. 앱 내 원격 본문 링크는 사용자 확인 후 브라우저에서 열리며, 본문 안의 스크립트·추적·자동 리디렉션은 허용되지 않습니다.
