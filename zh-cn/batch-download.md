# URL 批量下载

已有一批作品链接或 ID 时，可在下载页「批量导入单作品」一次粘贴并下载。支持插画、漫画、动图与小说混合输入；下载小说需启用 `novel` 插件，下载受限作品需保存含 `PHPSESSID` 的 Pixiv Cookie。

## 操作步骤

1. 打开 `http://localhost:6999/pixiv-batch.html`，切换到「批量导入单作品」。
2. 在文本框粘贴 URL 或 ID 列表（每行一条），点击「获取信息」。
3. 核对识别出的作品类型与数量。
4. 按需设置附加筛选与下载设置，将作品加入队列并点击「开始下载」。
5. 下载结束后在队列检查结果（完成、已存在跳过、筛选跳过与失败分别统计）。

## 输入格式

每行填写一条记录，以下作品 ID 仅为格式示例，使用时请替换为实际作品：

```text
# 完整 URL
https://www.pixiv.net/artworks/12345678
https://www.pixiv.net/novel/show.php?id=87654321

# 纯数字 ID（默认按插画处理，可选附带标题）
12345678
12345679 | 作品标题

# 区段头：指定后续纯数字 ID 的作品类型
artwork:
11111
22222
novel:
33333
44444 | 小说标题

# OneTab / N-Tab 导出格式
https://www.pixiv.net/artworks/55555 | 标签页标题
```

- `artwork:` 与 `novel:` 单独成行（不区分大小写，半角 / 全角冒号均可），将后续纯数字 ID（或 `id | title`）按对应类型解析，直到遇到下一个区段头或输入末尾。
- 以 `https://` 开头的完整链接始终按链接自身类型解析，不受区段头影响。
- 可直接粘贴 OneTab / N-Tab 导出的 `URL | 标题` 列表，非 Pixiv 作品链接会自动跳过。

## 附加筛选与下载设置

「附加筛选」支持按内容分级（全部 / 全年龄 / R18+ / R-18 / R-18G）、AI 作品（全部 / 排除 AI / 仅 AI）、标签（逗号分隔，精确或模糊匹配且需全部命中）、最低收藏数、插画页数、小说字数与作品类型（插画 / 漫画 / 动图）过滤。下载时逐件判定，不满足条件的作品在队列中显示具体跳过原因。

| 下载设置 | 作用 |
| --- | --- |
| 文件名模板 | 使用 `{artwork_id}`、`{author_name}`、`{page}` 等变量，详见[文件名模板变量](/zh-cn/usage-guide#文件名模板变量) |
| 下载目录（收藏夹） | 指定保存到的本地收藏夹 |
| 跳过已下载作品 | 命中下载历史时直接跳过 |
| 实际目录检测 | 除查历史记录外，同时检查磁盘文件是否存在；缺失则重新下载 |
| 允许已删除的作品被重新下载 | 画廊删除的作品带有[删除标记](/zh-cn/gallery#删除作品)，默认跳过；勾选后重新下载并清除删除标记 |
| 自动收藏 | 下载完成后调用 Pixiv API 收藏作品（需有效 Cookie） |
| 小说格式 | 选择保存为 TXT、HTML 或 EPUB |

## 排障与相关入口

- **纯数字小说 ID 被当成插画**：改用完整小说链接，或在数字 ID 上方单独添加一行 `novel:`。
- **识别数量少于输入行数**：检查空行、区段头、非 Pixiv 链接或格式错误的 URL，以预览列表为准。
- **作品被跳过或下载失败**：查看队列条目的具体原因；在 Pixiv 原站确认作品可访问，并核对 Cookie 与代理设置（参阅[常见问题](/zh-cn/faq)）。

下载指定画师作品见[画师批量下载](/zh-cn/user-download)，按关键词查找见[搜索下载](/zh-cn/search)，定时自动下载见[计划任务](/zh-cn/scheduled-tasks)。
