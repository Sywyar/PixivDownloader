# 画师批量下载

在下载页「User 模式」输入画师主页链接或数字 ID，可预览该画师的插画、漫画、动图、小说或已公开约稿成品，并选择全部或部分作品下载。实际可获取范围受当前账号权限、附加筛选和已下载检测约束。

## 操作步骤

1. 打开 `http://localhost:6999/pixiv-batch.html`，切换到「User 模式」。
2. 粘贴画师主页链接或纯数字用户 ID。
3. 选择下载范围（插画 + 漫画 + 动图、小说或约稿；小说需启用 `novel` 插件）。
4. 点击「解析并预览」，按需配置附加筛选。
5. 点击「全部入队」或勾选部分作品入队，再点击「开始下载」。
6. 下载完成后在队列检查成功、跳过和失败记录。

支持以下输入格式（`123456` 仅为示例，请替换为实际画师 ID）：

```text
https://www.pixiv.net/users/123456
https://www.pixiv.net/users/123456/artworks
https://www.pixiv.net/users/123456/illustrations
https://www.pixiv.net/users/123456/novels
https://www.pixiv.net/users/123456/request/artworks
https://www.pixiv.net/en/users/123456
123456
```

## 下载范围与附加筛选

| 范围 | 包含内容 |
| --- | --- |
| 插画 + 漫画 + 动图 | 该画师投稿的图片类作品 |
| 小说 | 该画师投稿的小说作品 |
| 约稿 | 该画师已完成并公开的约稿（リクエスト）成品，按普通插画链路预览、入队、下载与判重 |

粘贴约稿页链接（`/users/{id}/request/artworks`）时会自动切换到「约稿」范围。预览区每次展示一种范围，切换范围会清空当前预览列表，但不会清空已加入的下载队列；可先将插画加入队列，再切换到小说入队后一并下载。

「附加筛选」可按内容分级、排除 AI、最低收藏数、标签或页数过滤，在预览和实际下载时均逐件生效。画师作品数量较多时，建议结合附加筛选、降低「最大并发数」并设置「作品间隔」（毫秒），减少触发上游限制的风险。

## 存为计划任务

在页面底部「存为计划任务」卡片填写任务名称与触发方式，可定期自动发现并下载该画师的新作。需登录访问的内容必须为任务绑定有效 Cookie；配置与水位线增量规则见[计划任务](/zh-cn/scheduled-tasks)。

## 未获取到预期作品

先确认输入的是画师用户 ID 而非单件作品 ID，再核对所选范围（图片 / 小说 / 约稿）、附加筛选及 Cookie 登录态。已删除或无权访问的作品不会因点击「全部入队」而变为可下载。
