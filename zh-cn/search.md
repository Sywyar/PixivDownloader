# 搜索下载

在下载页「Search 模式」输入关键词，由后端调用 Pixiv 搜索接口获取结果，筛选后加入下载队列。此功能搜索的是 Pixiv 线上作品，不是本地画廊检索。

!> Search 模式必须先保存含 `PHPSESSID` 的有效 Pixiv Cookie；未配置时搜索按钮不可用。

## 操作步骤

1. 打开 `http://localhost:6999/pixiv-batch.html`，切换到「Search 模式」。
2. 输入搜索关键词（中文、日文、英文均可）。
3. 选择子模式、排序方式与内容分级，点击「搜索」。
4. 在预览网格中勾选作品并点击「选中入队」，或点击「当前页全部入队」。
5. 点击「开始下载」，在队列核对下载结果。

## 搜索范围、排序与筛选

| 子模式 | 获取范围 |
| --- | --- |
| 搜索模式 | 仅获取第 1 页结果，适合快速确认关键词 |
| 作品批量获取模式 | 获取到指定结束页（默认 3 页）；结束页设为 `-1` 时向后翻页拉取全部结果（翻页间隔约 10 秒，最多 1,000 页） |

| 排序方式 | 说明 |
| --- | --- |
| 最新 (`date_d`) | 按发布时间倒序，所有登录账号可用 |
| 热门 (`popular_d`) | 按热门程度排序，需 Pixiv Premium 会员权限；无权限时请改用「最新」，勿将返回结果视为完整热门榜 |

内容分级可选「全年龄」「R-18」「R-18G」或「全部」（需 Pixiv 账号开启相应年龄设置）。结果加载后，可通过「附加筛选」按排除 AI、最低收藏数、标签与页数范围实时过滤预览页。

## 结果核对与计划任务

建议先用单个关键词和较少页数验证结果，再扩大页数范围。搜索结果为空时检查关键词、分级、账号权限和附加筛选；搜索报错时检查 Cookie 是否过期及后端代理连接。队列中的筛选跳过不代表搜索请求失败。

需要将当前搜索保存为定时任务时，在页面底部「存为计划任务」卡片设置触发频率即可。「最新排序 + 结束页 `-1`」的任务支持水位线增量抓取，其余组合与上限规则见[计划任务](/zh-cn/scheduled-tasks)。
