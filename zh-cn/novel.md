# 小说与朗读

启用 `novel` 插件后，可将单篇小说或整套小说系列保存为 TXT、HTML 或 EPUB，并在本地小说画廊中阅读、全文检索、翻译和听书。翻译需启用 `translation` 插件，AI 多角色朗读需同时配置 `ai` 与 `tts` 插件。下文 ID 仅为格式示例，请替换为你有权访问的实际作品或系列。

## 下载小说与系列

### 单篇小说

1. 打开 `http://localhost:6999/pixiv-batch.html`，选择「批量导入单作品」。
2. 粘贴小说链接：

   ```text
   https://www.pixiv.net/novel/show.php?id=12345678
   ```

   只填纯数字 ID 时，需在上方单独写一行 `novel:` 区段头：

   ```text
   novel:
   12345678
   ```

3. 在下载设置中选择保存格式（TXT / HTML / EPUB），加入队列并开始下载。自己的小说或收藏也可从[快捷获取](/zh-cn/quick-access)直接入队。

### 小说系列与 EPUB 合订本

1. 在下载页选择「系列模式」，粘贴系列链接并点击「解析并预览」：

   ```text
   https://www.pixiv.net/novel/series/123456
   ```

2. 选择「全部入队」或勾选部分章节入队，开始下载。

| 格式 | 特点 |
| --- | --- |
| TXT | 纯文本，无排版格式 |
| HTML | 保留 Ruby 注音、标题等原始排版，可在浏览器直接打开 |
| EPUB | 遵循 EPUB3，包含多级章节目录、内嵌封面与书籍元数据（简介、标签、来源链接） |

- **下载时生成合订本**：在下载设置勾选「生成系列合订本」并选择格式（推荐 EPUB），文件保存在 `novel-series-{seriesId}/{系列标题}.epub`（译文合订本为 `{系列标题}_{语言代码}.epub`）。
- **在系列目录页随时生成**：打开 `pixiv-series.html?type=novel&seriesId=...`，点击「下载合订本」，选择**原文**或已有**译文语言**即可按当前数据库状态即时生成并下载 EPUB。选择译文语言时，未翻译章节会回退为原文；若需整本统一语言，请先完成「翻译整个系列」。

## 本地阅读与全文检索

访问小说画廊：

```text
http://localhost:6999/pixiv-novel-gallery.html
```

支持按标题、作者、系列、标签筛选，以及基于本地索引的**正文全文检索**。点击卡片进入 `pixiv-novel.html?id=<id>` 阅读正文、查看系列目录并切换上 / 下一章。

## 听书（单一语音 TTS）

在小说阅读页点击「听书」按钮，按段落顺序朗读正文，自动高亮当前段落、滚动页面并保存阅读进度：

| 语音引擎 | 说明 |
| --- | --- |
| 浏览器引擎（默认） | 调用浏览器 / 系统语音服务；可用音色及是否联网取决于浏览器与操作系统 |
| 在线引擎（Edge 神经语音） | 经后端代理调用微软在线 TTS，需联网 |

## AI 多角色朗读（管理员）

在桌面设置「AI 模型」中同时配置并启用「文本模型」（OpenAI 兼容大模型）和「TTS 模型」（本地 VoxCPM / CosyVoice 或云端 TTS）后，阅读页可使用「多角色朗读」（任一未启用时，「听书」中不会显示该引擎选项）。先确认模型与 TTS 连接可用；分析失败检查文本模型响应，合成失败检查 TTS 引擎与参考音配置。

- **逐句归属与播放**：大模型将整章逐句归属给旁白与各角色，按固定角色音色合成、顺序播放并预取下一句；播放栏显示当前说话人与台词。
- **旁白与角色音色锁定**：首次分析前可试听并锁定旁白基调（默认温暖女声）；在配角面板可查看或修改各角色的性别、年龄和英文音色画像，保存后即锁定，后续章节不再被 AI 覆盖，修改对后续合成立即生效。
- **角色参考音克隆**：可为任意角色（含旁白）生成标准参考音或上传 WAV / MP3（可附转录文本），跨句与跨章保持一致音色并保留情绪起伏；变更参考音后会自动按新音色重算缓存音频。可在配置中关闭克隆或调整生成上限。
- **音色冲突处理**：当正文新证据与已锁定角色音色明显冲突时，面板会列出冲突供选择「采纳建议 / 保留当前 / 改写」。
- **分段字数与缓存**：`0`（默认）表示整章单次请求分析（超长正文会拒绝并提示缩小范围）；填入正整数则按段落累积到约该字数分批分析。分析结果缓存在本地，重播无需重算，需要时可点「重新分析」。

## 翻译引擎（管理员）

安装并启用 `translation` 插件（会随依赖安装 `novel-translation-contract`），在桌面设置「翻译」页选择引擎，保存后按提示重启后端。阅读页手动翻译、系列翻译与下载后自动翻译共用所选引擎：

| 引擎 | 配置与限制 |
| --- | --- |
| AI 模型 | 复用 `ai` 插件已保存的模型、基础地址与凭据（支持本地 OpenAI 兼容服务） |
| 有道 | 填写有道智云文本翻译 API 的应用 ID 与应用密钥（有道词典客户端账号不可用） |
| LibreTranslate | 填写自建服务基础地址（不含 `/translate`）与可选 API Key；需自行准备服务与语言模型 |

- 有道与 LibreTranslate 接收目标语言代码（如 `en`、`ja`、`zh-CN`），按段落且单次最多 1,000 个 Unicode 字符分批请求（分段字数设 `0` 时取 1,000，设正数时取较小值），保留图片、分页、跳转等 Pixiv 标记，标题与正文分别请求，不使用或学习 AI 名词映射表。
- AI 凭证归 `ai` 插件管理，有道与 LibreTranslate 凭证归 `translation` 插件管理，语音凭证归 `tts` 插件管理。

## AI 翻译与名词映射表（管理员）

配置并启用文本模型后，在小说阅读页或系列目录页点击「翻译」：

- **目标语言**：默认按当前界面语言预填，可改为任意自然语言名称。
- **分段字数**：`0` 表示整篇单次翻译；长篇可填正整数（如 `5000`）按段落切分后逐段翻译拼接。
- **已有译文处理**：选择「覆盖重译」或「跳过」。
- **名词映射表**：保存「原文 ↔ 各语言译名」以统一专有名词译法。系列作品默认共用同名表，单篇作品默认使用各自表；也可选择不使用、切换现有表或新建 / 编辑映射表。AI 在翻译中发现的新专有名词会自动并入所选表供后续章节复用（模型仍可能偏离映射，请核对译文）。
- **内容语言切换**：阅读页与系列页的「内容语言」下拉可独立于界面语言切换原文或已有译文（正文、章节标题、系列名与译文 EPUB 标题同步切换，未译项回退原文），听书也会朗读当前所选语言。章节标题与正文在同一 AI 请求中翻译；系列名翻译会附带同语言已译章节标题对与名词映射表。
- **翻译整个系列**：在系列页按章节顺序批量翻译，支持后台隐藏或取消（取消后保留已译章节），完成后生成 `{系列标题}_{语言代码}.epub`。选择「跳过已翻译」时，先用一次轻量请求将目标语言名解析为规范语言代码，已存在译文的章节直接跳过。重新生成系列合订本时会同步刷新所有已存在译文语言的合订本。
- **下载后自动翻译**：在下载页或计划任务「小说设置」勾选「新下载小说自动翻译」并指定目标语言与分段字数。自动翻译固定使用作品 / 系列的默认名词映射表，在后台按系列章节顺序执行，不阻塞下载；下载成功即记为完成，翻译失败仅标注「完成（翻译失败）」，不影响已保存的原文。

## 删除、批量管理与结果核对

管理员可在阅读页删除单篇小说，或在小说画廊通过「批量管理」全选筛选结果、批量导出 ZIP（可选导出后删除源文件，在侧栏「任务列表」查看进度）、加入收藏夹或批量删除。程序管理的文件删除后不可从界面撤销，但保留[删除标记](/zh-cn/gallery#删除作品)以避免默认重复下载；通过[导入外部下载](/zh-cn/pixiv-batch-downloader-import)登记的只读源文件会保留。完整批量管理规则与[作品画廊](/zh-cn/gallery)一致。

下载完成后请分别检查本地 TXT / HTML / EPUB 文件与小说画廊记录。若磁盘有文件但画廊无记录，先核对当前数据库与下载目录是否属于同一实例，切勿删除数据库尝试重建。
