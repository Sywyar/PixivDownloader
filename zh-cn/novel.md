# 小说与朗读

启用 `novel` 插件后，可将单篇小说或整套小说系列保存为 TXT、HTML 或 EPUB，并在本地小说画廊中阅读、全文检索、翻译和听书。翻译需启用 `translation` 插件，AI 多角色朗读需同时配置 `ai` 与 `tts` 插件。下文 ID 仅为格式示例，请替换为你有权访问的实际作品或系列。

## 下载小说与系列

### 单篇小说

1. 打开 `http://localhost:6999/pixiv-batch.html`，选择「批量导入单作品」。
2. 粘贴小说链接：

   ```text
   https://www.pixiv.net/novel/show.php?id=12345678
   ```

   只填纯数字 ID 时，需在上方单独写一行 `novel:` 区段头：

   ```text
   novel:
   12345678
   ```

3. 在下载设置中选择保存格式（TXT / HTML / EPUB），加入队列并开始下载。自己的小说或收藏也可从[快捷获取](/zh-cn/quick-access)直接入队。

### 小说系列与 EPUB 合订本

1. 在下载页选择「系列模式」，粘贴系列链接并点击「解析并预览」：

   ```text
   https://www.pixiv.net/novel/series/123456
   ```

2. 选择「全部入队」或勾选部分章节入队，开始下载。

| 格式 | 特点 |
| --- | --- |
| TXT | 纯文本，无排版格式 |
| HTML | 保留 Ruby 注音、标题等原始排版，可在浏览器直接打开 |
| EPUB | 遵循 EPUB3，包含多级章节目录、内嵌封面与书籍元数据（简介、标签、来源链接） |

- **下载时生成合订本**：在下载设置勾选「生成系列合订本」并选择格式（推荐 EPUB），文件保存在 `novel-series-{seriesId}/{系列标题}.epub`（译文合订本为 `{系列标题}_{语言代码}@{引擎}.epub`）。
- **在系列目录页随时生成**：打开 `pixiv-series.html?type=novel&seriesId=...`，点击「下载合订本」，分别选择阅读语言（原文或已有译文）与翻译引擎即可按当前数据库状态即时生成并下载 EPUB。选择译文语言时，未翻译章节会回退为原文；若需整本统一语言，请先完成「翻译整个系列」。

## 本地阅读与全文检索

访问小说画廊：

```text
http://localhost:6999/pixiv-novel-gallery.html
```

支持按标题、作者、系列、标签筛选，以及基于本地索引的**正文全文检索**。点击卡片进入 `pixiv-novel.html?id=<id>` 阅读正文、查看系列目录并切换上 / 下一章。

阅读页顶部保留返回、听书、翻译和收藏入口。「更多操作」菜单中可切换界面语言和外观、打开 Pixiv 原小说链接；管理员也可从这里导出或删除小说，删除前仍需确认。

管理员可在阅读页的「更多操作」中选择导出，分别选择阅读语言与翻译引擎，直接下载单篇 EPUB。导出不会创建压缩任务或临时归档，也不会修改已下载的源文件。

批量导出从小说画廊勾选作品后操作，同样分别选择语言与引擎，并保留打包方式和 ZIP 选项。译文按已有本地文档的格式生成；没有本地文档时生成 EPUB。只提供所选小说都已保存的译文组合；未翻译的字段保留原文。

## 听书（单一语音 TTS）

在小说阅读页点击「听书」按钮，按段落顺序朗读正文，自动高亮当前段落、滚动页面并保存阅读进度：

| 语音引擎 | 说明 |
| --- | --- |
| 浏览器引擎（默认） | 调用浏览器 / 系统语音服务；可用音色及是否联网取决于浏览器与操作系统 |
| 在线引擎（Edge 神经语音） | 经后端代理调用微软在线 TTS，需联网 |

## AI 多角色朗读（管理员）

在桌面设置「AI 模型」中同时配置并启用「文本模型」（OpenAI 兼容大模型）和「TTS 模型」（本地 VoxCPM / CosyVoice 或云端 TTS）后，阅读页可使用「多角色朗读」（任一未启用时，「听书」中不会显示该引擎选项）。先确认模型与 TTS 连接可用；分析失败检查文本模型响应，合成失败检查 TTS 引擎与参考音配置。

- **逐句归属与播放**：大模型将整章逐句归属给旁白与各角色，按固定角色音色合成、顺序播放并预取下一句；播放栏显示当前说话人与台词。
- **旁白与角色音色锁定**：首次分析前可试听并锁定旁白基调（默认温暖女声）；在配角面板可查看或修改各角色的性别、年龄和英文音色画像，保存后即锁定，后续章节不再被 AI 覆盖，修改对后续合成立即生效。
- **角色参考音克隆**：可为任意角色（含旁白）生成标准参考音或上传 WAV / MP3（可附转录文本），跨句与跨章保持一致音色并保留情绪起伏；变更参考音后会自动按新音色重算缓存音频。可在配置中关闭克隆或调整生成上限。
- **音色冲突处理**：当正文新证据与已锁定角色音色明显冲突时，面板会列出冲突供选择「采纳建议 / 保留当前 / 改写」。
- **分段字数与缓存**：`0`（默认）表示整章单次请求分析（超长正文会拒绝并提示缩小范围）；填入正整数则按段落累积到约该字数分批分析。分析结果缓存在本地，重播无需重算，需要时可点「重新分析」。

## 翻译引擎（管理员）

安装并启用 `translation` 插件（会随依赖安装 `novel-translation-contract`），在桌面设置「翻译」页选择引擎，保存后按提示重启后端。阅读页手动翻译、系列翻译与下载后自动翻译共用所选引擎：

| 引擎 | 配置与限制 |
| --- | --- |
| AI 模型 | 复用 `ai` 插件已保存的模型、基础地址与凭据（支持本地 OpenAI 兼容服务） |
| 有道 | 填写有道智云文本翻译 API 的应用 ID 与应用密钥（有道词典客户端账号不可用） |
| LibreTranslate | 填写自建服务基础地址（不含 `/translate`）与可选 API Key；需自行准备服务与语言模型 |

有道与 LibreTranslate 按各自的请求设置拆分长文本，将短段落合并为批量请求，并保留换行、图片、分页与跳转标记。单段优先在句末或空白处切开；超过上限的长单词按 Unicode 码点切分，不拆开代理对。标题与正文分别请求，不使用或学习 AI 名词映射表。

在桌面设置「翻译」中，只显示当前引擎的请求参数。下面是客户端默认值；配置键分别加前缀 `translation.youdao.` 或 `translation.libretranslate.`。保存后重启后端。

| 参数 | 有道默认值 | LibreTranslate 默认值 | 可设范围 |
| --- | --- | --- | --- |
| `request-chars` | 5000 | 5000 | Youdao: 1–5000; LibreTranslate: 1–1,000,000 |
| `batch-size` | 50 | 10 | 1–100 |
| `request-interval-ms` | 1000 ms | 0 ms | 0–60,000 ms |
| `request-concurrency` | 1 | 1 | 1–32 |
| `max-retries` | 3 | 3 | 0–10 |
| `read-timeout-seconds` | 120 s | 120 s | 1–3600 s |
| `use-proxy` | false | false | true / false |


字符预算同时约束单段和整批总量。有道单次查询的官方上限为 5000 字符；LibreTranslate 的实际字符、批量条数与调用额度由部署方或 API 密钥决定，5000 是本客户端预算。每批 50/10 条和有道 1000 毫秒间隔也只是客户端预设，不代表账户额度。LibreTranslate 按批次中的文本条数消耗调用额度，因此发送间隔会乘以文本条数；第三方服务还需按实际额度调整批量条数。

手动、系列和下载后自动翻译共享各引擎的请求并发与间隔。仅遇到有道 `411` / `412` 或 HTTP `429` 时重试当前批次，并逐次延长等待；遵守 `Retry-After`。需要等待超过 60 秒时先报告限流，冷却期间不提前发送新任务。认证失败、超时及其他错误不自动重发。整篇所选内容全部成功后才保存，失败不会覆盖已有译文；继续原任务时复用已保存的成功响应。日志记录批次、请求、重试和已译字符计数，不记录原文、译文或凭据。
- AI 凭证归 `ai` 插件管理，有道与 LibreTranslate 凭证归 `translation` 插件管理，语音凭证归 `tts` 插件管理。

翻译弹窗显示当前引擎。有道的目标语言下拉框使用官方语种表；LibreTranslate 从配置的服务读取实际支持的目标语言，失败时可重新加载。AI 保留自由输入和名词映射表。失败提示按原因提供处理说明，后端英文日志记录执行 ID、作品 ID、引擎、阶段和安全错误码，不记录正文或密钥。

同一小说、同一目标语言可以同时保留不同引擎的译文。「覆盖重译」和「跳过」只针对当前引擎。阅读页与系列页在同一组控件中分别选择「阅读语言」和「翻译引擎」，只提供已有译文的组合；选择原文时，引擎显示「不适用」。合订本下载与小说导出也分别选择语言和引擎，听书读取当前选中的译文。没有引擎记录的旧译文保留为「来源未知」，不会归入某个引擎；其合订文件仍使用原有语言后缀。AI 模型共用 `ai` 引擎身份，切换 AI 模型不会新增译文版本。

翻译进度由后端保存。关闭或隐藏页面后任务继续执行；重新点击「翻译」可查看原任务，选择暂停、继续或取消。取消会等待正在执行的请求退出，保留成功检查点和已完成章节。丢弃任务需要再次确认，只清除任务与检查点，不删除正式译文。

后端重启后，未完成任务保持暂停，不会自动再次调用翻译服务。继续时会检查原文、目标译文、引擎地址、模型及分段设置；不匹配时需恢复设置或丢弃任务后重新翻译。AI 术语上下文随检查点保留。模型截断输出不会保存为完整译文。可丢弃任务后用更小分段重新翻译；如模型服务支持，也可在服务端调整输出限制后继续。

如果 AI 回复缺少必需字段、语言与目标不符或语言代码无效，任务会暂停。点击继续后会重新请求无效部分，并复用其余已保存的成功响应。

最多保留 256 项任务，检查点合计最多 256 Mi UTF-16 码元。完成记录在新建任务时按 7 天保留期或容量需要清理；暂停和取消的任务需手动丢弃。外部服务已执行但响应尚未落盘时，继续可能再次发送该请求，不能保证只计费一次。

## AI 翻译与名词映射表（管理员）

配置并启用文本模型后，在小说阅读页或系列目录页点击「翻译」：

- **目标语言**：默认按当前界面语言预填，可改为任意自然语言名称。
- **分段字数**：`0` 使用设置中的 `translation.ai-segment-size`（默认 `0`，表示整章）；正数按段落累计到约该长度。此值以 UTF-16 码元计，是段落分组目标，不是严格的请求上限，单个长段落可能超过该值。模型上下文和输出 token 上限仍由 AI 模型配置控制，字符数不能换算成固定 token 数。普通翻译弹窗的 `0` 则继承对应服务的字符预算，正数只能进一步缩小单段。
- **已有译文处理**：选择「覆盖重译」或「跳过」。
- **名词映射表**：保存「原文 ↔ 各语言译名」以统一专有名词译法。系列作品默认共用同名表，单篇作品默认使用各自表；也可选择不使用、切换现有表或新建 / 编辑映射表。AI 在翻译中发现的新专有名词会自动并入所选表供后续章节复用（模型仍可能偏离映射，请核对译文）。
- **内容语言切换**：阅读页与系列页的「阅读语言」与「翻译引擎」可独立于界面语言切换原文或已有译文（正文、章节标题、系列名与译文 EPUB 标题同步切换，未译项回退原文），听书也会朗读当前所选语言。章节标题与正文在同一 AI 请求中翻译；系列名翻译会附带同语言已译章节标题对与名词映射表。
- **翻译整个系列**：在系列页按章节顺序批量翻译，支持后台隐藏或取消（取消后保留已译章节），完成后生成 `{系列标题}_{语言代码}@{引擎}.epub`。选择「跳过已翻译」时，先用一次轻量请求将目标语言名解析为规范语言代码，已存在译文的章节直接跳过。本次翻译只更新所选语言和引擎的合订本。
- **下载后自动翻译**：在下载页或计划任务「小说设置」勾选「新下载小说自动翻译」并指定目标语言与分段字数。自动翻译固定使用作品 / 系列的默认名词映射表，在后台按系列章节顺序执行，不阻塞下载；下载成功即记为完成，翻译失败仅标注「完成（翻译失败）」，不影响已保存的原文。

## 删除、批量管理与结果核对

管理员可在阅读页删除单篇小说，或在小说画廊通过「批量管理」全选筛选结果、批量导出 ZIP（可选导出后删除源文件，在侧栏「任务列表」查看进度）、加入收藏夹或批量删除。程序管理的文件删除后不可从界面撤销，但保留[删除标记](/zh-cn/gallery#删除作品)以避免默认重复下载；通过[导入外部下载](/zh-cn/pixiv-batch-downloader-import)登记的只读源文件会保留。完整批量管理规则与[作品画廊](/zh-cn/gallery)一致。

下载完成后请分别检查本地 TXT / HTML / EPUB 文件与小说画廊记录。若磁盘有文件但画廊无记录，先核对当前数据库与下载目录是否属于同一实例，切勿删除数据库尝试重建。
