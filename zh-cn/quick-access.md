# 快捷获取

在下载页的「快捷获取」中，使用已保存的 Pixiv Cookie 拉取当前账号的收藏、投稿、约稿、关注列表、关注新作和珍藏集。先加载预览，再将作品加入队列并开始下载；获取列表本身不会保存文件。

!> 快捷获取必须先保存含有效 `PHPSESSID` 的 Cookie；未保存时各入口按钮保持禁用。

## 支持的数据源与操作步骤

| 数据源 | 获取范围 |
| --- | --- |
| 我的收藏 | 插画 / 漫画与小说，支持公开与不公开收藏 |
| 我的作品 | 当前账号投稿的插画 / 漫画与小说，含不公开作品 |
| 我的约稿作品 | 当前账号已完成并公开的约稿（リクエスト）成品，按插画链路处理 |
| 我的关注 | 已关注的画师列表（含不公开关注），支持按用户名或 ID 实时过滤 |
| 已关注的用户的新作 | 关注画师的最新插画 / 漫画 / 动图（フォロー新着作品），支持按页浏览 |
| 我的珍藏集 | Pixiv 珍藏集（コレクション）中的插画与小说混合列表 |

1. 打开 `http://localhost:6999/pixiv-batch.html`，切换到「快捷获取」。
2. 点击目标数据源按钮，等待下方展示作品列表。
3. 在「我的关注」或「我的珍藏集」中，点击具体画师或珍藏集展开其作品预览（关注画师可切换插画 / 小说）。
4. 选择单件入队、「整页入队」或「全部入队」，再点击「开始下载」。

## 附加筛选

展开具体作品列表后，可通过「附加筛选」按内容分级、AI 作品、标签、作品类型、页数、字数和最低收藏数实时过滤当前预览页：

- **整页入队**：仅将当前页过滤后可见的作品加入队列。
- **全部入队**：将来源内的全部作品加入队列，下载时逐件按筛选条件判定；不满足条件的作品会在队列中标记跳过原因。

停留在关注画师列表或珍藏集列表时，需先点进具体画师或珍藏集才能使用筛选与入队。

## 存为计划任务（管理员）

展开任一具体来源（收藏、我的作品、我的约稿、已关注用户的新作，或点进某位关注画师、某个珍藏集）后，可在页面底部「存为计划任务」卡片填写名称和触发方式，将其保存为后台自动下载任务。

?> 收藏、关注新作和珍藏集属于账号私有来源，任务必须绑定有效 Cookie（单人模式新建时自动绑定当前 Cookie）。创建后来源类型只读，更换来源需删除任务后重新创建；详见[计划任务](/zh-cn/scheduled-tasks)。

## 结果核对与排障

下载结束后，在队列中分别核对完成、跳过和失败条目，再到画廊确认作品。若预览列表为空，先检查所选账号、公开 / 不公开范围与附加筛选条件；按钮禁用或报鉴权错误时重新保存有效 Cookie；网络报错时检查后端代理连接，不要把空列表直接当作已同步完成。

指定链接下载见[URL 批量下载](/zh-cn/batch-download)，按画师 ID 下载见[画师批量下载](/zh-cn/user-download)，按关键词搜索见[搜索下载](/zh-cn/search)。
