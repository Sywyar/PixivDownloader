# 作品画廊

作品画廊用于浏览、筛选、整理和批量导出数据库中已登记的插画、漫画与动图。需启用 `gallery` 插件；批量管理、导出、删除与收藏夹管理需管理员登录。画廊以数据库记录为准，将图片直接放入文件夹不会自动登记为作品。

访问地址：`http://localhost:6999/pixiv-gallery.html`

## 查找、筛选与排序

左侧边栏用于切换视图（全部图片、按作者、按系列漫画）、管理本地收藏夹及访问各功能页面；侧栏右缘按钮可收起导航或打开管理员「任务列表」（查看后台打包进度与有效期）。顶部工具栏提供画廊类型切换（插画 / 小说等已启用画廊插件）、搜索框、筛选与排序。

| 搜索范围 | 匹配内容 |
| --- | --- |
| 综合 | 标题 + 作者名（默认） |
| 标题 / 作者名 / 简介 | 对应文本字段模糊匹配 |
| 作品 ID / 作者 ID | 数字 ID 精确匹配 |
| 标签（模糊 / 精确） | 包含关键词或完全匹配标签名 |

「筛选」支持按内容分级（全部 / 全年龄 / R-18 / R-18G）、AI 生成（全部 / 排除 AI / 仅 AI）、图片格式、收藏夹及上传日期范围（含结束日期当天，按浏览器时区解释；未知上传时间不进入日期范围结果）过滤。标签与作者支持三态组合：

| 状态 | 规则 |
| --- | --- |
| 必须有 | 多个「必须有」之间取交集 |
| 或者有 | 多个「或者有」之间取并集 |
| 不能有 | 从结果中排除命中项 |

排序支持按**下载时间**（默认最新在前）、**上传时间**（未知上传时间在升序和降序中均排在末尾）、**作品 ID**、**图片数**、**状态**、**画师 ID**、**标签数**和**漫画系列**升序或降序排列。

点击缩略图进入 `pixiv-artwork.html` 查看多图（支持左右切换与灯箱）、简介、标签、同作者作品、相关推荐及原站链接；点击「作品赏析」可进入 `pixiv-showcase.html` 全屏浏览。

## 批量管理与导出（管理员）

点击顶部「批量管理」进入多选模式：

- **全选本页 / 清除选择**：仅作用于当前页。
- **全选所有结果**：选中当前筛选条件下的全部作品（跨页保留选择，可单独取消个别作品）。

在底部「操作」菜单可执行：

| 动作 | 结果 |
| --- | --- |
| 导出 | 选择目录结构（按作者/作品分类，或按作品 ID 分目录）、格式（ZIP）及是否「导出后删除源文件」，在后台生成含 `manifest.json` 的压缩包 |
| 添加到收藏夹 | 将所选作品批量加入指定本地收藏夹 |
| 删除 | 批量删除所选作品 |

开始导出后会自动打开侧栏「任务列表」显示进度，打包完成后自动触发下载，也可在有效期内从任务列表手动下载（过期或重启服务后任务清理）。

!> 勾选「导出后删除」时，服务端成功生成压缩包后即删除源文件与下载记录，不会等待浏览器下载完成或人工检查压缩包内容。

## 删除作品

管理员可在作品详情页点击红色「删除」按钮，或通过「批量管理 → 操作 → 删除」移除作品。对本程序管理的作品，删除会移除本地媒体文件及派生数据（标签、收藏夹关联、缩略图），无法从界面撤销；通过[导入外部下载](/zh-cn/pixiv-batch-downloader-import)登记的只读源文件会保留。小说画廊与小说阅读页提供相同的删除与批量管理入口。

**删除标记**：被删除的作品在下载历史中保留删除标记，对画廊、筛选和统计不可见；当批量下载、油猴脚本或计划任务开启「跳过已下载作品」时，默认将其识别为「已经下载过，但被删除」并跳过。如需重新下载，在下载设置中勾选「允许已删除的作品被重新下载」，下载成功后自动清除删除标记。

## 收藏夹与访客邀请

本地收藏夹独立于 Pixiv 线上收藏。在左侧边栏底部点击「+ 新建收藏夹」创建；右键收藏夹或进入编辑页可重命名、上传自定义图标（PNG / JPG / WebP，最大 1 MB）、绑定独立下载目录或删除收藏夹。悬停缩略图点击心形图标或在详情页点击「收藏到...」即可归入收藏夹。

管理员可点击画廊右上角「邀请访客」，设置有效期、内容分级（如仅 SFW）及标签 / 作者白名单，生成 `http://host:port/invite?code=xxx` 只读分享链接（在 `http://localhost:6999/pixiv-invite-manage.html` 管理邀请码）。访客无修改或批量管理权限，但已显示在浏览器中的图片仍可能被访客另存。

## 未找到作品与统计看板

找不到预期作品时，先清除搜索与筛选条件（特别是上传日期范围与三态标签），并核对邀请码白名单、当前连接的数据库、下载目录和删除标记。仅在磁盘移动文件不会更新另一数据库，搬迁与恢复见[存储与备份](/zh-cn/storage)。

管理员访问 `http://localhost:6999/pixiv-stats.html`（需启用 `gallery-tools` 插件）可查看作品与图片总数、按月下载折线、Top 作者排行及热门标签词云（点击作者或标签可直达画廊筛选）。
