# ローカル作品の取り込みとプリセット

自分のフォルダーに保存してある画像を、パスに含まれる作品 ID から作品ライブラリへ登録できます。元のフォルダーとファイルはそのまま残ります。タイトルや作者などが不明でも先に登録し、後からメタデータを補完できます。

?> 「ローカル作品の取り込み」があるバージョンを使用し、バックエンドを起動しておいてください。Compose、Swing ともにデスクトップのツールページから開きます。HTTP API に渡すパスも、バックエンドが動作するマシン上のパスです。

Compose では「クイックツール」からダイアログで開きます。閉じても開始済みのスキャンや取り込みは続行します。進捗確認やキャンセルは、ツールを開き直して行えます。

保存済みのパスがあれば、3 つの入力欄をすべて空欄にしてスキャンできます。一時パステンプレート、作品 ID、対象ファイルは「今回の取り込みオプション」にまとめています。初期状態では折りたたまれています。必要なときに手動で展開してください。

保存済みプリセットがない場合は、パステンプレートの入力が必要です。空欄のままスキャンを実行すると、オプションが展開され、テンプレート欄に赤い枠と入力を促すメッセージが表示されます。作品 ID と対象ファイルは空欄のままで構いません。

## 実際のパスをテンプレートにする

**パステンプレート**では、パスの変わる部分を波括弧で示します。アプリはその位置から情報を読み取ります。各テンプレートには必ず `{artwork_id}` を含めます。フォルダー名とファイル名のどちらにあっても構いません。

| 既存ファイルのパス | 入力するパステンプレート | 読み取る情報 |
| --- | --- | --- |
| `D:/xxx/12345/pic.png` | `D:/xxx/{artwork_id}/` | 作品 ID は 12345。このフォルダーとサブフォルダー内の対応ファイルを収集 |
| `D:/xxx/12345_xxx.png` | `D:/xxx/{artwork_id}_xxx.{extension}` | 作品 ID は 12345、拡張子は png。`_xxx` は固定文字列 |
| `D:/678/12345/pic.png` | `D:/{author_id}/{artwork_id}/` | 作者 ID は 678、作品 ID は 12345 |
| `D:/xxx/12345_p0.jpg` | `D:/xxx/{artwork_id}_p{page}.{extension}` | 作品 ID は 12345、ページ番号は 0 |

末尾に `/` がないテンプレートは、フォルダーではなくファイルを指定するものとして扱われます。フォルダーとその配下の対応ファイルを照合するには末尾の `/` を残してください。ファイルのテンプレートはファイル名と拡張子まで書きます。絶対パスを使い、Windows では `/` と `\` のどちらも使用できます。フォルダーの作成やファイル名の変更は行いません。

## 一度だけ取り込む：一時テンプレートを入力する

1. デスクトップの「ツール → ローカル作品の取り込み」を開きます。
2. 「今回の取り込みオプション」を展開し、一時パステンプレート欄に `D:/xxx/{artwork_id}/` などを入力します。複数の場合は 1 行に 1 件ずつ書きます。
3. 1 作品だけなら作品 ID 欄に `12345` を入力します。一括取り込みでは改行、空白、カンマで ID を区切ります。空欄にすると一致する全作品をスキャンします。
4. ファイルを 1 つだけ登録する場合は、対象ファイル欄にもパスを指定します。そのファイルの ID を読み取れるテンプレートは引き続き必要です。
5. スキャンしてプレビューを表示し、作品 ID、パス、処理内容を確認してから取り込みを開始します。

一時テンプレートを入力した場合は、そのテンプレートだけを使います。空欄の場合にプリセットを使います。ツールページの入力は今回の操作にだけ適用され、設定には保存されません。

## 繰り返し使う：プリセットを保存する

**ローカル取り込みプリセット**は保存済みのパステンプレート一覧です。入力したパスをそのまま表示し、取り込み時にはすべてのパスを自動的に使用します。

1. 「ツール → ローカル作品の取り込み」を開き、ダイアログ内の「ローカル取り込みプリセット」をクリックします。
2. 「パスを追加」を選び、`D:/{author_id}/{artwork_id}/` などの絶対パステンプレートを 1 行に 1 件ずつ入力します。パスをダブルクリックして編集したり、行を削除したりできます。
3. 「プリセットを保存」をクリックします。再起動せずに次回のスキャンから使用できます。キャンセルしても保存済みのパスは変わりません。
4. 「ローカル作品の取り込み」を開き、3 つの欄を空欄のままにすると、保存済みの全パスをスキャンできます。作品を限定する場合はオプションを展開し、`12345` または ID の一覧を入力します。
5. ツールには保存済みのすべてのパスが表示され、そのすべてを使用します。プレビューを確認してから開始します。

ID を `12345` に限定した場合、この例では作者 ID を入力しなくても `D:/` の作者フォルダー内からその作品を探します。スキャン範囲を抑えるため、できるだけ作品を保存している狭い範囲のフォルダーを指定してください。設定キーは `local-import.presets` です。ローカル作品の取り込みツール内のプリセット編集画面から変更してください。

## 使用できる変数

| 変数 | 意味 |
| --- | --- |
| `{artwork_id}` | 必須。正の整数の作品 ID |
| `{author_id}` | 正の整数の作者 ID |
| `{artwork_title}` | パスに含まれている作品タイトル |
| `{author_name}` | パスに含まれている作者名 |
| `{page}` | 0 から始まるページ番号 |
| `{extension}` | 先頭のドットを除く拡張子 |
| `{name}` | パスの 1 区間内にあるその他の名前。作品タイトルには使わない |

変数名は表にある小文字とアンダースコアの表記に正確に合わせてください。隣り合う変数は固定文字列で区切り、`{artwork_id}_{name}` のように書きます。`{artwork_id}{name}` は使えません。`*` はワイルドカードではありません。

## プレビュー、再スキャン、結果の確認

- スキャン対象は JPG、JPEG、PNG、APNG、GIF、WebP、WebM、MP4、ZIP です。ファイルは取り込み時の検証にも通る必要があり、任意の ZIP を展開して取り込めるわけではありません。
- プレビューでは新規作品、ファイル追加、登録済み、競合、ファイルなしを区別します。競合を先に解消してください。既存の登録を強制的に上書きしません。
- 最近のスキャン索引はメモリ内に 5 分間保持されます。フォルダーの変更は監視しません。ファイルを追加・移動・削除したら、再スキャンして索引を更新するオプションを選び、もう一度プレビューしてください。
- キャンセル時は処理中の作品の登録が終わるまで待ち、登録済みの作品は残します。範囲が大きすぎる場合はフォルダーや ID 一覧を分割してください。
- 外部ファイルは読み取り専用で参照します。アプリで作品の登録を削除しても元ファイルは削除しません。後から元ファイルを移動・削除すると参照できなくなるため、データベースと外部フォルダーを両方バックアップしてください。
- タイトル、作者、総ページ数はパスだけでは分からない場合があります。メタデータの補完待ちは登録失敗ではありません。後から行うオンライン補完については[ネットワークアクセス](/ja/network-access)を参照してください。

## HTTP API

管理者は `/api/local-import` で同じ操作ができます。アプリの認証と CSRF 保護が適用されます。

1. `GET /api/local-import/presets` で保存済みプリセットを取得します。
2. `POST /api/local-import/previews` に JSON を送り、プレビュー ID を受け取ります。
3. `GET /api/local-import/previews/{id}` で `phase` が `READY` になるまで確認します。明細は `/previews/{id}/items?offset=0&limit=20` で取得します。
4. `POST /api/local-import/tasks` に `{"previewId":"返されたプレビュー UUID"}` を送ります。
5. `GET /api/local-import/tasks/{id}` で結果を確認します。キャンセルは `POST /api/local-import/tasks/{id}/cancel` です。

保存済みのすべてのパスで 2 作品をスキャンするリクエスト本文：

```json
{
  "templates": [],
  "artworkIds": [12345, 12346],
  "refreshIndex": false,
  "selectedFile": ""
}
```

`202` は受け付けを示すため、結果を引き続き確認してください。1 インスタンスで同時に実行できる取り込みは 1 件です。プレビューと索引はプロセス再起動後には残りません。この説明は HTTP API のもので、専用 MCP ツールの提供を意味しません。

ダウンローダーの履歴 JSON を使う場合は、[外部ダウンロードのインポート](/ja/pixiv-batch-downloader-import)を参照してください。
