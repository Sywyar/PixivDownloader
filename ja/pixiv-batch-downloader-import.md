# PixivBatchDownloader インポート

公式の `pixiv-batch-downloader-import` プラグインとユーザースクリプトを使うと、PixivBatchDownloader で今後ダウンロードするイラスト、漫画、うごイラ、小説をローカルギャラリーへ自動登録できます。最初にダウンロード先を設定すれば、その後の手動インポートは不要です。元ファイルはコピー・移動せず、ギャラリーの登録を削除しても残ります。

ブラウザーと本アプリは同じマシンで動かし、アプリは solo モードを使います。スクリプトはローカルサービスにだけ接続し、処理待ち情報を Tampermonkey のストレージに保存します。「ファイルの URL へのアクセスを許可する」の設定は不要です。インストール前の過去のダウンロードは自動走査しません。

## 設定して使う

通常の配布パッケージにはこのプラグインは含まれません。オフライン完全版には含まれます。

1. プラグインマーケットで公式の PixivBatchDownloader インポートプラグインをインストールし、アプリを完全に終了して再起動します。すでに有効な場合は次へ進みます。
2. ブラウザーで PixivBatchDownloader と Tampermonkey を有効にし、Pixiv での実行を許可します。Chrome 138 以降は Tampermonkey の拡張機能の詳細画面で「ユーザースクリプトを許可する」も有効にします。他のバージョンは [Tampermonkey の案内](https://www.tampermonkey.net/faq.php?ext=dhdg&q=Q209)に従ってください。
3. デスクトップ設定のインポートプラグイン欄で、ブラウザーのダウンロードルートを選びます。初回ダウンロード後の候補確認まで待つこともできます。ファイルはその配下のサブディレクトリに置けます。手動設定では `config/plugins/pixiv-batch-downloader-import.properties` の `pixiv-batch-downloader-import.source-root` に絶対パスを指定します。Windows では `D:/Downloads` のようにスラッシュを使います。保存後はバックエンドの再起動なしで反映されます。
4. ブラウザーでローカルサービスにログインし、[インポートスクリプトのインストール URL](http://localhost:6999/api/scripts/pixiv-batch-downloader-import.user.js) を開いて Tampermonkey でインストール・有効化します。必要に応じてポートを変更してください。ワークベンチが有効なら「その他 → ユーザースクリプト」からもインストールできます。スクリプトとインストール API はワークベンチに依存しません。
5. 開いている Pixiv ページを再読み込みします。スクリプトはインストール元のローカルホスト、プロトコル、ポートを使用します。手動で保存したアドレスが優先され、スクリプトメニューの「ローカルサーバーの設定」で変更できます。ソースファイルを直接インストールした場合の既定値は `http://localhost:6999` です。
6. バックエンドを起動したまま、通常どおり PixivBatchDownloader で取得・ダウンロードします。作品の全ファイルが揃うと、対応するギャラリーへ登録されます。JSON のコピーや貼り付けは不要です。

保存先が未設定で、最初の完全な成功記録に絶対パスがある場合、アプリはウィンドウのフォーカスを要求し、設定のディレクトリ確認画面を開きます。今後のファイルも含むルートを選び、確認・保存すると設定を書き込み、インポートを再試行します。キャンセルでは保存せず、同じ記録の再試行で繰り返しダイアログを開きません。後から設定画面で選択できます。

相対パス、GUI のない起動、安全性を確認できない候補は手動設定が必要です。候補表示、保存、実際のインポートの各段階でパスを検証し、シンボリックリンクや junction を通常のディレクトリとして受け入れません。

## ダウンロード後に表示されない場合

スクリプトをインストール・有効化した後は、アプリのダウンロード画面と Pixiv ページを再読み込みします。Pixiv 上の Tampermonkey メニューで自動インポートの状態を確認してください。

- `SOURCE_ROOT_REQUIRED`：候補の確認、または設定画面でダウンロード先の選択が必要です。
- `SERVER_UNAVAILABLE`：バックエンドの起動状態とサービスアドレスを確認します。

一時的にサービスへ接続できなくても、保存済みの待機情報は Tampermonkey に残ります。Pixiv ページを開くと自動再試行し、再読み込みでも失われません。状態メニューには待機、未完了、確認が必要な件数が表示されます。

メタデータ不明、ページ不足、ダウンロードのスキップ、パスの競合は完全な作品として登録しません。完全な情報を取得し直してください。スクリプトは過去のディレクトリを走査せず、PixivBatchDownloader の状態も変更しません。

## 統計とバックアップ

デスクトップのデータ概要では、このプラグインが正常に登録した一意の作品数を表示します。複数ページの漫画は 1 件で、同じ ID のイラストと小説は別に数えます。再起動しても残り、ギャラリーの記録を削除しても減りません。既存作品、失敗、スキップは加算せず、過去のインポートを自動集計しません。

統計は `data/pixiv-batch-downloader-import/plugin.db` に保存するため、バックアップに含めてください。統計の書き込みが一時的に失敗すると利用不可と表示し、再試行で加算してから成功を返します。作品の登録と統計は別々にコミットするため、その間にプロセスが強制終了すると件数に漏れが生じることがあります。

## ファイル形式と制限

- 実際のファイルは設定したルート配下に必要です。任意のファイル名とサブディレクトリを使えます。リンク、junction、範囲外パス、存在しないファイル、未対応のファイルヘッダーは拒否します。
- 画像は JPEG、PNG、WebP、GIF、うごイラは WebP、GIF、APNG、WebM、MP4、ZIP、小説は TXT、EPUB に対応します。小説本文は同じ取得時のメタデータを使います。ZIP のサムネイルには最初の画像エントリーだけを読み、元ファイルは ZIP のままです。
- 小説の表紙、添付ファイル、元の公開日時は取り込みません。小説画面のアップロード日時には登録時刻が表示されます。
- データベースにはページごとの実パスと作品メタデータを保存します。メディアメンテナンスは外部の読み取り専用作品を除外します。元ファイルを移動した場合は、保存場所を修復する必要があります。アプリは新しいパスを推測しません。
- 論理削除を含む既存記録は上書き・重複登録しません。小説機能が利用できない場合は待機情報を保持し、成功を返しません。
- 1 ファイルは最大 1 GiB、1 作品は最大 8 GiB・1000 ページです。ブラウザーの現在のメタデータは最大 1000 作品・8 MiB、待機キューは最大 1000 作品・5000 ファイル・8 MiB です。満杯の場合は通知し、新しい記録の受け入れを止めます。
- HTTP リクエストは最大 12 MiB、JSON の深さは 20、小説本文は 300 万文字です。クライアントは 1 件ずつ送信し、失敗時の間隔を最大 60 秒まで延ばします。トークンは 1 回限り、有効期間は 1 分です。接続先は loopback に限り、Pixiv Cookie や管理者パスワードは送信しません。

対象のイベントは [PixivBatchDownloader の固定ソース](https://github.com/xuejianxianzun/PixivBatchDownloader/tree/e3bbdfdd2fb452cc9073450b8aa1ad065f982b64)に基づきます。上流の内部イベントを使用するため、同じバッチの成功イベントより先にメタデータが届く必要があります。実際の拡張機能イベントとの互換性はブラウザーとユーザースクリプト管理環境に依存します。

## ユーザースクリプトから履歴をインポートする

1. ローカルのバックエンドを起動し、プラグイン設定の外部ダウンロード先に元ファイルのルートフォルダーを保存します。連携スクリプトをインストールまたは更新して Pixiv を再読み込みし、対象作品にアクセスできるアカウントでログインします。
2. PixivBatchDownloader を使用しているブラウザーとプロファイルで、元の Pixiv サイトを開きます。外部ダウンロードを一時停止し、Tampermonkey メニューの「ブラウザーのダウンロード履歴を読み込む」から「読み込んで確認」を選んで確認結果を待ちます。履歴の出力やファイル選択は不要です。
3. 対象、登録済み、不足・競合の件数を確認し、「インポート開始」を選びます。ブラウザーが作品情報を順に取得し、ローカルサーバーがファイルを検証して登録します。Pixiv の Cookie はブラウザー内に留まります。

確認の詳細には最大 100 作品の判定結果を表示します。対象が 0 件なら確認は完了しており、「インポート開始」は無効のままです。待ち続ける必要はありません。不足・競合は、ファイルが移動されたことを必ずしも意味しません。設定したルートフォルダーに履歴の相対パス `n` を結合した場所が実際のファイルと一致するか、ファイル名やページ記録に不足がないかを確認してください。セッションの解放後は「読み込んで確認」を再度選べます。解放に失敗した場合は、結果が未確認であることを表示します。

現在の Pixiv サイトの履歴データベースを読み取り専用で分割して読み込み、1 回あたり合計 1 GiB までローカルへ送信します。読み込み中は履歴の消去や変更を避けてください。同時に変更された履歴の一貫したスナップショットは保証しません。元作品ファイルの読み取り・送信や、履歴データベースの作成・更新・書き換えは行いません。別のブラウザープロファイルやオリジンの履歴、消去済みの履歴は読み込めません。元ファイルは読み取り専用で参照し、論理削除済みを含む既存作品はスキップします。ファイル・ページ不足や情報を取得できない作品は登録しません。登録後は既存の補完ツールで対応項目を補えますが、失われた元ファイルは復元できません。

処理中はページを開いたままにします。キャンセル、ページ移動、サーバー変更は停止を要求し、登録済み作品は保持します。履歴タスクはスクリプトのキューに保存せず、再読み込み後に自動再開しません。通信障害時は結果が未確認の可能性があります。ローカルサーバーを確認してください。セッション作成の応答が失われた場合は、約 15 分のアイドル期限と現在の処理の終了を待って再試行します。一時ファイルは `data/pixiv-batch-downloader-import/browser-history/` に保存し、正常終了またはアイドル期限後に削除します。強制終了で残ったファイルは、アプリを完全に停止してから削除できます。
