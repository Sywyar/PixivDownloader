# PixivBatchDownloader のインポート対応

公式の `pixiv-batch-downloader-import` プラグインと専用ユーザースクリプトを使うと、PixivBatchDownloader でダウンロードが完了したイラスト、漫画、うごイラ、小説を、**読み取り専用の参照**としてこのマシンのギャラリーに登録できます。元ファイルのコピーや移動は行わず、ギャラリーの記録を削除しても元ファイルは残ります。既存の PixivBatchDownloader の履歴をギャラリーに一括インポートすることもできます。

ブラウザーと本プログラムは同じマシンで実行し、本プログラムはシングルユーザーモード（`solo`）を使用する必要があります。スクリプトはローカルのループバックサービスにだけ接続し、ブラウザーの「ファイルの URL へのアクセスを許可」は不要です。

## 自動インポートを有効にする

通常の配布パッケージにはこのプラグインはプリインストールされていません。オフライン完全パッケージには含まれています。

1. プラグインマーケットで「PixivBatchDownloader インポート対応」をインストールして有効にし、プログラムを完全に終了して再起動します。
2. ブラウザーで PixivBatchDownloader と Tampermonkey を有効にします。Chrome 138+ では「拡張機能 → Tampermonkey → 詳細」で「ユーザースクリプトを許可」を有効にしてください。他のバージョンは [Tampermonkey の権限説明](https://www.tampermonkey.net/faq.php?ext=dhdg&q=Q209)を参照してください。
3. 外部ダウンロードのルートディレクトリを設定します。デスクトップの「設定 → PixivBatchDownloader インポート対応」で選択するか、`config/plugins/pixiv-batch-downloader-import.properties` に絶対パス `pixiv-batch-downloader-import.source-root=D:/Downloads` を設定します。Windows ではスラッシュを使い、保存すると即時反映されます。初回のダウンロード完了後にダイアログで候補ディレクトリを確認する方法もあります。
4. ブラウザーでローカルサービスにログインしてから、`http://localhost:6999/api/scripts/pixiv-batch-downloader-import.user.js`、またはダウンロードページの「ユーザースクリプト」からインポートスクリプトをインストール・有効化し、Pixiv ページを再読み込みします。
5. ローカルのバックエンドを起動したまま、通常どおり PixivBatchDownloader でダウンロードします。作品の全ファイルの保存が完了すると、対応するギャラリーに自動登録されます。

ディレクトリを事前設定していない場合、最初に全ファイルが揃った作品の絶対パスをもとに、デスクトップに候補ディレクトリの確認ダイアログが表示されます。候補はその作品の全ファイルに共通する親ディレクトリで、単一作品のサブディレクトリの場合もあります。PixivBatchDownloader の相対パスを除いた最上位のダウンロードルートを選択してください。たとえばファイルが `D:/Downloads/pixiv/作者/123_p0.png`、相対パスが `pixiv/作者` なら、`D:/Downloads` を選びます。「ディレクトリを保存」で反映され、自動的に再試行します。キャンセルした場合は設定を書き込まず、同じ候補で繰り返しダイアログを表示しません。

## 自動インポートの状態と統計

ダウンロードが完了してもギャラリーに表示されない場合は、Pixiv ページの Tampermonkey メニューから「自動インポートの状態」を開きます。

- `SOURCE_ROOT_REQUIRED`：デスクトップのダイアログで候補ディレクトリを確認するか、設定でダウンロードルートを指定してください。
- `SERVER_UNAVAILABLE`：ローカルのバックエンドが起動しているか、シングルユーザーモードでログイン済みか、スクリプトメニューの「ローカルサービスのアドレスを設定」のポートが正しいかを確認してください。

バックエンドが一時的に利用できない場合、登録待ちの記録は Tampermonkey のストレージに保存されます（最大 1,000 作品、5,000 ファイル、8 MiB）。Pixiv ページを開くと、間隔を空けながら自動再試行します。ページ不足、メタデータ不明、ダウンロードのスキップ、パスの競合がある作品は、完全な作品として登録しません。上流のイベントは [PixivBatchDownloader の固定バージョンのソース](https://github.com/xuejianxianzun/PixivBatchDownloader/tree/e3bbdfdd2fb452cc9073450b8aa1ad065f982b64)に基づき、同じバッチのメタデータがダウンロード成功イベントより先に届く必要があります。

デスクトップのホームにある「インポート済みの作品」は、`(作品の種類, 作品 ID)` の重複を除いて、このプラグインが正常に取り込んだ作品数を集計します。記録は `data/pixiv-batch-downloader-import/plugin.db` に保存されるため、バックアップに含めてください。ギャラリーの記録を削除しても件数は減りません。

## ファイル形式、読み取り専用参照、上限

- 実ファイルは設定したルート内に存在する必要があります。シンボリックリンク、junction、範囲外のパス、存在しないファイル、不正なファイルヘッダーは拒否されます。
- 画像は JPEG、PNG、WebP、GIF、うごイラは WebP、GIF、APNG、WebM、MP4、ZIP に対応します。ZIP のサムネイルは最初の画像エントリーから取得し、元ファイルは ZIP のまま保持します。小説は TXT、EPUB に対応し、本文は同時に取得したメタデータを使います。小説の表紙、添付ファイル、元の公開日時は現在インポートせず、投稿日時には登録日時を表示します。
- 既存の記録（論理削除を含む）は上書きも重複登録もしません。小説プラグインが利用できない場合は処理待ちの記録を保持し、成功を返しません。メディア保守ツールは外部の読み取り専用作品をスキップします。元ファイルを移動した場合はパスの修復が必要で、プログラムは新しい場所を推測しません。
- 1 ページのファイル上限は 1 GiB、1 作品は 8 GiB / 1,000 ページです。1 回の HTTP リクエストは 12 MiB、JSON の深さは 20、小説本文は 300 万文字が上限です。

## 過去の履歴をインポートする

プラグインのインストール前にダウンロードした作品は、次の 2 通りで追加登録できます。どちらも上記のファイル形式と読み取り専用参照のルールに従い、既存作品（論理削除を含む）は自動スキップします。インポート後はデータ補完ツールで対応する項目を補えますが、失われた元ファイルは復元できません。

### 方法 1：ユーザースクリプトでブラウザー履歴を直接読み込む（ファイルのエクスポート不要）

1. ローカルのバックエンドを起動したまま、プラグイン設定で「外部ダウンロードディレクトリ」を保存し、ログイン済みの Pixiv ページを再読み込みします。
2. PixivBatchDownloader を使っていたのと同じブラウザープロファイルで元の Pixiv サイトを開き、外部ダウンロードを一時停止して、Tampermonkey メニューの「ブラウザーのダウンロード履歴を読み込む → 読み込みと確認」をクリックします。スクリプトは現在のサイトの履歴データベースを読み取り専用で分割走査し、1 回の上限は 1 GiB です。処理中は履歴を変更・消去しないでください。
3. インポート待ち、登録済み、不足・競合の件数を確認し、「インポート開始」をクリックします。詳細表示は最大 100 件で、インポート待ちが `0` なら確認だけで終了します。ブラウザーが各作品の Pixiv メタデータを取得し、このマシンでファイルを検証してから登録します。Pixiv Cookie はブラウザー内に留まり、ローカルサービスには送信しません。

インポート中はページを開いたままにしてください。100% は処理の完了を示し、全件の成功を意味しません。キャンセル、ページからの移動、接続先サービスの変更により以降の処理は停止しますが、登録済みの作品は保持されます。一時データは `data/pixiv-batch-downloader-import/browser-history/` に置かれ、正常終了時または約 15 分間操作がない場合に自動削除されます。

### 方法 2：エクスポートした JSON をデスクトップツールで取り込む

1. デスクトップ GUI の「ツール」から「PixivBatchDownloader の履歴インポート」を開きます。ユーザースクリプトは不要です。
2. PixivBatchDownloader で履歴 JSON をエクスポートします。分割ファイルが複数ある場合は、専用の同じディレクトリにまとめ、そのディレクトリを選びます。1 ファイルは最大 512 MiB、最大 64 ファイル、合計 1 GiB です。
3. 元ファイルのルートディレクトリを選び、「確認とプレビュー」をクリックします。記録内の相対パス `n` と結合して実ファイルに対応する必要があります。この選択では自動インポートの設定は変更されません。
4. 必要に応じて今回使用する Pixiv Cookie を入力し（永続保存しません）、「インポート開始」をクリックして成功・スキップ・失敗の件数を確認します。一時整理ディレクトリは `data/pixiv-batch-downloader-import/history-import/` にあり、タスク終了時または正常に閉じた際に削除されます。
