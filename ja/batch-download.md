# URL 一括ダウンロード

作品リンクや ID の一覧がある場合は、ダウンロードページの「単一作品の一括インポート」にまとめて貼り付けてダウンロードできます。イラスト、漫画、うごイラ、小説を混在させて入力できます。小説には `novel` プラグインの有効化が必要です。閲覧制限のある作品には、`PHPSESSID` を含む Pixiv Cookie を保存してください。

## 操作手順

1. `http://localhost:6999/pixiv-batch.html` を開き、「単一作品の一括インポート」に切り替えます。
2. テキスト欄に URL または ID を 1 行に 1 件ずつ貼り付け、「情報を取得」をクリックします。
3. 認識された作品の種類と件数を確認します。
4. 必要に応じて追加フィルターとダウンロード設定を指定し、作品をキューに追加して「ダウンロード開始」をクリックします。
5. 完了後にキューで結果を確認します。完了、既存のためスキップ、フィルターによるスキップ、失敗は別々に集計されます。

## 入力形式

1 行に 1 件ずつ入力します。以下の作品 ID は形式の例なので、実際の作品に置き換えてください。

```text
# 完全な URL
https://www.pixiv.net/artworks/12345678
https://www.pixiv.net/novel/show.php?id=87654321

# 数字のみの ID（デフォルトはイラスト。タイトルは任意）
12345678
12345679 | 作品タイトル

# 区分見出し：以降の数字のみの ID の作品種類を指定
artwork:
11111
22222
novel:
33333
44444 | 小説タイトル

# OneTab / N-Tab のエクスポート形式
https://www.pixiv.net/artworks/55555 | タブのタイトル
```

- `artwork:` と `novel:` はそれぞれ単独の行に記述します。大文字と小文字は区別せず、半角・全角のコロンに対応します。以降の数字のみの ID、または `id | title` を指定した種類として解析し、次の区分見出しまたは入力末尾まで適用します。
- `https://` から始まる完全なリンクは、区分見出しに関係なくリンク自身の種類で解析します。
- OneTab / N-Tab からエクスポートした `URL | タイトル` の一覧をそのまま貼り付けられます。Pixiv の作品リンク以外は自動的にスキップされます。

## 追加フィルターとダウンロード設定

「追加フィルター」は、年齢区分（すべて / 全年齢 / R18+ / R-18 / R-18G）、AI 作品（すべて / AI を除外 / AI のみ）、タグ（カンマ区切り、完全一致または部分一致ですべてのタグを満たす必要あり）、最小ブックマーク数、イラストのページ数、小説の文字数、作品の種類（イラスト / 漫画 / うごイラ）に対応しています。ダウンロード時に 1 件ずつ判定し、条件に合わない作品には具体的なスキップ理由を表示します。

| ダウンロード設定 | 効果 |
| --- | --- |
| ファイル名テンプレート | `{artwork_id}`、`{author_name}`、`{page}` などの変数を使用。[ファイル名テンプレートの変数](/ja/usage-guide#ファイル名テンプレートの変数)を参照 |
| ダウンロード先（コレクション） | 保存先のローカルコレクションを指定 |
| ダウンロード済み作品をスキップ | ダウンロード履歴にある作品をそのままスキップ |
| 実際のディレクトリを確認 | 履歴に加えてディスク上のファイルの有無も確認し、欠けていれば再ダウンロード |
| 削除済み作品の再ダウンロードを許可 | ギャラリーで削除した作品には[削除マーク](/ja/gallery#作品を削除する)が付き、既定ではスキップ。選択すると再ダウンロードして削除マークを解除 |
| 自動ブックマーク | ダウンロード後に Pixiv API で作品をブックマーク。有効な Cookie が必要 |
| 小説の形式 | TXT、HTML、EPUB から保存形式を選択 |

## ダウンロード設定の保存と複数 Cookie

管理者はダウンロード設定と追加フィルターを設定セットとして保存し、プルダウンから切り替えられます。保存できる設定セットは最大 64 件です。切り替えは直接編集と同じく即時に反映され、待機中および新しく追加した作品に適用されます。すでにダウンロード中の作品は元の処理を続けます。Cookie、プロキシ、保存先、キューは設定セットに含まれません。

ページの現在の設定、設定セット、スケジュールタスクは別々に保存されます。ページで編集しても設定セットは上書きされず、設定セットの保存操作が必要です。設定セットの編集や削除は保存済みタスクを変更しません。タスク編集中の適用は下書きだけを変更し、保存後にそのタスクへ反映されます。実行中の手動キューには影響しません。ページを再読み込みすると現在のページ設定が復元され、選択した設定セットが再適用されることはありません。

Cookie 管理は管理者専用で、最大 8 件を保存できます。使用する Cookie を選択し、上下移動で優先順位を指定します。サーバーは Cookie を暗号化して保存し、ページには名前と状態だけを返します。旧ページの Cookie は保存と読み戻し検証が成功してから削除します。保存済み認証情報をタスクに設定すると候補がコピーされます。その後のライブラリ編集やページ選択はタスクのコピーに影響しないため、更新には再設定が必要です。すべての候補が利用できない場合はキューが一時停止します。認証情報を修正して手動で再開してください。

## 問題の対処と関連ページ

- **数字のみの小説 ID がイラストとして扱われる**：完全な小説リンクを使うか、数字 ID の前に `novel:` だけの行を追加してください。
- **認識件数が入力行数より少ない**：空行、区分見出し、Pixiv 以外のリンク、不正な URL を確認してください。プレビュー一覧が実際に認識された結果です。
- **作品がスキップされる、またはダウンロードに失敗する**：キューの項目に表示された具体的な理由を確認します。Pixiv 上で作品を閲覧できることと、Cookie、プロキシ設定を確認してください（[よくある質問](/ja/faq)を参照）。

指定した作者の作品は[作者別一括ダウンロード](/ja/user-download)、キーワードでの取得は[検索ダウンロード](/ja/search)、定期的な自動ダウンロードは[スケジュールタスク](/ja/scheduled-tasks)を参照してください。
