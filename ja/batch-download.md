# URL 一括ダウンロード

作品リンクの一覧を、ダウンロード画面の「作品の一括インポート」に貼り付けて取得します。イラストと小説を混在させられます。小説には有効な `novel` プラグイン、ログインが必要な作品には有効な Pixiv Cookie が必要です。

## ダウンロードする

1. `http://localhost:6999/pixiv-batch.html` を開き、作品の一括インポートタブに切り替えます。
2. URL の一覧を貼り付け、「情報を取得」を押します。
3. 認識された作品の種類と件数を確認します。
4. 使用中のレイアウトで作品をキューに追加し、ダウンロードを開始します。
5. 終了後、キューの結果を確認します。完了、既存、フィルターによるスキップ、失敗はそれぞれ異なる結果です。

## 入力形式

1 行に 1 件を入力します。次の ID は形式の例です。取得したい実際の作品に置き換えてください。

```text
# 完全な URL
https://www.pixiv.net/artworks/12345678
https://www.pixiv.net/novel/show.php?id=87654321

# 数字だけならイラストとして処理
12345678
12345679 | 作品タイトル

# セクション見出しで後続の ID の種類を指定
artwork:
11111
22222
novel:
33333
44444 | 小説タイトル

# OneTab / N-Tab のエクスポート形式
https://www.pixiv.net/artworks/55555 | タブのタイトル
```

`artwork:` と `novel:` は単独の行に書きます。大文字・小文字、全角・半角のコロンは区別しません。次のセクション見出しか入力末尾まで、数字 ID と `id | title` をその種類として扱います。タイトルは省略できます。

完全な URL はリンク自身の種類で判定し、セクション見出しの影響を受けません。OneTab / N-Tab の一覧はそのまま貼り付けられます。Pixiv 作品以外のリンクはスキップされます。

## フィルターと保存設定

追加フィルターでは、年齢区分（すべて、全年齢、R18+、R-18、R-18G）、AI 作品の除外・限定、タグの完全一致・部分一致、最低ブックマーク数、イラストのページ数、小説の文字数、作品の種類を指定できます。複数のタグはカンマで区切り、すべての条件に一致する必要があります。

実際のダウンロード時にも作品ごとに判定します。条件に一致しない作品には、キューにスキップ理由が表示されます。

ダウンロード設定では次を指定できます。

| 設定 | 動作 |
|---|---|
| ファイル名テンプレート | `{artwork_id}`、`{author_name}`、`{page}` など。[変数一覧](/ja/usage-guide)を参照 |
| ダウンロード先 | 保存するローカルコレクション |
| ダウンロード済みをスキップ | 履歴にある作品をスキップ |
| 実際のディレクトリを確認 | 履歴に加え、ディスク上のファイルを確認。欠けていれば再ダウンロード |
| 削除済み作品の再ダウンロードを許可 | ギャラリーの削除マークを未取得として扱い、成功後にマークを解除 |
| 自動ブックマーク | 完了後、Pixiv API でブックマーク。Cookie が必要 |
| 小説形式 | TXT / HTML / EPUB |

ギャラリーで削除した作品には削除マークが残ります。通常は取得済みとしてスキップし、削除済みであることを理由に表示します。再取得する場合は上記の許可を有効にしてください。

## 入力どおりにならない場合

- 数字の小説 ID がイラストになる場合は、完全な小説 URL を使うか、前の行に `novel:` を追加します。
- 件数が少ない場合は、空行、セクション見出し、無効な URL、他サイトのリンクを確認し、プレビューを見てから開始します。
- スキップされた場合は理由を確認し、フィルターや取得済み判定を調整します。削除マークは自動的に未取得にはなりません。
- 接続や保存に失敗した場合は、Pixiv 上で作品を開けるか、Cookie とバックエンドのネットワークを確認します。[よくある質問](/ja/faq)も参照してください。

作者単位の取得は[ユーザー一括ダウンロード](/ja/user-download)、キーワード検索は[検索](/ja/search)、定期取得は[スケジュールタスク](/ja/scheduled-tasks)を参照してください。
