# URL 一括ダウンロード

「作品 URL 一括インポート」タブは最も柔軟なダウンロード方法です。作品 URL または ID の一覧を貼り付けて一括取得できます。イラストと小説を混在させることも可能です。

## クイックスタート

1. `http://localhost:6999/pixiv-batch.html` を開く
2. 「**🎨 作品 URL 一括インポート**」タブに切り替える
3. テキスト欄に URL 一覧を貼り付ける
4. 「**情報を取得**」をクリックする
5. プレビューを確認して「**ダウンロード開始**」をクリックする

## 入力形式

1 行に 1 件を入力します。複数の形式を混在できます。

```
# 完全な URL（最も一般的）
https://www.pixiv.net/artworks/12345678
https://www.pixiv.net/novel/show.php?id=87654321

# 数字だけの ID（既定ではイラストとして扱う）
12345678
12345679 | 作品タイトル（タイトルは省略可。空欄なら自動取得）

# セクション見出し。以降の ID の種類を指定
artwork:
11111
22222
novel:
33333
44444 | 小説のタイトル

# OneTab / N-Tab のエクスポート形式にも対応
https://www.pixiv.net/artworks/55555 | タブのタイトル
```

### セクション見出し

`artwork:` と `novel:` は単独の行に記述します。大文字・小文字を区別せず、半角・全角コロンのどちらも使えます。

セクション見出しの後にある数字 ID（`id | title` 形式）は、次の見出しまたは入力末尾まで、その種類として解釈されます。

`https://` で始まる完全な URL は、所属するセクションに関係なく、URL 自身の種類で常に解釈されます。

## 追加フィルター

「**追加フィルター**」カードを展開すると、ダウンロード前にキューを絞り込めます。

| フィルター | 説明 |
|--------|-------------|
| **コンテンツレーティング** | すべて / 全年齢 / R18+ / R-18 / R-18G |
| **AI 作品** | すべて / AI を除外 / AI のみ |
| **タグ** | 完全一致 / あいまい一致（カンマ区切り、すべて一致） |
| **ブックマーク数** | 最小ブックマーク数 |
| **ページ数** | イラストのページ数範囲 |
| **文字数** | 小説の文字数範囲 |
| **作品種別** | イラスト / マンガ / うごイラ |

フィルターはダウンロード時に作品ごとに適用されます。一致しない作品はキューにスキップ理由（例：「コンテンツレーティングが一致しない」「タグが一致しない」）を表示します。

## ダウンロード設定

「**ダウンロード設定**」カードでは次を変更できます。

- **ファイル名テンプレート**：`{artwork_id}`、`{author_name}`、`{page}` などの変数に対応。[設定リファレンス](/ja/configuration) を参照
- **ダウンロード先（コレクション）**：指定したローカルコレクションに保存
- **ダウンロード済み作品をスキップ**：履歴を確認し、取得済みの作品を直接スキップ。展開すると次の項目を設定できます。
  - **実フォルダーを検出**：履歴だけでなくディスク上のファイルも確認し、ファイルがない場合は再取得
  - **削除済み作品の再ダウンロードを許可**：ギャラリーで削除した作品には [削除マーク](/ja/gallery?id=deleting-artworks) が残り、既定では取得済みとしてスキップされます。「取得済みだが削除済み」という理由でスキップされる作品を再取得するには有効にしてください。成功すると削除マークは消去されます。
- **自動ブックマーク**：ダウンロード後、Pixiv API で自動的にブックマーク（Cookie が必要）
- **小説形式**：TXT / HTML / EPUB

## OneTab / N-Tab エクスポートへの対応

OneTab または N-Tab からタブ一覧をエクスポートした後、そのまま貼り付けられます。形式は `URL | title` です。PixivDownloader が自動的に解析します。

Pixiv の作品リンクでない行（他サイトの URL など）は自動的にスキップされます。
