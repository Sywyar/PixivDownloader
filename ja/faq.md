# よくある質問（FAQ）

## インストールと起動

### 「Java が認識されない」と表示される

Java 17 以上を [Adoptium](https://adoptium.net/) からインストールし、ターミナルを開き直してください。必要なら `JAVA_HOME` と `PATH` を設定します。

### 起動後に文字化けする

起動時に `-Dfile.encoding=UTF-8` を付けます。

```bash
java -Dfile.encoding=UTF-8 -jar PixivDownload-vX.X.X.jar
```

### ポート 6999 が使用中

そのポートを使うプログラムを終了するか、`config.yaml` の `server.port` を変更して再起動してください。

### Windows インストーラーが失敗する

`PixivDownload.exe` を終了し、以前のインストーラーが残っていないか確認して、必要なら管理者として実行してください。

### アンインストール方法

インストーラー版はインストーラーまたは Windows の「設定 → アプリ」からアンインストールします。JAR 版はプログラムディレクトリを削除します。

### すべての設定をリセットしたい

サービスを停止し、`state/setup_config.json` を削除して `--setup` または GUI の「ホーム」ウィザードを再実行します。ダウンロードファイルとデータベースは削除されません。

### サーバー / Docker が「先にセットアップしてください」と言って終了する

ヘッドレス起動では初回セットアップが必要です。

```bash
java -Dfile.encoding=UTF-8 -jar PixivDownload-vX.X.X.jar --setup
java -Dfile.encoding=UTF-8 -jar PixivDownload-vX.X.X.jar --no-gui
```

### 管理者パスワードを忘れた

サービスを停止し、以前のパスワードなしで次を実行します。

```bash
java -Dfile.encoding=UTF-8 -jar PixivDownload-vX.X.X.jar --reset-password
```

6 文字以上の新しいパスワードを 2 回入力します。既存セッションは無効になります。変更だけなら `--change-password` を使います。

### 起動引数が認識されない

引数は厳密に検証されます。`--no-guii` のような typo、`--username admin` のように `=` がない値、単独の位置引数は拒否されます。`--help` で一覧を確認してください。

## プロキシとネットワーク

### プロキシを設定してもダウンロードできない

設定が保存されているか、プロキシ経由で `https://i.pximg.net/` に接続できるか、ファイアウォールがポートを許可しているかを確認してください。GUI または CLI で保存した設定はホットリロードされます。`config.yaml` を直接編集した場合は再起動するか GUI で保存します。

### リバースプロキシの後ろで全ユーザーが同じ制限を受ける

`server.trusted-proxy-cidrs` に実際のプロキシ出口アドレスまたはコンテナサブネットを設定し、完全な `Forwarded`、または `X-Forwarded-For` / `X-Forwarded-Proto` / `X-Forwarded-Host` を毎回送信します。公開ネットワークやクライアントネットワークを信頼しないでください。詳しくは [設定リファレンス](/ja/configuration#https-and-reverse-proxies) を参照してください。

### LAN の別端末からアクセスできない

ファイアウォールでポート 6999 を許可し、バインド設定を確認し、`http://<サーバー IP>:6999/` を開きます。

## Cookie

### 検索結果がない

検索モードには Pixiv Cookie が必要です。Netscape 形式で正しく貼り付けたか、期限切れでないか、プロキシが動作しているかを確認してください。

### Cookie 形式エラー

Cookie-Editor から Netscape 形式でエクスポートし、ページでも Netscape タブを選んでください。内容を手動編集しないでください。

### 保存した Cookie を消したい

ソロモードでは `pixiv-batch.html` の Cookie カードから消去するか、ログアウトします。ログアウトするとサーバー側の Cookie も消去されます。

## ダウンロード

### うごイラが再生できない

WebP 変換には FFmpeg が必要です。`ffmpeg -version` で確認し、`PATH` に追加するか GUI のステータスページからインストールしてください。

### 小説 EPUB の表紙が表示されない

プロキシと、表紙 URL のホストが `.pximg.net` で終わるかを確認し、小説を再取得してください。

### 読み上げのオンラインエンジンが失敗する

オンライン音声はバックエンドのプロキシ経由で Microsoft に接続します。ネットワーク、プロキシ、システム時計を確認してください。改善しない場合は再生設定でオフラインのブラウザーエンジンに切り替えます。招待ゲストには `guest-invite.tts-request-limit-minute` の制限があります。

### 一括ダウンロードの一部が失敗する

Cookie の期限、Pixiv のレート制限、プロキシの安定性、作品の削除・非公開化を確認してください。同時実行数と作品間隔を下げると改善する場合があります。

### ファイル名テンプレートが効かない

変数を `{artwork_id}` のように波かっこで書き、対応している変数だけを使います。使用できない文字は自動除去され、新しい設定は新規ダウンロードにだけ適用されます。

### うごイラがクォータを多く消費する

マルチモードでは `multi-mode.quota.limit-image` を設定します。指定数を超える画像を含む作品は複数のクォータ単位として計算されます。

## GUI

### 「起動中」のまま進まない

10 秒以上待っても進まない場合は `log/latest.log` を確認します。必要ならデータベースをバックアップしてから再生成し、Java 17 以上かも確認してください。

### GUI のオンライン更新に失敗する

ネットワークとプロキシを確認し、改善しなければ [Releases](https://github.com/Sywyar/PixivDownloader/releases) から手動で取得して上書きインストールします。

### エラーダイアログが文字化けする

詳細はログに記録されます。ダイアログの「ログファイルを開く」から確認してください。

## データベース

### データベースはどこにあるか

既定では `data/pixiv_download.db` です。実行中は `-wal` / `-shm` も確認してください。

### データベースが壊れた

サービスを停止し、`.db`、`.db-wal`、`.db-shm` をバックアップしてから `sqlite3 pixiv_download.db "PRAGMA integrity_check;"` を実行します。修復できなければデータベースを削除して再起動できますが、ギャラリー情報は失われます。ダウンロード済みファイルは残ります。

### データベースを失ったら再ダウンロードされるか

既定のファイル名（例：`{artwork_id}_p{page}.{ext}`）のファイルが作品ディレクトリに残っていれば、ページ数と拡張子から履歴が再構成され、再ダウンロードをスキップします。カスタムテンプレートのファイルやタイトル・作者などのメタデータは復元されません。

### バックアップ方法

アプリを停止して `data/`、`pixiv-download/`、`state/`、`config/`、必要ならコレクションアイコンをコピーします。詳細は [ストレージの仕組み](/ja/storage) を参照してください。

## ユーザースクリプト

Tampermonkey が有効か、スクリプトが対象ページで有効か、`@match` と `@connect` が正しいかを確認してページを再読み込みします。オールインワンと単体版を同時に有効にするとパネルが重複するため、どちらか一方だけを使います。バックエンドに接続できない場合はサービス、ログイン状態、非 localhost の接続先を確認してください。

## セキュリティ

Pixiv へのアクセスにはユーザーの Cookie を使うため、アカウントのリスクはユーザー自身が負担します。適切な間隔と同時実行数を設定し、Pixiv の利用規約を守ってください。マルチモードのゲストは自分の状態または招待の許可範囲だけを閲覧できます。

HTTPS は `config.yaml` で設定します。

```yaml
server.ssl.enabled: true
server.ssl.certificate: /path/to/cert.pem
server.ssl.certificate-private-key: /path/to/key.pem
```

## その他

新しい PC へ移行する場合は `data/`、`pixiv-download/`、`state/`、`config/` をコピーします。アップグレードは GUI の更新確認、JAR の置換、または新しい Windows インストーラーで行います。データベースは自動移行されます。

不具合や要望は [GitHub Issues](https://github.com/Sywyar/PixivDownloader/issues) に、OS、バージョン、再現手順、ログ、必要ならスクリーンショットを添えて報告してください。
