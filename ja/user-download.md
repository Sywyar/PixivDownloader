# 作者別一括ダウンロード

ダウンロードページの「User モード」に作者のプロフィールリンクや数字 ID を入力すると、その作者のイラスト、漫画、うごイラ、小説、公開済みのリクエスト作品をプレビューし、すべてまたは一部をダウンロードできます。実際に取得できる範囲は、現在のアカウントの権限、追加フィルター、ダウンロード済みの判定に従います。

## 操作手順

1. `http://localhost:6999/pixiv-batch.html` を開き、「User モード」に切り替えます。
2. 作者のプロフィールリンク、または数字のみのユーザー ID を貼り付けます。
3. 取得範囲を選びます。イラスト + 漫画 + うごイラ、小説、リクエストに対応し、小説には `novel` プラグインの有効化が必要です。
4. 「解析してプレビュー」をクリックし、必要に応じて追加フィルターを設定します。
5. 「すべてキューに追加」をクリックするか、一部の作品を選んで追加し、「ダウンロード開始」をクリックします。
6. 完了後にキューで成功、スキップ、失敗を確認します。

以下の入力形式に対応しています。`123456` は例なので、実際の作者 ID に置き換えてください。

```text
https://www.pixiv.net/users/123456
https://www.pixiv.net/users/123456/artworks
https://www.pixiv.net/users/123456/illustrations
https://www.pixiv.net/users/123456/novels
https://www.pixiv.net/users/123456/request/artworks
https://www.pixiv.net/en/users/123456
123456
```

## 取得範囲と追加フィルター

| 範囲 | 含まれる内容 |
| --- | --- |
| イラスト + 漫画 + うごイラ | その作者が投稿した画像系の作品 |
| 小説 | その作者が投稿した小説 |
| リクエスト | その作者が完成させて公開したリクエスト作品。通常のイラストと同じ処理経路でプレビュー、キュー登録、ダウンロード、重複判定を行う |

リクエストページのリンク（`/users/{id}/request/artworks`）を貼り付けると、「リクエスト」の範囲へ自動的に切り替わります。プレビューは一度に 1 種類の範囲を表示します。範囲を切り替えると現在のプレビュー一覧は空になりますが、登録済みのダウンロードキューは残ります。先にイラストをキューに追加し、小説へ切り替えて追加してから、まとめてダウンロードできます。

「追加フィルター」では、年齢区分、AI の除外、最小ブックマーク数、タグ、ページ数で絞り込めます。プレビュー時と実際のダウンロード時の両方で、作品ごとに適用されます。作者の作品数が多い場合は、追加フィルターを組み合わせ、「最大同時実行数」を下げて「作品間隔」（ミリ秒）を設定すると、取得元の制限に達するリスクを抑えられます。

## スケジュールタスクとして保存する

ページ下部の「スケジュールタスクとして保存」カードに名前と起動方法を入力すると、その作者の新作を定期的に検出してダウンロードできます。ログインが必要な内容には、タスクへ有効な Cookie を紐付ける必要があります。設定とウォーターマークによる差分取得のルールは、[スケジュールタスク](/ja/scheduled-tasks)を参照してください。

## 期待した作品が取得されない場合

まず、入力した ID が個別作品の ID ではなく作者のユーザー ID であることを確認し、選択した範囲（画像 / 小説 / リクエスト）、追加フィルター、Cookie のログイン状態を確認してください。削除済みの作品や閲覧権限のない作品は、「すべてキューに追加」をクリックしてもダウンロードできるようにはなりません。
