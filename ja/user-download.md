# ユーザー一括ダウンロード

「ユーザーモード」では作者 ID またはプロフィール URL を入力し、その作者の作品（イラスト / マンガ / うごイラ、または小説）をワンクリックで取得できます。

## 使い方

1. `http://localhost:6999/pixiv-batch.html` を開く
2. 「**👤 ユーザーモード**」タブに切り替える
3. 作者プロフィール URL または数字 ID を貼り付ける
4. ダウンロード範囲（イラストまたは小説）を選ぶ
5. 「**解析してプレビュー**」をクリックする
6. 必要に応じて追加フィルターを設定する
7. 「**すべてキューに追加**」または作品を選んで追加する
8. ダウンロードを開始する

## 対応リンク形式

次のいずれかを貼り付けてください。数字 ID は自動的に抽出されます。

```
https://www.pixiv.net/users/123456
https://www.pixiv.net/users/123456/artworks
https://www.pixiv.net/users/123456/illustrations
https://www.pixiv.net/users/123456/novels
https://www.pixiv.net/users/123456/request/artworks   ← リクエストページ（範囲を「リクエスト」に自動切替）
https://www.pixiv.net/en/users/123456
123456                                               ← 数字 ID だけでも可
```

## ダウンロード範囲

| 範囲 | 含まれるもの |
|-------|---------|
| **イラスト + マンガ + うごイラ** | 作者の画像形式の作品すべて |
| **小説** | 作者の小説すべて |
| **リクエスト作品** | 作者の**完了済み・公開リクエスト**納品物。通常のイラストとして、イラストのプレビュー / キュー / ダウンロード / 重複排除処理を通ります |

プレビューでは一度に 1 種類だけ取得します。種類を切り替えると古いプレビュー結果は消えますが、ダウンロードキューは影響を受けません。先にイラストを追加し、種類を小説へ切り替えて再取得し、最後にまとめてダウンロードできます。

> `https://www.pixiv.net/users/{id}/request/artworks` を貼り付けると、手動選択なしで「リクエスト」範囲に自動切り替わります。

## 追加フィルター

「追加フィルター」カードを展開すると、たとえば次のように絞り込めます。

- 作者の R-18 作品だけを取得
- AI 生成作品を除外
- ブックマーク数 100 以上の作品だけを取得

フィルターはプレビューと**実際のダウンロード**の両方で作品ごとに適用され、一致しない作品は自動的にスキップされます。

## スケジュールタスクとして保存

作者の新作を定期的に自動取得するには、現在の設定をスケジュールタスクとして保存します。「⏰ スケジュールタスクとして保存」カードまでスクロールし、名前と実行間隔を設定して「タスクを作成」をクリックしてください。

作成後、バックエンドが指定間隔で新作を検出・ダウンロードします。詳しくは [スケジュールタスク](/ja/scheduled-tasks) を参照してください。

## 大量取得時のヒント

作者によっては数百、数千件の作品があります。初回取得には時間がかかるため、次を検討してください。

- 追加フィルターで対象を絞る
- 「最大同時実行数」を下げ、Pixiv サーバーへの負荷を減らす
- 「作品間隔」（ミリ秒）を設定して作品間に待ち時間を入れる
