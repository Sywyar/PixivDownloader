# ユーザー一括ダウンロード

「User モード」に作者のプロフィール URL または ID を入力すると、イラスト、漫画、うごイラ、小説、公開済みのリクエスト作品をプレビューし、全件または選んだ作品を取得できます。アカウントの閲覧権限、フィルター、取得済み判定は引き続き適用されます。

## 取得する

1. `http://localhost:6999/pixiv-batch.html` の「User モード」を開きます。
2. 作者の URL または数字 ID を貼り付けます。
3. 画像、小説、リクエストの取得範囲を選びます。小説には `novel` プラグインが必要です。
4. 解析・プレビューを実行し、必要なら追加フィルターを設定します。
5. 全件、または選んだ作品をキューに追加し、ダウンロードを開始します。
6. キューで完了、スキップ、失敗を確認します。

次の形式を使えます。例の ID を実際の作者 ID に置き換えてください。

```text
https://www.pixiv.net/users/123456
https://www.pixiv.net/users/123456/artworks
https://www.pixiv.net/users/123456/illustrations
https://www.pixiv.net/users/123456/novels
https://www.pixiv.net/users/123456/request/artworks
https://www.pixiv.net/en/users/123456
123456
```

## 範囲とフィルター

| 範囲 | 対象 |
|---|---|
| イラスト・漫画・うごイラ | 作者の画像作品 |
| 小説 | 作者の小説 |
| リクエスト | 完成し、公開されているリクエスト作品 |

リクエスト作品は通常のイラストとしてプレビュー、キュー登録、ダウンロード、重複判定を行います。`/users/{id}/request/artworks` のリンクを貼り付けると、リクエストの範囲に自動で切り替わります。

一度に取得するプレビューは 1 種類です。範囲を切り替えると以前のプレビューは消えますが、キューは残ります。画像をキューに追加してから小説に切り替え、まとめてダウンロードできます。

追加フィルターで R-18 のみ、AI 作品の除外、最低ブックマーク数などを設定できます。プレビューだけでなく、ダウンロード時にも作品ごとに判定し、条件外の作品をスキップします。

## 定期取得する

画面下部のスケジュール保存欄で、名前と実行間隔を設定してタスクを作成します。バックエンドが起動している間、指定時刻に新作を取得します。ログインが必要な内容には、有効な Cookie をタスクに関連付けてください。アカウントの失効や接続エラーは、タスクの状態を確認して対処します。[スケジュールタスク](/ja/scheduled-tasks)に詳しい手順があります。

## 期待した作品が出ない場合

入力が作品 ID ではなく作者 ID か、画像・小説・リクエストの範囲が正しいかを確認し、フィルターと Cookie を見直してください。全件をキューに入れても、削除済み作品や権限のない作品は取得できません。

作品が数百・数千件ある作者では、初回の取得に時間がかかります。フィルターで対象を絞り、必要に応じて最大同時実行数を下げ、作品間の待ち時間（ミリ秒）を設定してください。
