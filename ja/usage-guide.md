## 起動パラメーター

```bash
java -Dfile.encoding=UTF-8 -jar PixivDownload-vX.X.X.jar
PixivDownload.exe

--no-gui    # デスクトップ GUI を無効化（サーバー / Docker 向け）
--intro     # 起動時に製品紹介を開く
--help, -h  # ヘルプを表示して終了
```

?> 既定では同梱の `gui-swing` provider が起動します。Compose を使う場合は、信頼済みプラグインリポジトリから `gui-compose` をインストールし、「設定 → インターフェース」で選択してアプリケーションを完全に再起動してください。`--no-gui` はサーバー用途でだけ推奨します。

### CLI 管理コマンド

| コマンド | 用途 |
|---------|---------|
| `--setup` | 初回初期化（アカウント、モード、プロキシ） |
| `--change-password` | 管理者パスワードを変更 |
| `--reset-password` | パスワードを忘れたときに強制リセット |

## ファイル名テンプレート

「ダウンロード設定 → ファイル名テンプレート」で次の変数を使えます。

| 変数 | 説明 |
|----------|-------------|
| `{artwork_id}` | 作品 ID |
| `{artwork_title}` | 作品タイトル（使用できない文字は自動除去） |
| `{author_id}` | 作者 ID |
| `{author_name}` | 作者名（使用できない文字は自動除去） |
| `{timestamp}` | Unix タイムスタンプ（ミリ秒） |
| `{page}` | 現在のページ番号（0 始まり） |
| `{count}` | 総ページ数 |
| `{ai}` | AI 生成なら `AI`、それ以外は空文字 |
| `{ai+}` | `AI` または `Human` |
| `{R18}` | `R18` / `R18G` / 空文字 |
| `{R18+}` | `SFW` / `R18` / `R18G` |

例：`{author_name}/{artwork_id}_p{page}` は作者名ごとのサブフォルダーに保存します。

## 自動ブックマーク

ダウンロード設定で「**自動ブックマーク**」を有効にすると、完了後に Cookie を使って Pixiv API でブックマークします。`PHPSESSID` を含む有効な Cookie が必要です。ブックマークの失敗でダウンロード全体が失敗することはありません。

## うごイラ

うごイラは自動検出され、ZIP のフレームを展開し、ファイル名順に並べ、`ffmpeg` で WebP アニメーションに変換します。先頭フレームは `_p0_thumb.jpg` としても保存されます。`ffmpeg` を `PATH` に追加するか、Windows インストーラー / GUI のステータスページから取得してください。

## ダウンロード監視

`http://localhost:6999/monitor.html` で、実行中の進捗、作者・タグ・AI で絞り込める履歴、ダウンロード傾向を確認できます。

## GUI ツール

| ツール | 説明 |
|------|-------------|
| **画像分類** | ダウンロードした画像を分類・整理 |
| **データベースディレクトリ検証** | データベース内のパスが有効か確認 |
| **データベースバックフィル** | バージョンアップで不足した項目を補完 |

データベース検証とバックフィルは SQLite の排他的アクセスを必要とします。GUI がバックエンドの一時停止・再開を処理するため、手動でサービスを停止する必要はありません。

## 重複候補

`http://localhost:6999/pixiv-duplicates.html`（管理者のみ）では、知覚ハッシュ（dHash）でファイル名や寸法が違う似た画像を検索できます。ハミング距離、作品横断モード、ライブラリ全体モードを設定でき、サムネイルから詳細ページを開いて処理できます。

## ゲスト招待

ソロモードとマルチモードのどちらでも利用できます。管理者はギャラリーの「**ゲストを招待**」から有効期限、コンテンツレーティング、タグ / 作者の許可リストを設定し、`http://host:port/invite?code=xxx` を共有できます。招待の管理ページは `http://localhost:6999/pixiv-invite-manage.html` です。
