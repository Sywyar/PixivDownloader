# 操作リファレンス

開始手順は[初回ダウンロード](/ja/first-download)、取得元別の操作は[クイック取得](/ja/quick-access)、[URL 一括](/ja/batch-download)、[作者](/ja/user-download)、[検索](/ja/search)、[小説](/ja/novel)を参照してください。整理は[ギャラリー](/ja/gallery)、自動実行は[スケジュール](/ja/scheduled-tasks)、Pixiv 上の操作は[ユーザースクリプト](/ja/userscripts)に説明があります。

## 起動と管理コマンド

配布パッケージ全体を展開したディレクトリで実行します。`APP.jar` は実際の主プログラムの JAR 名に置き換えてください。次の 1 行コマンドは PowerShell / Bash 共通です。

```text
java -Dfile.encoding=UTF-8 -jar APP.jar --help
java -Dfile.encoding=UTF-8 -jar APP.jar --no-gui
```

| 引数 | 動作 |
|---|---|
| `--no-gui` | デスクトップ画面を起動しない。サーバー・Docker 向け |
| `--intro` | 起動時に紹介ページを開く |
| `--help`、`-h` | ヘルプを表示して終了 |
| `--setup` | アカウント・モード・プロキシの初期化 |
| `--change-password` | 管理者パスワードを変更 |
| `--reset-password` | パスワードを忘れた場合のリセット |

Windows のインストール版は `PixivDownload.exe` から起動できます。配布物には Compose と Swing があり、`app.gui-provider` が空なら既定の Compose を選びます。切り替え後は完全に再起動してください。初期化前の headless 起動は終了コード `78` で停止します。

管理コマンドの前には同じデータディレクトリを使う他のインスタンスを止めます。パスワード変更・リセットで既存セッションは無効になるため、再起動後に新しいパスワードでログインを確認します。[初回セットアップ](/ja/first-setup)に条件と復旧手順があります。

## ファイル名テンプレート

ダウンロード設定のテンプレートで次の変数を使えます。

| 変数 | 内容 |
|---|---|
| `{artwork_id}` | 作品 ID |
| `{artwork_title}` | 作品タイトル。無効な文字は除去 |
| `{author_id}` | 作者 ID |
| `{author_name}` | 作者名。無効な文字は除去 |
| `{timestamp}` | Unix 時刻（ミリ秒） |
| `{page}` | ページ番号（0 始まり） |
| `{count}` | 総ページ数 |
| `{ai}` | AI 作品なら `AI`、それ以外は空 |
| `{ai+}` | `AI` または `Human` |
| `{R18}` | `R18` / `R18G` / 空 |
| `{R18+}` | `SFW` / `R18` / `R18G` |

例：`{author_name}/{artwork_id}_p{page}` は作者名のディレクトリに保存します。

## 自動ブックマーク

Web のダウンロード画面で有効にすると、保存済みの `PHPSESSID` を含む Cookie を使い、完了後にバックエンドが Pixiv へブックマークを送ります。ユーザースクリプトではブラウザーの Pixiv ログイン状態を使い、`document.cookie` をバックエンドへ転送しません。

ブックマークは best-effort で、失敗してもダウンロードは失敗扱いになりません。

## うごイラ

1. フレームを含む ZIP を取得します。
2. 展開したフレームをファイル名で並べます。
3. `ffmpeg` で選択した動画・アニメーション形式へ変換します。[対応設定](/ja/configuration)を参照してください。
4. 最初のフレームを `_p0_thumb.jpg` として保存します。

`ffmpeg` をシステムの PATH から実行できる必要があります。Windows では GUI の状態画面から FFmpeg のダウンロードを実行できます。

## 監視とメンテナンス

`http://localhost:6999/monitor.html` で進行中のダウンロード、履歴、取得数の推移を確認できます。履歴は作者・タグ・AI 条件や部分一致で検索できます。

GUI のツールには画像分類、データベース内のファイルパス確認、不足フィールドの補完があります。データベースツールは排他的なメンテナンスセッションを使い、GUI がバックエンドの停止・復帰を管理します。

実行前に対象データベースをバックアップし、同じデータディレクトリで別のインスタンスを起動しないでください。選択した database provider が必要です。PostgreSQL はサーバー側のデータベースも別途バックアップします。終了後は報告、バックエンドの状態、ギャラリーのアクセスを確認してください。ツールのウィンドウを閉じただけでは成功を確認できません。

## 類似画像を調べる

管理者は `http://localhost:6999/pixiv-duplicates.html` で dHash による類似画像の検出を使えます。ファイル名やサイズが異なっても視覚的に似た画像を候補にします。ハミング距離のしきい値は小さいほど厳しく、既定は `10` です。作品間またはライブラリー全体を対象にし、サムネイルから詳細を開いて判断します。

## 閲覧用の招待

招待は solo / multi の両モードで使えます。管理者がギャラリーの招待から期限、年齢区分、タグ・作者の許可リストを指定し、`http://host:port/invite?code=xxx` を共有します。招待されたユーザーは読み取り専用です。管理画面は `http://localhost:6999/pixiv-invite-manage.html` です。
