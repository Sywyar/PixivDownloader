# CLI と詳細リファレンス

このページでは、起動時のコマンドライン引数、ファイル名テンプレートの変数、メディア・保守ツール、ゲスト招待を説明します。通常のダウンロードや管理の操作は、[クイック取得](/ja/quick-access)、[URL 一括ダウンロード](/ja/batch-download)、[作者別一括ダウンロード](/ja/user-download)、[検索ダウンロード](/ja/search)、[小説と読み上げ](/ja/novel)、[作品ギャラリー](/ja/gallery)、[スケジュールタスク](/ja/scheduled-tasks)、[ユーザースクリプト](/ja/userscripts)を参照してください。

## 起動と管理の引数

配布パッケージをすべて展開したディレクトリで実行します。`APP.jar` は実際のメインプログラムの JAR 名に置き換えてください。次の 1 行コマンドは PowerShell と Bash のどちらでも使用できます。

```text
java -Dfile.encoding=UTF-8 -jar APP.jar --help
java -Dfile.encoding=UTF-8 -jar APP.jar --no-gui
```

| 引数 | 動作 |
| --- | --- |
| `--no-gui` | デスクトップ GUI を起動しない。ヘッドレスサーバーや Docker 向け。初回起動の前に `--setup` を完了する必要があり、未完了なら終了コード `78` で終了 |
| `--intro` | 起動時にブラウザーで製品紹介ページを開く |
| `--help`、`-h` | コマンドラインのヘルプを表示して終了 |
| `--setup` | 管理者アカウント、動作モード、HTTP プロキシを初期設定 |
| `--change-password` | 現在のパスワードを確認して管理者パスワードを変更 |
| `--reset-password` | パスワードを忘れた場合に、このマシンで管理者パスワードを強制リセット |
| `--web-publications` | ページエディターの公開済みページの状態をオフラインで照会・復旧（[ページエディター](/ja/page-editor#フォーム検証とリソース認可)を参照） |

`--setup`、`--change-password`、`--reset-password` などの管理コマンドを実行する前に、同じデータディレクトリを使用する実行中のインスタンスを停止してください。パスワードの変更・リセットにより既存のセッションは無効になります。再起動後に新しいパスワードでログインを確認してください（[初回セットアップ](/ja/first-setup)を参照）。Windows インストール版は `PixivDownload.exe` から直接起動できます。配布パッケージには Compose（デフォルト）と Swing の両方のデスクトップ画面が含まれ、`app.gui-provider` の切り替え後は完全な再起動が必要です。

## ファイル名テンプレートの変数

ダウンロードページの「ダウンロード設定 → ファイル名テンプレート」で、次の 11 個の変数を使えます。ファイル名に使用できない文字は自動的に除去され、新しいテンプレートは以降の新規ダウンロードにだけ適用されます。

| 変数 | 意味 |
| --- | --- |
| `{artwork_id}` | 作品 ID |
| `{artwork_title}` | 作品タイトル |
| `{author_id}` | 作者 ID |
| `{author_name}` | 作者名 |
| `{timestamp}` | ダウンロード時の Unix タイムスタンプ（ミリ秒） |
| `{page}` | 現在のページのインデックス（`0` から開始） |
| `{count}` | 作品の総ページ数 |
| `{ai}` | AI 生成作品なら `AI`、それ以外は空文字列 |
| `{ai+}` | `AI` または `Human` |
| `{R18}` | `R18`、`R18G`、または空文字列 |
| `{R18+}` | `SFW`、`R18`、または `R18G` |

例：`{author_name}/{artwork_id}_p{page}` は作者名のサブフォルダーを作成して画像を保存します。

## 自動ブックマークとうごイラ（Ugoira）の処理

- **自動ブックマーク**：ダウンロードページで「自動ブックマーク」を選ぶと、バックエンドは作品のダウンロード完了時に、保存済みの Cookie（`PHPSESSID` が必要）を使って Pixiv API でブックマークします。ユーザースクリプトはブラウザーの現在の Pixiv ログイン状態を使い、`document.cookie` をバックエンドへ転送しません。ブックマークは best-effort で実行され、失敗しても完了済みのダウンロードが失敗に変わることはありません。
- **うごイラ（Ugoira）**：フレーム入り ZIP をダウンロードしてフレーム順に展開し、システムの `PATH` または自動インストールした `ffmpeg` を使って選択した形式に変換します。デフォルトは WebP で、GIF、APNG、MP4、元 ZIP の保持も選べます（[設定リファレンス](/ja/configuration#画像とうごイラの保存形式)を参照）。同時に最初のフレームを `_p0_thumb.jpg` サムネイルとして保存します。

## ダウンロード監視、重複候補の検出、デスクトップツール

- **ダウンロード監視（`http://localhost:6999/monitor.html`）**：実行中のダウンロードの進捗、作者・タグ・AI 状態による履歴の絞り込みや部分一致検索、ダウンロード傾向のグラフを確認できます。
- **重複候補の検出（`http://localhost:6999/pixiv-duplicates.html`、管理者のみ、`gallery-tools` が必要）**：知覚ハッシュ（dHash）を使い、ファイル名や解像度が異なっても見た目が似た画像を探します。ハミング距離のしきい値（デフォルト `10`、小さいほど厳格）を調整し、「作品間モード / ライブラリ全体モード」を切り替えられます。サムネイルをクリックすると詳細ページで処理できます。
- **デスクトップ GUI のツールページ**：**画像分類ツール**、**データベースのディレクトリ検査**、**データ補完ツール**、**旧データとメタデータのインポート**、**過去のメディア処理**、**PixivBatchDownloader の履歴インポート**があります。

!> データベースを扱うデスクトップ保守ツールは、排他的な保守セッションを使用し、GUI がバックエンドを自動的に停止・再開します。実行前に選択中のデータベースをバックアップしてください。PostgreSQL ではサーバー側のデータベースも必要です。同じデータディレクトリを使う別インスタンスを同時起動しないでください。終了後はツールのレポート、バックエンドの状態、ギャラリーへのアクセスを確認し、ツールのウィンドウを閉じたことだけで成功と判断しないでください。

## ゲスト招待

ゲスト招待は `solo` と `multi` の両モードで使用できます。管理者はギャラリー右上の「ゲストを招待」で、有効期限、許可する年齢区分（SFW / R18 / R18G）、タグ・作者の許可リストを設定し、`http://host:port/invite?code=xxx` をコピーして外部のゲストに読み取り専用で共有できます。すべての招待コードは `http://localhost:6999/pixiv-invite-manage.html` でまとめて確認、無効化、削除できます。
