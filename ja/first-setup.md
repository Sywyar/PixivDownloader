# 初回セットアップ

初回セットアップでは、PixivDownloader にログインする管理者アカウントを作成します。Pixiv アカウントの登録や Cookie の設定は別の操作です。

| 起動方法 | 初期化の手順 |
|---|---|
| デスクトップ | 起動後の案内でアカウントを作成し、ログインする |
| GUI のない環境 | `--setup` で初期化してから `--no-gui` で起動する |
| Docker | `docker compose run` で初期化し、その後 `up -d` で起動する |

## デスクトップで設定する

1. 配布パッケージ全体を展開し、起動します。必須プラグインやデータベースの修復画面が表示された場合は、その案内を先に完了してください。アカウントのリセットではこれらの問題は直りません。
2. 初期化画面でユーザー名とパスワードを設定します。パスワードは **8 文字以上**が必要で、12 文字以上を推奨します。弱いパスワードには追加の確認が表示されます。
3. Pixiv への接続に HTTP プロキシが必要なら、実際に動作しているプロキシのホストとポートを入力します。`127.0.0.1:7890` は、そのアドレスでプロキシを動かしている場合の例です。プロキシを使わない場合は無効にします。
4. 保存後、設定したアカウントでログインします。ブラウザーから使う場合の既定アドレスは `http://localhost:6999` です。

GUI とブラウザーのセットアップは単人モード (`solo`) を設定します。ここにモードの選択欄はありません。ローカルの `/setup.html` はローカル接続からのみ開けます。未初期化の状態で `--no-gui` を指定しても、セットアップ画面は自動起動しません。

設定するプロキシは、アプリや対応タスクがその経路を使う通信に適用されます。ブラウザー、SMTP、データベースなどの通信は経路が異なります。[ネットワークアクセス](/ja/network-access)を参照してください。

## コマンドラインで初期化する

既存のアプリを停止し、配布物を展開したディレクトリで実行します。以下の `APP.jar` は実際の JAR 名に置き換えてください。隣接する `plugins/` などのファイルも必要です。

PowerShell / Bash 共通：

```text
java -Dfile.encoding=UTF-8 -jar APP.jar --setup --mode=solo
```

画面の質問に従ってユーザー名とパスワードを入力します。8 文字未満は使えず、12 文字未満では確認が必要です。CLI のモード指定は `solo` と `multi` を受け付けます。

初期化に成功すると、アカウント情報は `state/setup_config.json`、プロキシなどの設定は `config/config.yaml` に保存されます。その後、次のように起動します。

```text
java -Dfile.encoding=UTF-8 -jar APP.jar --no-gui
```

対話入力できない環境では、引数でも指定できます。値を自分のものに置き換えてください。

```text
java -Dfile.encoding=UTF-8 -jar APP.jar --setup --mode=solo --username=admin --password=REPLACE_WITH_A_UNIQUE_PASSWORD --proxy-enabled=true --proxy-host=127.0.0.1 --proxy-port=7890
```

パスワード、プロキシのホスト・ポートは実際の値に置き換えます。プロキシ不要なら `--proxy-enabled=false` を指定してください。引数のパスワードはコマンド履歴やプロセス一覧に残ることがあります。共有環境では対話入力を使い、実際の認証情報をログや Issue に貼り付けないでください。

## Docker で初期化する

Compose ファイルのあるディレクトリで実行します。

```bash
docker compose run --rm app --setup --mode=solo
docker compose up -d
docker compose logs -f app
```

コンテナー内の `localhost` はコンテナー自身です。ホスト上のプロキシを使う場合は、環境に応じて `host.docker.internal` などの到達可能なアドレスを使い、プロキシ側でもコンテナーからの接続を許可してください。

未初期化の headless 起動は終了コード `78` で停止します。再起動ポリシーによってループする場合は、いったん停止して `--setup` を完了してから起動してください。

## 設定できたか確認する

管理者アカウントでログインし、ダウンロード画面を開ければ、アプリの初期化は完了です。Pixiv に接続できることや Cookie が有効なことは、[初回ダウンロード](/ja/first-download)で別途確認します。

保存できない場合は、起動中の別インスタンス、ディレクトリへの書き込み権限、必須プラグインとデータベースの状態を確認し、`log/` のエラーを調べてください。初期化ファイルを繰り返し削除しても、接続やストレージの問題は解決しません。

## パスワードを変更・リセットする

アプリを停止して、次のどちらかを実行します。

```text
java -Dfile.encoding=UTF-8 -jar APP.jar --change-password
java -Dfile.encoding=UTF-8 -jar APP.jar --reset-password
```

`--change-password` は現在のパスワードを確認します。`--reset-password` はローカル環境から、現在のパスワードなしでリセットします。これらの管理コマンドは同時に指定できません。完了後は既存セッションが無効になるため、アプリを起動し直して新しいパスワードでログインしてください。作品データベースは削除されません。

アカウントやモードを含めて初期化し直す場合に限り、停止・バックアップ後に `state/setup_config.json` を退避します。この操作はアカウント、モード、セッションに影響します。パスワードだけの問題には `--reset-password` を使ってください。
