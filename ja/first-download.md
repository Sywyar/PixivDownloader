# 初回ダウンロード

まず閲覧できるイラストを 1 件取得し、キューの完了と保存先を確認します。[インストール](/ja/installation)と[初回セットアップ](/ja/first-setup)を済ませてください。例の ID は入力形式を示すもので、実際に取得したい作品に置き換えます。

## 画面を開く

`http://localhost:6999/pixiv-batch.html` にアクセスし、管理者アカウントでログインします。デスクトップの状態画面からダウンロード画面を開くこともできます。新規環境の既定レイアウトは `pixiv-batch-alt` です。レイアウトの選択は保存され、どちらの URL からでも選択した画面に移動します。

初回の管理者向けガイドでは、ニックネーム、接続確認、Cookie とユーザースクリプト、作品の取得・キュー登録・フィルター・保存、ギャラリーの閲覧を順に確認できます。ニックネームはギャラリーのサイドバーやシステムメールの呼びかけに使われ、未設定時は管理者名を使います。接続確認はその時点の応答時間を測るものです。

ガイドは途中で閉じられます。再開する場合は画面右下の操作ガイドを開いてください。設定済みのニックネームは再入力しません。multi モードの未ログイン利用者には自動表示されません。

## 必要に応じて Pixiv Cookie を保存する

公開された全年齢作品の一部は Cookie なしでも取得できます。R-18、検索、クイック取得、ログインが必要な作品には Cookie が必要です。Cookie がない場合、R-18 作品はスキップされます。

必要な値は `PHPSESSID` です。Cookie ヘッダー全体を貼り付けることもできます。次のいずれかで取得します。

### Cookie-Editor で書き出す

1. ブラウザーに [Cookie-Editor](https://chromewebstore.google.com/detail/cookie-editor/hlkenndednhfkekhgcdicdfddnkalmdm) をインストールします。
2. [Pixiv](https://www.pixiv.net/) にログインしてから拡張機能を開きます。
3. Export で Netscape 形式を選び、書き出した内容をコピーします。
4. ダウンロード画面の Cookie 設定で Netscape 形式を選び、貼り付けて保存します。

### ブラウザーの開発者ツールから取得する

1. ログイン済みの Pixiv ページで `F12` を押します。
2. Application / Storage の Cookies から Pixiv を選びます。
3. `PHPSESSID` の値をコピーし、`PHPSESSID=値` の形にします。
4. アプリの Cookie 設定で Cookie ヘッダー形式を選び、保存します。

HttpOnly Cookie も開発者ツールでは確認できます。Tampermonkey の Cookie 権限を変更する必要はありません。Network タブで `www.pixiv.net` へのリクエストを選び、Request Headers の `Cookie` 全体をコピーする方法もあります。

### ツールボックスの Cookie 取得を使う

ツールボックスの取得操作は Pixiv を開き、Cookie を読み取ってアプリに返します。この方法では Tampermonkey の詳細設定で Cookie アクセスを HttpOnly を含む `All` にする必要があります。

この設定は他のスクリプトにも認証 Cookie の読み取りを許可します。使う場合は一時的に変更し、取得後は `All except HttpOnly` に戻してください。権限を広げたくない場合は、上記の開発者ツールを使います。

Cookie 設定の位置はレイアウトによって異なります。設定欄を開いて形式を選び、貼り付けた後に保存してください。Cookie をスクリーンショット、ログ、Issue に含めないでください。

## 作品をキューに入れる

1. 作品の一括インポート欄を開きます。
2. 次のような作品 URL、または数字の ID を入力します。

   ```text
   https://www.pixiv.net/artworks/12345678
   ```

3. 情報を取得し、プレビューの作品名と種類を確認します。
4. 作品をキューに追加し、ダウンロードを開始します。
5. キューの状態を確認します。待機中、ダウンロード中、完了、既存によるスキップ、失敗は別の状態です。失敗時は表示された理由を確認してください。

## 保存先を確認する

デスクトップ画面に表示された実際の保存先を開いてください。既定では作業ディレクトリの `pixiv-download/` です。JAR を直接起動した場合は起動時の作業ディレクトリが基準になり、インストーラーでは選択したディレクトリなど実際の表示を確認します。

ファイル構成の例：

```text
pixiv-download/
└── 12345678/
    ├── 12345678_p0.jpg
    └── 12345678_p1.jpg
```

実際の構成はファイル名テンプレートや作品の種類によって変わります。`config/config.yaml` の `download.root-folder` が基本の保存先で、コレクションには個別の保存先を設定できます。設定変更だけでは既存ファイルは移動しません。[ストレージ](/ja/storage)を参照してください。

ギャラリープラグインが有効なら、`http://localhost:6999/pixiv-gallery.html` で登録された作品を確認できます。

## うまくいかない場合

- 作品を取得できない：Pixiv で現在も閲覧できるか確認します。非公開・削除済み・権限不足の作品は取得できません。
- 認証エラーや R-18 のスキップ：Cookie を保存し直し、対象アカウントの閲覧権限を確認します。
- 接続エラー：バックエンド側のプロキシとネットワークを確認します。ブラウザーで開けることだけではバックエンドの接続成功は確認できません。
- 完了したのに見つからない：実際の `download.root-folder`、コレクションの保存先、起動時の作業ディレクトリを確認します。

複数作品は [URL 一括ダウンロード](/ja/batch-download)、作者単位は[ユーザー一括ダウンロード](/ja/user-download)、キーワードからの取得は[検索](/ja/search)を参照してください。
