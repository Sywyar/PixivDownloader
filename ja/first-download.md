# 初回ダウンロード

このチュートリアルでは、Pixiv 作品を 1 件取得してダウンロードし、ローカルファイルとギャラリーで結果を確認します。始める前に[インストールと起動](/ja/installation)と[初回セットアップ](/ja/first-setup)を完了してください。以下の作品 ID は形式の例です。自分が閲覧できる実際の作品に置き換えてください。

## 1. ダウンロードワークベンチを開く

ブラウザーで `http://localhost:6999/pixiv-batch.html` を開き、管理者アカウントでログインします。デスクトップ GUI の「状態」ページで「一括ダウンロード」をクリックして開くこともできます。新しい環境では、新レイアウトの `pixiv-batch-alt.html` が既定で開きます。ページ上部で新旧レイアウトを切り替えられ、選択は自動保存されます。

管理者として初めてログインすると、ページをまたぐ初回ガイドが自動で始まります。呼び名の設定、Pixiv への接続確認、Cookie とユーザースクリプト、作品 1 件のキュー登録とダウンロード、ギャラリーの閲覧を順に案内します。入力した呼び名はギャラリーのサイドバーカードとシステム通知メールの挨拶に使われ、空欄の場合は「管理者」と表示されます。ガイドはいつでもスキップでき、ページ右下の「操作ガイド」から開き直せます。

## 2. Pixiv Cookie を保存する（必要な場合）

公開されている全年齢向けイラストは Cookie なしでダウンロードできます。**R-18 / R-18G 作品、検索ダウンロード、クイック取得、ログインしないと閲覧できない作品には、有効な `PHPSESSID` を含む Cookie が必要です**。未設定の場合、閲覧制限のある作品はスキップされます。先にブラウザーで [Pixiv](https://www.pixiv.net/) にログインし、以下のいずれかの方法で取得してください。

### 方法 A：ブラウザーの開発者ツール（推奨、拡張機能への追加権限は不要）

1. ログイン済みの Pixiv ページで `F12` を押し、開発者ツールを開きます。
2. **Application（アプリケーション）パネル**：左側で `Storage → Cookies → https://www.pixiv.net` を展開し、`PHPSESSID` の `Value` をコピーして、`PHPSESSID=コピーした値` の形にします。
3. または **Network（ネットワーク）パネル**：ページを再読み込みし、`www.pixiv.net` 宛ての任意のリクエストを選んで、`Request Headers → Cookie` の値全体をコピーします。
4. ダウンロードページで「Cookie」を展開し、形式を **Header String** にして内容を貼り付け、「Cookie を保存」をクリックします。

### 方法 B：Cookie-Editor 拡張機能

1. [Cookie-Editor](https://chromewebstore.google.com/detail/cookie-editor/hlkenndednhfkekhgcdicdfddnkalmdm) をインストールし、ログイン済みの Pixiv ページで拡張機能のアイコンをクリックします。
2. `Export → Netscape` をクリックして、エクスポートされた内容をコピーします。
3. ダウンロードページの「Cookie」で **Netscape** 形式を選び、貼り付けて保存します。

### 方法 C：ユーザースクリプトの「Cookie をワンクリックでインポート」

1. 「機能拡張ツールボックス（Toolbox）」スクリプトをインストールして有効にします（[ユーザースクリプト](/ja/userscripts)を参照）。
2. Tampermonkey の「設定 → 設定モード：上級者 → セキュリティ」で、「スクリプトによる Cookie へのアクセスを許可」を一時的に `すべて / All` にします。
3. ダウンロードページの Cookie 欄で「Cookie をワンクリックでインポート」をクリックすると、スクリプトが `PHPSESSID` を読み取ってバックエンドに送ります。

!> `PHPSESSID` は HttpOnly Cookie のため、Tampermonkey の既定設定では読み取れません。ただし権限を `すべて / All` にすると、ブラウザー内のすべてのユーザースクリプトがログイン認証情報を読み取れるようになります。インポート後すぐに `All except HttpOnly` へ戻すか、上記の開発者ツールを優先してください。Cookie をスクリーンショット、ログ、Issue に貼り付けないでください。

## 3. 作品を追加してダウンロードする

1. ダウンロードページで「単一作品の一括インポート」を選びます。
2. 作品リンク、または数字のみのイラスト ID を 1 行に 1 件ずつ貼り付けます。

   ```text
   https://www.pixiv.net/artworks/12345678
   ```

3. 「情報を取得」をクリックし、プレビューの作品名と種類を確認します。
4. 作品をキューに追加して「ダウンロード開始」をクリックします。
5. 「ダウンロードキュー」で状態を確認します。待機中、ダウンロード中、完了、既存のためスキップ、失敗は別々に表示されます。失敗した項目をクリックすると、具体的な原因を確認できます。

## 4. ローカルファイルとギャラリーを確認する

デスクトップ GUI の「状態」ページで、現在の「ダウンロードディレクトリ」を確認します。既定の場所はプログラムの作業ディレクトリ内の `pixiv-download/` です。起動時の作業ディレクトリや、コレクションごとに指定したディレクトリによって変わります。

```text
pixiv-download/
└── 12345678/
    ├── 12345678_p0.jpg
    └── 12345678_p1.jpg
```

ダウンロードルートは、`config/config.yaml` の `download.root-folder` で指定します。設定を変えても既存ファイルは移動しません。ディレクトリを移す場合は、[ストレージとバックアップ](/ja/storage)に従ってください。`gallery` プラグインが有効な場合は、`http://localhost:6999/pixiv-gallery.html` で登録されたばかりの作品を閲覧できます（[作品ギャラリー](/ja/gallery)を参照）。

## よくある問題の確認

- **Cookie が必要と表示される、または R-18 がスキップされる**：有効な `PHPSESSID` を含む Cookie を保存していることと、その Pixiv アカウントで Web サイト側の R-18 表示設定を有効にしていることを確認します。
- **プロキシ接続に失敗する**：プロキシソフトが起動していることを確認し、デスクトップの設定ページで `proxy.host` と `proxy.port` を確認します。ブラウザーで Pixiv を開けても、バックエンドのプロキシ設定が正しいとは限りません。
- **作品が存在しないと表示される**：Pixiv 上で作品が削除、非公開、マイピク限定になっていないか確認します。
- **ダウンロードは完了したがファイルが見つからない**：デスクトップ GUI の「状態」ページで実際の作業ディレクトリとダウンロードディレクトリを確認します。また、ダウンロード時に独自の保存先を指定したローカルコレクションを選んでいないか確認してください。

さらに作品をダウンロードするには、[URL 一括ダウンロード](/ja/batch-download)、[作者別一括ダウンロード](/ja/user-download)、[検索ダウンロード](/ja/search)、[小説と読み上げ](/ja/novel)を参照してください。
