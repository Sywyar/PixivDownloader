# クイック取得

保存した Pixiv Cookie で、自分のブックマーク、投稿作品、フォロー中の新作などを取得します。まず一覧を確認し、キューに追加してからダウンロードを開始します。一覧の取得だけではファイルは保存されません。

!> `PHPSESSID` を含む Cookie が必要です。未設定では取得ボタンが使えません。

## 取得元を選ぶ

| 取得元 | 内容 |
|---|---|
| 自分のブックマーク | イラスト・小説。非公開ブックマークも対象にできる |
| 自分の作品 | 自分のイラスト・小説。非公開作品を含む |
| 自分のリクエスト | 完成し公開されたリクエストのイラスト |
| フォロー中のユーザー | 非公開フォローを含む。名前や ID で絞り込み可能 |
| フォロー中の新着作品 | イラスト・漫画・うごイラをページ単位で取得 |
| Pixiv のコレクション | コレクション内のイラスト・小説 |

1. `http://localhost:6999/pixiv-batch.html` のクイック取得タブを開きます。
2. 取得元を選び、一覧が表示されるまで待ちます。
3. 全件または選んだ作品をキューに追加します。
4. ダウンロードを開始し、キューの結果を確認します。

フォロー中のユーザーでは、作者を展開してイラスト・小説をプレビューします。1 件の選択、現在のページ、ページ送りに対応しています。コレクションにはイラストと小説が混在することがあります。

## フィルターを使う

追加フィルターで年齢区分、AI 作品、タグ、作品の種類、ページ数、文字数、ブックマーク数を指定できます。読み込み済みのプレビューを絞り込めます。

現在のページをまとめて追加するときは、フィルター後の表示が対象です。全件追加では全体をキューに入れ、実際のダウンロード時に作品ごとの条件を判定します。条件外は理由付きでスキップされます。先に作品一覧を展開する必要がある操作では、未展開時に案内が表示されます。

## 定期取得として保存する

管理者は、次の取得元をスケジュールとして保存できます。

- 公開・非公開のブックマーク（イラスト・小説）
- 自分の作品と完成済みリクエスト
- フォロー中の新作
- 選択した作者
- 選択したコレクション

画面下部のスケジュール保存欄で名前と実行条件を指定します。非公開ブックマーク、フォロー中の新着、コレクションなどには、権限のある Cookie が必要です。solo モードで新規作成すると Cookie が自動で関連付けられます。

作成後、取得元は編集できません。別の取得元に変更する場合は、タスクを作り直します。実行条件やエラーの確認方法は[スケジュールタスク](/ja/scheduled-tasks)を参照してください。

## 結果とエラーを確認する

ダウンロード後はキューの完了・スキップ・失敗を確認し、必要に応じてギャラリーでファイルを開きます。

一覧が空の場合は、Cookie のアカウント、公開範囲、フィルターを確認してください。ボタンが使えない場合は Cookie の保存状態を、認証エラーの場合は失効を確認して保存し直します。取得エラーはバックエンドの接続やプロキシも確認します。空の一覧だけでは、すべて同期できたとは判断できません。

URL からの取得は[一括ダウンロード](/ja/batch-download)、作者単位の取得は[ユーザー一括ダウンロード](/ja/user-download)、キーワード検索は[検索](/ja/search)を参照してください。
