# クイック取得

「クイック取得」は `pixiv-batch.html` を開いたときに最初に表示されるタブです。保存済みの Pixiv Cookie で現在のアカウントを自動認識し、アカウントに関連するデータをワンクリックでダウンロードキューに追加します。

?> `PHPSESSID` を含む保存済み Cookie が必要です。Cookie がない場合、ボタンは無効になりヒントが表示されます。

## 利用できるデータソース

| データソース | 説明 |
|-------------|-------------|
| **自分のブックマーク** | 非公開ブックマークを含むイラスト / マンガと小説 |
| **自分の作品** | 非公開作品を含む自分のイラスト / マンガと小説 |
| **自分のリクエスト作品** | 完了済みで公開されている自分のリクエスト納品物（イラストとして処理） |
| **フォロー中のユーザー** | 非公開フォローを含む全作者。ユーザー名 / ID でリアルタイム絞り込み可能 |
| **フォロー中ユーザーの新着作品** | フォロー中の作者の最新イラスト / マンガ / うごイラ（Pixiv の「フォロー新着」）。ページ分割対応 |
| **自分のコレクション** | Pixiv のコレクションに入れた作品 |

## 使い方

1. `http://localhost:6999/pixiv-batch.html` を開く
2. 既定で「**⚡ クイック取得**」タブが開いていることを確認する
3. 対応するボタン（「自分のブックマーク」「自分の作品」など）をクリックする
4. データの読み込みを待つ。作品一覧が下に表示されます
5. 「**すべてキューに追加**」または作品を選んで「**選択項目をキューに追加**」をクリックする
6. キューが表示されたら「**ダウンロード開始**」をクリックする

## フォロー中ユーザーの二段階展開

一覧のフォロー中ユーザーをクリックすると、そのユーザーの作品プレビューが下に展開されます。イラストと小説は切り替えできます。

- 作品の横にある「キューに追加」で 1 件追加
- 「ページをキューに追加」で現在のページをすべて追加
- ページを移動して追加を続行

## コレクション

コレクションをクリックすると、イラストと小説が混在した一覧が展開されます。フォロー中ユーザーの一覧と同じ方法で操作できます。

## 追加フィルター（プレビューのリアルタイム絞り込み）

作品一覧を展開すると、上部の「**追加フィルター**」カードで、コンテンツレーティング、AI、タグ、作品種別、ページ数、文字数、ブックマーク数を使って現在のプレビューを絞り込めます。

- 「ページをキューに追加」は**絞り込み後の作品だけ**を追加します。
- 「すべてキューに追加」はすべてを追加します。一致しない作品は実際のダウンロード時に理由付きで個別にスキップされます。

作品一覧を展開していない場合は、先に一覧を展開するよう案内が表示されます。

## スケジュールタスクとして保存（管理者）

クイック取得の**すべてのソース**を、バックグラウンドの [スケジュールタスク](/ja/scheduled-tasks) として保存できます。

| ソース | タスクの動作 |
|------|-------------|
| 自分のブックマーク（イラスト / 小説 × 公開 / 非公開） | 新しく追加されたブックマークを定期取得 |
| 自分の作品 | 新しく投稿した作品を定期取得 |
| 自分のリクエスト作品 | 新しく完了したリクエスト納品物を定期取得 |
| フォロー中ユーザーの新着作品 | フォロー中の作者の新作を定期取得 |
| フォロー中ユーザーを開く | その作者の新作を定期取得 |
| コレクションを開く | コレクションに新しく追加された作品を定期取得 |

ソースを展開すると、ページ下部の「**⏰ スケジュールタスクとして保存**」カードに説明が表示されます。名前と実行方法を入力して作成してください。ソースを展開していない場合は、先に展開するよう案内されます。

?> ブックマーク、フォロー中ユーザーの新着作品、コレクションはアカウント非公開情報です。対応するタスクの実行には `PHPSESSID` を含む Cookie が必要です（ソロモードでは新しいタスクに自動で紐付けられます）。これらのタスクを編集するとき、ソースは読み取り専用です。変更する場合は削除して作り直してください。
