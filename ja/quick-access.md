# クイック取得

ダウンロードページの「クイック取得」では、保存済みの Pixiv Cookie を使い、現在のアカウントのブックマーク、投稿作品、リクエスト作品、フォロー一覧、フォロー新着作品、Pixiv コレクションを取得します。プレビューを読み込み、作品をキューに追加してからダウンロードを開始してください。一覧を取得するだけではファイルは保存されません。

!> クイック取得を使うには、有効な `PHPSESSID` を含む Cookie を先に保存する必要があります。未保存の場合は各入口のボタンが無効になります。

## 対応する取得元と操作手順

| 取得元 | 取得範囲 |
| --- | --- |
| 自分のブックマーク | イラスト / 漫画と小説。公開・非公開のブックマークに対応 |
| 自分の作品 | 現在のアカウントが投稿したイラスト / 漫画と小説。非公開作品を含む |
| 自分のリクエスト作品 | 現在のアカウントで完成・公開済みのリクエスト作品。イラストの処理経路で扱う |
| 自分のフォロー | フォロー中の作者一覧。非公開フォローを含み、ユーザー名や ID でリアルタイムに絞り込める |
| フォロー中のユーザーの新作 | フォロー中の作者の最新イラスト / 漫画 / うごイラ（フォロー新着作品）。ページ単位で閲覧できる |
| 自分のPixiv コレクション | Pixiv のコレクションに含まれるイラストと小説の混在一覧 |

1. `http://localhost:6999/pixiv-batch.html` を開き、「クイック取得」に切り替えます。
2. 取得したいデータのボタンをクリックし、下部に作品一覧が表示されるまで待ちます。
3. 「自分のフォロー」や「自分のPixiv コレクション」では、作者またはコレクションをクリックして作品プレビューを開きます。フォロー中の作者では、イラストと小説を切り替えられます。
4. 1 件ずつのキュー追加、「ページ全体をキューに追加」、「すべてキューに追加」のいずれかを選び、「ダウンロード開始」をクリックします。

## 追加フィルター

作品一覧を開くと、「追加フィルター」で現在のプレビューページをリアルタイムに絞り込めます。対象は年齢区分、AI 作品、タグ、作品の種類、ページ数、文字数、最小ブックマーク数です。

- **ページ全体をキューに追加**：現在のページで、フィルター適用後に表示されている作品だけをキューに追加します。
- **すべてキューに追加**：取得元の全作品をキューに追加し、ダウンロード時に 1 件ずつ条件を判定します。条件に合わない作品には、キュー内にスキップ理由が表示されます。

フォロー中の作者一覧やコレクション一覧を表示している場合は、先に個別の作者またはコレクションを開かないと、フィルターやキュー追加を使えません。

## スケジュールタスクとして保存する（管理者）

ブックマーク、自分の作品、自分のリクエスト作品、フォロー新着作品、または個別のフォロー中の作者やコレクションを開くと、ページ下部の「スケジュールタスクとして保存」カードで名前と起動方法を指定し、バックグラウンドの自動ダウンロードタスクとして保存できます。

?> ブックマーク、フォロー新着作品、コレクションはアカウント専用の取得元のため、タスクに有効な Cookie を紐付ける必要があります。シングルユーザーモードで新規作成する場合は、現在の Cookie が自動的に紐付けられます。作成後は取得元の種類を変更できません。変更するにはタスクを削除して作り直してください。詳しくは[スケジュールタスク](/ja/scheduled-tasks)を参照してください。

## 結果の確認と問題の対処

ダウンロードが終わったら、キュー内の完了、スキップ、失敗をそれぞれ確認し、ギャラリーでも作品を確認します。プレビューが空の場合は、選択したアカウント、公開・非公開の範囲、追加フィルターを先に確認してください。ボタンが無効な場合や認証エラーの場合は、有効な Cookie を保存し直します。ネットワークエラーの場合はバックエンドのプロキシ接続を確認してください。空の一覧を、そのまま同期完了と判断しないでください。

指定リンクからの取得は [URL 一括ダウンロード](/ja/batch-download)、作者 ID からの取得は[作者別一括ダウンロード](/ja/user-download)、キーワードでの取得は[検索ダウンロード](/ja/search)を参照してください。
