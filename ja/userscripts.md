# ユーザースクリプト

ユーザースクリプトを使うと Pixiv のページ上で直接操作できます。閲覧中にダウンロードしたい作品を見つけたら、PixivDownloader のページへ移動せずワンクリックでキューに追加できます。

?> ユーザースクリプトは任意です。多くのダウンロード操作は `pixiv-batch.html` だけで行えます。

## 前提条件

1. ブラウザーに [Tampermonkey](https://www.tampermonkey.net/) をインストール
2. PixivDownloader のバックエンドを起動
3. ソロモードでログイン

## スクリプト一覧

| スクリプト | 用途 |
|-------------|---------|
| **オールインワン** | 下記の全スクリプトを収録（推奨。これ 1 つだけをインストール） |
| ページ作品一括ダウンローダー | 検索、ランキングなどの一覧ページから作品を一括確認・取得 |
| ユーザー一括ダウンローダー | 作者プロフィールから全作品をワンクリックで取得 |
| URL 一括インポーター | 任意のページにパネルを表示し、リンクを貼り付けて一括取得 |
| 単作品ダウンローダー（Java バックエンド） | 作品ページからバックエンド経由で取得 |
| 単作品ダウンローダー（ローカル） | Java バックエンドなしでブラウザーから直接取得 |
| 機能拡張ツールボックス | ダウンロード済み作品の枠表示、Cookie のワンクリック登録など |

## インストール

### 方法 1：Web 管理ページから（推奨）

1. PixivDownloader を起動し、`http://localhost:6999/pixiv-batch.html` を開く
2. 上部の「**🧩 ユーザースクリプト**」カードを展開する
3. 必要なスクリプトの「**⬇ インストール**」をクリックする
4. Tampermonkey の確認画面で「インストール」をクリックする

?> この方法では、現在のバックエンドアドレスに合わせてスクリプトの `@connect` が自動設定されます。

### 方法 2：リリースからダウンロード

1. [Releases](https://github.com/Sywyar/PixivDownloader/releases) から `.user.js` ファイルをダウンロードする
2. Tampermonkey のダッシュボードへファイルをドラッグし、「インストール」をクリックする

## スクリプトの詳細

### オールインワン（推奨）

このパッケージで全機能を利用できます。単体版をすでにインストールしている場合は、**パネルの重複表示を避けるため**単体版を無効にしてください。

### ページ作品一括ダウンローダー

Pixiv の**検索ページ**、**フォローフィード**、**ランキングページ**などの一覧ページで使用できます。

- 各作品サムネイルの隅にチェックボックスが表示されます
- 取得したい作品を選びます
- フローティングパネルの「ダウンロード開始」をクリックします

すでにキューへ追加された作品には、サムネイルに枠が表示されます。

### ユーザー一括ダウンローダー

Pixiv の**作者プロフィールページ**（`/users/<id>` とサブページ）にパネルを表示します。

- 作者の**作品**をすべてワンクリックでキューに追加
- イラストと小説を別々に取得

### URL 一括インポーター

Pixiv の**任意のページ**にパネルを表示します。`pixiv-batch.html` の「作品 URL 一括インポート」タブと同じように URL 一覧を貼り付けて取得できます。

### 単作品ダウンローダー（Java バックエンド）

**作品ページ**（`/artworks/<id>`）にダウンロードボタンを表示します。メタデータ、自動ブックマークなどを含め、バックエンド経由でワンクリック取得できます。

### 単作品ダウンローダー（ローカル）

作品ページにダウンロードボタンを表示します。

- Java バックエンドなしでブラウザーから直接取得
- メタデータを記録せず、ギャラリーデータベースにも追加しない

### 機能拡張ツールボックス

Pixiv の**任意のページ**の右側にツールバーを表示します。各機能は個別に切り替えられます。

| 機能 | 説明 |
|---------|-------------|
| **ダウンロード済み作品の枠** | サーバーデータベースにある作品のサムネイルに色付きの枠を付け、取得済みかどうかを識別 |
| **Cookie のワンクリック登録** | 現在の Pixiv Cookie を読み取り、ワンクリックでサーバーへ保存（Tampermonkey の特別な権限が必要） |

### ダウンロード履歴と削除済み作品のスキップ

各ダウンロードスクリプトの設定パネルには「**ダウンロード履歴をスキップ**」があります。有効にすると取得済み作品を自動的にスキップします。展開すると次の 2 項目が表示されます。

- **実フォルダーを検出**：履歴に加えてディスク上のファイルも確認し、ファイルがない場合は再取得
- **削除済み作品の再ダウンロードを許可**：ギャラリーで削除した作品には [削除マーク](/ja/gallery?id=deleting-artworks) が残ります。既定（無効）では取得済みとしてスキップされます。「取得済みだが削除済み」という理由の作品を再取得するには有効にしてください。成功すると削除マークは消去されます

## localhost 以外に配置する場合の設定

スクリプトは既定で `http://localhost:6999` に接続します。別のマシンやポートにバックエンドを配置した場合は次のように変更します。

1. Tampermonkey のダッシュボードでスクリプトを選び、「編集」をクリックする
2. 冒頭の `@connect` 行で `localhost` を実際のサーバーアドレスに置き換える

Web 管理ページからインストールしたスクリプトには、現在のバックエンドアドレスが自動設定されています。

## FAQ

### インストールしたのに Pixiv のページが変わらない

1. Tampermonkey が有効か確認する（拡張機能アイコンにスクリプト数が表示されます）
2. ダッシュボードでスクリプトの状態が「有効」か確認する
3. Pixiv のページを再読み込みする（スクリプトはページ読み込み時に注入されます）
4. 現在のページがスクリプトの `@match` 規則に一致するか確認する（例：ユーザー一括版は `/users/` ページだけに表示）

### オールインワンと単体版を両方有効にするとパネルが 2 つ表示される

単体版を無効にしてオールインワンだけを使うか、逆にしてください。両者の保存領域は独立しているため、どちらか一方だけを使うことを推奨します。

### 「バックエンドを利用できません」または「接続に失敗しました」と表示される

PixivDownloader のバックエンドが起動していること、スクリプトに設定したアドレスとポートが正しいことを確認してください。
