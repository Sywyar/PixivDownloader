# ユーザースクリプト

Tampermonkey スクリプトを使うと、Pixiv のページから作品を選んでダウンロードできます。導入は任意で、ブラウザーの `pixiv-batch.html` からもほとんどの取得操作を行えます。

スクリプト一覧とインストール API はホストが提供し、ダウンロードワークベンチに依存しません。有効なプラグインが宣言するスクリプトだけを配布します。ワークベンチを無効にするとその補助スクリプトは一覧から消えますが、他のプラグインのスクリプトは利用できます。solo モードではログインが必要です。バックエンドの `@updateURL` を指定しても、Tampermonkey のバックグラウンド要求にセッションが付くとは限りません。

## 準備とスクリプトの選択

[Tampermonkey](https://www.tampermonkey.net/) をインストールしてください。Java バックエンド版とツールボックスには、起動中のバックエンドと solo モードでのログインが必要です。ブラウザーだけで保存する Local Download はバックエンド不要ですが、ギャラリーには登録しません。

| スクリプト | 操作 |
|---|---|
| All-in-One | 組み込みのダウンロード補助スクリプトをまとめたもの。プラグイン独自のスクリプトは含まない |
| Page Scrape | 検索、ランキング、フォロー中の新着などの一覧で作品を選ぶ |
| User Batch | 作者のプロフィールと配下のページから、画像・小説を分けて全作品をキューへ追加 |
| URL Batch | Pixiv 上のパネルに複数 URL を貼り付ける |
| 単作品ダウンロード（Java バックエンド） | `/artworks/<id>` からバックエンドに保存。メタデータ記録などを利用 |
| 単作品ダウンロード（Local Download） | ブラウザーで直接保存。メタデータやデータベース記録は作らない |
| Toolbox | 取得済み作品の枠表示、Cookie の取り込み |

## インストールする

1. バックエンドを起動し、`http://localhost:6999/pixiv-batch.html` のユーザースクリプト一覧を開きます。
2. 対象スクリプトのインストールを押します。
3. Tampermonkey の確認画面でインストールします。
4. アプリのダウンロード画面と Pixiv ページを再読み込みし、検出結果と実際の操作パネルを確認します。

この方法では、配信時に現在のバックエンドのホストに合わせた `@connect` を設定します。

個別スクリプトは[ソースリポジトリ](https://github.com/Sywyar/PixivDownloader)のコミット済み `.user.js` を Raw で開き、Tampermonkey でインストールするか、ダウンロードして管理画面へ読み込む方法もあります。その場合は接続先とホスト許可を確認してください。

All-in-One はビルド時に生成するため、起動中のバックエンドからインストールします。現在の配布処理は独立した userscript 添付ファイルを Release にアップロードしません。

All-in-One と、その中に含まれる個別スクリプトを同時に有効にするとパネルが重複します。片方を無効にしてください。保存データは別々です。

## Pixiv 上で使う

Page Scrape は作品サムネイルのチェックボックスで選び、パネルから開始します。キューに追加した作品には枠が表示されます。User Batch は作者ページ、URL Batch は Pixiv の各ページにパネルを表示します。単作品版は作品ページのボタンを使います。

Toolbox はページ右側に表示し、機能ごとにオン・オフできます。取得済みの枠はサーバーのデータベースで判定します。Cookie の取り込みには Tampermonkey の HttpOnly アクセス権限が必要です。[初回ダウンロード](/ja/first-download)で設定と手動取得の代替手順を確認してください。通常の `document.cookie` だけでは完全なログイン情報を取得できません。

取得履歴のスキップを有効にすると、取得済み作品を除外します。実際のディレクトリ確認を有効にすると、ファイルがない作品を再取得します。ギャラリーで削除した作品は既定で削除済みとしてスキップします。再取得を許可した場合は、成功後に削除マークを解除します。

## 外部ダウンロードを登録するスクリプト

[PixivBatchDownloader インポート](/ja/pixiv-batch-downloader-import)は、公式プラグインをインストールして再起動した後、そのプラグインのスクリプトを別途インストールします。All-in-One には含まれません。保存先とローカル接続の制限は専用ガイドを参照してください。

## 別のサーバー・ポートを使う

既定の接続先は `http://localhost:6999` です。

1. スクリプトの設定で、実際のプロトコル・ホスト・ポートを指定します。
2. そのバックエンドの画面からスクリプトを再インストールし、`@connect` を設定します。手動導入ならヘッダーのホスト許可を確認します。
3. Pixiv ページを再読み込みし、1 件送信して、対象バックエンドのキューで受信を確認します。

`@connect` はアクセス許可です。これだけ変更しても送信先アドレスは切り替わりません。

## 表示・接続の問題

パネルが出ない場合は、拡張機能とスクリプトの有効状態、サイト権限、ページの `@match` 対象を確認して再読み込みします。User Batch など、特定のページだけで動くスクリプトもあります。

ダウンロード画面の「未検出」は、現在のページで応答を受信していないことを示します。未インストールと断定する表示ではありません。現在のバックエンドから導入し直し、更新後に確認します。一覧にあるインストール可能なバージョンと、実際のスクリプトが返したバージョンは別の情報です。インストールボタンを押した記録だけでは実行成功を確認できません。

接続エラーではバックエンドの起動状態とアドレスを確認します。バックエンド版の成功は、キュー完了とファイルを開けること、Local Download の成功はブラウザーのダウンロード結果で判断します。
