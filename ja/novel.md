# 小説と読み上げ

`novel` プラグインを有効にすると、単一小説や小説シリーズ全体を TXT、HTML、EPUB で保存し、ローカルの小説ギャラリーで読書、全文検索、翻訳、読み上げを利用できます。翻訳には `translation` プラグイン、AI による複数キャラクターの読み上げには `ai` と `tts` の設定が必要です。以下の ID は形式の例です。アクセス権のある実際の作品・シリーズに置き換えてください。

## 小説とシリーズをダウンロードする

### 単一小説

1. `http://localhost:6999/pixiv-batch.html` を開き、「単一作品の一括インポート」を選びます。
2. 小説のリンクを貼り付けます。

   ```text
   https://www.pixiv.net/novel/show.php?id=12345678
   ```

   数字の ID だけを入力する場合は、その上に独立した行で `novel:` のセクション見出しを書きます。

   ```text
   novel:
   12345678
   ```

3. ダウンロード設定で保存形式（TXT / HTML / EPUB）を選び、キューに追加してダウンロードを開始します。自分の小説やブックマークは[クイック取得](/ja/quick-access)から直接追加できます。

### 小説シリーズと EPUB 合本

1. ダウンロードページで「シリーズモード」を選び、シリーズのリンクを貼り付けて「解析とプレビュー」をクリックします。

   ```text
   https://www.pixiv.net/novel/series/123456
   ```

2. 「すべてキューに追加」、または一部の章を選択して追加し、ダウンロードを開始します。

| 形式 | 特徴 |
| --- | --- |
| TXT | 書式を持たないプレーンテキスト |
| HTML | ルビや見出しなど元の書式を保持し、ブラウザーで直接開ける |
| EPUB | EPUB3 に準拠。階層付きの章目次、埋め込み表紙、書籍メタデータ（紹介文、タグ、出典リンク）を含む |

- **ダウンロード時に合本を生成**：ダウンロード設定で「シリーズ合本を生成」を選び、形式を指定します（EPUB を推奨）。ファイルは `novel-series-{seriesId}/{シリーズタイトル}.epub`、翻訳合本は `{シリーズタイトル}_{言語コード}.epub` に保存されます。
- **シリーズ目次ページでいつでも生成**：`pixiv-series.html?type=novel&seriesId=...` を開き、「合本をダウンロード」で**原文**または既存の**翻訳言語**を選ぶと、現在のデータベースの状態から即座に EPUB を生成してダウンロードできます。翻訳言語を選んだ場合、未翻訳の章は原文になります。全体の言語を揃えるには、先に「シリーズ全体を翻訳」を完了してください。

## ローカルでの読書と全文検索

小説ギャラリーにアクセスします。

```text
http://localhost:6999/pixiv-novel-gallery.html
```

タイトル、作者、シリーズ、タグによる絞り込みと、ローカル索引を使った**本文の全文検索**に対応します。カードをクリックすると `pixiv-novel.html?id=<id>` で本文を読み、シリーズ目次を確認して前後の章に移動できます。

## 読み上げ（単一音声 TTS）

小説の閲覧ページで「読み上げ」をクリックすると、本文を段落順に読み上げ、現在の段落の強調表示、ページのスクロール、読書位置の保存を自動で行います。

| 音声エンジン | 説明 |
| --- | --- |
| ブラウザーエンジン（デフォルト） | ブラウザー・システムの音声サービスを使用。利用できる声と通信の有無はブラウザーと OS に依存 |
| オンラインエンジン（Edge ニューラル音声） | バックエンドのプロキシ経由で Microsoft のオンライン TTS を使用。ネット接続が必要 |

## AI による複数キャラクターの読み上げ（管理者）

デスクトップ設定の「AI モデル」で「テキストモデル」（OpenAI 互換 LLM）と「TTS モデル」（ローカルの VoxCPM / CosyVoice、またはクラウド TTS）を両方設定して有効にすると、閲覧ページで「複数キャラクターの読み上げ」を使えます。片方でも無効なら「読み上げ」のエンジン一覧に表示されません。まずモデルと TTS に接続できることを確認してください。分析失敗時はテキストモデルの応答、合成失敗時は TTS エンジンと参照音声の設定を確認します。

- **文ごとの話者判定と再生**：LLM が章全体の各文をナレーターと登場人物に割り当て、固定したキャラクターの声で合成します。順番に再生しながら次の文を先読みし、再生バーには現在の話者と台詞を表示します。
- **ナレーターとキャラクターの声の固定**：初回分析前にナレーターの基本的な声を試聴して固定できます（デフォルトは温かみのある女性の声）。キャラクターパネルでは性別、年齢、英語の声の特徴を確認・変更でき、保存すると固定されます。以降の章で AI に上書きされず、変更は次の音声合成から即座に反映されます。
- **キャラクターの参照音声によるクローン**：ナレーターを含む任意のキャラクター用に標準の参照音声を生成するか、WAV / MP3 をアップロードできます。文字起こしも添付でき、文や章をまたいで声を統一しつつ感情の変化を保ちます。参照音声を変更すると、キャッシュした音声は新しい声で自動的に再生成されます。設定でクローンを無効にしたり、生成上限を調整したりできます。
- **声の矛盾への対処**：本文中の新しい情報が固定済みの声と明らかに矛盾する場合、パネルに矛盾が表示され、「提案を採用 / 現在の設定を維持 / 書き換え」を選べます。
- **分割文字数とキャッシュ**：`0`（デフォルト）は章全体を 1 回のリクエストで分析します。長すぎる本文は拒否され、範囲を小さくするよう案内されます。正の整数を指定すると、段落を約その文字数までまとめて分割分析します。分析結果はローカルにキャッシュされ、再生のたびに再分析する必要はありません。必要な場合は「再分析」を実行できます。

## 翻訳エンジン（管理者）

`translation` プラグインをインストールして有効にします。依存関係の `novel-translation-contract` もインストールされます。デスクトップ設定の「翻訳」でエンジンを選び、保存後の案内に従ってバックエンドを再起動してください。閲覧ページでの手動翻訳、シリーズ翻訳、ダウンロード後の自動翻訳は同じ選択エンジンを使います。

| エンジン | 設定と制限 |
| --- | --- |
| AI モデル | `ai` プラグインに保存したモデル、ベースアドレス、認証情報を使用。ローカルの OpenAI 互換サービスにも対応 |
| 有道 | 有道智雲のテキスト翻訳 API のアプリケーション ID とアプリケーション秘密キーを指定。有道辞書クライアントのアカウントは使用不可 |
| LibreTranslate | 自前のサービスのベースアドレス（`/translate` を含めない）と任意の API Key を指定。サービスと言語モデルは自分で用意する必要がある |

- 有道と LibreTranslate は対象言語コード（`en`、`ja`、`zh-CN` など）を受け取り、段落単位かつ 1 回最大 1,000 Unicode 文字に分割してリクエストします。分割文字数が `0` なら 1,000、正の値ならそれと 1,000 の小さい方を使います。画像、改ページ、ジャンプなどの Pixiv 記法を保持し、タイトルと本文は別々にリクエストします。AI の用語対応表は使用も学習もしません。
- AI の認証情報は `ai`、有道と LibreTranslate の認証情報は `translation`、音声の認証情報は `tts` プラグインが管理します。

## AI 翻訳と用語対応表（管理者）

テキストモデルを設定して有効にした後、小説の閲覧ページまたはシリーズ目次ページで「翻訳」をクリックします。

- **対象言語**：デフォルトでは現在の画面言語が入力され、任意の自然言語名に変更できます。
- **分割文字数**：`0` は全文を 1 回で翻訳します。長編では `5000` などの正の整数を指定すると、段落ごとに分割して翻訳後に結合します。
- **既存の翻訳の扱い**：「上書きして再翻訳」または「スキップ」を選べます。
- **用語対応表**：「原語 ↔ 各言語の訳語」を保存し、固有名詞の訳を揃えます。シリーズ作品はデフォルトで同名の表を共有し、単独作品はそれぞれの表を使います。表を使わない、既存の表に切り替える、新規作成・編集することもできます。AI が翻訳中に見つけた新しい固有名詞は、選択中の表に自動追加され、以降の章で再利用されます。モデルが対応表どおりに訳さない場合もあるため、翻訳結果を確認してください。
- **内容の言語切り替え**：閲覧・シリーズページの「内容の言語」で、画面言語とは独立して原文と既存の翻訳を切り替えられます。本文、章タイトル、シリーズ名、翻訳 EPUB のタイトルが連動し、未翻訳の項目は原文になります。読み上げも選択中の言語を使います。章タイトルと本文は同じ AI リクエストで翻訳し、シリーズ名の翻訳には同じ言語の翻訳済み章タイトルの対と用語対応表を添えます。
- **シリーズ全体を翻訳**：シリーズページで章の順に一括翻訳できます。バックグラウンドに隠すことやキャンセルに対応し、キャンセルしても翻訳済みの章は残ります。完了後に `{シリーズタイトル}_{言語コード}.epub` を生成します。「翻訳済みをスキップ」を選ぶと、最初に軽量なリクエストを 1 回送り、対象言語名を正規の言語コードに解決したうえで、既存の翻訳がある章をそのままスキップします。シリーズ合本を再生成すると、既存のすべての翻訳言語の合本も更新します。
- **ダウンロード後の自動翻訳**：ダウンロードページまたはスケジュールタスクの「小説設定」で「新規ダウンロード小説を自動翻訳」を選び、対象言語と分割文字数を指定します。自動翻訳は作品・シリーズのデフォルトの用語対応表を使い、シリーズの章順でバックグラウンド実行され、ダウンロードを妨げません。ダウンロード成功時点で完了と記録し、翻訳に失敗した場合は「完了（翻訳失敗）」と表示するだけで、保存済みの原文には影響しません。

## 削除、一括管理、結果の確認

管理者は閲覧ページで単一小説を削除できます。小説ギャラリーの「一括管理」では、絞り込み結果の全選択、ZIP の一括エクスポート、コレクションへの追加、一括削除ができます。エクスポート後の元ファイル削除も選べ、進捗はサイドバーの「タスク一覧」で確認できます。プログラム管理下のファイルを削除すると画面からは元に戻せませんが、[削除マーク](/ja/gallery#作品を削除する)を保持し、デフォルトでの再ダウンロードを防ぎます。[外部ダウンロードのインポート](/ja/pixiv-batch-downloader-import)で登録した読み取り専用の元ファイルは残ります。一括管理の詳しいルールは[作品ギャラリー](/ja/gallery)と同じです。

ダウンロード後は、ローカルの TXT / HTML / EPUB と小説ギャラリーの記録をそれぞれ確認してください。ディスクにファイルがあってもギャラリーに記録がない場合は、まず現在のデータベースとダウンロードディレクトリが同じインスタンスのものか確認し、再構築を試すためにデータベースを削除しないでください。
