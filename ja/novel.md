# 小説ダウンロード

PixivDownloader は Pixiv 小説を TXT / HTML / EPUB で保存し、小説シリーズの結合にも対応しています。

## 単一小説をダウンロード

### 方法 1：URL 一括インポート

`pixiv-batch.html` の「🎨 作品 URL 一括インポート」で次を入力します。

```text
https://www.pixiv.net/novel/show.php?id=12345678
```

または、次のように ID を入力します。

```text
novel:
12345678
```

TXT / HTML / EPUB を選び、ダウンロードを開始します。

### 方法 2：クイック取得

「⚡ クイック取得」で「自分のブックマーク（小説）」または「自分の作品（小説）」を選び、キューに追加します。

## 小説シリーズ

1. `pixiv-batch.html` の「📚 シリーズモード」を開く
2. `https://www.pixiv.net/novel/series/123456` のような URL を貼り付ける
3. 「解析してプレビュー」で章一覧を表示
4. すべて、または必要な章をキューに追加
5. ダウンロードを開始

ダウンロード設定で「**シリーズ結合を生成**」を選ぶと EPUB を作成できます。`novel-series-{seriesId}/` に `{シリーズ名}.epub` として保存され、シリーズの目次、表紙、説明、タグ、元 URL が含まれます。

シリーズページの「**結合巻をダウンロード**」から、既存の翻訳言語を選んでいつでも最新 EPUB を生成することもできます。未翻訳章は原文にフォールバックします。

## 形式

| 形式 | 特徴 |
|--------|----------------|
| **TXT** | プレーンテキスト。互換性が高い |
| **HTML** | ルビ、見出しなどの書式を保持。ブラウザーで読める |
| **EPUB** | 電子書籍リーダー向け。目次と表紙に対応 |

## ローカルで読む

`http://localhost:6999/pixiv-novel-gallery.html` を開きます。タイトル、作者、シリーズ、タグに加えて、ローカル FTS5 索引による本文検索も使えます。小説をクリックすると `pixiv-novel.html?id=<id>` で本文、タグ、作者、章移動を表示します。

## 読み上げ

小説ページの「**🎧 読み上げ**」で段落ごとに再生できます。

| エンジン | 特徴 |
|--------|----------------|
| **ブラウザー**（既定） | 完全オフライン。速度は OS の音声に依存 |
| **オンライン（Edge neural）** | 自然な Microsoft 音声。バックエンドのネットワーク / プロキシが必要 |

再生、一時停止、前後の段落、停止、進捗移動、音声と速度の選択に対応します。読書位置は自動保存されます。

## AI 多声ナレーション（ベータ、管理者のみ）

LLM とナレーションエンジンを設定すると、「**多声ナレーション**」で文ごとにナレーターや登場人物を割り当て、声を変えて再生できます。話者分析はキャッシュされ、話者ごとの声、参照音声、ナレーターを編集できます。設定がない場合はこの項目は表示されません。ベータ機能のため、合成失敗や声質の揺れが発生する場合があります。

## AI 翻訳（管理者）

小説ページの「**AI 翻訳**」で本文を指定言語へ翻訳し、ローカルに保存できます。OpenAI 互換プロトコルの LLM を GUI の「AI モデル」で設定・有効化してください。

- 対象言語は自由に指定できる
- セグメントサイズ `0` は全文を一度に処理し、数値指定は段落を分割
- 既存翻訳は上書きまたはスキップを選択
- 処理はバックグラウンドで継続でき、「非表示」と「キャンセル」を使える

### 用語集

用語集は「原文 → 翻訳」の対応表です。シリーズ内の小説は同じ用語集を共有し、単独小説は個別の用語集を使えます。AI が見つけた新しい固有名詞は選択した用語集へ自動追加され、後続の章・再翻訳でも同じ訳語を使います。

### 内容言語

小説ページとシリーズページの「**内容言語**」は UI の言語とは独立しており、原文または既存翻訳を選べます。選択した言語は本文、タイトル、読み上げに反映されます。未翻訳のタイトルや章は原文に戻ります。

### シリーズ全体を翻訳

シリーズページの「**シリーズ全体を翻訳**」で章ごとに翻訳します。既存翻訳をスキップでき、処理中は成功・スキップ・失敗数を確認できます。キャンセルしても完了済み章は保持され、言語別 EPUB が生成されます。元の EPUB は変更されません。

### ダウンロード時の自動翻訳

一括ダウンロードまたはスケジュールタスクの小説設定で「**新しくダウンロードした小説を自動翻訳**」を有効にすると、指定言語へバックグラウンド翻訳します。翻訳失敗はダウンロード失敗にはせず、作品は取得済みとして扱います。管理者のみ利用でき、LLM の設定が必要です。

## 小説の削除（管理者）

小説ページの赤い「**削除**」、または小説ギャラリーの一括管理から削除できます。本文・表紙・派生データは復元できません。削除マークが残るため、再取得するには「削除済み作品の再ダウンロードを許可」を有効にします。小説ギャラリーの一括エクスポート、コレクション追加、削除は作品ギャラリーと同じです。
