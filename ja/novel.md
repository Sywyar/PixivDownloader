# 小説のダウンロードと閲覧

`novel` プラグインを有効にすると、単独の小説やシリーズを TXT / HTML / EPUB で保存できます。翻訳には翻訳プラグイン、多役朗読には AI / TTS プラグインとモデルの設定が必要です。以下の ID は形式の例なので、閲覧権限のある実際の ID に置き換えてください。

## 小説・シリーズを保存する

単独の小説は、`http://localhost:6999/pixiv-batch.html` の作品一括インポートに URL を貼り付けます。

```text
https://www.pixiv.net/novel/show.php?id=12345678
```

数字だけで指定する場合は、前の行に種類を書きます。

```text
novel:
12345678
```

形式を選び、キューに追加して開始します。自分の投稿やブックマークは、クイック取得の小説用ボタンから取得できます。

シリーズはシリーズモードで次の URL を入力し、解析・プレビューして全章または選択した章をキューに入れます。

```text
https://www.pixiv.net/novel/series/123456
```

| 形式 | 内容 |
|---|---|
| TXT | 装飾のない本文 |
| HTML | ルビや見出しなどの書式を保持し、ブラウザーで開ける |
| EPUB | 電子書籍リーダー向け。目次と表紙を含められる |

### シリーズの合本

ダウンロード設定でシリーズ合本の生成を有効にすると、`novel-series-{seriesId}/` に `{シリーズタイトル}.epub` を保存します。翻訳版は `{シリーズタイトル}_{言語コード}.epub` です。EPUB3 の階層目次（シリーズ・章）、表紙、説明、タグ、出典リンクを含みます。本文だけが必要な場合は TXT も選べます。

シリーズ画面 `pixiv-series.html?type=novel&seriesId=...` の合本ダウンロードから、現在のデータベースに基づく EPUB をその場で生成できます。原文または保存済みの翻訳言語を選択します。翻訳言語を選んでも、未翻訳の章は原文になります。全章を同じ言語にしたい場合は、先にシリーズ全体の翻訳を完了してください。ダウンロード時に合本生成を有効にしていなくても、この操作を使えます。

## 保存した小説を読む

`http://localhost:6999/pixiv-novel-gallery.html` でタイトル、作者、シリーズ、タグを検索できます。保存した本文の全文検索にも対応します。

作品を開くと `pixiv-novel.html?id=<id>` で本文、タグ、作者、シリーズの章一覧を表示し、前後の章へ移動できます。

## 単一の音声で読み上げる

小説画面の読み上げボタンから、本文を段落ごとに再生します。

| エンジン | 条件 |
|---|---|
| ブラウザー（既定） | 利用できる音声と通信の有無は、ブラウザー・OS の音声サービスによる |
| オンライン（Edge ニューラル音声） | Microsoft のオンライン TTS。バックエンドのプロキシ経由で接続する |

再生・一時停止、前後の段落、停止、位置の移動、音声・速度の選択ができます。再生中の段落を強調して自動スクロールし、進捗を保存します。同じ小説を開き直すと続きから再生できます。

## AI による多役朗読（管理者）

GUI の AI モデル設定で、テキストモデル（OpenAI 互換 LLM）と TTS モデルを設定・有効化してください。VoxCPM などのローカルサービスや対応するクラウド TTS を使えます。どちらかが未設定なら、読み上げのエンジン一覧に多役朗読は表示されません。

多役朗読は章を文ごとに解析し、ナレーターと登場人物に割り当て、人物ごとの声で合成します。解析に失敗した場合はモデルの応答を、合成に失敗した場合はエンジンと参照音声を確認してください。

- 文ごとに合成・再生し、次の文を先読みします。現在の段落を強調・自動スクロールし、再生バーに話者と文を表示します。
- 初回解析前に、ナレーターの基調を温かい女性声、落ち着いた男性声、中性から選び、試聴できます。確定すると固定され、AI は変更しません。現在の設定を保持する場合は既存の声を使い、既定は温かい女性声です。
- 再生バーの配役パネルでは、人物の性別、年齢、英語の声質説明を確認・編集・試聴できます。保存した声は固定され、AI は上書きしません。変更は以後の合成に反映され、再解析は不要です。
- ナレーターを含む各人物に標準音声を生成するか、参照音声（WAV / MP3、任意で文字起こし）をアップロードできます。参照音声がある場合はその声質を複製し、文ごとの感情も反映します。試聴・削除ができ、変更するとキャッシュ済み音声を新しい声で再生成します。設定で複製を無効にしたり、生成上限を調整したりできます。
- 固定した声質と本文の証拠に明確な矛盾や不足があれば、パネルに表示します。提案を採用する、現状を保持する、自分で書き換える、のいずれかを選べます。
- 分割文字数 `0`（既定）は章全体を 1 回のリクエストで解析します。数値を指定すると、段落をまとめておおよその文字数ごとに解析します。過大な本文の一括解析は拒否され、範囲を縮める案内が出ます。
- 話者の割り当て結果はキャッシュされ、再生のたびには解析しません。必要な場合は設定から再解析します。

## 翻訳エンジン（管理者）

`translation` プラグインを有効にし、デスクトップ設定の「翻訳」でエンジンを選び、保存後に案内に従ってバックエンドを再起動します。小説と翻訳の共通契約 `novel-translation-contract` は依存プラグインとしてインストールされます。手動翻訳とダウンロード後の自動翻訳は、選択した同じエンジンを使います。

- AI は `ai` に保存したモデル、接続先、認証情報を使います。OpenAI 互換 API を持つローカル LLM も既存の設定で利用できます。
- Youdao はテキスト翻訳 API のアプリケーション ID とシークレットを設定します。辞書アプリへのログイン情報では利用できません。
- LibreTranslate は自分で用意したサービスのベース URL と、必要な場合は API キーを設定します。オフライン利用にはサービスと必要な言語モデルを事前にインストールしてください。プラグインはモデルを取得したりサービスを起動したりしません。

小説画面の「翻訳」とシリーズ全体の翻訳で、本文・タイトル・紹介文、既存訳の上書きまたはスキップを選べます。訳文は原文とともに小説データベースへ保存され、内容言語の切り替え、翻訳版合本、読み上げで利用します。

Youdao と LibreTranslate の対象言語は `en`、`ja`、`zh-CN` などのコードで指定します。対応言語はサービス側の設定によります。段落ごとに、最大 1,000 Unicode コードポイントで分割して送信します。分割文字数 `0` はこの上限、正数は指定値と上限の小さい方を使います。画像・改ページ・ジャンプなどの Pixiv 記法を保持します。用語対応表の利用や自動学習は行わず、タイトルと本文は別々に翻訳します。以下のプロンプト、自由入力の言語名、用語対応表の説明は AI エンジンだけに適用されます。

AI の認証情報は `ai`、Youdao と LibreTranslate は `translation`、音声は `tts` が管理します。通常の読み上げは翻訳プラグインを必要としません。多役朗読の分析は引き続き AI、音声合成は TTS を使います。

## AI 翻訳（管理者）

AI モデル設定のテキストモデルを設定・有効化すると、小説・シリーズ画面に翻訳ボタンが表示されます。小説画面では読み上げボタンの左から開き、次を指定します。

| 項目 | 動作 |
|---|---|
| 対象言語 | UI 言語に応じて初期入力される。自由に変更でき、存在しない言語は AI の判定後に通知する |
| 分割文字数 | `0` は全文を一度に翻訳。`5000` などを指定すると段落をまとめ、その程度の文字数ごとに翻訳して結合する |
| 同じ言語の翻訳がある場合 | 上書きして再翻訳、またはスキップ |

開始後は進捗と経過時間を表示します。非表示にしても翻訳は続き、翻訳ボタンを押すと現在の進捗を再表示します。キャンセルは現在のリクエストを中断してフロントエンドの結果を破棄しますが、バックエンドがデータベースへ書き込むことは止められない場合があります。

翻訳はローカルに保存され、次回は再翻訳せずに読めます。シリーズの章を翻訳すると、その言語の合本も再生成します。

### 用語対応表

人名、地名、組織名などを揃えるため、翻訳時に原語と各言語の訳語をまとめた対応表を選べます。

シリーズ内の小説は共通の表を、単独の小説は個別の表を既定で使います。表の既定名はシリーズ名または小説名です。使わない、別の既存表を選ぶ、新しく作ることもできます。

選択した表の訳語を AI に送りますが、モデルが必ず従うとは限らないため、結果を確認してください。翻訳中に見つかった新しい固有名詞の訳語は表に追加され、後の段落・章・再翻訳で再利用します。シリーズをまとめて翻訳する場合も、各章で更新を共有します。

編集では、表名、対象言語の選択・追加、原語と訳語の組の追加・削除を順に行います。

### 本文の言語を切り替える

小説・シリーズ画面の内容言語で、原文と保存済みの翻訳を選べます。UI 言語とは独立し、選択を記憶します。読み上げも選択中の内容言語を使います。

小説タイトル、シリーズ名、章のカード、翻訳版 EPUB の見出しも翻訳に切り替わります。未翻訳のタイトルは原文を表示します。章タイトルは本文と同じリクエスト・対応表で翻訳します。シリーズ名は別のリクエストですが、同言語の翻訳済み章タイトルの組と対応表を渡し、用語や表記の参考にします。

### シリーズをまとめて翻訳する

シリーズ画面から全体翻訳を選び、言語、分割文字数、翻訳済み章の扱いを指定します。章ごとに処理し、`{シリーズタイトル}_{言語コード}.epub` を生成します。未翻訳の章は原文を保持し、原文の合本には影響しません。

処理中はタブを閉じないでください。進捗画面には現在の章、今回の成功・スキップ・失敗数、経過時間、キャンセルの扱いを表示します。非表示にしても処理は続きます。キャンセルすると後続の章を止め、完了済みの翻訳はデータベースに残し、その言語の合本を生成します。

翻訳済みをスキップする場合は、最初に小さな AI リクエストで入力した言語名を正規の言語コードに変換します。その後、同言語の翻訳がある章を、本文全体の翻訳リクエストを送らずにスキップします。シリーズ合本を再生成するときは、既存の翻訳言語の合本も更新します。

### ダウンロード後に自動翻訳する

一括ダウンロードやスケジュールの小説設定で、新しく取得した小説の自動翻訳を有効にし、言語と分割文字数を設定できます。管理者と有効なテキストモデルが必要です。

- 小説・シリーズの既定の用語対応表を必要に応じて作成して使います。この設定から別の表は選べません。表を選びたい場合は小説画面から翻訳します。
- シリーズ合本の生成も有効なら、各章の翻訳後にその言語の合本を更新します。
- 翻訳はバックグラウンドで行い、ダウンロードを妨げません。同一シリーズは章順に処理し、キューやスケジュールの今回のキュー詳細に翻訳中・先行する章の待機数を表示します。
- ダウンロードできれば取得は成功です。翻訳の失敗は「完了（翻訳失敗）」として表示し、保存済みの原文には影響しません。訳文は小説画面の内容言語から確認します。

## 削除と一括管理

管理者は小説画面で単品を削除するか、小説ギャラリーの一括管理で複数を選び、操作メニューから削除できます。アプリが管理する本文・表紙・派生データは削除され、画面から元に戻せません。[外部インポート](/ja/pixiv-batch-downloader-import)の読み取り専用元ファイルは残ります。

削除マークが履歴に残るため、取得済みをスキップする設定では再取得しません。必要なら削除済み作品の再ダウンロードを許可してください。

小説ギャラリーも全結果の選択、エクスポート、コレクション追加、削除に対応します。エクスポートの分類・形式・完了後の元ファイル削除、バックグラウンド圧縮とタスク一覧の扱いは[作品ギャラリー](/ja/gallery)と共通です。

## 結果を確認する

保存した TXT / HTML / EPUB を開き、本文と章順を確認してから、小説ギャラリーでも同じ作品を開いてください。ファイルがあるのに登録がない場合は、データベースと保存先が同じインスタンスのものか確認します。データベースを削除して再構築しようとしないでください。

翻訳・朗読の入口がない場合は、管理者ログイン、プラグインの有効状態、モデル設定を確認します。ダウンロード成功と翻訳成功は別々に判断してください。
