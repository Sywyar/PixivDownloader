# 検索ダウンロード

ダウンロードページの「Search モード」にキーワードを入力すると、バックエンドが Pixiv の検索 API から結果を取得し、絞り込んでダウンロードキューに追加できます。検索対象は Pixiv 上の作品で、ローカルギャラリーではありません。

!> Search モードを使うには、有効な `PHPSESSID` を含む Pixiv Cookie を先に保存する必要があります。未設定の場合、検索ボタンは使えません。

## 操作手順

1. `http://localhost:6999/pixiv-batch.html` を開き、「Search モード」に切り替えます。
2. 検索キーワードを入力します。中国語、日本語、英語を使えます。
3. サブモード、並び順、年齢区分を選び、「検索」をクリックします。
4. プレビューのグリッドで作品を選んで「選択項目をキューに追加」をクリックするか、「現在のページをすべてキューに追加」をクリックします。
5. 「ダウンロード開始」をクリックし、キューで結果を確認します。

## 検索範囲、並び順、フィルター

| サブモード | 取得範囲 |
| --- | --- |
| 検索モード | 1 ページ目だけを取得。キーワードを手早く確認する場合に適する |
| 作品一括取得モード | 指定した終了ページまで取得。既定は 3 ページ。終了ページを `-1` にすると、後続ページを順に読み込んですべての結果を取得する。ページ間隔は約 10 秒、最大 1,000 ページ |

| 並び順 | 説明 |
| --- | --- |
| 新しい順 (`date_d`) | 投稿日時の降順。ログイン済みのすべてのアカウントで利用可能 |
| 人気順 (`popular_d`) | 人気の高い順。Pixiv Premium の権限が必要。権限がない場合は「新しい順」を使い、返された結果を完全な人気ランキングとして扱わないこと |

年齢区分は「全年齢」「R-18」「R-18G」「すべて」から選べます。Pixiv アカウントで対応する年齢設定を有効にしている必要があります。結果の読み込み後は、「追加フィルター」で AI の除外、最小ブックマーク数、タグ、ページ数の範囲を指定し、プレビューページをリアルタイムに絞り込めます。

## 結果の確認とスケジュールタスク

まず 1 つのキーワードと少ないページ数で結果を確かめ、その後で範囲を広げることを推奨します。結果が空の場合は、キーワード、年齢区分、アカウント権限、追加フィルターを確認してください。検索エラーの場合は、Cookie の期限切れとバックエンドのプロキシ接続を確認します。キュー内でフィルターによりスキップされたことは、検索リクエストの失敗を意味しません。

現在の検索を定期タスクとして保存するには、ページ下部の「スケジュールタスクとして保存」カードで起動頻度を設定します。「新しい順 + 終了ページ `-1`」のタスクは、ウォーターマークによる差分取得に対応しています。それ以外の組み合わせと上限のルールは、[スケジュールタスク](/ja/scheduled-tasks)を参照してください。
