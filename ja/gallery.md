# 作品ギャラリー

作品ギャラリーは、ダウンロード済み作品を閲覧・整理・管理する中心ページです。

`http://localhost:6999/pixiv-gallery.html`

## 画面構成

- **左サイドバー**：すべての画像、作者別、マンガシリーズ、コレクション、各ページへの移動
- **中央グリッド**：作品サムネイル
- **上部ツールバー**：検索、並べ替え、絞り込み、表示切り替え

サイドバーの「Nav」で展開・折りたたみできます。管理者の「Tasks」では、エクスポートやパッケージ作成の進捗を確認し、完了したアーカイブをダウンロードできます。上部の「マンガ」と「小説」タブで作品ギャラリーと小説ギャラリーを切り替えます。

## 検索

検索欄左の範囲を切り替えられます。

| 範囲 | 説明 |
|-------|-------------|
| **全般** | タイトル + 作者名 |
| **タイトル** | 作品タイトル |
| **作者名** | 作者名 |
| **作品 ID** | 作品 ID の完全一致 |
| **作者 ID** | 作者 ID の完全一致 |
| **説明** | 作品説明 |
| **タグ（あいまい）** | キーワードを含むタグ |
| **タグ（完全一致）** | タグの完全一致 |

## 絞り込み

「**フィルター**」を開くと、コンテンツレーティング、AI 生成、画像形式、コレクションで絞り込めます。

### タグ / 作者の 3 状態フィルター

| 状態 | 意味 |
|-------|---------|
| ✅ 必須 | このタグを含む / この作者の作品 |
| ❌ 除外 | このタグを含まない / この作者ではない |
| 🔵 いずれか | 「いずれか」の条件を 1 つ以上満たす |

複数の「必須」は AND、「いずれか」は OR として評価され、最後に「除外」が取り除かれます。

## 並べ替え

ダウンロード日時、作品 ID、画像数、状態、作者 ID、タグ数、マンガシリーズで並べ替えられます。各項目は昇順・降順を切り替えられます。

## 作品詳細

サムネイルをクリックすると `pixiv-artwork.html` が開き、タイトル、作者、公開日時、タグ、説明、複数画像の閲覧、関連作品、作者の他作品、元 Pixiv ページへのリンクを確認できます。

## 一括管理（管理者）

上部の「**一括管理**」で複数選択モードに入り、「ページを選択」「すべての検索結果を選択」「選択解除」を使えます。「操作」メニューには次があります。

- **エクスポート**：作者 / 作品でまとめる方法、ZIP 形式、エクスポート後に元ファイルを削除するかを選び、バックグラウンドでアーカイブを作成
- **コレクションに追加**：選択作品をコレクションへ追加
- **削除**：選択作品を削除

エクスポートには `manifest.json` が含まれ、作成完了後に元ファイルを削除する設定を選んだ場合だけ、成功後に元ファイルと履歴が消去されます。

### 作品の削除

!> 削除するとローカル画像、タグ、コレクションリンク、サムネイルキャッシュが消え、復元できません。管理者のみ実行できます。

詳細ページの赤い「**削除**」または一括管理の「削除」から実行します。削除済み作品には履歴上の削除マークが残り、ギャラリーや統計からは見えなくなりますが、「ダウンロード済みをスキップ」は「取得済みだが削除済み」として扱います。再取得するにはダウンロード設定で「削除済み作品の再ダウンロードを許可」を有効にしてください。成功するとマークは消えます。

## コレクション管理

コレクションは Pixiv のブックマークとは独立したローカル分類です。

- 左サイドバーの「**+ 新しいコレクション**」で作成
- 編集画面で名前、PNG / JPG / WEBP（最大 1MB）のアイコン、専用ダウンロード先を設定
- サムネイルの「❤️」または詳細ページの「コレクションに登録」で作品を追加
- 右クリックまたは編集画面から名前変更・削除

## 作品ショーケース

詳細ページの「**作品ショーケース**」をクリックすると `pixiv-showcase.html` が開き、現在の作品を全画面で閲覧できます。

## ゲスト招待

管理者はギャラリー右上の「**ゲストを招待**」から有効期限、レーティング、タグ / 作者の許可リストを設定できます。生成した `http://host:port/invite?code=xxx` を共有すると、ゲストは許可範囲を読み取り専用で閲覧できます。管理ページは `http://localhost:6999/pixiv-invite-manage.html` です。

## 統計ダッシュボード

`http://localhost:6999/pixiv-stats.html`（管理者のみ）で、作品数、画像数、作者数、タグ数、月別ダウンロード、作者ランキング、タグワードクラウドを確認できます。
