# 作品ギャラリー

作品ギャラリーでは、データベースに登録済みのイラスト・漫画・うごイラを閲覧、絞り込み、整理、一括エクスポートできます。`gallery` プラグインを有効にする必要があり、一括管理、エクスポート、削除、コレクション管理には管理者ログインが必要です。ギャラリーはデータベースの記録を参照するため、フォルダーに画像を直接置いても作品として自動登録されません。

アクセス先：`http://localhost:6999/pixiv-gallery.html`

## 検索、絞り込み、並べ替え

左サイドバーでは、表示の切り替え（すべての画像、作者別、漫画シリーズ別）、ローカルコレクションの管理、各機能ページへの移動ができます。サイドバー右端のボタンでは、ナビゲーションの折りたたみや管理者用の「タスク一覧」（バックグラウンドでのアーカイブ作成状況と有効期限）を開けます。上部ツールバーには、ギャラリーの種類の切り替え（イラスト、小説など、有効なギャラリープラグイン）、検索、絞り込み、並べ替えがあります。

| 検索対象 | 一致条件 |
| --- | --- |
| 総合 | タイトル + 作者名（デフォルト） |
| タイトル / 作者名 / 紹介文 | 対応するテキスト項目の部分一致 |
| 作品 ID / 作者 ID | 数値 ID の完全一致 |
| タグ（部分一致 / 完全一致） | キーワードを含むタグ、またはタグ名の完全一致 |

「絞り込み」では、年齢区分（すべて / 全年齢 / R-18 / R-18G）、AI 生成（すべて / AI を除外 / AI のみ）、画像形式、コレクション、投稿日範囲を指定できます。投稿日範囲は終了日当日を含み、ブラウザーのタイムゾーンで解釈されます。投稿日時が不明な作品は日付範囲の結果に含まれません。タグと作者は次の 3 種類の条件を組み合わせられます。

| 状態 | 条件 |
| --- | --- |
| 必須 | 複数の「必須」のすべてに一致 |
| いずれか | 複数の「いずれか」の少なくとも 1 つに一致 |
| 除外 | 一致する作品を結果から除外 |

**ダウンロード日時**（デフォルトは新しい順）、**投稿日時**（不明な作品は昇順・降順とも末尾）、**作品 ID**、**画像数**、**状態**、**作者 ID**、**タグ数**、**漫画シリーズ**で昇順または降順に並べ替えられます。

サムネイルをクリックすると `pixiv-artwork.html` が開き、複数画像（左右切り替えとライトボックスに対応）、紹介文、タグ、同じ作者の作品、おすすめ作品、元サイトへのリンクを確認できます。「作品鑑賞」をクリックすると `pixiv-showcase.html` で全画面表示できます。

## 一括管理とエクスポート（管理者）

上部の「一括管理」をクリックして複数選択モードに入ります。

- **このページをすべて選択 / 選択解除**：現在のページだけが対象です。
- **すべての検索結果を選択**：現在の絞り込み条件に一致する全作品を選択します。選択はページを移動しても保持され、個別に解除できます。

下部の「操作」メニューから次の操作を実行できます。

| 操作 | 結果 |
| --- | --- |
| エクスポート | ディレクトリ構成（作者・作品別、または作品 ID 別）、形式（ZIP）、「エクスポート後に元ファイルを削除」の有無を選び、`manifest.json` を含むアーカイブをバックグラウンドで作成 |
| コレクションに追加 | 選択した作品を指定のローカルコレクションに一括追加 |
| 削除 | 選択した作品を一括削除 |

エクスポートを開始すると、サイドバーの「タスク一覧」が自動的に開いて進捗を表示し、アーカイブの完成後にダウンロードが自動で始まります。有効期限内であればタスク一覧から手動でもダウンロードできます。期限切れ、またはサービスの再起動後にタスクは削除されます。

!> 「エクスポート後に削除」を選ぶと、サーバーでアーカイブの作成に成功した時点で元ファイルとダウンロード記録が削除されます。ブラウザーでのダウンロード完了や、利用者によるアーカイブ内容の確認は待ちません。

## 作品を削除する

管理者は、作品詳細ページの赤い「削除」ボタン、または「一括管理 → 操作 → 削除」で作品を削除できます。本プログラムが管理する作品では、ローカルのメディアファイルと派生データ（タグ、コレクションとの関連、サムネイル）が削除され、画面上で元に戻すことはできません。[外部ダウンロードのインポート](/ja/pixiv-batch-downloader-import)で登録した読み取り専用の元ファイルは保持されます。小説ギャラリーと小説の閲覧ページにも、同じ削除・一括管理の入口があります。

**削除マーク**：削除した作品にはダウンロード履歴上の削除マークが残り、ギャラリー、絞り込み、統計には表示されません。一括ダウンロード、ユーザースクリプト、スケジュールタスクで「ダウンロード済みの作品をスキップ」を有効にすると、デフォルトでは「ダウンロード済みだが削除された作品」と判定してスキップします。再ダウンロードするには、ダウンロード設定で「削除済みの作品の再ダウンロードを許可」を選びます。ダウンロードに成功すると削除マークは自動的に解除されます。

## コレクションとゲスト招待

ローカルコレクションは Pixiv 上のブックマークとは別に管理されます。左サイドバー下部の「+ 新しいコレクション」で作成できます。コレクションを右クリックするか編集ページを開くと、名前の変更、カスタムアイコンのアップロード（PNG / JPG / WebP、最大 1 MB）、専用ダウンロード先の割り当て、削除ができます。サムネイルにマウスを重ねてハートをクリックするか、詳細ページの「コレクションに追加...」で作品を登録します。

管理者はギャラリー右上の「ゲストを招待」で、有効期限、年齢区分（SFW のみなど）、タグ・作者の許可リストを設定し、読み取り専用の共有リンク `http://host:port/invite?code=xxx` を作成できます。招待コードは `http://localhost:6999/pixiv-invite-manage.html` で管理します。招待ゲストには変更や一括管理の権限はありませんが、ブラウザーに表示された画像はゲストが保存できる可能性があります。

## 作品が見つからない場合と統計ダッシュボード

目的の作品が見つからない場合は、まず検索と絞り込み条件（特に投稿日範囲と 3 種類のタグ条件）を解除し、招待コードの許可リスト、現在接続しているデータベース、ダウンロード先、削除マークを確認してください。ディスク上でファイルを移動しても、別のデータベースは更新されません。移転と復元は[ストレージとバックアップ](/ja/storage)を参照してください。

管理者は `http://localhost:6999/pixiv-stats.html` にアクセスすると（`gallery-tools` プラグインが必要）、作品・画像の総数、月別ダウンロードの折れ線グラフ、作者ランキング、人気タグのワードクラウドを確認できます。作者やタグをクリックすると、該当条件で絞り込んだギャラリーに移動します。
