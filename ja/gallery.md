# 作品ギャラリー

データベースに登録されたイラスト、漫画、うごイラを閲覧し、コレクションへ整理したり、まとめて書き出したりできます。`gallery` プラグインが必要です。管理、エクスポート、削除は管理者が行います。任意のディレクトリに画像を置くだけでは作品として登録されません。

アクセス先：`http://localhost:6999/pixiv-gallery.html`

## 作品を探す

左のサイドバーで全作品、作者別、漫画シリーズ別、コレクションを選びます。中央にサムネイル、上部に検索・並び順・フィルターがあります。ギャラリー種別のタブから、小説ギャラリー `pixiv-novel-gallery.html` にも移動できます。サイドバー右端のナビゲーションボタンで開閉します。

検索範囲は検索欄の左で切り替えます。

| 範囲 | 検索対象 |
|---|---|
| 総合 | タイトルと作者名。既定の検索範囲 |
| タイトル / 作者名 / 説明 | 指定した項目 |
| 作品 ID / 作者 ID | ID の完全一致 |
| タグ（部分一致） | キーワードを含むタグ |
| タグ（完全一致） | 同じ表記のタグ |

フィルターでは年齢区分（すべて・全年齢・R-18・R-18G）、AI 作品（すべて・除外・限定）、画像形式、コレクションを選べます。タグと作者には 3 つの状態があります。

| 状態 | 条件 |
|---|---|
| 必須 | 指定タグ・作者のすべてに一致する |
| 除外 | 指定タグ・作者を含まない |
| いずれか | 指定条件の少なくとも 1 つに一致する |

必須条件の共通部分と「いずれか」の和集合を使い、除外条件を取り除きます。並び順は登録時刻（既定は新しい順）、作品 ID、画像数、状態、作者 ID、タグ数、漫画シリーズから選べ、それぞれ昇順・降順を切り替えられます。

サムネイルを開くと `pixiv-artwork.html` の詳細画面で、タイトル、作者、公開日時、タグ、説明、複数ページ、関連作品、作者の他作品を確認できます。画像は左右切り替えと全画面表示に対応し、Pixiv 原ページへのリンクもあります。「作品鑑賞」から `pixiv-showcase.html` の全画面表示へ移動できます。

## 一括管理とエクスポート

管理者は上部の一括管理を開き、作品を選んで下部の操作メニューを使います。「このページを全選択」は現在のページだけを対象にします。「すべての結果を選択」は現在のフィルターに一致する全件が対象で、ページを移動しても選択を保持します。個別に選択解除することもできます。

| 操作 | 結果 |
|---|---|
| エクスポート | 作者・作品ごとの分類、または作品 ID のフォルダーで ZIP を作成する |
| コレクションに追加 | 選択した作品を指定コレクションへ追加する |
| 削除 | 選択した作品を削除する |

エクスポートでは、完了後に元ファイルを削除するか選べます。確認後はバックグラウンドで圧縮し、サイドバー端のタスク一覧が自動で開きます。完了後は自動ダウンロードし、一覧から手動でも取得できます。ZIP には作品情報と元パスを記録した `manifest.json` が含まれます。

タスク一覧には進捗と残り有効期間を表示します。期限切れのタスクは削除され、サービスの再起動でも一覧は消えます。圧縮成功を確認し、ダウンロードした内容も確認してください。

!> エクスポート後の削除を選ぶと、サーバー上で圧縮が成功した時点で元ファイルとダウンロード記録を削除します。ブラウザーでのダウンロードや内容確認の完了を待つ動作ではありません。

## 作品を削除する

詳細画面の削除ボタン、または一括管理の操作メニューから確認して実行します。アプリが管理する画像と派生データ（タグ、コレクションの関連、サムネイル）は削除され、画面から元に戻せません。[外部ダウンロードのインポート](/ja/pixiv-batch-downloader-import)で登録した読み取り専用の元ファイルは残ります。小説にも同じ一括管理・単品削除の入口があります。

削除した作品にはダウンロード履歴に削除マークが残ります。ギャラリー、フィルター、統計などの閲覧画面には出ませんが、一括ダウンロード、ユーザースクリプト、スケジュールで取得済みスキップが有効なら、削除済みとしてスキップします。再取得する場合は、ダウンロード設定で削除済み作品の再ダウンロードを許可してください。成功後にマークが解除され、ギャラリーへ戻ります。

## コレクションを管理する

コレクションは本アプリ内の分類で、Pixiv のブックマークとは独立しています。サイドバー下部から名前を指定して作成します。右クリックや編集画面で、名前、アイコン、個別のダウンロード先を変更したり、削除したりできます。アイコンは PNG / JPG / WebP、最大 1 MB です。

サムネイルにカーソルを重ねたときのハート、または詳細画面のコレクション追加から作品を登録します。

## 招待して閲覧してもらう

管理者は招待リンクを作り、限定した範囲のギャラリーを共有できます。招待されたユーザーに管理や一括操作の権限は与えません。ただし、表示された画像はブラウザーで保存できるため、コピーを防ぐ仕組みではありません。

1. ギャラリー右上の招待を開きます。
2. 有効期限、年齢区分、タグ・作者の許可リストを設定します。
3. `http://host:port/invite?code=xxx` のリンクを相手に渡します。

招待管理は `http://localhost:6999/pixiv-invite-manage.html` で行います。

## 見つからない作品を確認する

検索やフィルターを解除し、招待リンクの閲覧範囲を確認します。管理者は使用中のデータベース、保存先、キューの結果、削除マークも確認してください。ファイルを移動するだけでは別のデータベースに記録は移りません。[ストレージ](/ja/storage)の復元・移行手順を参照してください。

管理者向けの `http://localhost:6999/pixiv-stats.html` では、作品数、画像数、作者数、タグ数、月別の取得数、取得数の多い作者、タグのワードクラウドを確認できます。タグからギャラリーの絞り込みへ移動できます。
